大家好！

过去两年，我一直在构建 **[Jiki](https://jiki.io)**，从一个想法开始，办了一个训练营来验证我的想法，然后与 Aron 和 Nicole 一起打造了一个（我希望是很棒的）产品。

我想和大家分享这段旅程：Jiki 为什么存在，我们为什么投入时间和精力去打造它，以及我希望它会走向哪里。

## Jiki 之前，有 Exercism

不知道的人可能不了解，过去十年我一直在构建 **[Exercism](https://exercism.org)**。Exercism 是一个帮助开发者深化技能、学习新编程语言的平台。这是一个巨大的协作成果，有成千上万的人提交代码，数百位维护者构建语言学习路径，数千位导师为其他开发者提供支持。数百万人用它来提升编程水平，我对此深感自豪。

不过，虽然 Exercism 是为已经会编程的开发者设计的，**但我们不断吸引到完全的初学者**。事实上，根据最新统计，每天有超过 **500 人** 注册 Exercism，而他们之前从未写过一行代码。Exercism 对他们来说确实不太合适，因为它不是为他们构建的，所以我们不得不让他们离开。

这太糟糕了。

我在 Exercism 上的动力始终是为了 **社会流动性**——帮助那些最需要帮助的人。我相信编程是几乎每个人都应该学习的核心技能。对一些人来说，它可以成为职业，但对每个人来说，它都能培养批判性思维、解决问题的能力，并给你一套在几乎所有数字化工作中都有用的技能。简而言之，我相信编程真的能改变人生，打开那些本来可能一直关着的门。所以，看着这些初学者满怀热情地到来，却不得不告诉他们“抱歉，这还不适合你”，这让我觉得是自己的失败。

我开始探索“学编程”这个领域，想了解有什么资源可以提供给他们。我和许多注册的初学者聊过，并开始研究市面上的资源。在尝试这些资源的过程中，我意识到缺少了一些东西。它们大多数没有触及我认为编程真正的核心：**有趣的问题解决**。

相反，它们给你看视频、做测验，可能有一点点编程练习，最后给你一张证书。它们教你语法和理论，但它们并没有真正让你去 **创造** 东西。我想这就是为什么那么多人放弃的原因。并不是编程太难了——而是他们被教授的方式完全不像是在编程。

所以我决定做点什么。

## Jiki 的成真之路

### 基于我的经验构建 Jiki

回想我是怎么学会编程的，我并不是通过课程或教程。我八岁就开始编程，远在互联网出现之前。我是通过 **构建游戏** 来学习的。我会把我那孩童的头脑当时痴迷的任何东西（那时候有很多《星际迷航》和巫师）变成一个随机的游戏。后来长大了，我给自己做网站和小工具——凡是我觉得有趣的。我没有课程大纲。我就是做东西，遇到困难，想办法解决，然后做更多的东西。

那段经历塑造了我对学习的一切看法。我相信人们是通过 **写代码** 来学习编程的——不是看别人写，不是做选择题，不是写一行代码来“完成”一个练习，而是通过真正地编写真实的程序、解决问题。

这就是为什么 Jiki 是基于 **从第一天就开始做项目** 的理念构建的。你不会连续好几个月做那种 5 行小练习。你在构建东西——游戏、动画、工具——并且在最初的几个月里写出 **几十行、然后上百行** 代码。这很有挑战性，但正是这种挑战让你感觉自己真的在成为一名程序员。

### 训练营

2025 年 1 月，我为 1,000 名学生办了一期训练营。他们学习了一门我专门为训练营编写的编程语言（叫 JikiScript）。每周他们有大约 3 小时的直播教学，然后有一些练习要解决，接着还有 3 小时的“实验课”环节，我们一起过一遍练习，他们提问等等。

那真是一段非常有趣的经历，我从中学到了很多。它也非常紧张，因为我既要写一门编程语言、编写练习和课程，还要每周做 6 小时的直播和数十小时的答疑——非常感谢那些帮助我的志愿者们！！

关键的是，我学到的是我设定的节奏太快了。我制作了一些我以为会很轻松容易的东西，但对大家来说仍然太太太太快了，太难了。所以我把这个经验带到了 Jiki 中，让节奏变得更慢——增加了更多节奏更慢的练习。如果你觉得容易，你会很快做完那些额外的练习，但如果你正在挣扎，它们（希望）会成为救命稻草！

### 移除那些容易踩坑的功能

我深信，在学习编程的同时还要学一门编程语言，这让学习变得困难得多。这听起来可能是个奇怪的论断，但请听我说完。

编程语言是为专业人士设计的。它们包含许多“高级”特性，让我们开发者能更快、更高效地工作。它们也往往有很多历史包袱（JavaScript 尤其深受其害）——那些很早以前就该从语言中剔除的特性，但因为要支持旧代码而不得不保留。

这意味着，当你在学习时，你会碰到一些要么非常高级、要么就是纯属奇怪的东西。我们把这些叫做容易踩坑的功能（那些容易让你伤到自己的东西）。办训练营时，我决定写一门没有这些坑的新语言（即 JikiScript）。但是，我收到的一条反馈是，学了一门在真实世界用不了的语言让人感到沮丧。所以对于 Jiki，我决定通过 JavaScript 或 Python 来教学（相同的教学大纲——你可以选择语言）。

但我移除了那些容易踩坑的功能。

我分别为这两种语言编写了自定义的解释器，它们会去除那些噪音。在 JavaScript 中，你不能再使用 `var`。在真正熟悉普通函数之前，你不能使用箭头函数。你写 `[] + {}` 只能得到错误，别想得到其他结果。如果某个阶段的学习者可能会无意中做出某些事，我们就把它禁用掉。随着你的进步，我们会启用更多的特性和功能。这是一个 **巨大** 的工作量，但我认为这将带来巨大的不同。

### 国际化

我知道需要添加的另一个关键特性是让 Jiki 支持多语言。

大多数人不说英语。大多数编程资源都是英文的。这对那些通常最没钱买资源的人来说是一个巨大的障碍。这是我非常想解决的问题。

所以在构建 Jiki 时，我们让一切都能够支持多语言——内容、练习、AI 助手和视频。我的计划是先用英文上线测试版，然后每个月发布几种新语言，直到年底覆盖全球 95% 的人口。

### 免费增值模式

我需要做出的最后一个决定是定价。

我百分百知道，我想让 Jiki 免费。其全部意义就是帮助那些需要帮助的人。但我也从 Exercism 中学到，如果没有足够的资金进来，运营一件事真的很难（**感谢** 每一位为 Exercism 捐款的人——是你们让 Jiki 成为可能！！）

所以我决定采用免费增值模式。Jiki 的核心内容是免费的——视频和练习对所有人开放。但还有一些不错的额外功能（AI 支持、一些奖励项目、直播、幕后内容等），人们可以通过每月一小笔费用（$9.99，并根据 [购买力平价](https://en.wikipedia.org/wiki/Purchasing_Power_parity) 按地区调整）来获取。这对世界上的大多数人来说都是可承受的金额，所以如果大家想支持我们所做的事，或者想获得这些功能，这是一个很好的开始方式。

## 接着，AI 智能体编程来了

就在我准备上线的时候，Claude Code 和它的伙伴们出现了，永远地改变了编程。我花了很长时间思考是否还要推出 Jiki——编程是否还有任何意义。但六个月后，我比以往任何时候都更加确信：代码会继续存在，软件开发者比以往任何时候都更有价值。

几十年来，代码一直是我们用来创造的工具，但它也是守门人。在掌握 Python 之前，你没法做数据科学；在学会 JavaScript 之前，你没法做网站；在学习 SQL 之前，你没法用数据库。现在，这一切都变了。Claude、ChatGPT 和许多其他工具可以为你写那些代码。

但是，这是一个巨大的但是，人类在软件设计、做出明智的技术决策、将模糊的想法塑造成足够精确以便构建的东西方面，与以往一样不可或缺。软件开发的真正意义一直就在这里：将想法变为现实的艺术。我们只是不再需要自己动手写代码了。

所以 Jiki 两者都教。它会教你编程的基础知识，因为你仍然需要理解你的 AI 在做什么。但它也会教你如何构建：网站底层如何工作，如何设计数据库，如何架构软件。所有你需要真正做出东西的技能。如果你想在科技行业找到工作，这些就是需要掌握的。如果你只是想做出点东西，这也会教你如何用你理解的方式去做，而不会最终变成一团乱麻。

## Jiki 是什么，我希望它走向何方

Jiki 是一个编程学习平台，设计上高度互动且有趣。它是为初学者打造的——已经编程不到一年、想要打下坚实基础的人。你通过在一个专为帮助你理解底层原理而设计的定制环境中构建项目来学习。

内容按关卡组织。在每个关卡里，你会看一段短视屏，教你一个新概念，然后有一系列项目来运用它。学习的核心是 **Jiki**，一个运行你代码的角色。我所教的一切都是通过 Jiki 的视角——他怎么看你的代码，他怎么运行它。当你运行代码时，你可以完全看到 Jiki 所看到的——他为什么会那样做。

不过，比这些功能更重要的是其背后的理念。不是每个人都需要成为软件开发者，但因为理解如何分解问题并构建解决方案是一种可以迁移到任何事情的技能。这就是课程的关键——放慢节奏，真正深入地思考如何解决问题。一开始这真的很难（我们生活在一个多巴胺驱动的时代！），但一旦领悟，就会是一项令人惊叹的技能。

我并没有什么让 Jiki 取代其他任何平台的宏大抱负。我完全无意与任何人竞争，而且我相信在基础之外还有很多优秀的内容。我期望在这个世界上出现这样一个平台，能让尽可能多的人获得 **真正扎实的基础**，并能在学习中享受到极大的乐趣。因为当你拥有了这些基础，学习其他任何东西都会 **轻松得多**。这就是 Jiki 的目标，我真的很兴奋能把它带给世界。

如果你是一名现有的开发者，我要坦率地说：这不是为你设计的。它可能会让你感觉相当基础和缓慢。但相信我，对新手来说，它让人感觉快速而紧张！我仍然希望你试玩一下，并给我反馈。你经验丰富的眼睛无疑会发现一些初学者想不到要提及的地方。如果你认识某个一直在考虑学编程的人，我非常感激你把 Jiki 分享给他们。这种口碑传播意义重大！
