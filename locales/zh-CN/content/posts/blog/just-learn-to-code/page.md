多数初学者面临的第一个抉择就是“该选哪门语言？”大多数人最终会选 JavaScript 或 Python。

这时，一个重要的转变发生了。他们从“我要学编程”变成了“我要学 Python”。一周前他们可能都没听说过 Python，更不用说真正理解 JS、Python、R、Java 和几十种主流语言之间的区别了。但转眼之间，他们就铁了心地认为“我就是 Python 那一卦的人”。

这也不能怪他们！初学者收到的最令人困惑、最容易被混为一谈的信息，就是学编程等于学一门编程语言。而我们开发者呢，人人都有自己偏爱的语言，看到一个毫无防备的新手，立刻就想把他拉进自己语言的阵营。说到对编程语言的执着，程序员大概是世界上最“部落化”的群体了。

![两群愤怒的程序员挥舞着不同编程语言的旗帜，中间一个困惑的初学者捂住了耳朵](/images/blog/just-learn-to-code-tribalism.webp)

但对初学者来说，这根本说不通。初学者不需要学 Python、JavaScript 或任何其他语言。他们需要的是学习编程基础，搭建一个坚实的地基，足以支撑他们将来会用到的那几十种语言。

尤其是在智能体编程时代，你第一周可能就得把 TypeScript、Python、SQL、bash、JSON、Ruby 等一大堆语言用到生产环境里。我们需要帮助初学者尽可能从更广的层面去理解编程，而不是一头扎进某一种具体的语言里。

我们设计 Jiki 就是为了教这些基础。目前它用的是一种略微修改过的 JavaScript。今年晚些时候我们会加入 Python，你可以自己选（或者我们扔个硬币帮你选！），但说真的，选哪个都行。

通过**[Jiki](https://jiki.io)**学习编程，这需要花上一段时间。等你真正理解了编程，再用 **[Exercism](https://exercism.org)** 去学语言。那时，因为你已经有了扎实的基础，学起语言来会快得多、容易得多。

下次有初学者问你该学哪门语言，告诉他这根本无所谓。让他摆脱枷锁，给他指路，让他去 Jiki 打下扎实的基础。
