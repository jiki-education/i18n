试着运行代码，却看到一条提示说这门语言的这个版本不支持某样东西？继续往下读，你就明白是怎么回事了！

如果你看到的提示是“这项功能对你来说尚未解锁”，那属于另一种情况——请阅读 **[这个功能什么时候解锁？](/articles/when-will-this-feature-unlock)**。

## 引言

你用到了一个关键字或概念，而我们提供的语言版本并不支持。别担心——这可不是 bug！

你在 Jiki 里使用的 JavaScript 和 Python，**都是我们专门设计**来帮助你学习的。我们特意移除了一些特性，以免你还没准备好，就意外撞上语言里复杂或容易让人困惑的部分。

## 为什么要排除特性？

编程语言是给**专业人士**设计的。它们包含一些能帮经验丰富的开发者提高效率的高级特性，也带着许多历史包袱——有些特性可能早该移除了，只是为了兼容老旧系统才一直保留下来。

学习的时候，这些特性只会制造困惑。把它们拿掉，Jiki 就能让你专心做真正重要的事：**学习像程序员一样思考**。

### 容易误用的功能

有些特性被我们叫做**“容易误用的功能”**——你一不留神就会被它坑到。这一类包括：

- **真正有问题**的特性，哪怕专业人士也最好别碰
- **让人糊涂的边界情况**，只会分散你对核心概念的注意力
- **历史包袱**，纯粹是为了向下兼容才存在的

这些特性被永久排除在 Jiki 之外，因为它们带来的困惑实在不值得。

### 高级特性

还有一些特性被排除，是因为它们对你目前的学习阶段来说**太高级了**。这些特性本身不坏——只是在你打基础的阶段没什么帮助。

随着你在 Jiki 里不断前进，其中一些特性可能会解锁。不过眼下，还是先把基础牢牢掌握好。

## 详细说明

你不需要阅读这一部分，除非你确实关心背后发生了什么，以及我们做了怎样的取舍。

### JavaScript

| 特性 | 为什么被排除 |
| --- | --- |
| `var` | 请改用 `let` 或 `const`。`var` 的作用域规则很混乱，即使经验丰富的开发者也容易因此写出 bug。 |
| `with` | 已废弃，且容易造成混淆。它会生成含义模糊的代码，难以推理。 |
| `debugger` | 开发工具，学习时用不到。 |
| `void` | 很少用到，对初学者来说难以理解。 |
| `yield` | 属于高级的生成器特性。生成器的内容你以后会学到。 |
| `delete` | 用在数组或对象上可能产生令人困惑的行为。 |
| `import` / `export` | 模块系统特性。Jiki 处理模块的方式不一样，就是想保持简单。 |
| 位运算符（`&`、`|`、`^`、`~`、`<<`、`>>`、`>>>`） | 极少用到，学习时只会让人困惑。这些是用于底层位操作的。 |

### Python

| 特性 | 为什么被排除 |
| --- | --- |
| `global` | 在函数内部修改全局变量会写出混乱的代码。去学习如何通过参数传递值吧。 |
| `nonlocal` | 嵌套函数中用到的高级作用域特性。打基础的时候并不需要。 |
| `assert` | 一种调试工具，在生产环境中可能被禁用。去学习正确的错误处理方式吧。 |

## 要是我需要某个特性该怎么办？

Jiki 里的每一个练习，都是设计成只用你到该练习为止学过的特性就能完成的。如果你碰到某个限制，通常是用已经可用的特性换一种更好的方式就能解决的问题。这本身就是学习的一部分——学会在约束条件下找出解法。

如果你真的觉得某个特性在你这个阶段应该可以使用，请告诉我们！我们会一直根据反馈来调整包含哪些东西。
