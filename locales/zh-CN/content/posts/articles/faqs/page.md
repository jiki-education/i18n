## 关于课程

### Jiki 收费吗？

Learn to Code 练习是核心的编程入门课程，完全免费。无需绑卡、不用试用，也没有任何隐藏条件。

Jiki Premium 是一次性付费，按国家/地区定价，开通后即可解锁 Learn to Build、Jiki 项目、无限制的 Ask Jiki AI 支持、可参与的定期问答直播、课程证书、无广告的学习体验，以及抢先体验新功能的权限。

### 我每周需要花多少时间在这门课上？

花多长时间都行，完全由你自己决定。大部分人在 12 到 20 周内学完 Learn to Code，每周大概 5 到 10 小时。而 Learn to Build 是持续更新的，有新内容上线时随时可以进来看看，方便的时候再参加直播就好。

### 这门课有多难？我需要多聪明才行？

这门课的设计初衷就是让所有人都能学得会，无论你之前是什么背景。我们并不认为你必须“很聪明”才能学会编程。但你得投入精力，并且愿意接受挑战。

只要你肯下功夫，遇到困难时主动寻求帮助，并拥抱挑战，你就会惊讶于自己在短时间内能走多远。

### Jiki 现在可以用了吗？

可以，你现在就可以注册，并开始学习免费的 Learn to Code 课程。

第一节 Learn to Build 将在六月中旬上线。注册进入后，你可以预约一个提醒。

### 我已经注册过训练营了，这个和之前有什么不同？

感谢你加入训练营！Jiki 是我们训练营发展演变之后的下一阶段。你之前做过的大部分练习都会出现在 Jiki 里，而且还会增加更多内容。我们也把原来 3 小时的视频拆成了更短小的 5 到 10 分钟片段，这样看起来更轻松！

作为训练营的成员，你将自动获得终身 Jiki Premium。这既适用于最初的 Learn to Code 课程，也适用于未来的课程。

## Jiki Premium

### 我可以免费试用 Jiki 吗？

当然可以！你可以免费注册，并一直使用 Basic 套餐。随时可按需升级到 Premium，没有任何强制要求。

### Premium 是订阅制吗？

不是。Premium 是一次性付费，付一次就能终身使用 Premium，不用续费，也没有什么需要取消的。

### 终身使用是指什么？

你的 Premium 权限永不过期，也不会再向你收费。所有 Premium 功能你都能一直使用，包括我们之后新增的功能。

### 我已经订阅了 Premium，我的订阅会怎样？

不会有任何变化。你的订阅保持原样继续，你随时可以在账户设置中管理或取消。

### 对学生或经济困难的人，有折扣吗？

我们希望 Jiki 对每个人来说都是触手可及的。如果费用是一个障碍，请[联系我们](/articles/support)，我们会尽力帮忙。

### 我之后可以升级吗？

完全没问题。你随时可以在账户中升级到 Premium。
