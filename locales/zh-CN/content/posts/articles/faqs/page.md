## 关于课程

### Jiki 收费吗？

Learn to Code 练习——也就是核心的编程入门课程——完全免费。无需绑卡、不用试用，也没有任何隐藏条件。

Jiki Premium 按国家/地区定价，开通后即可解锁 Learn to Build、Jiki 项目、无限制的 Ask Jiki AI 支持、可参与的定期问答直播、课程证书、无广告的学习体验，以及抢先体验新功能的权限。

### 我每周需要花多少时间在这门课上？

花多长时间都行，完全由你自己决定。大部分人在 12 到 20 周内学完 Learn to Code，每周大概 5 到 10 小时。而 Learn to Build 是持续更新的，有新剧集上线时随时可以进来看看，方便的时候再参加直播就好。

### 这门课有多难？我需要多聪明才行？

这门课的设计初衷就是让所有人都能学得会，无论你之前是什么背景。我们并不认为你必须“很聪明”才能学会编程。但你得投入精力，并且愿意接受挑战。

只要你肯下功夫，遇到困难时主动寻求帮助，并拥抱挑战，你就会惊讶于自己在短时间内能走多远。

### Jiki 现在可以用了吗？

可以，你现在就可以注册，并开始学习免费的 Learn to Code 课程。

第一节 Learn to Build 将在六月中旬上线。注册进入后，你可以预约一个提醒。

### 我已经注册过 Bootcamp 了，这个和之前的不同吗？

感谢你曾经是 Bootcamp 的一员！Jiki 是我们 Bootcamp 演化之后的下一阶段。你之前做过的大部分练习都会出现在 Jiki 里，而且还会增加更多内容。我们也把原来 3 小时的视频拆成了更短小的 5 到 10 分钟片段，这样看起来更轻松！

作为 Bootcamp 的成员，你将自动获得终身 Jiki Premium。这既适用于最初的 Learn to Code 课程，也适用于未来的课程。

## Jiki Premium

### 我可以免费试用 Jiki 吗？

当然可以！你可以免费注册，并一直使用 Basic 套餐。随时可按需升级到 Premium，没有任何强制要求。

### 有最低合约期限吗？

没有最低期限。Premium 按月计费，你可以随时在账户设置中取消。

### 如果我取消了 Premium 订阅，会发生什么？

在当前计费周期结束之前，你仍然可以继续使用 Premium，之后账户就会回到 Basic 套餐。你不会丢失任何学习进度，只是不再能使用 Premium 专享的功能。

### 对学生或经济困难的人，有折扣吗？

我们希望 Jiki 对每个人来说都是触手可及的。如果费用是一个障碍，请[联系我们](/articles/support)，我们会尽力帮忙。

### 我之后可以升级或降级吗？

完全没问题。你随时可以在账户中升级到 Premium，想取消时同样很方便，随时都能操作。
