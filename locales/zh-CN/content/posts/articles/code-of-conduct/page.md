## 引言

Jiki 是一个以同理心对话为核心的平台。我们不会容忍任何让人感到不受欢迎、不被支持、受到侮辱或歧视的交流方式。

## 看到或经历了让人不适的事情？

如果你目睹或经历了滥用、骚扰、歧视，或者感到不安全或不安，请发送邮件至 abuse@jiki.io。我们会认真对待你的举报。

## 执行措施

我们积极监控违反行为准则（CoC）的行为，并极其严肃地对待所有违规举报。我们已经因违规行为封禁过贡献者、导师和用户。

我们收到关于违反 CoC 的举报后，会查看该用户在 Jiki 及相关交流渠道中的对话历史，尝试了解对方是故意违反行为准则，还是无意间越过了界限。通常我们会联系被举报人，讨论我们关注的问题，并警告对方再次违规将导致封禁。有时我们认定没有发生违规行为，无需采取行动；而有时我们也会在首次违规时就进行封禁。我们力求公平，但会优先保护社区的文化。

Jiki 有限公司的管理层保留对违反 CoC 的行为采取其认为适当措施的权利。

## 详细内容

无论以下任何方面，Jiki 都应该是一个对所有人安全的地方：

- 性别、性别认同或性别表达
- 性取向
- 残疾
- 身体外貌（包括但不限于体型）
- 种族
- 年龄
- 宗教
- 以及你能想到的其他任何方面。

作为本社区的一员，你同意：

- 我们集体和个人都致力于营造安全和包容的环境。
- 我们对滥用、骚扰或歧视采取零容忍态度。
- 我们尊重他人的边界和身份认同。
- 我们避免使用可能被视为冒犯或压迫（无论是否系统性的）的语言，例如性别歧视、种族主义、恐同、恐跨、残障歧视、阶级歧视等——这包括（但不限于）各种侮辱性言论。
- 我们避免将冒犯性话题当作幽默来使用。

我们积极致力于：

- 成为一个安全的社区
- 构建彼此支持和鼓励的网络
- 鼓励负责任且多样化的表达方式

我们谴责：

- 跟踪、人肉搜索或公开私人信息
- 暴力、暴力威胁或暴力语言
- 任何危害他人安全的行为
- 可能被视为具有性别歧视、种族主义、恐同、恐跨、残障歧视或其他本质上歧视或冒犯的行为或言论。
- 使用不受欢迎的、暗示性的、贬损的或不恰当的昵称或称呼。
- 对他人的不尊重（笑话、影射、轻视的态度）以及对待不同意见的不尊重。
- 恐吓或骚扰（线上或线下）。请参阅 [Citizen Code of Conduct](https://github.com/stumpsyn/policies/blob/master/citizen_code_of_conduct.md) 了解我们对骚扰的界定。
- 不当的关注或接触。
- 不理解建设性批评与贬低之间的区别。

这些事情都是不可接受的。

注意你的行为对他人的影响。如果让人感到不适，就停止。

如果你说的话被他人认为是冒犯，并且被指出了，请尝试：

- 不打断地倾听。
- 相信对方所说的话，不要试图否定对方的感受。
- 寻求如何避免将来再犯的建议或帮助。
- 道歉并请求原谅。

_本政策是一份“活的”文件，未来会不断完善和扩展。本政策适用于 Jiki 网站、Jiki GitHub 组织、任何其他与 Jiki 相关的交流渠道（例如论坛、Slack、Twitter、电子邮件）以及 Jiki 有限公司的任何其他实体或活动。_
