## 引言

在这篇指南里，我想简单聊聊网页到底是什么，以及它是怎么运作的。我们只讲最基本的东西。如果你已经知道一点 HTML，可能会觉得这些内容太基础了。如果你还不知道，这应该是一份不错的入门读物，为接下来的学习打下基础。

## 网页到底是什么

网页其实就是一个文本文件。当你访问一个网站时，浏览器会收到一份 HTML 文件，它读取这份文件，然后把它“画”出来，形成你看到的页面。

你可以立刻验证一下。随便打开一个网站，在页面任意地方点击右键，然后选择 **查看网页源代码**。那就是 HTML。在一个大型网站上，它看起来可能会让人眼花缭乱，东西多得不得了，但它都是由我们下面要讲的同一小批基础构件组成的。

HTML 是 **HyperText Markup Language**（超文本标记语言）的缩写。“标记”的意思就是我们拿到一些文字，然后用额外的信息去标记它们，说明每一部分是什么。浏览器——无论是 Chrome 还是别的什么——会读取这些标记，并据此决定如何把内容展现在屏幕上。

## 标签

HTML 最出名的就是**标签**，它们以一个 `<` 开头，以一个 `>` 结尾。在这两个尖括号的中间，写着这个标签描述的内容类型。然后我们放上一些内容，最后再加上一个闭合标签，它和开头的标签一样，只是多了一条斜杠。

我们来看一个例子：

```html
<p>你好。</p>
```

这里的 `p` 代表段落（paragraph）。通过这样写，我们就是在告诉浏览器，我们想在屏幕上渲染一个段落，而那个段落里的文字就是“你好。”

标签内部还能携带一些额外的信息，叫作**属性**，它们写在开头的标签里面。链接是一个很好的例子：

```html
<a href="https://jiki.io">访问 Jiki</a>
```

要创建链接，我们使用 `a` 标签（它代表锚点（anchor），这背后有[略微奇怪的历史原因](https://thehistoryoftheweb.com/brief-history-hypertext/)）。链接通常都有一个 `href` 属性，用来指定链接指向哪里，而标签之间的文字就是你可以点击的部分。

有一些标签不包裹任何内容，所以它们没有闭合标签。图片就是最经典的例子：

```html
<img src="photo.jpg" alt="一张我在山上的照片" />
```

这里的 `img` 代表图像（image）。`src` 属性指向图片文件，而 `alt` 属性则描述了这张图片的内容，供使用屏幕阅读器的人了解。同时，如果图片加载失败，这也是会显示出来的替代文字。

## 一个页面的结构

每一个网页都拥有相同的骨架，就像同样的骨头一样。下面是一个你能写出来的最精简的**有效**页面（你也可以用更少的 HTML 写出无效页面，浏览器照样会渲染，但我们还是从负责任的开发者做起，一开始就把好习惯养成）：

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <title>Jeremy Walker</title>
  </head>
  <body>
    <h1>Jeremy Walker</h1>
    <p>我在网上构建东西。</p>
  </body>
</html>
```

我们从头到尾读一遍。

`<!doctype html>` 这行告诉浏览器，这是一份现代的 HTML 文档。它是一段必需的样板代码，在最顶部写一次，然后就可以把它忘掉了。

`html` 标签是包裹整个文档的根元素。`lang="zh-CN"` 属性告诉浏览器和搜索引擎，这个页面是用简体中文写的。

在它里面，我们有两个部分：**head** 和 **body**。

### head 部分

head 里装的是所有**不会**出现在屏幕上的东西。它是元数据（metadata），而元数据的意思就是关于页面本身的数据，而不是你能直接看到的内容。在我们的例子中，里面有两样东西：

- `<meta charset="UTF-8" />` 指明了页面所使用的字符集。UTF-8 是标准的字符集，几乎覆盖了一切：拉丁字母、带重音符号的字符、其他语言的文字系统，甚至包括 emoji。如果你把 emoji 粘贴到 HTML 中，就是靠这一行来让它正确显示的。永远记得把它加上。
- `<title>` 设置了浏览器标签页顶部显示的文本。它也是搜索引擎用来当作你的页面标题的内容。你以后写代码时，会经常琢磨一件事：当别人同时打开了二十个标签页时，你希望在那里显示什么。

在 head 里，你常常还会看到另一行代码，值得认识一下：

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

这行代码告诉手机，要以合理的尺寸来显示页面，而不是把页面缩得很小。现在，我们不需要操心更多细节了。把它加上，然后继续往下就好。

### body 部分

body 就是你真正看到的一切，是标签栏和地址栏下面那个大方块空间里的所有东西。每个标题、段落、图片和链接都住在 body 里面。这篇指南剩下的部分，就是在讲往里面放的那些标签。

## index.html

在我们开始讲标签之前，还有一件事值得了解。有一个非常古老的惯例：名为 `index.html` 的文件，就是一个网站的首页。如果你访问一个域名，后面没有跟任何内容，网站就会去找找看有没有一个叫 `index.html` 的文件，如果有，它就会直接把文件里的内容展示给你。这个文件本身并没有什么神奇的地方，它只是一个几乎所有网站都遵循的标准，所以你的主页就应该放在这个名字的文件里。

## 你最先会用到的标签

你只需要不到十个标签，就能搭建出一个真正有用的页面。我们大致按照你会用到它们的顺序，来一一看看它们。

### 标题

标题共有六级，从 `h1` 一直排到 `h6`：

```html
<h1>Jeremy Walker</h1>
<h2>关于我</h2>
<h3>我的摄影作品</h3>
```

`h1` 是整个页面的主标题，通常一个页面应该只有一个。用 `h2` 来做分节标题，再用 `h3` 来做小节标题，以此类推。因为 `h1` 是一级标题，浏览器就知道要把它显示得更大一点、更粗一点。

选择标题级别时，要依据它的含义，而不是依据它的大小。它们会给你的页面勾勒出一个大纲，有点像一本书里的章和节。

### 段落

`p` 标签用来标记一个文本段落，任何页面上的绝大多数文字，都住在一个 `p` 标签里：

```html
<p>我在网上构建东西已经有三十年了。</p>
<p>最近我大部分的时间都花在了 Jiki 上面。</p>
```

每个段落都要用自己独立的标签，浏览器会自动在段落之间加上间距。

### 列表

列表有两种。**无序列表**（`ul`）会给你圆点符号，而**有序列表**（`ol`）则会给你数字序号。在这两种列表的内部，每一项都是一个**列表项**（`li`）：

```html
<ul>
  <li>摄影</li>
  <li>播客</li>
  <li>教人编程</li>
</ul>
```

把 `ul` 换成 `ol`，圆点符号就会变成 1、2、3。

### 链接

链接是让网络成为一张“网”的东西。`a` 标签能将任何东西变成可以点击的内容：

```html
<p>你可以在 <a href="https://github.com/ihid">GitHub</a> 上找到我的代码。</p>
```

链接既可以指向别人的网站，也可以指向你自己网站上的其他页面。如果你的 `resume.html` 和 `index.html` 放在同一目录下，你就可以用 `<a href="resume.html">我的简历</a>` 来链接到它。

### 图片

`img` 标签可以把一张图片放在页面上：

```html
<img src="images/me.jpg" alt="Jeremy 站在湖区的一座小山上" />
```

`src` 可以是你自己网站上的某个文件，也可以是一个完整的网络地址。一定要用真诚的图片描述来填好 `alt` 文本。

### 强调

有两个小标签可以让你强调文字中的某些词。`strong` 用来标记重要内容，浏览器会把它显示为粗体。`em` 用来标记重音强调，浏览器会把它显示为斜体：

```html
<p>正是在挣扎之中，<strong>学习</strong>才真正发生，所以，<em>写下你自己的解答方案</em>。</p>
```

## 为你的页面赋予结构

到目前为止我们看到的标签，都在描述单独一块一块的内容。还有另一类标签，它们用来描述页面的不同区域。这类标签常常被称为**语义标签**，因为它们为每个区域赋予了含义，而不会改变它们的外观：

- `header` 包裹页面顶部的区域，通常包含你的网站名称和标志。
- `nav` 包裹导航部分，也就是链接到你网站其他页面的那一组链接。
- `main` 包裹页面的主内容区域。整个页面应该只有一个 `main`。
- `section` 用来把一块独立的内容分组，通常还会配上自己的标题。
- `article` 包裹一篇自成一体的内容，比如一篇博客文章或一则新闻。
- `footer` 包裹底部的区域，通常包括版权信息和联系链接。

一个使用这些标签的个人主页，结构可能会像下面这样：

```html
<body>
  <header>
    <h1>Jeremy Walker</h1>
    <nav>
      <a href="index.html">首页</a>
      <a href="resume.html">简历</a>
      <a href="portfolio.html">作品集</a>
    </nav>
  </header>
  <main>
    <section>
      <h2>关于我</h2>
      <p>...</p>
    </section>
    <section>
      <h2>我的项目</h2>
      <p>...</p>
    </section>
  </main>
  <footer>
    <p>联系方式：jeremy@example.com</p>
  </footer>
</body>
```

这些标签本身并不会给你的页面外观带来多大变化。那为什么还要用它们呢？因为带有含义的结构，能够帮助所有那些阅读你页面的、并非盯着屏幕的人类用户的“读者”。屏幕阅读器利用这些标签，让盲人用户可以直接跳到导航区域或主要内容。搜索引擎利用它们来理解你的页面是讲什么的。而且当你以后要给页面加上样式时，有条理的组织会让一切都变得简单得多。

如果页面上的某一块内容，不符合上面任何一种含义，那么还有两个通用的容器标签：`div` 用来包裹一整块内容，而 `span` 用来包裹文字里的几个词。它们本身没有任何意义，这也正是在此应该优先选择那些有含义的标签的原因。

## 更多值得认识的标签

你不需要记住这些标签，但你在看别人写的页面时，很可能会碰见它们，所以知道它们的存在是有好处的：

- `blockquote` 用于标记来自别处的引用文字。
- `code` 用于标记文字中的一小段代码，而 `pre` 用于标记一块预先格式化好的文本。
- `table` 用于呈现真正的表格数据，用 `tr` 表示每一行，用 `td` 表示每个单元格。
- `form`、`input`、`label` 和 `button` 用于收集来自访客的输入。
- `video` 和 `audio` 用于嵌入媒体文件。
- `br` 用于在文字中换行。尽量少用它。如果需要一个新段落，就另起一个新的 `p`。

HTML 标签总共有一百多个，但本指南中提到的这些，已经涵盖了你将会看到和写下的绝大多数标签。当你遇到一个不认识的标签时，可以到 [MDN](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Element) 上查询一下，那是专业开发者也参考的网站。

## 接下来做什么

要真正记住这一切，最好的方法就是动手构建点什么。创建一个 `index.html`，套用本指南里的页面骨架，然后用标题、段落、列表和链接来构建一个关于你自己的页面。完成后在你的浏览器里打开它，看看你做好的成果。

一旦你觉得顺手了，就养成一个习惯：去查看你访问的网站源代码。你会开始发现，随处都能认出这些标签，并且你会看到，哪怕是最复杂的网站，也是用你刚刚学会的这些完全一样的零件构建出来的。

目前，你的页面会看起来非常朴素，这完全没问题。HTML 赋予一个页面结构，而让它变得好看则是 CSS 的工作，那也是我们接下来要去的地方。
