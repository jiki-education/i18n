## 引言

当你开始在个人电脑上编写代码时，你需要一个地方来写它。那个“地方”就是代码编辑器。它是你最先接触的工具之一，也是你职业生涯中会花大量时间使用的地方。随着时间的推移，你很可能会更换和尝试新的编辑器，所以了解它是什么，以及如何选择一个好的编辑器来入门是值得的。

## 代码编辑器不是文字处理软件

我们很容易认为，任何能让你打字的程序都能胜任。最常见的错误是使用像 Microsoft Word 或 Google Docs 这样的文字处理软件。这些软件是为人们阅读的文档而构建的，所以它们会悄悄地改变你输入的内容。它们把直引号变成弯引号（“智能”引号），自动更正你的单词，并保存隐藏的格式。所有这些都会破坏代码。

代码编辑器是一种文本编辑器。它处理纯文本，从不添加隐藏格式，所以你输入的内容就是计算机所看到的内容。区别在于，代码编辑器是一种专门为代码构建的文本编辑器。在纯文本的基础上，它理解你所写内容的结构，并以文字处理软件永远无法做到的方式帮助你：

- **语法高亮** 为代码的不同部分着色，使其更易于阅读和发现错误。
- **自动缩进** 使你的代码保持整齐对齐，这在很多语言中都非常重要。
- **错误提示** 会在你运行程序之前就指出问题。
- **自动补全** 会建议你正在输入的内容的剩余部分，让你写得更快，减少输入错误。
- **扩展** 让你随着成长添加对新语言和工具的支持。

## 我们的推荐

有很多优秀的代码编辑器，你在这里无法做出错误的选择。尽管如此，我们推荐 **Visual Studio Code**，通常简称为 VS Code。它是免费的，可以在 Windows、macOS 和 Linux 上运行，对初学者友好，并且是世界上使用最广泛的编辑器之一，所以你找到的几乎任何教程都会假定你在使用它。

当你准备好安装它时，请按照我们的指南 [安装 VS Code](/guides/installing-vscode) 操作。

## 你可能听过的其他编辑器

你不需要这些编辑器中的任何一个来跟上 Jiki 的步伐，但你会遇到它们，所以这里快速浏览一下常见的编辑器：

- <a href="https://code.visualstudio.com" target="_blank" rel="noopener noreferrer">Visual Studio Code（VS Code）</a> 是我们推荐的免费、跨平台编辑器。
- <a href="https://www.sublimetext.com" target="_blank" rel="noopener noreferrer">Sublime Text</a> 是一个快速、轻量级的编辑器，已流行多年。
- <a href="https://zed.dev" target="_blank" rel="noopener noreferrer">Zed</a> 是一个较新的、非常快的编辑器，专注于速度和协作。
- <a href="https://www.jetbrains.com/ides/" target="_blank" rel="noopener noreferrer">JetBrains IDE</a>（如 <a href="https://www.jetbrains.com/pycharm/" target="_blank" rel="noopener noreferrer">PyCharm</a> 和 <a href="https://www.jetbrains.com/idea/" target="_blank" rel="noopener noreferrer">IntelliJ IDEA</a>）是功能强大、更重的工具，面向从事大型项目的专业开发者。
- <a href="https://www.vim.org" target="_blank" rel="noopener noreferrer">Vim</a> 和 <a href="https://neovim.io" target="_blank" rel="noopener noreferrer">Neovim</a> 是存在于终端中的键盘驱动编辑器。它们深受有经验的开发者喜爱，但学习曲线陡峭。

我们的建议很简单：从 VS Code 开始，习惯编写代码，然后在你知道自己喜欢什么之后再去探索其他的。
