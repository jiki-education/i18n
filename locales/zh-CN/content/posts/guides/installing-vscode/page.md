## 简介

Visual Studio Code（简称 VS Code）是一款由微软开发的免费代码编辑器，可以在 Windows、macOS 和 Linux 上运行。它是我们推荐你在学习编程时使用的编辑器。如果你还不清楚什么是代码编辑器，或者为什么需要它，可以先阅读我们的指南：[使用代码编辑器](/guides/using-a-code-editor)。

本指南将带你逐步完成在每种操作系统上安装 VS Code 的操作。找到你的系统，按照下面的步骤操作即可。你只需要执行一次。

## Windows

1. 在网页浏览器中打开 [code.visualstudio.com](https://code.visualstudio.com)。
2. 点击 **Download for Windows** 按钮。这会下载官方安装程序（一个 `.exe` 文件）。
3. 下载完成后，打开该文件以运行安装程序。
4. 接受许可协议，然后一直点击 **Next** 以接受默认选项。我们建议勾选将 VS Code 添加到右键菜单的选项，以后会很方便。
5. 点击 **Install**，然后点击 **Finish**。VS Code 准备就绪后就会打开。

## macOS

1. 在网页浏览器中打开 [code.visualstudio.com](https://code.visualstudio.com)。
2. 点击 **Download for macOS** 按钮。这会下载一个包含应用程序的 `.zip` 文件。
3. 打开你的下载（Downloads）文件夹，双击下载好的文件进行解压。你会得到一个名为 **Visual Studio Code** 的应用程序。
4. 将 **Visual Studio Code** 拖入你的应用程序（Applications）文件夹。
5. 打开应用程序（Applications）文件夹，双击 **Visual Studio Code** 以启动它。如果 macOS 询问你是否确定要打开它，请点击 **Open**（打开）。

## Linux

1. 在网页浏览器中打开 [code.visualstudio.com](https://code.visualstudio.com)。
2. 点击 **Download for Linux**，然后选择与你的发行版匹配的软件包：
   - 在基于 Debian 和 Ubuntu 的系统上，选择 **.deb** 软件包。
   - 在基于 Fedora、Red Hat 和 openSUSE 的系统上，选择 **.rpm** 软件包。
3. 使用系统的软件安装程序打开下载的软件包，然后点击 **Install**（安装），或者从终端执行安装：
   - 在 Debian 或 Ubuntu 上，在下载目录中运行 `sudo apt install ./<file>.deb`。
   - 在 Fedora 或 Red Hat 上，在下载目录中运行 `sudo dnf install ./<file>.rpm`。
4. 安装完成后，从应用程序菜单中打开 VS Code，或者在终端中运行 `code` 命令。

## 打开 VS Code

无论采用哪种安装方式，现在你都可以随时打开 VS Code 来编写代码。在 Windows 和 macOS 上，它会和其他应用程序一同出现；在 Linux 上，它就在应用程序菜单里。

就这样。你现在已经安装了一个像样的代码编辑器，可以开始写代码了。
