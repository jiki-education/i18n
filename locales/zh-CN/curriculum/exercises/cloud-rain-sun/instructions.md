在这个练习中，你的任务是绘制一个雨天天气图标，太阳在云层后面若隐若现。完成后的效果应如下所示：

<img src="/static/images/exercise-assets/cloud-rain-sun/finished.webp" alt="完成后的云、雨和太阳场景" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.3); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

我们已经为你准备好了模板。你的图形应恰好位于线条内部。为了方便你动手，我们还在代码中加入了云的基础部分。**你不能更改这一行**（你会看到它呈灰色显示，旁边有一个锁图标）。

你将需要 `circle`（圆形）和 `ellipse`（椭圆）函数。你应该只用椭圆来绘制雨滴。如果你用它们来绘制太阳或云朵，就无法正常显示。

### 算出正确的坐标

在这个练习中，你**可以**把鼠标悬停在绘图区域上，来找到坐标。另外，和往常一样，用到的所有数字都**能被 5 整除，只有一个例外**。雨滴的水平半径是 `3`。其他所有数字，包括雨滴的垂直半径，都能被 5 整除。
