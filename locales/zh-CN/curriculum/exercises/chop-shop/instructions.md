你经营着一家小理发店，比起质量，更看重速度。客人离开时发型可能有点毛糙，但不用在椅子上坐太久。

你提供好几种服务，从简单造型到完整剪发，完成时间各不相同。店里实行先到先得，没有预约制度。

一天快要结束时，你需要一个办法来判断还有没有时间接待新进店的客人。

写一个名为 `canFitIn`（能否安排得下）的函数，它接收三个输入：

- 第一个是已经排在队列里的发型（字符串数组）
- 第二个是新客人想要的发型（字符串）
- 第三个是今天还剩下的分钟数（数字）

返回一个布尔值，表示能不能把这位客人安排进去。

你提供的发型有：

- Mohawk：20 分钟
- Slicked-Back Pixie：15 分钟
- Bob：25 分钟
- Shave and Polish：15 分钟
- Afro Trim：45 分钟
- Up-do：30 分钟

### 嵌套数组

这是第一个会遇到“数组里面装着其他数组”的练习，我们把这样的数组叫作“嵌套数组”。嵌套数组和其他数组没有区别，只是它里面装的不是字符串或数字，而是另外的数组。

看看 `cuts`（各种发型）这个数组。它装着其他数组，每个发型对应一个，而每个内层数组都有两个元素：名称和时长。

理解它最简单的办法，是先看里面的小数组，也就是一组组名称和时长的配对，然后想象它们全都被归拢进另一个数组里。

下标的用法和别处完全一样，但你可以像这样把下标连起来写：

```javascript
let cuts = [
  ["Mohawk", 20],
  ["Slicked-Back Pixie", 15],
  ["Bob", 25],
  //...
]

cuts[0] // ["Mohawk", 20]
cuts[0][0] // "Mohawk"
cuts[0][1] // 20
cuts[2][0] // "Bob"
```
