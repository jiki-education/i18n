小时候，我每天上学前都要装好午餐盒。妈妈会把物品摆出来给我（从大到小整整齐齐地排好），我就尽量往午餐盒里塞，但显然它只能装那么多。装不下的东西，我只能放进书包，一整天背在身上，而不能留在储物柜里。

在这个练习里，你的任务是写一个算法，算出哪些物品能装进午餐盒，哪些得放进书包。

你的任务是写一个名为`packLunch(items, capacity)`（装午餐）的函数，它接收两个输入：物品数组（从大到小排列），以及午餐盒的大小`capacity`（容量，一个数字）。

物品数组是一个嵌套数组：每个物品本身也是一个数组，包含两个元素，即物品的名字和它的大小。物品总是从大到小排列。例如，物品数组可能是这样的：

```javascript
[
  ["Water bottle", 20],
  ["Crisps", 10],
  ["Peanut Butter Sandwich", 8],
  ["Chocolate bar", 6],
  ["Satsuma", 3]
]
```

午餐盒有最大容量。你需要算出哪些物品能装进午餐盒。要尽可能多装。其余的都放进书包。

你的函数应该返回一个包含两个元素的数组。第一个元素是装进午餐盒的物品数组，第二个是放进书包的物品数组。两个数组都要从小到大排列。

例如，对于上面的数组，容量为 20 时，你应该返回：

```javascript
return [
  ["Satsuma", "Chocolate bar", "Peanut Butter Sandwich"],
  ["Crisps", "Water bottle"]
]
```

### 有用的方法

和这一节的所有练习一样，你需要用`.push(element)`方法来构建数组。

你还有一个新方法`[...].toReversed()`，它会创建一个数组的副本，把里面所有元素都反过来。例如：

```
["A", 1, true].toReversed()
// [true, 1, "A"]
```

你不一定要用它，但它可能会派上用场。
