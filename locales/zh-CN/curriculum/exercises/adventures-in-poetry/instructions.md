你正在制作一个机器人诗歌游戏，叫“诗歌历险记”。第一步，你需要给机器人编程，让它一边走一边收集词语，最后把整首诗朗诵出来。

每个格子里装着四种东西中的一种：

1. 什么都没有（`""`）
2. 诗里的一个**词语**。
3. 像叶子或蝴蝶这样的**景物**（一个 emoji）。
4. 一面方格旗（`🏁`），这是让机器人停下的信号。

为了帮你，我们准备了几个函数。首先是`move()`函数，它会让诗歌机器人向前走到下一个格子，并返回那个格子上原本放着的东西。还有一个`isEmoji(thing)`函数，它返回一个布尔值，告诉你传入的字符串是不是一个 emoji。最后是`recite(poem)`函数，你要用它把最终拼好的诗朗诵出来。

你的任务就是沿着小路走，把诗拼出来，然后朗诵它。

## 规则

- **词语**要放进诗里，每个词语之间加**一个空格**。
- **景物**不是诗的一部分，要忽略掉。
- **撇号**单独占一个格子，它会把两边的词语连起来。先读`heart`，再读`'`，再读`s`，就连成`heart's`了。
- **逗号**也单独占一个格子。它紧贴在前面的词语后面，但后面仍然有一个空格。
- 诗人走到**方格旗**时停下，或者一收集到**七个词语**就停下，以先发生的为准。
- 不管诗人在什么时候停下、因为什么停下，都要把收集到的东西朗诵出来。`recite()`只能调用**一次**。

## 限制

这道练习有很多种解法，但我们希望你能用上刚学的`continue`和`break`关键字，所以有几条规则：

1. 你的解法必须同时用到`continue`和`break`。
2. 你的解法里不能用`&&`或`!`。
3. 不能写任何辅助函数。
4. 最多只能有两层缩进：

```javascript

// 允许：2 层缩进
repeat() {
  if(...) {
    //...
  }
}

// 不允许：3 层缩进
repeat() {
  if(...) {
    if(...) {
    }
  }
}
```

也就是说，你最终写出来的解法会相当“扁平”。
