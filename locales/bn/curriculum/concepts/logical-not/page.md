এখন পর্যন্ত, দুটি জিনিস সমান কি না তা দেখতে আমরা তিনটি সমান চিহ্ন ব্যবহার করেছি। কিন্তু কখনো কখনো আমরা দেখতে চাই জিনিসগুলো সমান নয় কি না, আর এর জন্য আমরা একটি বিস্ময় চিহ্নের পরে দুটি সমান চিহ্ন ব্যবহার করি। আর সাধারণভাবে, প্রোগ্রামিংয়ে বিস্ময় চিহ্ন বা ব্যাং (আমার ধারণা আমাদের আমেরিকান বন্ধুরা এটাকে এই নামেই ডাকেন) মানে হলো "নয়"। তাহলে কল্পনা করুন, আপনি একটি দোকানে কাজ করেন, আর কর্তৃপক্ষ সিদ্ধান্ত নিয়েছে যে ভেতরে কোনো ডিস্কো পোশাক ঢুকতে দেওয়া হবে না।

আমরা বলতে পারি, "পোশাকটি যদি ডিস্কো না হয়, দরজা খুলে দাও।" `if` স্টেটমেন্টটি ঠিক একইভাবে কাজ করে।

```javascript
if (outfit !== "disco") {
  openDoor()
}
```

পার্থক্য শুধু এটুকুই যে জিনিস দুটি আলাদা হলে শর্তটি ট্রু রিটার্ন করে, আর একই হলে ফলস রিটার্ন করে। তাই আমরা একই জিনিস এভাবেও লিখতে পারতাম: "পোশাকটি যদি ডিস্কো হয়, কিছুই করো না। নাহলে, দরজা খুলে দাও।" কিন্তু সাধারণত `not` অপারেটর ব্যবহার করাই সহজ ও পরিচ্ছন্ন, কারণ তাতে আপনি ঠিক যা বোঝাতে চান সেটাই বলা হয়।

এর সাথে সম্পর্কিত আরেকটি বিষয়। কখনো কখনো আপনার কাছে এমন একটি ভ্যারিয়েবল থাকবে যেটি ট্রু, আর আপনি সেটিকে উল্টে ফলস করতে চাইবেন; আবার কখনো এমন কিছু থাকবে যেটি ফলস, আর আপনি সেটিকে উল্টে ট্রু করতে চাইবেন। কোনো কিছুর হিসাব রাখতে আমরা এটি ব্যবহার করতে পারি। তাহলে কল্পনা করুন, একটি জিনিস বাঁ থেকে ডানে লাফিয়ে বেড়াচ্ছে, আর আমাদের কাছে `movingRight` (ডান দিকে যাওয়া) নামে একটি ভ্যারিয়েবল আছে, যেটি ট্রু থাকে যখন ডান দিকে যাওয়ার কথা। কিন্তু ডান প্রান্তে ধাক্কা লাগলে আপনি সেটিকে টগল করে ফলস করতে চাইবেন।

তাহলে আমরা এটি এভাবে করতে পারতাম: "`movingRight` যদি ট্রু হয়, `movingRight` হবে ফলস। নাহলে, `movingRight` হবে ট্রু।" এটি ভ্যারিয়েবলটিকে টগল করার একটি উপায়। জিকি `movingRight` দেখে বুঝে নেবে সেটি ট্রু নাকি ফলস, তারপর তার উল্টোটা বের করে সেই মান আবার বাক্সে রেখে দেবে।

```javascript
if (movingRight === true) {
  movingRight = false
} else {
  movingRight = true
}
```

কিন্তু এটি করার আরও পরিচ্ছন্ন একটি উপায় আছে, আর তা হলো সেই একই বিস্ময় চিহ্ন বা ব্যাং ব্যবহার করা:

```javascript
movingRight = !movingRight
```

আর এতেই মানটি উল্টে যায়। `!movingRight` মানে হলো আগে যা ছিল ঠিক তার উল্টোটা।

তাই `movingRight` ট্রু হয়ে থাকলে এখন সেটি ফলস। ফলস হয়ে থাকলে এখন ট্রু। জিকি বাক্সে এই মুহূর্তে যা আছে তা বের করে নেয়, আর ওই ব্যাং তাকে বলে দেয় এর উল্টোটা খুঁজে বের করতে। ট্রুর উল্টো হলো ফলস। ফলসের উল্টো হলো ট্রু, আর তারপর সে সেটি আবার বাক্সে রেখে দেয়। এটি ওই লম্বা if/else স্টেটমেন্টের সাথে হুবহু একই কাজ করে, শুধু লিখতে অনেক বেশি পরিচ্ছন্ন ও সংক্ষিপ্ত।
