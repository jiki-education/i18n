`break` কিওয়ার্ডটি যেকোনো লুপের বডির যেকোনো জায়গায় ব্যবহার করা যায়।

দ্বিতীয় বন্ধনী দুটির মাঝের যে অংশ, সেটাই হলো বডি। আর জিকি যখন `break` দেখে, তখন সে সাথে সাথে লুপ থেকে বেরিয়ে যায় এবং লুপের নিচে যে কোড আছে, সেখানে চলে যায়।

ধরুন, নিয়ম হলো এই লুপটি ৫০ বার চলবে, কিন্তু ইউজার পাঁচবার গুলি করলেই আমরা থামাতে চাই। সেক্ষেত্রে আমরা ওপরে একটি `for` লুপ রাখতে পারি, যেটি ৫০ পর্যন্ত গুনতে থাকবে।

কিন্তু লুপের মাঝখানে আমরা একটি শর্ত রাখতে পারি, যেটি পরীক্ষা করবে ইউজার পাঁচবার গুলি করেছে কি না। যদি করে থাকে, তাহলে লুপটি থামাতে আমরা `break` করি।

```javascript
for (let i = 0; i < 50; i++) {
  if (numShots >= 5) {
    break; // লুপ থেকে বেরিয়ে যাওয়া
  }
}
```
