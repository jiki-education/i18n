আপনার হয়তো মনে আছে, repeat লুপ আসলে JavaScript-এ নেই। শুরুর দিকে আপনার কাজটা একটু সহজ করার জন্যই এটা যোগ করা হয়েছিল।

তাহলে এর বদলে আমরা কী ব্যবহার করি? আমরা ব্যবহার করি একটি সাধারণ `for` লুপ, আর সেটা দেখতে এরকম।

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

বুঝতেই পারছেন, প্রথম দিনে এটা দেখলে আপনার কেন একটু ভয় লাগতে পারত।

কিন্তু এর সাথে সহজ হয়ে ওঠার জন্য যা যা জানা দরকার, এখন সবই আপনার জানা আছে। তাহলে চলুন এটাকে ভেঙে দেখি।

একটি for লুপের তিনটি উপাদান থাকে: একটি ইনিশিয়ালাইজার, একটি শর্ত, আর একটি ইনক্রিমেন্ট।

ইনিশিয়ালাইজার, মানে এই `let i = 0` অংশটি, পুরো লুপের একেবারে শুরুতে চলে। এটি মাত্র একবারই চলে, আর এখানে এটি `i` নামে একটি বাক্স তৈরি করে, যার মান শূন্য ধরা হয়। `i` আসলে শুধু একটি অক্ষর, লুপ চলার সময় একটি মান ট্র্যাক করতে এটি ব্যবহার করা হয়। প্রথাগতভাবে এই কাজে `i` বা `x` ব্যবহার করা হয়।

এর পরের অংশটি, মানে শর্তটি, প্রতিটি লুপ ইটারেশনের আগে প্রতিবারই চলে।

শর্তটি ট্রু হলে আমরা লুপটি আবার চালাই।

আর ট্রু না হলে চালাই না।

আর সবশেষে আসে ইনক্রিমেন্ট, ওই `i++` অংশটি।

`i++` মানে আসলে `i = i + 1`-এর মতোই। এটা শুধু একটা শর্টহ্যান্ড, প্রতিবার `i`-এর মান এক করে বাড়ানোর একটা উপায়।

তাহলে এই উদাহরণে আমরা `i`-এর মান শূন্য সেট করি। এরপর দেখি `i` দুইয়ের চেয়ে ছোট কি না—যেহেতু তা সত্য, তাই আমরা লুপটি চালাই।

আর শেষে আমরা `i`-এর মান এক বাড়াই, ফলে `i` হয়ে যায় এক। শূন্য যোগ এক সমান এক।

এরপর আমরা আবার লুপে প্রবেশ করি। দেখি এক দুইয়ের চেয়ে ছোট কি না।

যেহেতু ছোট, তাই লুপটি চালাই। এরপর লুপের শেষে আমরা আবার `i`-এর মান বাড়াই। ফলে এখন `i`-এর মান হয় দুই (এক যোগ এক সমান দুই)।

```javascript
i = 0
i < 2 // true - লুপটি চালাই
...   // ইটারেশনটি করি
i = i + 1 // 1

i < 2 // true - লুপটি চালাই
...   // ইটারেশনটি করি
i = i + 1 // 2

i < 2 // false - লুপ থেকে বেরিয়ে যাই
```

এরপর আমরা তৃতীয়বার লুপে প্রবেশ করি। এবার দেখি দুই, দুইয়ের চেয়ে ছোট কি না—যা সত্য নয়। ফলে লুপটি আর চালাই না এবং এখানেই এর কাজ শেষ হয়ে যায়। এরপর আমরা শুধু নিচের কোডগুলোতে এগিয়ে যাই। সুতরাং লুপটি মোট দুবার চলল, যা জেনে রাখা বেশ কাজের একটা বিষয়। যতক্ষণ আমরা শূন্য থেকে শুরু করি এবং `i < n` শর্তটি ব্যবহার করি, ততক্ষণ `n` সংখ্যাটিই নির্ধারণ করে দেয় যে লুপটি ঠিক কতবার চলবে।

সুতরাং এটা repeat two বলারই সমান।

তাহলে ব্যাপারটা কঠিন নয়, তবে শুধু repeat two লেখার চেয়ে অনেকটাই প্যাঁচানো। for লুপের সুবিধা হলো, ওই তিনটি স্লটে আপনি যা খুশি করতে পারেন। আপনি অন্য কোনো সংখ্যা থেকে শুরু করতে পারেন, একের বেশি করে গুনে উঠতে পারেন, উল্টো দিকে গুনে নামতে পারেন, কিংবা এমন একটি শর্ত ব্যবহার করতে পারেন যা সাধারণ কাউন্টার ছাড়া অন্য কিছুর ওপর নির্ভর করে। এই নমনীয়তাই for লুপকে JavaScript-এর প্রতিদিনের কাজের প্রধান হাতিয়ার করে তুলেছে।
