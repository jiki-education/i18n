কখনো কখনো আমরা লুপ থেকে পুরোপুরি বেরিয়ে না গিয়ে শুধু একটি নির্দিষ্ট ইটারেশন বাদ দিতে চাইতে পারি। ধরুন, আমরা শুধু বিজোড় সংখ্যার জন্য কিছু করতে চাই।

আমরা এমনভাবে বলতে চাই যে, `i` যদি বিজোড় হয়, তাহলে এইবারের ইটারেশনটি বাদ দিতে হবে।

কিন্তু আমরা লুপ থেকে পুরোপুরি বেরিয়ে যেতে চাই না। আমরা শুধু এই একটি ইটারেশন বাদ দিয়ে তারপর পরেরটি দেখতে চাই।

আর এর জন্যই আমাদের আরেকটি কিওয়ার্ড আছে, যার নাম `continue`.

জিকি যখন `continue` দেখে, তখন সে পরের ইটারেশনের জন্য সোজা লুপের শুরুতে ফিরে যায়। তাই একটি for-of লুপে `continue` দেখলে সে লিস্টের পরের আইটেমে চলে যায়।

```javascript
for (let item of list) {
  if (item === "something") {
    continue; // "something"-এর জন্য লুপের বাকি অংশ বাদ দেয়
  }
  // লুপের বাকি অংশ...
}
```

একটি for লুপে সে `i++`-এর ইনক্রিমেন্টে পৌঁছায়, তারপর পরের ইটারেশন শুরু করে।

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue; // জোড় সংখ্যার জন্য লুপের বাকি অংশ বাদ দেয়
  }
  // লুপের বাকি অংশ...
}
```
