এখন পর্যন্ত আপনি যে ফাংশনগুলো লিখেছেন, সেগুলোর প্রতিটি মোটামুটি নিজের পায়ে দাঁড়িয়ে থেকেছে এবং কাজ করার জন্য যে লজিক দরকার, তার সবটাই নিজের ভেতরে রেখেছে।

এখন আমরা দেখব কীভাবে ফাংশনগুলোকে ভেঙে ফেলা যায়, যাতে অনেক কিছু ঘটতে থাকা বড় বড় ফাংশনের বদলে আমাদের থাকে ছোট ছোট ফাংশন, যারা একসাথে কাজ করে।

প্রোগ্রামিংয়ের একটি সাধারণ নিয়ম হলো, প্রতিটি ফাংশন যতটা সম্ভব কম কাজ করবে। একে আমরা বলি ফাংশনের একক দায়িত্ব (ইংরেজিতে _single responsibility_) থাকা। প্রতিটি ফাংশনের উচিত শুধু একটি কাজ করা, আর সেই কাজের বিভিন্ন উপ-অংশের জন্য অন্য ফাংশন ব্যবহার করা।

তাহলে চলুন একটি উদাহরণ দেখি।

ধরুন আমাদের একটি ফাংশন আছে, যার কাজ হলো একটি নামের বর্ণনা দেয় এমন একটি স্ট্রিং রিটার্ন করা।

এর একটি সহজ সংস্করণ দেখতে এরকম হবে। এখানে আছে একটি গণনার লুপ, যেমনটা আপনি আগেই লিখেছেন, আর তারপর একটি স্ট্রিং টেমপ্লেট, যা ফলাফলটি জোড়া লাগায়।

```javascript
function describeName(name) {
  let length = 0
  for (const letter in name) {
    length += 1
  }
  return `This name is ${length} letters long`
}
```

এটি ঠিকঠাক কাজ করে, কিন্তু এটি দুটি কাজ করছে। একটি বেশ জেনেরিক কাজ, গণনা করা, আর আরেকটি খুব নির্দিষ্ট কাজ, একটি বিশেষ ফরম্যাটে এই স্ট্রিংটি তৈরি করা।

এটিকে দুটি ফাংশনে ভেঙে ফেললে অনেক ভালো হবে, যার একটির দায়িত্ব হবে গণনা করা, আর অন্যটির দায়িত্ব হবে এই বিশেষ ফরম্যাটে একটি নামের বর্ণনা দেওয়া।

```javascript
// শুধু অক্ষর গণনা করে
function countLetters(str) {
  let count = 0
  for (const letter in str) {
    count += 1
  }
  return count
}

// শুধু টেক্সট সুন্দরভাবে ফরম্যাট করে
function describeName(name) {
  const count = countLetters(name)
  return `The name has ${count} letters`
}
```

এরপর সেই জেনেরিক গণনার ফাংশনটিকে আমরা এই স্ট্রিং ফরম্যাটিংয়ে তো বটেই, অন্য যেকোনো জায়গায় দরকার হলেও আবার ব্যবহার করতে পারি। যখনই কোনো স্ট্রিংয়ের অক্ষর গণনা করতে হবে, সেই কাজটি প্রিন্ট করার ব্যাপার থেকে সম্পূর্ণ আলাদা থাকবে।

আপনি ফাংশন দুটিকে আলাদা আলাদা করে পড়েই সাথে সাথে বুঝে ফেলতে পারবেন কোনটি কী করে।

আপনার ফাংশনগুলো যত জটিল হবে আর সংখ্যায় যত বাড়বে, এই কৌশলটিই ঠিক করে দেবে আপনার কোড পরিচ্ছন্ন ও সহজপাঠ্য হবে, নাকি পুরোপুরি বিভ্রান্তি আর জগাখিচুড়ি।

এখানে একটি বিষয় আবার মনে করিয়ে দেওয়া দরকার। একটি ফাংশনের ভেতরে আপনি যা-ই তৈরি করুন না কেন, ইচ্ছা করে রিটার্ন না করলে অন্য ফাংশনগুলো সেটি ব্যবহার করতে পারে না।

তাই আপনি যদি `describeName` (নামের বর্ণনা) ফাংশনের ভেতর থেকে `count` (গণনা) ভ্যারিয়েবলটি ব্যবহার করার চেষ্টা করেন, তা পারবেন না, কারণ সেটি অন্য ফাংশনটির নিজস্ব জিনিস।

JavaScript-এ আমরা সবকিছুর উপরে একেবারে শুরুতে এমন ভ্যারিয়েবল তৈরি করতে পারি, যা ফাংশনগুলোর মধ্যে শেয়ার হয়। কিন্তু আমার জোরালো পরামর্শ, খুব ভালো কোনো কারণ না থাকলে সেটি করবেন না।

আপনি প্রতিটি ফাংশনকে যত স্বাধীন রাখবেন, আর এর টেকনিক্যাল নাম হলো পিওর, পিওর ফাংশন, আপনার কোড তত পরিচ্ছন্ন হবে এবং তত কম বাগ তৈরি হবে।
