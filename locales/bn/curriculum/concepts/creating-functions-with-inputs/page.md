এখন পর্যন্ত আপনি যে ফাংশনগুলি বানিয়েছেন, সেগুলি প্রতিবার ঠিক একই কাজ করে। `turnAround` (ঘুরে দাঁড়ানো) সবসময় দুইবার বামে ঘোরে। `shootIfAlienAbove` (উপরে এলিয়েন থাকলে গুলি করা) সবসময় পরীক্ষা করে গুলি করে।

কিন্তু পুরো কোর্স জুড়ে আপনি যে ফাংশনগুলি ব্যবহার করে আসছেন, সেগুলির কথা ভাবুন, ইনপুটের ওপর ভিত্তি করে সেগুলি কীভাবে ভিন্ন ভিন্ন কাজ করে। Rectangle ইনপুট হিসেবে একটি left, একটি top, একটি width আর একটি height নেয়, তারপর আপনি যা বলেন সেই অনুযায়ী ভিন্ন ভিন্ন আয়তক্ষেত্র আঁকে।

এবার আমরা আপনার নিজের ফাংশনেও ইনপুট স্লট যোগ করব।

এটি করতে হলে আপনার দুটি জিনিস জানা দরকার। প্রথমটি হলো এটি দেখতে আসলে কেমন, অর্থাৎ আপনাকে কী লিখতে হবে, আর দ্বিতীয়টি হলো আসলে কী ঘটছে।

প্রথম অংশটি বেশ সহজ। আপনি শুধু সাধারণ বন্ধনী যোগ করবেন, তারপর যে ইনপুটগুলি চান সেগুলির নাম লিখবেন।

ধরুন আমরা এমন একটি ফাংশন বানাচ্ছি যার অনেকবার গুলি করার কথা। চলুন এর নাম দিই `shootMany` (অনেকবার গুলি করা)।

আমরা এটি এভাবে লিখব:

```javascript
function shootMany(numShots) {
  // ...
}
```

যখন এই ফাংশনটি ব্যবহার করতে চাইবেন, তখন যতবার গুলি করাতে চান সেই সংখ্যা দিয়ে এটিকে কল করবেন:

```javascript
shootMany(5)
shootMany(2)
```

এবার আসল কথাটি। কোড রান হওয়ার সময়, আপনি ওই ইনপুটে যা-ই দিন না কেন, `5` হোক বা `2`, ফাংশনের ভিতরে টুপি-পরা মিনি-জিকি সেই ইনপুটটি নিয়ে `numShots` (গুলির সংখ্যা) নামের একটি বাক্সে রাখে, তারপর সেই বাক্সটি ফাংশনের ভিতরের তাকে রেখে দেয়, যাতে আপনি ফাংশনের কোডে সেটি ব্যবহার করতে পারেন।

আবার বলি।

ফাংশনটি ব্যবহার করতে আমরা যখন `shootMany(5)` লিখি, তখন বাইরের জিকি গিয়ে একটি `5` নিয়ে আসে এবং সেটিকে `shootMany`-এর ইনপুট স্লটে রাখে। মেশিনের ভিতরে, মিনি-জিকি সেই `5`-টি বের করে `numShots` নামের একটি বাক্সে রাখে, কারণ ওই ইনপুট স্লটটিকে আপনি এই নামই দিয়েছিলেন, তারপর সে বাক্সটি মেশিনের ভিতরে থাকা ফাংশনের তাকে রেখে দেয়।

তারপর ফাংশনের ভিতরে, আপনি `numShots` বাক্সটি অন্য যেকোনো বাক্সের মতোই ব্যবহার করতে পারবেন। `numShots` নামটির মধ্যে জাদুকরী কিছু নেই। আমরা চাইলে একে যেকোনো নাম দিতে পারতাম। এটি আসলে মিনি-জিকির জন্য একটি নির্দেশ মাত্র: ফাংশনের ভিতরে সবসময় ওই লেবেলওয়ালা একটি বাক্স তৈরি করা, আর ওই স্লটে যা-ই পাঠানো হোক তা সেই বাক্সে রাখা।

আর একবার ওই বাক্সে একটি মান চলে এলে, বাক্স নিয়ে আপনি সাধারণত যা যা করেন তার সবই করতে পারবেন। সঠিক সংখ্যকবার গুলি করার জন্য আপনি `numShots` বাক্সটিকে একটি repeat লুপের অংশ হিসেবে ব্যবহার করতে পারেন। আর একাধিক ইনপুটও রাখা যায়। শুধু কমা দিয়ে সেগুলি আলাদা করুন। ধরুন আমাদের `drawStar` (তারা আঁকা) নামের একটি ফাংশন আছে, যা তার উপরের-বাম অবস্থানের ওপর ভিত্তি করে একটি তারা আঁকে; সেটি আপনি এভাবে লিখবেন:

```javascript
function drawStar(left, top) {
  // ...
}
```
