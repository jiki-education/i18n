আমাদের প্রোগ্রামের প্রতিটি মানের একটি টাইপ আছে। `"7"` একটি স্ট্রিং, আর `7` একটি সংখ্যা। দেখতে প্রায় একই রকম মনে হলেও জিকি এই দুটির সাথে একেবারে আলাদাভাবে আচরণ করে। স্ট্রিং `"7"`-এর সাথে সংখ্যা `3` যোগ করে `10` পাওয়ার আশা করতে পারবেন না, কারণ একটি হলো এক টুকরো টেক্সট আর অন্যটি একটি পরিমাণ।

প্রায়ই আমাদের একটি মানকে এক টাইপ থেকে অন্য টাইপে নিয়ে যেতে হয়। একে বলা হয় টাইপ কনভার্সন (ডেটা টাইপ রূপান্তর), আর এমন দুটি কনভার্সন আছে যেগুলো আপনার সবসময়ই কাজে লাগবে।

### স্ট্রিংকে সংখ্যায় রূপান্তর করা

স্ট্রিং থেকে ক্যারেক্টার পড়ে বের করলে প্রতিটি ক্যারেক্টার নিজেই একটি স্ট্রিং, এমনকি সেটি দেখতে ডিজিটের মতো হলেও। এটি দিয়ে কোনো গাণিতিক কাজ করার আগে একে একটি আসল সংখ্যায় রূপান্তর করে নিতে হবে। সেটা আমরা করি `Number()` দিয়ে।

```javascript
Number("7")
// 7

Number("42")
// 42
```

একবার সত্যিকারের সংখ্যা পেয়ে গেলে সেটি দিয়ে যোগ, গুণ, সবকিছুই করতে পারবেন।

```javascript
let digit = Number("7")
let doubled = digit * 2
// 14
```

`Number()`-কে যদি এমন কিছু দেন যা বৈধ কোনো সংখ্যা নয়, যেমন `Number("cat")`, তাহলে ফেরত কোনো সংখ্যাই পাবেন না। তাই নিশ্চিত হয়ে নেওয়া ভালো যে একে শুধু এমন স্ট্রিং-ই দিচ্ছেন যেগুলো সত্যিই ডিজিট।

### সংখ্যাকে স্ট্রিংয়ে রূপান্তর করা

উল্টো দিকটাও সমান কাজের। কখনো কখনো আপনার কাছে একটি সংখ্যা থাকে আর আপনি সেটিকে টেক্সট হিসেবে ব্যবহার করতে চান, হয়তো অন্য একটি স্ট্রিংয়ের সাথে জুড়ে দিতে, বা এর ডিজিটগুলো আলাদা আলাদা করে দেখতে। সেটা আমরা করি `String()` দিয়ে, যা `Number()`-এর ঠিক উল্টো।

```javascript
String(42)
// "42"

let count = 7
String(count)
// "7"
```

এখন যেহেতু এটি একটি স্ট্রিং, তাই স্ট্রিংয়ের চেনা সব টুল এতে ব্যবহার করতে পারবেন, যেমন ক্যারেক্টার ধরে ধরে পড়া বা এর দৈর্ঘ্য দেখা।
