আপনি দেখেছেন `if` আর `else` কীভাবে আপনাকে দুটি পথ দেয়: শর্ত ট্রু হলে একটি কাজ করা, আর ফলস হলে অন্য কাজটি করা। কিন্তু আপনার সামনে যদি দুটির বেশি সম্ভাবনা থাকে, তখন?

ধরুন আমাদের বাউন্সার এবার টিকিট বিক্রি করছে। বয়স তেরোর নিচে হলে আপনি পাবেন শিশুদের টিকিট। তেরো থেকে বিশের মধ্যে হলে টিন টিকিট। বিশ বা তার বেশি হলে প্রাপ্তবয়স্কদের টিকিট। অর্থাৎ এখন সম্ভাব্য ফলাফল তিনটি। এর জন্য আমরা else-এর পরে আরেকটি `if` স্টেটমেন্ট যোগ করতে পারি। তখন আমরা বলতে পারি, "যদি এটা হয়, তাহলে এটা করো। নয়তো যদি ওটা হয়, তাহলে ওটা করো। আর কোনোটাই না হলে এই অন্য কাজটি করো।" তাহলে এই উদাহরণে জিকি প্রথমে if দেখে প্রথম শর্তটি যাচাই করবে। ষোলো কি তেরোর চেয়ে ছোট? না। তাই সে else if-এ চলে যাবে। ষোলো কি বিশের চেয়ে ছোট? হ্যাঁ, এটা ট্রু। তাই সে ওই ব্লকটি রান করবে আর একটি টিন টিকিট দিয়ে দেবে। কিন্তু তারপরই তার কাজ শেষ। সে আর কিছুই যাচাই করে না। শেষের ওই else-এর দিকে সে ফিরেও তাকায় না। জিকি একবার কোনো শর্ত ট্রু পেলে সেই ব্লকটি রান করে, আর তার নিচের বাকি সবকিছু বাদ দিয়ে এগিয়ে যায়।

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

এটাই বোঝার সবচেয়ে গুরুত্বপূর্ণ বিষয়। কখনোই একটির বেশি ব্লক রান হয় না। জিকি এই চেইন ধরে নিচের দিকে এগোয়, প্রথম যে শর্তটি ট্রু পায় সেটির ব্লক রান করে, তারপর সামনে এগিয়ে যায়।

এবার এমন একটি বিষয় আছে যেটা সত্যিই ভালো করে বোঝা দরকার, কারণ এখানেই অনেকে হোঁচট খায়। দুটি আলাদা `if` স্টেটমেন্ট লেখা আর else if ব্যবহার করার মধ্যে একটি সূক্ষ্ম কিন্তু খুব গুরুত্বপূর্ণ পার্থক্য আছে। ধরুন আমরা এমন একটি প্রোগ্রাম বানাচ্ছি যেটা কারো স্কোরের ভিত্তিতে হয় একটি সাধারণ পুরস্কার, নয়তো একটি বোনাস পুরস্কার দেয়। নিচের দুটি সম্ভাবনা দেখুন। একটিতে else if ব্যবহার করা হয়েছে, অন্যটিতে দুটি আলাদা `if` স্টেটমেন্ট। দুটির আচরণে কী পার্থক্য হবে?

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

প্রথম ক্ষেত্রে, else if থাকায়, আমরা উঁচু স্কোরের শর্তটি যাচাই করে বোনাস পুরস্কার দিই, আর তারপর else if-টি আর রান করি না। ফলে কারো স্কোর একশোর বেশি হলে সে শুধু বোনাস পুরস্কারটিই পায়।

কিন্তু দ্বিতীয় উদাহরণে `if` দুটি সম্পূর্ণ স্বাধীন। দুটিই রান হবে এবং দুটিই ট্রু হবে। তাই এখানে সেই ব্যক্তি দুটি পুরস্কার পায়। প্রথমটিতে একটি পুরস্কার। দ্বিতীয়টিতে দুটি পুরস্কার। একটু সময় নিয়ে নিশ্চিত হয়ে নিন যে বিষয়টি আপনি সত্যিই বুঝেছেন।

আরেকটি মজার বিষয় হলো, গেমটি কীভাবে সাজানো হয়েছে তার ওপর নির্ভর করে দুটির যেকোনোটিই সঠিক হতে পারে। হয়তো প্রতিযোগী একটি সাধারণ পুরস্কারের সাথে একটি বোনাস পুরস্কারও পাবে, অথবা হয়তো তাকে শুধু বোনাস পুরস্কারে উন্নীত করা হবে। কোনো কোডই ঠিক বা ভুল নয়। দুটি শুধু ভিন্ন ভিন্ন পরিস্থিতিতে কাজে লাগে। কিন্তু আপনি কোনটি ব্যবহার করতে চাইছেন, সেটা আপনার জানা থাকতে হবে।
