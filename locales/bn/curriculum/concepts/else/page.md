`if` স্টেটমেন্ট দিয়ে আপনি শর্ত পরীক্ষা করতে পারেন এবং কেবল কোনো কিছু ট্রু হলেই কোড চালাতে পারেন। এবার চলুন `if`-এর সবচেয়ে ঘনিষ্ট সঙ্গীর সাথে পরিচিত হই, যার নাম `else`।

একটি `if` স্টেটমেন্টে শর্তটি ট্রু হলে জিকি কোড ব্লকটি চালায়, আর ফলস হলে সেই কোড ব্লকটি এড়িয়ে যায়। কিন্তু আপনি যদি চান শর্তটি ট্রু হলে জিকি এক কাজ করুক, আর ফলস হলে অন্য কাজ, তখন কী হবে? এই কাজের জন্যই `else`। `if`-এর শেষের দ্বিতীয় বন্ধনীটির পরে আমরা একটি `else` ক্লজ বসাতে পারি, আর `if`-এর শর্তটি ফলস হলে জিকি সেটিই চালাবে। তাহলে ক্লাবের দারোয়ানের উদাহরণে ফিরে যাই: এখন আমাদের কাছে দরজা খুলে দেওয়ার বা কাউকে ফিরিয়ে দেওয়ার সুযোগ আছে, যা আগের মতো কাউকে একেবারে উপেক্ষা করার চেয়ে সম্ভবত ভালো। বিষয়টিকে এমন একটি রাস্তার মতো ভাবুন যা সামনে গিয়ে দুই দিকে ভাগ হয়ে গেছে। জিকি এই ভাগের মুখে পৌঁছে শর্তটি পরীক্ষা করে, তারপর শর্তটি ট্রু হলে এক দিকে যেতে পারে, আর ফলস হলে অন্য দিকে। কিন্তু সে কখনোই দুই দিকে একসাথে যায় না।

```javascript
if (age >= 21) {
  openDoor()
} else {
  turnAway()
}
```

কিন্তু সম্ভাবনা যদি দুটির বেশি হয়? ধরুন আমাদের দারোয়ান এখন টিকিট বিক্রি করছে। বয়স তেরোর নিচে হলে শিশুদের টিকিট। তেরো থেকে বিশের মধ্যে হলে কিশোরদের টিকিট। বিশ বা তার বেশি হলে প্রাপ্তবয়স্কদের টিকিট। তাহলে এখন আপনার সামনে তিনটি আলাদা ফলাফল। এর জন্য আমরা `else`-এর পরে আরেকটি `if` স্টেটমেন্ট যোগ করতে পারি। অর্থাৎ আমরা বলতে পারি, "যদি এটা হয়, তাহলে এই কাজ করো। নয়তো যদি ওটা হয়, তাহলে ওই কাজ করো। আর কোনোটাই না হলে, এই অন্য কাজটি করো।" এই উদাহরণে জিকি `if` দেখে প্রথম শর্তটি পরীক্ষা করবে। ষোলো কি তেরোর চেয়ে ছোট? না। তাই সে `else if`-এ এগিয়ে যাবে। ষোলো কি বিশের চেয়ে ছোট? হ্যাঁ, এটা ট্রু। তাই সে ওই ব্লকটি চালিয়ে একটি কিশোরদের টিকিট দেবে। কিন্তু তারপরই তার কাজ শেষ। সে আর কিছুই পরীক্ষা করে না। শেষের `else`-টির দিকে সে তাকায়ও না। জিকি একবার একটি ট্রু শর্ত পেয়ে গেলে সেই ব্লকটি চালায়, আর তার নিচের বাকি সবকিছু এড়িয়ে যায়।

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

এটাই বোঝার মূল বিষয়। কখনোই একটির বেশি ব্লক চলে না। জিকি উপর থেকে নিচে এক এক করে শর্তগুলো দেখে যায়, প্রথম যে শর্তটি ট্রু পায় সেটির ব্লক চালায়, তারপর সামনে এগিয়ে যায়।

এবার এমন একটি বিষয় আছে যা সত্যিই ভালো করে বোঝা দরকার, কারণ এখানে অনেকেই হোঁচট খান। দুটি আলাদা `if` স্টেটমেন্ট লেখা আর `else if` ব্যবহার করার মধ্যে একটি সূক্ষ্ম কিন্তু খুব গুরুত্বপূর্ণ পার্থক্য আছে। ধরুন আমরা এমন একটি প্রোগ্রাম বানাচ্ছি যা কারও স্কোরের ভিত্তিতে হয় একটি সাধারণ পুরস্কার, নয়তো একটি বোনাস পুরস্কার দেয়। নিচের দুটি সম্ভাবনা দেখুন। একটিতে `else if` ব্যবহার করা হয়েছে, অন্যটিতে দুটি আলাদা `if` স্টেটমেন্ট। কী আলাদা ঘটবে?

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

প্রথম ক্ষেত্রে, `else if` থাকায়, আমরা বেশি স্কোরের শর্তটি পরীক্ষা করে পুরস্কার দিই, আর তারপর `else if`-টি আর চালাই না। তাই কারও স্কোর একশোর বেশি হলে সে শুধু বোনাস পুরস্কারটিই পায়।

কিন্তু দ্বিতীয় উদাহরণে `if` দুটি সম্পূর্ণ স্বাধীন। দুটিই চলবে এবং দুটিই ট্রু হবে। তাই এখানে সেই ব্যক্তি দুটি পুরস্কার পায়। প্রথমটিতে একটি পুরস্কার। দ্বিতীয়টিতে দুটি পুরস্কার। একটু সময় নিয়ে নিশ্চিত হয়ে নিন যে বিষয়টি আপনি সত্যিই বুঝেছেন।

আরেকটি মজার বিষয় হলো, গেমটি কীভাবে ডিজাইন করা হয়েছে তার ওপর নির্ভর করে দুটির যেকোনোটিই সঠিক হতে পারে। হয়তো প্রতিযোগী একটি সাধারণ পুরস্কারের সাথে একটি বোনাস পুরস্কারও পাবে, অথবা হয়তো তাকে শুধু বোনাস পুরস্কারে উন্নীত করা হবে। কোনো কোডই ঠিক বা ভুল নয়। এগুলো শুধু ভিন্ন ভিন্ন পরিস্থিতিতে কাজে লাগে। কিন্তু আপনি কোনটি ব্যবহার করতে চাইছেন সেটা আপনাকে জানতে হবে।
