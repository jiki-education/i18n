এই অনুশীলনীতে আপনি একটি মক Spotify API থেকে পাওয়া ডেটা পার্স করবেন।

এই API-তে দুই ধরনের রিকোয়েস্ট করতে হয়:

1. **ইউজার রিকোয়েস্ট**: `https://api.spotify.com/v1/users/{username}` থেকে একজন ইউজারের প্রিয় ট্র্যাকগুলো নিয়ে আসুন। এটি একটি ডিকশনারি রিটার্ন করে, যার মধ্যে একটি `items` অ্যারে থাকে; সেই অ্যারের প্রতিটি আইটেমে একটি `urls` ডিকশনারি থাকে, যার ভেতরে একটি `spotify_api` URL রয়েছে।

2. **আর্টিস্ট রিকোয়েস্ট**: আগের রেসপন্সে পাওয়া URL থেকে আর্টিস্টের বিবরণ নিয়ে আসুন। এটি একটি ডিকশনারি রিটার্ন করে, যাতে একটি `name` কী (key) থাকে।

`favoriteArtists` (প্রিয় আর্টিস্ট) নামে একটি ফাংশন তৈরি করুন, যা একটি ইউজারনেম নেয় এবং এই রকম একটি বাক্য রিটার্ন করে:

```
"fred's most listened to artists are: Glee, NSYNC, Beethoven, and Limp Bizkit!"
```

API থেকে কোনো এরর এলে, এররটির শুরুতে `"Error: "` যোগ করে সেটি রিটার্ন করুন।

`fetch(url, params)` (ডেটা নিয়ে আসা) ফাংশনটি আগে থেকেই দেওয়া আছে। এই অনুশীলনীর জন্য params সবসময় একটি খালি ডিকশনারি `{}` হবে।
