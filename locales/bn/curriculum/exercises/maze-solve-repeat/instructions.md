আপনাকে একটি গোলকধাঁধার একটি কার্যকর সমাধান দেওয়া হয়েছে, কিন্তু সেটি খুবই লম্বা এবং একই ধরনের কোড বারবার রয়েছে। আপনার কাজ হলো কোডটি বদলে **যতটা সম্ভব কম লাইনে** নিয়ে আসা।

এর গোপন কৌশল হলো `repeat` লুপ ব্যবহার করে কোডটি ছোট করা। মনে রাখবেন, একটি repeat লুপের সিনট্যাক্স এরকম:

```javascript
repeat(3) {
  // আপনি যা রিপিট করতে চান, তা এখানে।
}
```

এখানে আপনার কাজ হলো কোডটিকে যতটা সম্ভব ছোট করা, কোডটি ২২ লাইনের মধ্যে নামিয়ে আনা। এর মানে ভাবতে হবে কখন `repeat` লুপ ব্যবহার করা ভালো আর কখন নয়। মনে রাখবেন, ফাঁকা লাইন আর শুধু কমেন্ট থাকা লাইনগুলো চূড়ান্ত লাইনের সংখ্যার মধ্যে গোনা হয় না, তাই কোডটি আরও সহজে পড়ার উপযোগী করতে চাইলে মাঝে ফাঁকা লাইন রাখতে পারেন!
