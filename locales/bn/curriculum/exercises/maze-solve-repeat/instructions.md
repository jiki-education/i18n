আপনাকে একটি গোলকধাঁধার একটি কার্যকর সমাধান দেওয়া হয়েছে, কিন্তু সেটি খুবই লম্বা আর পুনরাবৃত্তিতে ভরা। আপনার কাজ হলো কোডটি বদলে **যতটা সম্ভব কম লাইনে** নিয়ে আসা।

এর গোপন কৌশল হলো `repeat` লুপ ব্যবহার করে কোডটি ছোট করা। মনে রাখবেন, একটি repeat লুপের সিনট্যাক্স এরকম:

```javascript
repeat(3) {
  // আপনি যা রিপিট করতে চান, তা এখানে।
}
```

এখানে আপনার কাজ হলো কোডটিকে যতটা সম্ভব ছোট করা, অর্থাৎ **কোডের ২২টি লাইনে** নামিয়ে আনা। তার মানে ভাবতে হবে কখন repeat লুপ ব্যবহার করা ভালো আর কখন নয়। মনে রাখবেন, ফাঁকা লাইন আর শুধু কমেন্ট থাকা লাইনগুলো এই লক্ষ্যের হিসাবে গোনা হয় না, তাই কোডটি আরও সহজে পড়ার উপযোগী করতে নির্দ্বিধায় মাঝে ফাঁকা জায়গা রাখুন!
