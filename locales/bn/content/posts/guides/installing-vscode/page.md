## ভূমিকা

Visual Studio Code (VS Code) হলো Microsoft-এর তৈরি একটি ফ্রি কোড এডিটর, যা Windows, macOS এবং Linux-এ চলে। কোড শেখার সময় আমরা এই এডিটরটিই ব্যবহার করার পরামর্শ দিই। কোড এডিটর কী বা কেন এটি আপনার দরকার তা নিয়ে নিশ্চিত না হলে, প্রথমে আমাদের [কোড এডিটর ব্যবহার করা](/guides/using-a-code-editor) গাইডটি পড়ুন।

এই গাইডে প্রতিটি অপারেটিং সিস্টেমে VS Code ইনস্টল করার ধাপগুলো দেখানো হয়েছে। নিচে আপনার সিস্টেমটি খুঁজে নিন এবং ধাপগুলো অনুসরণ করুন। এটি আপনাকে মাত্র একবারই করতে হবে।

## Windows

1. আপনার ওয়েব ব্রাউজারে [code.visualstudio.com](https://code.visualstudio.com) খুলুন।
2. **Download for Windows** বাটনে ক্লিক করুন। এতে অফিসিয়াল ইনস্টলারটি (একটি `.exe` ফাইল) ডাউনলোড হবে।
3. ডাউনলোড শেষ হলে ফাইলটি খুলে ইনস্টলারটি চালু করুন।
4. লাইসেন্স চুক্তিতে সম্মতি দিন, তারপর ডিফল্ট অপশনগুলো মেনে নিতে **Next**-এ ক্লিক করতে থাকুন। যে বাক্সটি VS Code-কে আপনার রাইট-ক্লিক মেনুতে যুক্ত করে, সেটিতে টিক দেওয়াই রাখার পরামর্শ দিই, পরে এটি বেশ কাজে লাগে।
5. **Install**-এ, তারপর **Finish**-এ ক্লিক করুন। প্রস্তুত হয়ে গেলে VS Code খুলে যাবে।

## macOS

1. আপনার ওয়েব ব্রাউজারে [code.visualstudio.com](https://code.visualstudio.com) খুলুন।
2. **Download for macOS** বাটনে ক্লিক করুন। এতে অ্যাপটিসহ একটি `.zip` ফাইল ডাউনলোড হবে।
3. আপনার **Downloads** ফোল্ডারটি খুলুন এবং ডাউনলোড করা ফাইলটিতে ডাবল ক্লিক করে আনজিপ করুন। **Visual Studio Code** নামের একটি অ্যাপ পাবেন।
4. **Visual Studio Code**-কে টেনে আপনার **Applications** ফোল্ডারে নিয়ে যান।
5. আপনার **Applications** ফোল্ডারটি খুলুন এবং **Visual Studio Code**-এ ডাবল ক্লিক করে এটি চালু করুন। আপনি সত্যিই এটি খুলতে চান কি না macOS জানতে চাইলে **Open**-এ ক্লিক করুন।

## Linux

Linux-এ VS Code ইনস্টল করার সবচেয়ে নির্ভরযোগ্য উপায় হলো Microsoft থেকে আপনার ডিস্ট্রিবিউশনের জন্য অফিসিয়াল প্যাকেজটি ডাউনলোড করা।

1. আপনার ওয়েব ব্রাউজারে [code.visualstudio.com](https://code.visualstudio.com) খুলুন।
2. **Download for Linux**-এ ক্লিক করুন এবং আপনার ডিস্ট্রিবিউশনের সাথে মেলে এমন প্যাকেজটি বেছে নিন:
   - Debian ও Ubuntu-ভিত্তিক সিস্টেমে **.deb** প্যাকেজটি বেছে নিন।
   - Fedora, Red Hat ও openSUSE-ভিত্তিক সিস্টেমে **.rpm** প্যাকেজটি বেছে নিন।
3. ডাউনলোড করা প্যাকেজটি আপনার সিস্টেমের সফটওয়্যার ইনস্টলার দিয়ে খুলে **Install**-এ ক্লিক করুন, অথবা টার্মিনাল থেকে ইনস্টল করুন:
   - Debian বা Ubuntu-তে, যে ফোল্ডারে ডাউনলোড করেছেন সেখানে `sudo apt install ./<file>.deb` রান করুন।
   - Fedora বা Red Hat-এ, যে ফোল্ডারে ডাউনলোড করেছেন সেখানে `sudo dnf install ./<file>.rpm` রান করুন।
4. ইনস্টল হয়ে গেলে আপনার অ্যাপ্লিকেশন মেনু থেকে VS Code খুলুন, অথবা টার্মিনালে `code` রান করে খুলুন।

## VS Code খোলা

যেভাবেই ইনস্টল করে থাকুন না কেন, এখন থেকে যখনই কোড লিখতে চাইবেন তখনই VS Code খুলতে পারবেন। Windows ও macOS-এ এটি আপনার অন্যান্য অ্যাপ্লিকেশনের পাশেই দেখা যাবে, আর Linux-এ এটি থাকবে আপনার অ্যাপ্লিকেশন মেনুতে।

ব্যস, এটুকুই। এখন আপনার কাছে একটি সত্যিকারের কোড এডিটর ইনস্টল করা আছে, আর আপনি কোড লেখা শুরু করার জন্য প্রস্তুত।
