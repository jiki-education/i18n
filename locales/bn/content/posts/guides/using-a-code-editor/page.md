## ভূমিকা

নিজের কম্পিউটারে কোড লেখা শুরু করলে সেটি লেখার জন্য একটি জায়গা দরকার হয়। সেই "জায়গা"-টিই হলো কোড এডিটর। এটি প্রথম দিকের যে টুলগুলো আপনি হাতে তুলে নেবেন তার একটি, আর আপনার পুরো ক্যারিয়ার জুড়ে এখানেই অনেকটা সময় কাটবে। সময়ের সাথে সাথে আপনি সম্ভবত এডিটর বদলাবেন, নতুন নতুন এডিটর চেষ্টা করে দেখবেন, তাই কোড এডিটর আসলে কী এবং শুরুতে একটি ভালো এডিটর কীভাবে বেছে নেবেন তা বুঝে নেওয়া কাজে দেবে।

## কোড এডিটর কোনো ওয়ার্ড প্রসেসর নয়

মনে হতেই পারে, যে প্রোগ্রামে টাইপ করা যায় সেটিই কাজ চালিয়ে দেবে। সবচেয়ে কমন ভুলটি হলো Microsoft Word বা Google Docs-এর মতো কোনো ওয়ার্ড প্রসেসর হাতে তুলে নেওয়া। এগুলো তৈরি হয়েছে মানুষের পড়ার জন্য ডকুমেন্ট লিখতে, তাই আপনি যা টাইপ করেন তা এরা চুপচাপ বদলে দেয়। সোজা কোটেশন চিহ্নকে বাঁকা "স্মার্ট" কোটেশনে বদলে দেয়, আপনার লেখা শব্দ অটোকারেক্ট করে, আর লুকানো ফরম্যাটিং সেভ করে রাখে। এর সবকিছুই কোড ভেঙে দেয়।

কোড এডিটর আসলে এক ধরনের টেক্সট এডিটর। এটি প্লেইন টেক্সট নিয়ে কাজ করে এবং কখনো লুকানো ফরম্যাটিং যোগ করে না, তাই আপনি যা টাইপ করেন কম্পিউটার ঠিক সেটিই দেখে। পার্থক্য হলো, কোড এডিটর এমন একটি টেক্সট এডিটর যা বিশেষভাবে কোডের জন্য তৈরি। প্লেইন টেক্সটের পাশাপাশি এটি আপনার লেখার গঠনটাও বোঝে, আর এমন সব উপায়ে আপনাকে সাহায্য করে যা কোনো ওয়ার্ড প্রসেসরের পক্ষে কখনোই সম্ভব নয়:

- **সিনট্যাক্স হাইলাইটিং** আপনার কোডের বিভিন্ন অংশে আলাদা আলাদা রং দেয়, ফলে কোড পড়া আর ভুল খুঁজে পাওয়া সহজ হয়।
- **অটো ইনডেন্টেশন** আপনার কোড সুন্দরভাবে সারিবদ্ধ রাখে, যা অনেক প্রোগ্রামিং ভাষায় খুবই গুরুত্বপূর্ণ।
- **এরর হিন্ট** সমস্যাগুলো ধরিয়ে দেয়, অনেক সময় প্রোগ্রাম রান করার আগেই।
- **অটোকমপ্লিট** আপনি যা টাইপ করছেন তার বাকিটা সাজেস্ট করে, ফলে আপনি দ্রুত লিখতে পারেন আর টাইপের ভুলও কম হয়।
- **এক্সটেনশন** দিয়ে আপনি যত এগোবেন, তত নতুন প্রোগ্রামিং ভাষা ও টুলের সাপোর্ট যোগ করে নিতে পারবেন।

## আমরা যেটির পরামর্শ দিই

ভালো কোড এডিটর অনেকগুলোই আছে, আর এখানে ভুল বাছাই করার সুযোগ আসলে নেই। তবু আমরা **Visual Studio Code** ব্যবহারের পরামর্শ দিই, যাকে সাধারণত সংক্ষেপে VS Code বলা হয়। এটি ফ্রি, Windows, macOS ও Linux সবখানেই চলে, নতুনদের জন্য সহজ, আর এটি পৃথিবীর সবচেয়ে বেশি ব্যবহৃত এডিটরগুলোর একটি, তাই আপনি যে টিউটোরিয়ালই খুঁজে পান না কেন, সেটি ধরেই নেবে যে আপনি VS Code ব্যবহার করছেন।

ইনস্টল করতে প্রস্তুত হলে আমাদের [VS Code ইনস্টল করার](/guides/installing-vscode) গাইডটি অনুসরণ করুন।

## অন্য যেসব এডিটরের নাম আপনি শুনতে পারেন

জিকির সাথে শেখার জন্য এগুলোর কোনোটিই আপনার দরকার নেই, তবে এদের নাম আপনার সামনে আসবেই, তাই কমন এডিটরগুলোর সাথে ঝটপট একটু পরিচয় করিয়ে দিই:

- <a href="https://code.visualstudio.com" target="_blank" rel="noopener noreferrer">Visual Studio Code (VS Code)</a> হলো আমাদের পরামর্শ দেওয়া ফ্রি, ক্রস প্ল্যাটফর্ম এডিটরটি।
- <a href="https://www.sublimetext.com" target="_blank" rel="noopener noreferrer">Sublime Text</a> একটি দ্রুত, হালকা এডিটর, যা বহু বছর ধরে জনপ্রিয়।
- <a href="https://zed.dev" target="_blank" rel="noopener noreferrer">Zed</a> তুলনামূলক নতুন, খুবই দ্রুত একটি এডিটর, যার মূল মনোযোগ গতি আর একসাথে কাজ করার সুবিধায়।
- <a href="https://www.jetbrains.com/ides/" target="_blank" rel="noopener noreferrer">JetBrains IDEs</a> (যেমন <a href="https://www.jetbrains.com/pycharm/" target="_blank" rel="noopener noreferrer">PyCharm</a> ও <a href="https://www.jetbrains.com/idea/" target="_blank" rel="noopener noreferrer">IntelliJ IDEA</a>) শক্তিশালী, ভারী টুল, যেগুলো মূলত বড় প্রজেক্টে কাজ করা পেশাদার ডেভেলপারদের জন্য তৈরি।
- <a href="https://www.vim.org" target="_blank" rel="noopener noreferrer">Vim</a> আর <a href="https://neovim.io" target="_blank" rel="noopener noreferrer">Neovim</a> কিবোর্ডনির্ভর এডিটর, যেগুলো টার্মিনালে চলে। অভিজ্ঞ ডেভেলপারদের কাছে এগুলো খুবই প্রিয়, তবে এগুলো শিখতে বেশ সময় ও ধৈর্য লাগে।

শেখার সময়ে আমাদের পরামর্শ সহজ: VS Code দিয়ে শুরু করুন, কোড লেখায় স্বচ্ছন্দ হয়ে উঠুন, আর নিজের পছন্দ বুঝে গেলে পরে বাকিগুলো ঘুরে দেখুন।
