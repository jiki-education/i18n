## ভূমিকা

WSL (**Windows Subsystem for Linux**) হলো Microsoft-এর তৈরি Windows-এর একটি ফিচার, যা আপনার Windows মেশিনের ভেতরে একটি সত্যিকারের Linux সিস্টেম চালায়। এটি আপনার দরকার, কারণ বেশিরভাগ প্রোগ্রামিং টুল প্রথমে Linux আর macOS-এর জন্য তৈরি হয় (এবং সেখানেই সবচেয়ে ভালো কাজ করে), আর WSL-এর মাধ্যমেই Windows-এর ডেভেলপাররা এই সবকিছুর নাগাল পান। Microsoft নিজেও Windows-এ ডেভেলপমেন্টের জন্য এই পদ্ধতিটিই সুপারিশ করে। ইনস্টল করতে মিনিট পনেরো লাগে, যার বেশিরভাগটাই অপেক্ষা, আর এটি আপনাকে মাত্র একবারই করতে হবে।

## শুরু করার আগে

আপনার লাগবে:

- **Windows 10 (ভার্সন 2004 বা তার পরের) অথবা Windows 11।** গত কয়েক বছরের যেকোনো Windows মেশিন হলেই চলবে।
- কম্পিউটারে **অ্যাডমিনিস্ট্রেটর অ্যাক্সেস**। এটি যদি পরিবারের সবার কম্পিউটার হয়, তাহলে যিনি কম্পিউটারটি সেট আপ করেছেন তাঁকে দিয়ে পাসওয়ার্ড টাইপ করিয়ে নেওয়ার দরকার হতে পারে।

## WSL ইনস্টল করা

1. **Start** বোতামে ক্লিক করে "powershell" টাইপ করুন। **Windows PowerShell** দেখতে পাবেন।
2. এটি এমনি এমনি খুলবেন না। বরং এর ওপর রাইট ক্লিক করে **Run as administrator** বেছে নিন। Windows জানতে চাইবে আপনি এটিকে পরিবর্তন করার অনুমতি দিতে চান কি না: **Yes**-এ ক্লিক করুন।
3. যে নীল উইন্ডোটি খুলবে, সেখানে নিচের লেখাটি টাইপ করে Enter চাপুন:
   ```
   wsl --install
   ```
4. Windows সবকিছু ডাউনলোড করে সেট আপ করে নেবে, সেই সাথে **Ubuntu** নামের একটি Linux সিস্টেমও (Linux-এর সবচেয়ে জনপ্রিয় ভার্সন)। এতে কয়েক মিনিট লাগতে পারে।
5. যখন বলা হবে, তখন **কম্পিউটারটি রিস্টার্ট করুন**।

## Ubuntu সেট আপ করা

রিস্টার্টের পরে Ubuntu-র সেটআপ শেষ করার জন্য একটি টার্মিনাল উইন্ডো নিজে থেকেই খুলবে। (না খুললে Start-এ ক্লিক করে "ubuntu" টাইপ করে সেটি খুলুন।)

এটি আপনার Linux সিস্টেমের জন্য একটি **ইউজারনেম** এবং **পাসওয়ার্ড** তৈরি করতে বলবে:

1. একটি ইউজারনেম টাইপ করে (ছোট হাতের অক্ষরে, কোনো স্পেস ছাড়া) Enter চাপুন।
2. একটি পাসওয়ার্ড টাইপ করে Enter চাপুন, তারপর নিশ্চিত করতে সেটি আবার টাইপ করুন।

এখানে একটি ব্যাপার সবাইকে ধাঁধায় ফেলে: **পাসওয়ার্ড টাইপ করার সময় স্ক্রিনে কিছুই দেখা যায় না**। কোনো ডট নেই, কোনো তারা নেই, কিছুই না। এটি Linux-এর একটি নিরাপত্তা ফিচার, কোনো ত্রুটি নয়। আপনার টাইপ করা ঠিকই রেজিস্টার হচ্ছে, তাই পাসওয়ার্ডটি টাইপ করে Enter চেপে দিন।

এই পাসওয়ার্ডটি ভুলবেন না। কিছু ইনস্টল করার সময় মাঝে মাঝে এটি লাগবে।

## ঠিকঠাক কাজ করছে কি না দেখা

সবকিছু বন্ধ করুন, তারপর **Start**-এ ক্লিক করে "ubuntu" টাইপ করে সেটি খুলুন। আপনি এমন একটি উইন্ডো দেখবেন যার প্রম্পট `$` দিয়ে শেষ হয়েছে এবং সেটি আপনার টাইপ করার অপেক্ষায় আছে। অভিনন্দন: এটিই একটি সত্যিকারের Linux টার্মিনাল, আর এখন আপনার হাতে পেশাদারদের মতোই ডেভেলপমেন্ট এনভায়রনমেন্ট আছে।

`ls` টাইপ করে Enter চেপে দেখুন। এটি আপনার বর্তমান ফোল্ডারের ফাইলগুলোর তালিকা দেখায় (এখনো অবশ্য সেখানে বেশি কিছু থাকবে না)।

## VS Code থেকে WSL ব্যবহার করা

আপনার যদি [VS Code ইনস্টল করা](/guides/installing-vscode) থাকে, তাহলে সেটি WSL-এর সাথে যুক্ত হতে পারে, যাতে আপনার এডিটর আর Linux টার্মিনাল একসাথে কাজ করে:

1. VS Code খুলুন।
2. Extensions প্যানেলটি খুলুন (বাঁ দিকের চারটি বর্গের আইকন, অথবা Ctrl+Shift+X), **WSL** লিখে সার্চ করুন, আর Microsoft-এর তৈরি এক্সটেনশনটি ইনস্টল করুন।
3. Ctrl+Shift+P চেপে "WSL" টাইপ করুন এবং **WSL: Connect to WSL** বেছে নিন। VS Code নতুন করে খুলে Ubuntu-র সাথে যুক্ত হয়ে যাবে।

এখন থেকে VS Code-এর ভেতরে আপনি যে টার্মিনালই খুলবেন (Terminal মেনু, তারপর New Terminal), সেটিই একটি Linux টার্মিনাল। আমাদের বাকি গাইডগুলোর জন্য আমরা এই সেটআপটিই সুপারিশ করি।

## কিছু ভুল হলে

সবচেয়ে কমন সমস্যাটি হলো এমন একটি এরর যেখানে **ভার্চুয়ালাইজেশন** (অথবা "VT-x", "AMD-V", বা "virtual machine platform") কথাটির উল্লেখ থাকে। WSL হার্ডওয়্যারের এমন একটি ফিচারের ওপর নির্ভর করে যা কিছু কম্পিউটারে বন্ধ করা থাকে। এটি চালু করতে হলে কম্পিউটারের BIOS-এ একটি সেটিং বদলাতে হয়, যা নির্মাতাভেদে আলাদা। নির্দেশনার জন্য আপনার ল্যাপটপের মডেলের নামের সাথে "enable virtualisation" লিখে সার্চ করুন, অথবা <a href="https://forum.jiki.io" target="_blank" rel="noopener noreferrer">আমাদের ফোরামে</a> জিজ্ঞেস করুন, আমরা আপনাকে সাহায্য করব।

অন্য যেকোনো কিছুর জন্য Microsoft-এর <a href="https://learn.microsoft.com/en-us/windows/wsl/install" target="_blank" rel="noopener noreferrer">অফিসিয়াল WSL ইনস্টলেশন গাইডে</a> একটি ট্রাবলশুটিং সেকশন আছে, আর ফোরাম তো সবসময়ই আছে।
