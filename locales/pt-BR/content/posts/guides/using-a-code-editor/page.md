## Introdução

Quando você começa a escrever código no seu próprio computador, precisa de um lugar onde escrevê-lo. Esse "lugar" é um editor de código. É uma das primeiras ferramentas a que você vai recorrer. É também onde você vai passar muito tempo ao longo da sua carreira. É provável que você vá trocando e experimentando novos editores com o tempo, então vale a pena entender o que é e como escolher um bom editor para começar.

## Um editor de código não é um processador de texto

É fácil supor que qualquer programa que deixe você escrever serve. O erro mais comum é recorrer a um processador de texto como o Microsoft Word ou o Google Docs. Esses programas foram criados para escrever documentos destinados a pessoas, então eles alteram silenciosamente o que você escreve. Transformam aspas retas em aspas curvas “inteligentes”, corrigem automaticamente as suas palavras e guardam formatação oculta. Tudo isso estraga o código.

Um editor de código é um tipo de editor de texto. Ele trabalha com texto simples e nunca acrescenta formatação oculta, então o que você escreve é exatamente aquilo que o computador vê. A diferença é que um editor de código é um editor de texto criado especificamente para código. Além de trabalhar com texto simples, ele entende a estrutura do que você está escrevendo e te ajuda de formas que um processador de texto nunca conseguiria:

- **Realce de sintaxe** colore as diferentes partes do código para ser mais fácil de ler e de detectar erros.
- **Indentação automática** mantém o código alinhado, o que é muito importante em muitas linguagens.
- **Indicações de erro** assinalam problemas, muitas vezes antes de você sequer executar o programa.
- **Preenchimento automático** sugere o resto do que você está escrevendo, para você escrever mais rápido e cometer menos erros de digitação.
- **Extensões** permitem adicionar suporte para novas linguagens e ferramentas à medida que você evolui.

## A nossa recomendação

Há muitos bons editores de código e você não tem como fazer uma má escolha por aqui. Ainda assim, recomendamos o **Visual Studio Code**, normalmente abreviado para VS Code. É gratuito, funciona em Windows, macOS e Linux, é amigável para iniciantes e é um dos editores mais usados no mundo todo, então quase todos os tutoriais que você encontrar vão partir do princípio de que você está usando ele.

Quando você quiser instalá-lo, siga o nosso guia sobre [instalar o VS Code](/guides/installing-vscode).

## Outros editores de que você pode ouvir falar

Você não precisa de nenhum destes para acompanhar o Jiki, mas é provável que se depare com eles. Fica aqui uma visita rápida pelos mais comuns:

- O <a href="https://code.visualstudio.com" target="_blank" rel="noopener noreferrer">Visual Studio Code (VS Code)</a> é o editor gratuito e multiplataforma que recomendamos.
- O <a href="https://www.sublimetext.com" target="_blank" rel="noopener noreferrer">Sublime Text</a> é um editor rápido e leve que tem sido popular durante muitos anos.
- O <a href="https://zed.dev" target="_blank" rel="noopener noreferrer">Zed</a> é um editor mais recente e muito rápido, focado na velocidade e na colaboração.
- Os <a href="https://www.jetbrains.com/ides/" target="_blank" rel="noopener noreferrer">IDEs da JetBrains</a> (como o <a href="https://www.jetbrains.com/pycharm/" target="_blank" rel="noopener noreferrer">PyCharm</a> e o <a href="https://www.jetbrains.com/idea/" target="_blank" rel="noopener noreferrer">IntelliJ IDEA</a>) são ferramentas poderosas e mais pesadas, destinadas a desenvolvedores profissionais que trabalham em grandes projetos.
- O <a href="https://www.vim.org" target="_blank" rel="noopener noreferrer">Vim</a> e o <a href="https://neovim.io" target="_blank" rel="noopener noreferrer">Neovim</a> são editores controlados pelo teclado que vivem no terminal. São muito apreciados por desenvolvedores experientes, mas têm uma curva de aprendizado íngreme.

O nosso conselho enquanto você está aprendendo é simples: comece pelo VS Code, se acostume a escrever código e explore os outros mais tarde, quando descobrir do que você gosta.
