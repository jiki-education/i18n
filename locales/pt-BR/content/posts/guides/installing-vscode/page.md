## Introdução

O Visual Studio Code (VS Code) é um editor de código gratuito criado pela Microsoft que funciona no Windows, no macOS e no Linux. É o editor que recomendamos enquanto você está aprendendo a programar. Se você não sabe bem o que é um editor de código ou por que precisa de um, comece pelo nosso guia sobre [como usar um editor de código](/guides/using-a-code-editor).

Este guia te acompanha durante a instalação do VS Code em cada sistema operacional. Encontre seu sistema abaixo e siga os passos. Você só precisa fazer isso uma vez.

## Windows

1. Abra [code.visualstudio.com](https://code.visualstudio.com) no seu navegador.
2. Clique no botão **Baixar para Windows**. Isso baixa o instalador oficial (um arquivo `.exe`).
3. Quando o download terminar, abra o arquivo para executar o instalador.
4. Aceite o contrato de licença e continue clicando em **Avançar** para aceitar as opções padrão. Recomendamos que você deixe marcada a caixa que adiciona o VS Code ao menu de contexto, porque ajuda mais tarde.
5. Clique em **Instalar** e, em seguida, em **Concluir**. O VS Code abre quando estiver pronto.

## macOS

1. Abra [code.visualstudio.com](https://code.visualstudio.com) no seu navegador.
2. Clique no botão **Baixar para macOS**. Isso baixa um arquivo `.zip` com o aplicativo.
3. Abra a pasta **Downloads** e dê um duplo clique no arquivo baixado para descompactá-lo. Você vai obter um aplicativo chamado **Visual Studio Code**.
4. Arraste o **Visual Studio Code** para a pasta **Aplicativos**.
5. Abra a pasta **Aplicativos** e dê um duplo clique em **Visual Studio Code** para iniciá-lo. Se o macOS perguntar se você quer mesmo abri-lo, clique em **Abrir**.

## Linux

A forma mais confiável de instalar o VS Code no Linux é baixar o pacote oficial para a sua distribuição a partir da Microsoft.

1. Abra [code.visualstudio.com](https://code.visualstudio.com) no seu navegador.
2. Clique em **Baixar para Linux** e escolha o pacote que corresponde à sua distribuição:
   - Escolha o pacote **.deb** nos sistemas baseados em Debian e Ubuntu.
   - Escolha o pacote **.rpm** nos sistemas baseados em Fedora, Red Hat e openSUSE.
3. Abra o pacote baixado com o instalador de software do seu sistema e clique em **Instalar**, ou instale-o a partir do terminal:
   - No Debian ou Ubuntu, execute `sudo apt install ./<file>.deb` na pasta onde você o baixou.
   - No Fedora ou Red Hat, execute `sudo dnf install ./<file>.rpm` na pasta onde você o baixou.
4. Quando estiver instalado, abra o VS Code pelo menu de aplicativos ou executando `code` no terminal.

## Abrir o VS Code

Não importa como você o instalou, agora você pode abrir o VS Code sempre que quiser escrever código. No Windows e no macOS, ele aparece ao lado dos seus outros aplicativos. No Linux, fica no menu de aplicativos.

É tudo. Agora você tem um editor de código de verdade instalado e já pode começar a escrever código.
