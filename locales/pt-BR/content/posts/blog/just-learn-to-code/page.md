Uma das primeiras decisões que a maioria dos iniciantes enfrenta é: “Que linguagem devo escolher?”. A maioria acaba escolhendo JavaScript ou Python.

Nesse momento, acontece algo importante. Eles deixam de pensar “vou aprender a programar” e passam a pensar “vou aprender Python”. Uma semana atrás, talvez nunca tivessem ouvido falar de Python e, com certeza, não têm uma verdadeira noção das diferenças entre JS, Python, R, Java ou as dezenas de outras linguagens importantes. Mas, de repente, estão dispostos a defender com unhas e dentes que “sou uma pessoa de Python”.

E eu não os culpo! Uma das mensagens mais confusas e misturadas que os iniciantes ouvem é a de que aprender a programar é o mesmo que aprender uma linguagem de programação. E nós, os desenvolvedores, que temos todos uma linguagem favorita, vemos um novato vulnerável e o identificamos logo como um potencial convertido à nossa linguagem. Há poucos grupos mais tribais do que os desenvolvedores no que diz respeito à linguagem.

![Desenvolvedores em duas multidões raivosas agitando cartazes de linguagens de programação diferentes enquanto um iniciante confuso tapa os ouvidos no meio](/images/blog/just-learn-to-code-tribalism.webp)

Mas, para um iniciante, isso é um disparate. Um iniciante não precisa aprender Python, JavaScript ou qualquer outra linguagem. Precisa aprender os fundamentos da programação e construir uma base sólida que abranja as dezenas de linguagens que vai acabar usando ao longo do tempo.

Sobretudo na era da programação com agentes, em que você pode estar colocando TypeScript, Python, SQL, bash, JSON, Ruby e muitas outras linguagens em produção logo na primeira semana. Precisamos ajudar os iniciantes a entender o que está acontecendo no nível mais abrangente possível, em vez de fechá-los numa linguagem específica.

Criamos o Jiki para ensinar os fundamentos. Neste momento, ele usa uma versão ligeiramente modificada de JavaScript. Mais tarde, ainda este ano, vamos acrescentar Python e você vai poder escolher (ou podemos jogar uma moeda para escolher por você!), mas, sinceramente, isso não importa.

Aprenda a programar com o **[Jiki](https://jiki.io)**. Vai demorar um tempo. Depois, quando você entender a programação, use o **[Exercism](https://exercism.org)** para aprender linguagens. Vai ser MUITO mais rápido e fácil se você tiver os fundamentos bem firmes.

E, da próxima vez que um iniciante te perguntar que linguagem deve aprender, diga para ele que isso não importa. Liberte-o das correntes e aponte-o para o Jiki, em vez disso, para ganhar fundamentos sólidos.
