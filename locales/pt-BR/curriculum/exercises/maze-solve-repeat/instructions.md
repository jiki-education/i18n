Você recebeu uma solução funcional para um labirinto, mas ela é muito longa e repetitiva. Sua tarefa é alterar o código para que ele fique com **o menor número de linhas possível**.

O segredo está em usar laços (_loops_ em inglês) `repeat` para deixar o código mais curto. Lembre-se de que um laço repeat tem esta sintaxe:

```javascript
repeat(3) {
  // O que você quiser repetir aqui.
}
```

Sua tarefa é deixar o código o mais curto possível: **22 linhas de código**. Isso implica pensar em quando vale a pena usar um laço repeat e quando não vale. Repare que as linhas em branco e as linhas só com comentários não contam para o objetivo, então você pode espaçar o código à vontade para deixá-lo mais legível!

Boa sorte!
