## Introduction

Visual Studio Code (VS Code) est un éditeur de code gratuit créé par Microsoft, qui fonctionne sous Windows, macOS et Linux. C'est l'éditeur que l'on recommande pendant que tu apprends à coder. Si tu ne sais pas trop ce qu'est un éditeur de code, ni pourquoi tu en as besoin, commence par notre guide sur [l'utilisation d'un éditeur de code](/guides/using-a-code-editor).

Ce guide t'accompagne dans l'installation de VS Code sur chaque système d'exploitation. Trouve ton système ci-dessous et suis les étapes. Tu n'as besoin de le faire qu'une seule fois.

## Windows

1. Ouvre [code.visualstudio.com](https://code.visualstudio.com) dans ton navigateur web.
2. Clique sur le bouton **Download for Windows**. Cela télécharge le programme d'installation officiel (un fichier `.exe`).
3. Quand le téléchargement est terminé, ouvre le fichier pour lancer le programme d'installation.
4. Accepte le contrat de licence, puis continue de cliquer sur **Suivant** (_Next_ en anglais) pour accepter les options par défaut. On te recommande de laisser cochée la case qui ajoute VS Code au menu du clic droit, car elle te sera bien utile plus tard.
5. Clique sur **Installer** (_Install_ en anglais), puis sur **Terminer** (_Finish_ en anglais). VS Code s'ouvrira dès qu'il sera prêt.

## macOS

1. Ouvre [code.visualstudio.com](https://code.visualstudio.com) dans ton navigateur web.
2. Clique sur le bouton **Download for macOS**. Cela télécharge un fichier `.zip` qui contient l'application.
3. Ouvre le dossier **Téléchargements** et double-clique sur le fichier téléchargé pour le décompresser. Tu obtiens une application appelée **Visual Studio Code**.
4. Fais glisser **Visual Studio Code** dans le dossier **Applications**.
5. Ouvre le dossier **Applications** et double-clique sur **Visual Studio Code** pour le lancer. Si macOS te demande si tu veux vraiment l'ouvrir, clique sur **Ouvrir** (_Open_ en anglais).

## Linux

La façon la plus fiable d'installer VS Code sous Linux est de télécharger depuis le site de Microsoft le paquet officiel qui correspond à ta distribution.

1. Ouvre [code.visualstudio.com](https://code.visualstudio.com) dans ton navigateur web.
2. Clique sur **Download for Linux** et choisis le paquet qui correspond à ta distribution :
   - Choisis le paquet **.deb** sur les systèmes basés sur Debian et Ubuntu.
   - Choisis le paquet **.rpm** sur les systèmes basés sur Fedora, Red Hat et openSUSE.
3. Ouvre le paquet téléchargé avec la logithèque de ton système et clique sur **Installer**, ou installe-le depuis le terminal :
   - Sous Debian ou Ubuntu, exécute `sudo apt install ./<file>.deb` dans le dossier où tu l'as téléchargé.
   - Sous Fedora ou Red Hat, exécute `sudo dnf install ./<file>.rpm` dans le dossier où tu l'as téléchargé.
4. Une fois l'installation terminée, ouvre VS Code depuis le menu des applications, ou en exécutant `code` dans le terminal.

## Ouvrir VS Code

Quelle que soit la méthode d'installation, tu peux maintenant ouvrir VS Code chaque fois que tu veux écrire du code. Sous Windows et macOS, il apparaît avec tes autres applications, et sous Linux, il se trouve dans le menu des applications.

Et voilà ! Tu as maintenant un véritable éditeur de code installé, et tout est prêt pour commencer à écrire du code.
