title: "Étoiles"
description: "Construis un motif d'étoiles qui grandit."
en_md5: 62e22f6eee11821cd56f0310e293a292
---

Tu vas construire un petit générateur de motifs en mode texte. À partir d'un nombre, crée un tableau de strings où chaque string contient un nombre croissant d'étoiles.

Par exemple, pour le nombre 3, tu dois renvoyer :

```
["*", "**", "***"]
```

Le premier élément a 1 étoile, le deuxième en a 2, et ainsi de suite jusqu'au nombre demandé.

Si le nombre est 0, renvoie un tableau vide.

Crée une fonction appelée `stars` (étoiles) qui prend une entrée, le nombre demandé, et renvoie le tableau de strings d'étoiles.
