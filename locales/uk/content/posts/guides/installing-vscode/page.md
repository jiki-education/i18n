## Вступ

Visual Studio Code (VS Code), безкоштовний редактор коду від Microsoft, працює на Windows, macOS і Linux. Саме його ми рекомендуємо використовувати, поки вчимося програмувати. Якщо не зовсім зрозуміло, що таке редактор коду й навіщо він потрібен, почніть з нашого посібника про [роботу з редактором коду](/guides/using-a-code-editor).

Цей посібник крок за кроком показує, як встановити VS Code у кожній операційній системі. Знайдіть нижче свою систему і виконайте наведені кроки. Зробити це потрібно лише один раз.

## Windows

1. Відкрийте [code.visualstudio.com](https://code.visualstudio.com) у своєму браузері.
2. Натисніть кнопку **Download for Windows** (завантажити для Windows). Це завантажить офіційний інсталятор (файл `.exe`).
3. Коли завантаження завершиться, відкрийте файл, щоб запустити інсталятор.
4. Прийміть ліцензійну угоду, а потім натискайте **Next** (далі), щоб залишити типові параметри. Радимо не знімати позначку з пункту, який додає VS Code до меню правої кнопки миші: це стане в пригоді пізніше.
5. Натисніть **Install** (встановити), а потім **Finish** (завершити). Коли все буде готово, VS Code відкриється.

## macOS

1. Відкрийте [code.visualstudio.com](https://code.visualstudio.com) у своєму браузері.
2. Натисніть кнопку **Download for macOS** (завантажити для macOS). Це завантажить файл `.zip`, у якому міститься програма.
3. Відкрийте папку **Завантаження** (Downloads) і двічі клацніть завантажений файл, щоб розпакувати його. Усередині буде програма з назвою **Visual Studio Code**.
4. Перетягніть **Visual Studio Code** до папки **Програми** (Applications).
5. Відкрийте папку **Програми** і двічі клацніть **Visual Studio Code**, щоб запустити редактор. Якщо macOS запитає, чи справді слід відкрити програму, натисніть **Відкрити** (Open).

## Linux

Найнадійніший спосіб встановити VS Code на Linux: завантажити з сайту Microsoft офіційний пакет для свого дистрибутива.

1. Відкрийте [code.visualstudio.com](https://code.visualstudio.com) у своєму браузері.
2. Натисніть **Download for Linux** (завантажити для Linux) і виберіть пакет для свого дистрибутива:
   - На системах на основі Debian та Ubuntu виберіть пакет **.deb**.
   - На системах на основі Fedora, Red Hat і openSUSE виберіть пакет **.rpm**.
3. Відкрийте завантажений пакет у системному засобі встановлення програм і натисніть **Install** (встановити), або скористайтеся терміналом:
   - На Debian або Ubuntu виконайте `sudo apt install ./<file>.deb` у папці із завантаженим файлом.
   - На Fedora або Red Hat виконайте `sudo dnf install ./<file>.rpm` у папці із завантаженим файлом.
4. Після встановлення відкрийте VS Code через меню програм або виконайте команду `code` у терміналі.

## Запуск VS Code

Хоч би яким способом ми його встановили, тепер VS Code можна відкривати щоразу, коли хочеться писати код. На Windows і macOS він зʼявиться поруч з іншими програмами, а на Linux його можна знайти в меню програм.

Ось і все. Тепер у нас встановлено справжній редактор коду, і можна починати писати код.
