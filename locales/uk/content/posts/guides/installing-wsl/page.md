## Вступ

WSL (**Windows Subsystem for Linux**, підсистема Windows для Linux) додає у Windows справжню систему Linux, яка працює просто всередині компʼютера. Цю можливість створила сама Microsoft. Вона потрібна нам, бо більшість інструментів для програмування спершу створюють (і найкраще вони працюють) для Linux і macOS, і саме через WSL розробники на Windows отримують доступ до всього цього. Саме такий спосіб розробки на Windows рекомендує сама Microsoft. Встановлення займає приблизно пʼятнадцять хвилин, більшість із яких припадає на очікування, і зробити це потрібно лише один раз.

## Перш ніж почати

Нам знадобляться:

- **Windows 10 (версія 2004 або новіша) або Windows 11.** Підійде будь-який компʼютер із Windows, випущений за останні кілька років.
- **Права адміністратора** на компʼютері. Якщо це сімейний компʼютер, можливо, доведеться попросити того, хто його налаштовував, ввести свій пароль.

## Встановлення WSL

1. Натисніть кнопку **Пуск** (Start) і введіть «powershell». Зʼявиться **Windows PowerShell**.
2. Не відкривайте його одразу. Натомість клацніть по ньому правою кнопкою миші й виберіть **Запуск від імені адміністратора** (Run as administrator). Windows запитає, чи дозволити вносити зміни: натисніть **Так**.
3. У синьому вікні, що відкриється, введіть таку команду й натисніть Enter:
   ```
   wsl --install
   ```
4. Windows завантажить і налаштує все необхідне, зокрема систему Linux під назвою **Ubuntu** (найпопулярнішу версію Linux). Це може тривати кілька хвилин.
5. Коли зʼявиться відповідний запит, **перезавантажте компʼютер**.

## Налаштування Ubuntu

Після перезавантаження автоматично відкриється вікно термінала, щоб завершити налаштування Ubuntu. (Якщо цього не сталося, натисніть Пуск, введіть «ubuntu» і відкрийте його.)

Система попросить створити **імʼя користувача** та **пароль** для Linux:

1. Введіть імʼя користувача (маленькими літерами, без пробілів) і натисніть Enter.
2. Введіть пароль і натисніть Enter, а потім введіть його ще раз для підтвердження.

На цьому кроці всі спотикаються об одну річ: **під час введення пароля на екрані нічого не зʼявляється**. Ані крапок, ані зірочок, нічого. Це не збій, а особливість безпеки Linux. Натискання клавіш реєструються, тож просто введіть пароль і натисніть Enter.

Не забувайте цей пароль. Він час від часу знадобиться під час встановлення програм.

## Перевірка, що все працює

Закрийте всі вікна, потім натисніть **Пуск**, введіть «ubuntu» і відкрийте його. Має відкритися вікно з рядком запрошення, що закінчується на `$` і чекає, поки ми щось введемо. Вітаємо: перед нами справжній термінал Linux, і тепер ми маємо те саме середовище розробки, що й професіонали.

Спробуйте ввести `ls` і натиснути Enter. Ця команда виводить список файлів у поточній теці (поки що їх буде небагато).

## Використання WSL із VS Code

Якщо [VS Code вже встановлено](/guides/installing-vscode), його можна зʼєднати з WSL, щоб редактор і термінал Linux працювали разом:

1. Відкрийте VS Code.
2. Відкрийте панель розширень (Extensions): значок із чотирьох квадратів ліворуч або Ctrl+Shift+X. У пошуку введіть **WSL** і встановіть розширення від Microsoft.
3. Натисніть Ctrl+Shift+P, введіть «WSL» і виберіть **WSL: Connect to WSL**. VS Code перезапуститься вже зʼєднаним з Ubuntu.

Відтепер будь-який термінал, відкритий у VS Code (меню Terminal, потім New Terminal), працює як термінал Linux. Саме таке налаштування ми рекомендуємо для решти наших посібників.

## Якщо щось пішло не так

Найпоширеніша проблема: помилка зі згадкою про **віртуалізацію** (або «VT-x», «AMD-V» чи «virtual machine platform»). WSL покладається на апаратну можливість, яку на деяких компʼютерах вимкнено. Щоб її увімкнути, потрібно змінити налаштування в BIOS компʼютера, а це залежить від виробника. Пошукайте в інтернеті назву моделі свого ноутбука разом зі словами «enable virtualisation», або запитайте на <a href="https://forum.jiki.io" target="_blank" rel="noopener noreferrer">нашому форумі</a>, і ми допоможемо.

З будь-якими іншими проблемами допоможе розділ про усунення несправностей в <a href="https://learn.microsoft.com/en-us/windows/wsl/install" target="_blank" rel="noopener noreferrer">офіційному посібнику Microsoft зі встановлення WSL</a>, і, знову ж таки, форум завжди поруч.
