У цій вправі ми будемо розбирати дані з тестового API Spotify.

API вимагає двох типів запитів:

1. **Запит користувача**: отримуємо улюблені треки користувача з `https://api.spotify.com/v1/users/{username}`. У відповідь приходить словник із масивом `items`, де кожен елемент має словник `urls` з URL-адресою `spotify_api`.

2. **Запит виконавця**: отримуємо деталі про виконавця за URL-адресою з попередньої відповіді. У відповідь приходить словник із ключем `name`.

Створіть функцію з назвою `favoriteArtists` (улюблені виконавці), яка приймає імʼя користувача й повертає речення на кшталт:

```
"fred's most listened to artists are: Glee, NSYNC, Beethoven, and Limp Bizkit!"
```

Якщо API повертає помилку, поверніть її, додавши на початку `"Error: "`.

Функція `fetch(url, params)` (отримати дані) вже надана. У цій вправі params завжди має бути порожнім словником `{}`.
