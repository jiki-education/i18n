속도를 품질보다 중요하게 여기는 작은 미용실을 운영하고 있어요. 손님들은 머리가 조금 엉성한 채로 나가기도 하지만, 의자에 오래 앉아 있을 필요는 없어요.

스타일링부터 전체 커트까지 몇 가지 서비스를 제공하는데, 각각 걸리는 시간이 달라요. 미용실은 선착순으로 운영해요. 예약은 받지 않아요.

하루가 저물어 갈 무렵이면, 가게에 새로 들어온 손님을 받을 시간이 있는지 알 방법이 필요해요.

`canFitIn`(들어갈 수 있는지)이라는 함수를 만들어 봐요. 이 함수는 세 가지 입력을 받아요:

- 첫 번째는 이미 대기 중인 커트들이 담긴 문자열 배열이에요.
- 두 번째는 새로 온 손님이 원하는 커트를 나타내는 문자열이에요.
- 세 번째는 오늘 하루에 남은 시간을 분으로 나타낸 숫자예요.

새 손님을 받을 수 있는지 여부를 불리언 값으로 반환해요.

제공하는 스타일은 다음과 같아요:

- Mohawk: 20분
- Slicked-Back Pixie: 15분
- Bob: 25분
- Shave and Polish: 15분
- Afro Trim: 45분
- Up-do: 30분

### 중첩 배열

이번 연습 문제에서는 배열 안에 다른 배열이 원소로 들어 있는 경우를 처음으로 다뤄요. 이런 배열을 "중첩 배열"이라고 해요. 중첩 배열도 다른 배열과 똑같지만, 문자열이나 숫자를 담는 대신 다른 배열을 담고 있어요.

`cuts`(커트) 배열을 한번 살펴봐요. 이 배열은 커트마다 배열을 하나씩 담고 있고, 각 배열에는 이름과 소요 시간, 두 개의 원소가 들어 있어요.

이럴 때는 안쪽 배열, 즉 이름과 소요 시간이 짝을 이룬 배열들을 먼저 떠올린 다음, 그 배열들이 바깥 배열 하나에 묶여 있다고 생각하면 이해하기 쉬워요.

인덱스를 쓰는 방법은 다른 곳과 똑같아요. 다만 이렇게 인덱스를 연달아 이어 붙일 수 있어요...

```javascript
let cuts = [
  ["Mohawk", 20],
  ["Slicked-Back Pixie", 15],
  ["Bob", 25],
  //...
]

cuts[0] // ["Mohawk", 20]
cuts[0][0] // "Mohawk"
cuts[0][1] // 20
cuts[2][0] // "Bob"
```
