지금 "시 속의 모험"이라는 로봇이 나오는 시 게임을 만들고 있어요. 첫 단계로, 로봇이 걸어가면서 단어를 모으고 마지막에 시를 낭송하도록 프로그래밍해야 해요.

각 칸에는 다음 네 가지 중 하나가 들어 있어요:

1. 아무것도 없음 (`""`)
2. 시에 나오는 **단어**
3. 나뭇잎이나 나비 같은 배경 요소(이모지)
4. 로봇에게 멈추라고 알려 주는 체커기(`🏁`)

도와줄 함수도 몇 개 있어요. 먼저 `move()` 함수는 시를 읊는 로봇에게 다음 칸으로 이동하라고 지시하고, 그 칸에 있던 것을 반환해요. `isEmoji(thing)` 함수는 전달한 문자열이 이모지인지 알려 주는 불리언을 반환해요. 그리고 마지막으로 `recite(poem)` 함수는 완성된 시와 함께 사용해야 해요.

할 일은 길을 따라 걸으면서 시를 완성한 뒤, 그 시를 낭송하는 거예요.

## 규칙

- **단어**는 시에 들어가고, 단어 **사이에는 공백**을 하나씩 넣어요.
- **배경 요소**는 시의 일부가 아니니 무시해요.
- **아포스트로피**는 따로 자기 칸을 차지하고, 양옆에 있는 단어를 이어 줘요. `heart` 다음에 `'`, 그다음에 `s`가 오면 `heart's`가 돼요.
- **쉼표**도 자기 칸을 따로 차지해요. 쉼표는 앞에 있는 단어에 붙지만, 뒤에는 공백이 하나 있어요.
- 시인은 **체커기**에 도착하거나 **단어 일곱 개**를 모으면 걷기를 멈춰요. 둘 중 먼저 일어나는 쪽을 따라요.
- 시인은 언제 멈추든, 어떻게 멈추든, 모은 것을 낭송해요. `recite()`는 **한 번만** 호출할 수 있어요.

## 제한 사항

이 연습 문제를 푸는 방법은 여러 가지지만, 최근에 배운 `continue`와 `break` 키워드를 써서 풀기를 바라요. 그래서 몇 가지 규칙이 있어요:

1. 풀이에는 `continue`와 `break`를 둘 다 사용해야 해요.
2. 풀이에서 `&&`나 `!`는 사용할 수 없어요.
3. 도우미 함수는 만들 수 없어요.
4. 들여쓰기는 두 단계까지만 허용돼요:

```javascript

// 허용 - 들여쓰기 2단계
repeat() {
  if(...) {
    //...
  }
}

// 허용 안 됨 - 들여쓰기 3단계
repeat() {
  if(...) {
    if(...) {
    }
  }
}
```

그래서 완성하게 될 풀이는 꽤 "평평한" 모양이 될 거예요.
