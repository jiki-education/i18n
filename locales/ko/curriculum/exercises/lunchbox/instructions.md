어릴 적에는 학교에 가져갈 도시락을 매일 쌌어요. 어머니는 제가 쓸 물건들을 큰 것부터 작은 것 순으로 가지런히 꺼내 놓아 주셨어요. 저는 도시락에 최대한 많이 담으려고 했지만, 당연히 들어갈 수 있는 양에는 한계가 있었죠. 다 들어가지 않은 것은 사물함에 두지 않고 가방에 넣어 하루 종일 들고 다녀야 했어요.

이번 연습 문제에서 할 일은, 제가 도시락에 무엇을 담을 수 있고 무엇을 가방에 넣어야 하는지 알아내는 알고리즘을 만드는 거예요.

이번에는 `packLunch(items, capacity)`(도시락 싸기)라는 함수를 작성해야 해요. 이 함수는 두 가지를 입력으로 받아요. 물건 배열(큰 것부터)과 도시락의 크기를 나타내는 숫자인 `capacity`(용량)예요.

물건 배열은 중첩 배열이에요. 각 물건도 원소 두 개짜리 배열로, 물건의 이름과 크기가 들어 있어요. 물건은 항상 큰 것부터 작은 것 순으로 정렬되어 있어요. 예를 들어 물건 배열은 이렇게 생겼을 수 있어요:

```javascript
[
  ["Water bottle", 20],
  ["Crisps", 10],
  ["Peanut Butter Sandwich", 8],
  ["Chocolate bar", 6],
  ["Satsuma", 3]
]
```

도시락에는 담을 수 있는 최대 용량이 있어요. 어떤 물건을 도시락에 담을 수 있는지 알아내야 해요. 가능한 한 많은 물건을 담아요. 나머지는 모두 가방에 넣어요.

함수는 원소 두 개를 담은 배열을 반환해야 해요. 첫 번째 원소는 도시락에 담을 물건들의 배열이고, 두 번째 원소는 가방에 넣을 물건들의 배열이에요. 두 배열 모두 작은 것부터 큰 것 순으로 정렬되어 있어야 해요.

예를 들어 위 배열에서 용량이 20이라면, 이렇게 반환해야 해요:

```javascript
return [
  ["Satsuma", "Chocolate bar", "Peanut Butter Sandwich"],
  ["Crisps", "Water bottle"]
]
```

### 도움이 되는 메서드

이 단원의 모든 연습 문제에서 그렇듯이, 배열을 만들 때는 `.push(element)` 메서드를 사용하면 좋아요.

`[...].toReversed()`라는 새로운 메서드도 있어요. 이 메서드는 배열의 모든 원소 순서를 뒤집은 복사본을 만들어요. 예를 들어:

```
["A", 1, true].toReversed()
// [true, 1, "A"]
```

꼭 써야 하는 건 아니지만, 알아 두면 유용할 거예요.

즐겁게 해봐요!
