## 도입

컴퓨터에서 직접 코드를 작성하기 시작하면, 코드를 쓸 곳이 필요해요. 그곳이 바로 코드 편집기예요.
코딩을 시작하면서 가장 먼저 손이 가는 도구이고, 앞으로 프로그래밍을 하며 많은 시간을 보내게 될 공간이기도 해요. 시간이 지나면서 여러 편집기를 바꿔가며 써보고 취향에 맞는 것을 찾아가게 될 텐데, 그래서 코드 편집기가 무엇인지, 처음에 어떤 것을 고르면 좋을지 미리 이해해 두면 좋아요.

## 코드 편집기는 워드 프로세서가 아니에요

타이핑을 할 수 있는 프로그램이면 충분하다고 생각하기 쉬워요. 가장 흔한 실수는 Microsoft Word나 Google Docs 같은 워드 프로세서를 사용하려는 거예요.
이런 프로그램들은 사람이 읽는 문서를 작성하기 위해 만들어졌기 때문에, 입력하는 내용을 조용히 바꿔버려요. 곧은 따옴표를 둥글게 변형된 ‘스마트’ 따옴표로 바꾸고, 단어를 자동으로 고치며, 보이지 않는 서식을 저장하지요. 이 모든 것이 코드를 망가뜨려요.

코드 편집기는 텍스트 편집기의 한 종류예요. 평문으로 작업하고 절대 숨은 서식을 추가하지 않아서, 입력한 그대로 컴퓨터가 인식해요.
차이점은, 코드 편집기는 코드 작성을 위해 특별히 만들어진 텍스트 편집기라는 거예요. 평문 기능 외에도, 작성 중인 코드의 구조를 이해하고 워드 프로세서로는 절대 할 수 없는 도움을 줘요:

- **구문 강조**: 코드의 각 부분을 색상으로 구분해 주기 때문에 읽기 쉽고 실수를 발견하기도 쉬워요.
- **자동 들여쓰기**: 코드를 깔끔하게 정렬해 줘서, 여러 언어에서 매우 중요한 역할을 해요.
- **오류 알림**: 프로그램을 실행하기도 전에 문제가 있는 곳을 미리 알려줘요.
- **자동 완성**: 입력 중인 내용의 나머지를 제안해 주기 때문에 더 빠르게 쓰고 오타도 줄일 수 있어요.
- **확장 프로그램**: 새로운 언어나 도구에 대한 지원을 추가할 수 있어서, 실력이 늘어갈수록 편집기를 더 강력하게 만들 수 있어요.

## Jiki가 추천하는 편집기

좋은 코드 편집기는 정말 많아서, 여기서 잘못 고르는 경우는 거의 없어요. 그래도 Jiki는 **Visual Studio Code**, 보통 VS Code로 줄여 부르는 편집기를 추천해요.
무료고 Windows, macOS, Linux에서 모두 동작하며, 초보자에게 친절하고, 전 세계에서 가장 널리 쓰이는 편집기 중 하나라서, 대부분의 튜토리얼이 VS Code를 사용한다고 가정하고 만들어져 있어요.

설치할 준비가 되면, [VS Code 설치하기](/guides/installing-vscode) 가이드를 따라해 보세요.

## 알아두면 좋을 다른 편집기들

Jiki를 따라가는 데 이 편집기들은 전혀 필요 없지만, 앞으로 자연스럽게 접하게 될 테니 대표적인 것들만 간단히 소개할게요.

- <a href="https://code.visualstudio.com" target="_blank" rel="noopener noreferrer">Visual Studio Code(VS Code)</a>는 Jiki가 추천하는 무료 크로스 플랫폼 편집기예요.
- <a href="https://www.sublimetext.com" target="_blank" rel="noopener noreferrer">Sublime Text</a>는 빠르고 가벼운 편집기로, 오랫동안 많은 사랑을 받아왔어요.
- <a href="https://zed.dev" target="_blank" rel="noopener noreferrer">Zed</a>는 더 최근에 나온, 속도와 협업에 중점을 둔 아주 빠른 편집기예요.
- <a href="https://www.jetbrains.com/ides/" target="_blank" rel="noopener noreferrer">JetBrains IDE</a>들(예: <a href="https://www.jetbrains.com/pycharm/" target="_blank" rel="noopener noreferrer">PyCharm</a>, <a href="https://www.jetbrains.com/idea/" target="_blank" rel="noopener noreferrer">IntelliJ IDEA</a>)은 대규모 프로젝트를 다루는 전문 개발자를 위한 강력한 도구지만 상대적으로 무거운 편이에요.
- <a href="https://www.vim.org" target="_blank" rel="noopener noreferrer">Vim</a>과 <a href="https://neovim.io" target="_blank" rel="noopener noreferrer">Neovim</a>은 터미널 안에서 키보드로만 조작하는 편집기예요. 경험 많은 개발자들에게 큰 사랑을 받지만, 배우기가 꽤 까다로워요.

코딩을 배우는 동안에는 간단해요. 먼저 VS Code로 시작해서 코드 작성에 익숙해진 다음, 자신이 무엇을 좋아하는지 알게 되면 그때 다른 편집기들을 탐험해 보세요.
