## 시작하며

이 가이드에서는 웹 페이지가 실제로 무엇이고 어떻게 작동하는지에 대해 조금 이야기해 볼게요. 가장 기본적인 내용에만 집중할 거예요. 이미 HTML을 조금 알고 있다면 아주 기초적인 내용처럼 느껴질 수도 있어요. 아니라면 앞으로 배울 모든 것에 좋은 기초가 될 거예요.

## 웹 페이지의 실체

웹 페이지는 그냥 텍스트 파일이에요. 웹사이트에 접속하면 브라우저가 HTML 파일을 받아서 읽고, 그 내용을 화면에 그려서 페이지를 만들어요.

지금 바로 확인해볼 수 있어요. 아무 웹사이트에 들어가서 페이지 아무 곳이나 마우스 오른쪽 버튼으로 클릭한 후 **페이지 소스 보기(View Page Source)**를 선택해 보세요. 그게 HTML이에요. 큰 사이트에서는 방대한 양이라서 압도적으로 보일 수 있지만, 모두 아래에서 살펴볼 몇 가지 기본 요소들로 이루어져 있어요.

HTML은 **HyperText Markup Language**(하이퍼텍스트 마크업 언어)의 약자예요. '마크업'이란 텍스트에 각 부분이 무엇인지에 대한 추가 정보를 표시하는 것을 뜻해요. 브라우저(Chrome이든 뭐든)는 그 표시를 읽고 화면에 어떻게 표시할지 결정해요.

## 태그

HTML은 **태그**로 유명한데, `<`로 시작해서 `>`로 끝나요. 이 꺾쇠괄호 사이에 태그가 나타내는 대상이 들어가요. 그다음에 콘텐츠가 오고, 마지막으로 닫는 태그가 와요. 닫는 태그는 여는 태그와 같지만 슬래시(`/`)가 하나 더 붙어요.

예를 볼까요?

```html
<p>Hello there.</p>
```

`p`는 문단(paragraph)을 뜻해요. 이렇게 쓰면 브라우저에게 "화면에 문단을 하나 그리고, 그 안의 텍스트는 'Hello there.'이야"라고 알려주는 거예요.

태그는 여는 태그 안에 **속성**이라는 추가 정보를 담을 수도 있어요. 링크가 좋은 예예요:

```html
<a href="https://jiki.io">Visit Jiki</a>
```

링크를 만들 때는 `a` 태그(앵커(anchor)의 약자로, [역사적인 이유](https://thehistoryoftheweb.com/brief-history-hypertext/) 때문에 그렇게 불러요)를 사용해요. 링크는 보통 `href` 속성으로 이동할 주소를 지정하고, 태그 사이의 텍스트가 클릭하는 부분이 돼요.

몇몇 태그는 어떤 콘텐츠도 감싸지 않아서 닫는 태그가 없어요. 이미지가 대표적인 예예요:

```html
<img src="photo.jpg" alt="A photo of me on a mountain" />
```

`img`는 이미지를 뜻해요. `src` 속성은 이미지 파일을 가리키고, `alt` 속성은 스크린 리더 사용자를 위해 이미지를 설명해요. 이미지가 로드되지 않을 때 표시되는 내용이기도 해요.

## 페이지의 뼈대

모든 웹 페이지는 똑같은 뼈대를 가지고 있어요. 다음은 만들 수 있는 가장 최소한의 **유효한** 페이지예요 (HTML을 더 적게 써서 유효하지 않은 페이지를 만들 수도 있고, 브라우저는 그걸 그리긴 하지만, 책임감 있는 개발자답게 제대로 시작해볼게요!):

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Jeremy Walker</title>
  </head>
  <body>
    <h1>Jeremy Walker</h1>
    <p>I build things on the web.</p>
  </body>
</html>
```

위에서부터 차근차근 읽어볼게요.

`<!doctype html>` 줄은 브라우저에게 이 문서가 최신 HTML 문서라고 알려줘요. 꼭 필요한 보일러플레이트 코드예요. 맨 위에 한 번 적고 잊어버리세요.

`html` 태그는 문서 전체를 감싸는 루트 요소예요. `lang="en"` 속성은 페이지가 영어로 작성되었음을 브라우저와 검색 엔진에 알려줘요.

그 안에는 **head**와 **body** 두 부분이 있어요.

### head

head는 화면에 **보이지 않는** 모든 정보를 담고 있어요. 메타데이터인데, 메타데이터는 우리가 직접 보는 내용이 아니라 페이지에 대한 정보를 뜻해요. 예제에는 두 가지가 들어 있어요.

- `<meta charset="UTF-8" />`는 페이지가 어떤 문자 집합을 사용하는지 알려줘요. UTF-8은 표준 문자 집합으로, 라틴 문자, 악센트가 있는 문자, 다른 알파벳, 심지어 이모지까지 거의 모든 것을 포함해요. HTML에 이모지를 붙여 넣으면 이 줄 덕분에 제대로 표시돼요. 항상 포함하세요.
- `<title>`은 브라우저 탭 상단에 표시될 텍스트를 설정해요. 검색 엔진이 페이지 제목으로 사용하는 곳이기도 해요. 코딩을 하다 보면, 누군가 탭 스무 개를 열어두고 있을 때 저 위에 무엇을 보여주고 싶은지 자주 고민하게 될 거예요.

head에는 자주 보게 될 한 줄이 더 있는데, 알아두면 좋아요.

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

이 줄은 스마트폰에서 페이지를 지나치게 축소하지 않고 적당한 크기로 표시하라고 알려줘요. 지금은 그 정도만 알고 넘어가면 돼요. 넣고 넘어가세요.

### body

body는 탭과 주소 표시줄 아래 커다란 네모 공간에서 실제로 보이는 모든 것이에요. 모든 제목, 문단, 이미지, 링크가 body 안에 들어가요. 이 가이드의 나머지 부분은 그 안에 들어가는 태그들에 관한 이야기예요.

## index.html

태그를 살펴보기 전에 하나 더 알아둘 것이 있어요. 아주 오래된 관습으로 `index.html`이라는 파일이 웹사이트의 첫 페이지 역할을 해요. 도메인 주소만 입력하고 뒤에 아무것도 붙이지 않았을 때, 웹사이트는 `index.html`이라는 파일이 있는지 확인하고, 있으면 그 내용을 그대로 보여줘요. 파일 자체에 특별한 것은 없어요. 거의 모든 웹사이트가 따르는 표준일 뿐이에요. 그래서 홈페이지는 그 이름의 파일에 저장하는 게 좋아요.

## 가장 먼저 사용하게 될 태그들

실제로 유용한 페이지를 만드는 데 필요한 태그는 열 개도 안 돼요. 사용할 순서대로 대략 살펴볼게요.

### 제목

제목은 `h1`부터 `h6`까지 여섯 단계가 있어요.

```html
<h1>Jeremy Walker</h1>
<h2>About me</h2>
<h3>My photography</h3>
```

`h1`은 페이지의 주 제목이고, 보통 하나만 사용해야 해요. `h2`는 섹션 제목, `h3`는 그 안의 하위 섹션 제목으로 사용하세요. `h1`이 레벨 1 제목이기 때문에, 브라우저는 조금 더 크고 굵게 표시해요.

제목 레벨은 크기가 아니라 의미에 따라 선택하세요. 제목은 책의 장이나 절처럼 페이지의 개요를 만들어 줘요.

### 문단

`p` 태그는 텍스트 문단을 나타내며, 페이지의 거의 모든 글자는 이 태그 안에 들어가요.

```html
<p>저는 30년 동안 웹에서 무언가를 만들어 왔어요.</p>
<p>요즘은 대부분의 시간을 Jiki를 만드는 데 쓰고 있어요.</p>
```

각 문단마다 별도의 태그를 사용하고, 브라우저가 자동으로 문단 사이에 간격을 넣어줘요.

### 목록

목록에는 두 종류가 있어요. **비순서 목록**(`ul`)은 글머리 기호를, **순서 목록**(`ol`)은 번호를 매겨줘요. 둘 중 어떤 목록이든 각 항목은 **목록 항목**(`li`)이에요.

```html
<ul>
  <li>사진 촬영</li>
  <li>팟캐스팅</li>
  <li>코딩 가르치기</li>
</ul>
```

`ul`을 `ol`로 바꾸면 글머리 기호가 1, 2, 3으로 바뀌어요.

### 링크

링크는 웹을 웹답게 만드는 요소예요. `a` 태그로 무언가를 클릭 가능하게 만들어줘요.

```html
<p><a href="https://github.com/ihid">GitHub</a>에서 제 코드를 볼 수 있어요.</p>
```

링크는 다른 웹사이트를 가리킬 수도 있고, 내 사이트의 다른 페이지를 가리킬 수도 있어요. `index.html`과 같은 폴더에 `resume.html`이 있다면 `<a href="resume.html">이력서</a>`처럼 링크할 수 있어요.

### 이미지

`img` 태그는 페이지에 이미지를 넣어요.

```html
<img src="images/me.jpg" alt="호수 지방의 언덕 위에 서 있는 Jeremy" />
```

`src`는 사이트 내 파일이나 전체 웹 주소가 될 수 있어요. `alt` 텍스트에는 항상 이미지에 대한 진짜 설명을 채워 넣으세요.

### 강조

텍스트 안에서 특정 단어를 강조하는 작은 태그 두 개가 있어요. `strong`은 중요함을 나타내며, 브라우저는 굵게 표시해요. `em`은 강조를 나타내며, 브라우저는 기울임꼴로 표시해요.

```html
<p>진짜 배움은 고군분투하는 과정에서 일어나니까, <em>직접 해결책을 작성하세요</em>.</p>
```

## 페이지에 구조 부여하기

지금까지 살펴본 태그들은 개별 콘텐츠 조각을 설명해요. 페이지의 구역을 설명하는 또 다른 태그들이 있어요. 이런 태그를 **시맨틱 태그**라고 부르는데, 각 영역에 의미를 부여할 뿐 모양을 바꾸지는 않아요.

- `header`는 페이지 상단 영역을 감싸며, 보통 사이트 이름과 로고를 담아요.
- `nav`는 사이트 내 다른 페이지로 이동하는 링크 모음을 감싸요.
- `main`은 페이지의 주요 콘텐츠를 감싸며, 하나만 있어야 해요.
- `section`은 독립적인 콘텐츠 덩어리를 그룹화하며, 보통 자체 제목을 가져요.
- `article`은 블로그 글이나 뉴스 기사처럼 그 자체로 완결된 콘텐츠를 감싸요.
- `footer`는 페이지 하단 영역을 감싸며, 저작권 정보나 연락처 링크를 담아요.

이 태그들을 사용한 개인 홈페이지를 다음과 같은 모양으로 만들 수 있어요.

```html
<body>
  <header>
    <h1>Jeremy Walker</h1>
    <nav>
      <a href="index.html">홈</a>
      <a href="resume.html">이력서</a>
      <a href="portfolio.html">포트폴리오</a>
    </nav>
  </header>
  <main>
    <section>
      <h2>소개</h2>
      <p>...</p>
    </section>
    <section>
      <h2>프로젝트</h2>
      <p>...</p>
    </section>
  </main>
  <footer>
    <p>jeremy@example.com으로 연락 주세요.</p>
  </footer>
</body>
```

이 태그들 자체로는 페이지의 모양이 크게 바뀌지 않아요. 그런데 왜 신경 써야 할까요? 의미 있는 구조는 화면으로 보는 사람이 아닌, 페이지를 읽는 모든 도구에 도움이 되기 때문이에요. 스크린 리더는 이 태그를 사용해 시각 장애인이 탐색 메뉴나 주요 콘텐츠로 바로 이동할 수 있게 해줘요. 검색 엔진은 이 태그를 통해 페이지의 내용을 이해해요. 그리고 나중에 스타일을 입힐 때도, 잘 정리되어 있으면 훨씬 쉬워져요.

페이지의 한 부분이 위 의미에 맞지 않는다면, 두 가지 범용 컨테이너가 있어요. `div`는 콘텐츠 블록을, `span`은 텍스트 안의 몇 단어를 감싸요. 이 태그들은 아무 의미도 없기 때문에, 먼저 의미 있는 태그를 사용하는 게 좋아요.

## 알아두면 좋은 추가 태그들

이 태그들을 다 외울 필요는 없지만, 다른 사람의 페이지를 보다 보면 마주치게 될 테니 알아두면 좋아요.

- `blockquote`는 다른 곳에서 가져온 인용문을 나타내요.
- `code`는 텍스트 안의 코드 조각을, `pre`는 미리 서식이 지정된 텍스트 블록을 나타내요.
- `table`은 진짜 표 데이터를 나타내며, `tr`은 각 행, `td`는 각 셀을 나타내요.
- `form`, `input`, `label`, `button`은 방문자로부터 입력을 받는 데 사용해요.
- `video`와 `audio`는 미디어를 삽입해요.
- `br`은 텍스트 안에서 줄바꿈을 해요. 자주 사용하지 마세요. 새 문단이 필요하면 새 `p`를 사용하세요.

태그는 총 백 개가 넘지만, 이 가이드에서 다룬 태그들이 여러분이 보고 쓰게 될 대부분을 차지해요. 모르는 태그를 만나면 전문가들이 참고하는 [MDN](https://developer.mozilla.org/ko/docs/Web/HTML/Element)에서 찾아보세요.

## 다음 단계

이 모든 것을 확실히 익히는 가장 좋은 방법은 직접 뭔가를 만들어 보는 거예요. `index.html` 파일을 만들고, 이 가이드의 뼈대를 넣은 다음, 제목, 문단, 목록, 링크를 사용해 자기소개 페이지를 구성해 보세요. 그런 다음 브라우저에서 열어서 만든 결과를 살펴보세요.

익숙해지면, 방문하는 웹사이트의 소스를 보는 습관을 들이세요. 태그가 곳곳에서 보이기 시작할 거예요. 그리고 아무리 복잡한 사이트도 방금 배운 똑같은 조각들로 만들어졌다는 걸 알게 될 거예요.

지금은 페이지가 아주 수수해 보일 거예요. 괜찮아요. HTML은 페이지에 구조를 부여해요. 멋지게 보이게 하는 건 CSS의 일이고, 그게 다음에 배울 내용이에요.
