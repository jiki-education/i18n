코드를 실행했더니 이 버전의 언어에서는 사용할 수 없다는 메시지가 나왔나요? 그럼 무슨 일인지 알아볼까요!

만약 "이 기능은 아직 사용할 수 없습니다"라는 메시지를 받았다면, 상황이 다릅니다. 대신 **[기능이 언제 열릴까요?](/articles/when-will-this-feature-unlock)**를 읽어보세요.

## 소개

사용한 키워드나 개념이 지금 사용 중인 언어 버전에서 지원되지 않는 거예요. 걱정 마세요, 버그가 아니에요!

Jiki에서 사용하는 JavaScript와 Python 버전은 여러분의 학습을 돕기 위해 저희가 **직접 설계한 것**이에요. 복잡하거나 혼란스러운 부분을 우연히 마주치지 않도록, 준비가 되기 전까지 특정 기능을 신중하게 제외했어요.

## 왜 기능을 제외했을까요?

프로그래밍 언어는 **전문가**를 위해 설계되었어요. 경험이 많은 개발자가 더 빨리 작업할 수 있도록 돕는 고급 기능과, 오래된 시스템이 계속 작동하려고 삭제하기 어려운 역사적인 잔재들이 포함되어 있죠.

학습 중에는 이런 기능들이 혼란만 줘요. Jiki는 그 기능들을 제거함으로써 여러분이 정말 중요한 것, 즉 **프로그래머처럼 생각하는 법을 배우는 데** 집중할 수 있게 해줘요.

### Foot-gun

저희는 이런 기능을 **"foot-gun"**이라고 부르는데, 말 그대로 실수로 자기 발에 총을 쏘게 할 수 있는 기능이라는 뜻이에요. 다음과 같은 것들이 있어요:

- **진정으로 문제가 될 수 있어** 전문가도 사용을 피하는 게 나은 기능
- 핵심 개념에서 벗어나게 하는 **혼란스러운 예외 상황**
- 하위 호환성 때문에 남아 있을 뿐인 **역사적인 잔재**

이런 기능들은 혼란을 초래할 가치가 전혀 없기 때문에 Jiki에서 영구히 제외되었어요.

### 고급 기능

다른 기능들은 여러분의 학습 여정에서 **너무 고급**이기 때문에 제외되었어요. 나쁜 기능이 아니라, 기본기를 다질 때는 도움이 되지 않을 뿐이에요.

Jiki를 진행하면서 일부 기능은 차차 열리게 될 거예요. 하지만 지금은 기본에 충실하는 데 집중하세요.

## 자세한 내용

내부에서 벌어지는 일이나 저희의 결정에 적극적으로 관심이 있는 게 아니라면 굳이 읽지 않으셔도 돼요.

### JavaScript

| 기능                                                       | 제외된 이유                                                                                                    |
| ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `var`                                                      | `let`이나 `const`를 대신 사용하세요. `var`는 스코프 규칙이 혼란스러워서 경험이 많은 개발자조차 버그를 유발해요. |
| `with`                                                     | 사용이 권장되지 않고 혼란스러워요. 추론하기 어려운 모호한 코드를 만들어요.                                      |
| `debugger`                                                 | 개발 도구로, 학습에는 필요하지 않아요.                                                                          |
| `void`                                                     | 거의 쓸 일이 없고 초보자에게 혼란스러워요.                                                                      |
| `yield`                                                    | 고급 제너레이터 기능이에요. 제너레이터는 나중에 배우게 될 거예요.                                               |
| `delete`                                                   | 배열이나 객체에서 혼란스러운 동작을 일으킬 수 있어요.                                                            |
| `import` / `export`                                        | 모듈 시스템 기능이에요. Jiki에서는 간단하게 유지하기 위해 모듈을 다른 방식으로 처리해요.                         |
| 비트 연산자 (`&`, `\|`, `^`, `~`, `<<`, `>>`, `>>>`)      | 아주 드물게 필요하고, 학습 중에는 혼란스러워요. 저수준 비트 조작을 위한 기능이에요.                              |

### Python

| 기능       | 제외된 이유                                                                                                |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| `global`   | 함수 내에서 전역 변수를 수정하면 코드가 혼란스러워져요. 대신 매개변수로 값을 전달하는 방법을 배우세요.       |
| `nonlocal` | 중첩 함수에 사용하는 고급 스코프 기능이에요. 기본 개념을 배우는 데는 필요하지 않아요.                        |
| `assert`   | 디버깅 도구로, 프로덕션 환경에서 비활성화될 수 있어요. 대신 적절한 오류 처리를 배우는 게 좋아요.             |

## 기능이 필요하면 어떻게 하나요?

Jiki의 모든 연습 문제는 그 시점까지 배운 기능만으로 해결할 수 있게 설계되었어요. 어떤 제한에 부딪혔다면, 보통은 현재 사용할 수 있는 기능으로 문제를 해결하는 더 나은 방법이 있어요. 제약 속에서 해결책을 찾는 것도 학습의 일부랍니다.

정말로 지금 수준에서 어떤 기능이 꼭 필요하다고 생각된다면, 알려주세요! 피드백을 바탕으로 포함할 기능을 계속 다듬고 있어요.
