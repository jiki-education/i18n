## Einleitung

Visual Studio Code (VS Code) ist ein kostenloser Code-Editor von Microsoft, der unter Windows, macOS und Linux läuft. Es ist der Editor, den wir dir empfehlen, während du programmieren lernst. Wenn du nicht sicher bist, was ein Code-Editor ist oder wofür du einen brauchst, dann schau dir zuerst unsere Anleitung [Einen Code-Editor verwenden](/guides/using-a-code-editor) an.

Diese Anleitung führt dich durch die Installation von VS Code auf jedem Betriebssystem. Such dir unten dein System aus und folge den Schritten. Du musst das nur einmal machen.

## Windows

1. Öffne [code.visualstudio.com](https://code.visualstudio.com) in deinem Browser.
2. Klick auf den Button **Windows herunterladen** (englisch: Download for Windows). Damit lädst du den offiziellen Installer herunter (eine `.exe`-Datei).
3. Wenn der Download fertig ist, öffne die Datei, um den Installer zu starten.
4. Akzeptiere die Lizenzvereinbarung und klick dich dann mit **Next** weiter durch die Standardoptionen. Lass am besten das Kästchen angehakt, das VS Code in dein Rechtsklick-Menü einträgt, das ist später praktisch.
5. Klick auf **Install** und dann auf **Finish**. VS Code öffnet sich, sobald es bereit ist.

## macOS

1. Öffne [code.visualstudio.com](https://code.visualstudio.com) in deinem Browser.
2. Klick auf den Button **macOS herunterladen** (englisch: Download for macOS). Damit lädst du eine `.zip`-Datei mit der App herunter.
3. Öffne deinen **Downloads**-Ordner und mach einen Doppelklick auf die heruntergeladene Datei, um sie zu entpacken. Du bekommst eine App namens **Visual Studio Code**.
4. Zieh **Visual Studio Code** in deinen **Programme**-Ordner (englisch: Applications).
5. Öffne deinen **Programme**-Ordner und mach einen Doppelklick auf **Visual Studio Code**, um die App zu starten. Wenn macOS dich fragt, ob du sie wirklich öffnen willst, klick auf **Öffnen**.

## Linux

Der zuverlässigste Weg, VS Code unter Linux zu installieren, ist, das offizielle Paket für deine Distribution von Microsoft herunterzuladen.

1. Öffne [code.visualstudio.com](https://code.visualstudio.com) in deinem Browser.
2. Klick auf **Linux herunterladen** (englisch: Download for Linux) und wähle das Paket aus, das zu deiner Distribution passt:
   - Wähle das **.deb**-Paket auf Debian- und Ubuntu-basierten Systemen.
   - Wähle das **.rpm**-Paket auf Fedora-, Red Hat- und openSUSE-basierten Systemen.
3. Öffne das heruntergeladene Paket mit der Softwareverwaltung deines Systems und klick auf **Installieren**, oder installiere es im Terminal:
   - Führe auf Debian oder Ubuntu `sudo apt install ./<file>.deb` in dem Ordner aus, in den du es heruntergeladen hast.
   - Führe auf Fedora oder Red Hat `sudo dnf install ./<file>.rpm` in dem Ordner aus, in den du es heruntergeladen hast.
4. Wenn es installiert ist, öffne VS Code über dein Anwendungsmenü oder indem du `code` im Terminal ausführst.

## VS Code öffnen

Egal, wie du es installiert hast, du kannst VS Code jetzt jederzeit öffnen, wenn du Code schreiben willst. Unter Windows und macOS erscheint es neben deinen anderen Programmen, unter Linux findest du es in deinem Anwendungsmenü.

Das war's. Du hast jetzt einen richtigen Code-Editor installiert und kannst damit loslegen, Code zu schreiben.
