Beim letzten Mal hast du die Mauer gesehen und oben eine Schicht ergänzt, um sie fertigzustellen. In dieser Übung gehst du noch einen Schritt weiter und baust eine ganze Mauer von Grund auf, insgesamt 55 Ziegel.

Die fertige Mauer sollte so aussehen:

<img src="/static/images/exercise-assets/build-wall/completed-wall.webp" alt="Fertige Mauer" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Das musst du wissen:

- **Jeder** Ziegel ist 10 hoch und 20 breit.
- Ziegel dürfen bei Bedarf **außerhalb** der Zeichenfläche beginnen oder enden, aber sie dürfen nicht **vollständig** außerhalb der Zeichenfläche liegen.
- Die Reihen wechseln sich ab: Eine Reihe beginnt am linken Rand (5 Ziegel), die nächste beginnt links außerhalb der Zeichenfläche (6 Ziegel). (Die unterste Reihe hat 5 Ziegel, die oberste 6.)
- Die Funktion `rectangle` (Rechteck) darf nur einmal in deinem Code vorkommen!

Das Ziel dieser Übung ist, dass du damit experimentierst, `repeat`-Blöcke und Bedingungen zusammen einzusetzen. Es gibt viele verschiedene Wege, diese Übung zu lösen. Deine Herausforderung ist es, sie so zu lösen, dass sauberer, schöner Code dabei herauskommt.

Eine gute Frage, die du dir stellen kannst, ist: „Wie würde ein Maurer das in der echten Welt machen?“
