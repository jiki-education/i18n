Du hast eine funktionierende Lösung für ein Labyrinth bekommen, aber sie ist sehr lang und voller Wiederholungen. Deine Aufgabe ist es, den Code so zu ändern, dass er **so wenige Zeilen wie möglich** hat.

Das Geheimnis dabei ist, `repeat`-Schleifen (_loops_ auf Englisch) zu verwenden, um den Code zu verkürzen. Zum Beispiel. Denk daran, dass eine repeat-Schleife diese Syntax hat:

```javascript
repeat(3) {
  // Alles, was du hier wiederholen möchtest.
}
```

Deine Aufgabe hier ist es, den Code so kurz wie möglich zu machen: **22 Zeilen Code**. Das bedeutet, du musst dir überlegen, wann sich eine repeat-Schleife lohnt und wann nicht. Beachte, dass leere Zeilen und Zeilen, die nur Kommentare enthalten, nicht zum Ziel zählen. Du darfst deinen Code also gern mit Leerzeilen auflockern, damit er besser lesbar ist!

Viel Glück!
