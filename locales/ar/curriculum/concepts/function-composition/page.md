حتى الآن، كانت كل دالة تكتبها تقف إلى حد كبير على قدميها وتحتوي على كل المنطق الذي تحتاجه لكي تعمل.

الآن سننظر في كيفية تقسيم الدوال، بحيث نحصل على دوال أصغر تعمل معًا، بدلًا من دوال كبيرة يحدث فيها الكثير.

وكقاعدة عامة في البرمجة، تريد أن تؤدي كل دالة أقل قدر ممكن. ونسمّي هذا أن تكون للدالة مسؤولية واحدة (‏_single responsibility_ بالإنجليزية). على كل دالة أن تؤدي شيئًا واحدًا فقط، وأن تستعين بدوال أخرى للأجزاء الفرعية المختلفة من ذلك.

لنلقِ نظرة على مثال.

تخيّل أن لدينا دالة مهمتها أن تُرجع سلسلة نصية تصف اسمًا.

ستبدو النسخة البسيطة هكذا: لدينا حلقة عدّ، وهي شيء سبق أن كتبته، ثم قالب سلسلة نصية يجمع النتيجة معًا.

```javascript
function describeName(name) {
  let length = 0
  for (const letter in name) {
    length += 1
  }
  return `This name is ${length} letters long`
}
```

هذا يعمل بشكل جيد، لكنه يؤدي مهمتين: مهمة عامة إلى حد كبير، وهي العدّ، ومهمة أخرى محددة جدًا، وهي بناء هذه السلسلة النصية بصيغة معينة.

سيكون أجمل بكثير أن نقسّمه إلى دالتين: واحدة مسؤولة عن العدّ، وأخرى مسؤولة عن وصف الاسم بهذه الصيغة المعينة.

```javascript
// عدّ الحروف فقط
function countLetters(str) {
  let count = 0
  for (const letter in str) {
    count += 1
  }
  return count
}

// تنسيق النص بشكل جميل
function describeName(name) {
  const count = countLetters(name)
  return `The name has ${count} letters`
}
```

ويمكننا بعد ذلك إعادة استخدام دالة العدّ العامة تلك في تنسيق السلسلة النصية هذا، وأيضًا في أي مكان آخر نحتاجها فيه. فكلما احتجنا إلى عدّ الحروف في سلسلة نصية، كانت منفصلة تمامًا عن أي شيء يتعلق بالطباعة.

يمكنك قراءة كلتا الدالتين بمعزل عن الأخرى، وفهم ما تفعله كل واحدة منهما فورًا.

وكلما أصبحت دوالك أكثر تعقيدًا وازداد عددها، كان هذا الأسلوب هو الفرق بين كود مرتب سهل القراءة، وبين ارتباك وفوضى تامّين.

وهناك أمر يستحق الذكر مرة أخرى هنا، وهو أن أي شيء تنشئه داخل دالة لا تستطيع الدوال الأخرى الوصول إليه، إلا إذا أرجعته عن قصد.

فإذا حاولت الإشارة إلى المتغير `count` (العدّ) من داخل `describeName` (وصف الاسم)، فلن تستطيع، لأنه ينتمي إلى الدالة الأخرى.

في JavaScript، يمكننا إنشاء متغيرات في الأعلى فوق كل شيء، تكون مشتركة بين الدوال، لكني أنصحك بشدة بألا تفعل ذلك، إلا إذا كان هناك سبب وجيه حقًا.

والمصطلح التقني لإبقاء كل دالة مستقلة هو «نقية» (‏_pure_ بالإنجليزية)، أي الدوال النقية. وكلما فعلت ذلك، كان كودك أنظف وكانت الأخطاء التي تنشئها وتواجهها أقل.
