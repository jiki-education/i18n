قد تتذكر أن حلقة `repeat` لا توجد فعلًا في JavaScript. إنها مجرد شيء أُضيف ليجعل حياتك أسهل قليلًا في أثناء انطلاقتنا.

إذن، ماذا نستخدم بدلًا منها؟ حسنًا، نستخدم حلقة `for` عادية، وتبدو هكذا.

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

يمكنك أن تفهم لمَ كان ذلك مُربِكًا بعض الشيء في اليوم الأول لك.

لكنّك الآن تملك كل المعرفة التي تحتاجها لتشعر بالراحة معها. لذا، لنحلّلها معًا.

حلقة `for` مكوَّنة من ثلاثة مكونات: مُهيِّئ (‏_initializer_ بالإنجليزية)، وشرط، وزيادة.

المُهيِّئ، وهو هذا الجزء `let i = 0`، يعمل في بداية الحلقة كلها. إنه يعمل مرة واحدة فقط، وهنا يُنشئ صندوقًا اسمه `i` (متغير العدّ) قيمته صفر. `i` هو مجرد حرف يُستخدم لتتبع قيمة أثناء التكرار، ومن المعتاد استخدام `i` أو `x` لهذا الغرض.

الجزء التالي، قبل الشرط، يعمل في كل مرة قبل كل تكرار للحلقة.

إذا كان الشرط صحيحًا، نُنفّذ الحلقة مرة أخرى.

إذا لم يكن كذلك، لا نُنفّذها.

ثم أخيرًا تأتي الزيادة، وهي `i++`.

`i++` تعني ببساطة نفس معنى `i = i + 1`. إنها مجرد اختصار، طريقة لزيادة `i` بمقدار واحد في كل مرة.

إذن في هذا المثال، سنضبط `i` على الصفر. نتحقق مما إذا كان `i` أصغر من اثنين، وهو بالفعل كذلك، فنُنفّذ الحلقة.

ثم في النهاية، نزيد `i` بمقدار واحد، فيصبح `i` واحدًا. صفر زائد واحد يساوي واحدًا.

ثم نكرر. نتحقق مما إذا كان الواحد أصغر من اثنين.

وهو كذلك، فنُنفّذ الحلقة. ثم في النهاية، نزيد `i` من جديد. فيصبح الآن اثنين، واحد زائد واحد يساوي اثنين.

```javascript
i = 0
i < 2 // true - run the loop
...   // Do the iteration
i = i + 1 // 1

i < 2 // true - run the loop
...   // Do the iteration
i = i + 1 // 2

i < 2 // false - exit the loop
```

ثم ننتقل للمرة الثالثة. نتحقق هذه المرة مما إذا كان اثنان أصغر من اثنين، وهو ليس كذلك، فلا نُنفّذ الحلقة، ونكون قد انتهينا من الحلقة فعلًا. ننتقل ببساطة إلى أي كود يليها. إذن، نُفّذت الحلقة مرتين، وهذه معلومة مفيدة. طالما نبدأ من الصفر ولدينا شرط `i < n`، فإن العدد `n` هو عدد مرات تنفيذ الحلقة.

إذن، هذا يعادل قول `repeat 2`.

إذن، الأمر ليس صعبًا، لكنه أكثر تعقيدًا بكثير من مجرد كتابة `repeat 2`. ميزة حلقة `for` هي أنك تستطيع فعل أي شيء في هذه الفتحات الثلاث. يمكنك أن تبدأ برقم مختلف، أو تعدّ تصاعديًا بأكثر من واحد، أو تعدّ تنازليًا، أو تستخدم شرطًا يعتمد على شيء آخر غير عداد بسيط. هذه المرونة هي ما يجعل حلقة `for` بمثابة حصان الشغل في JavaScript.
