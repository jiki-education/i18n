يمكن استخدام الكلمة المفتاحية `break` في أي مكان داخل جسم أي حلقة.

أما الجزء الذي يقع بين الأقواس المعقوفة فهو الجسم. وعندما يرى Jiki الكلمة المفتاحية `break`، يخرج من الحلقة على الفور وينتقل إلى أي كود يأتي بعدها.

فإذا كان لدينا قيد يقول إن علينا تشغيل هذه الحلقة 50 مرة، لكننا نريد أن نتوقف إذا أطلق المستخدم النار خمس مرات، فيمكننا أن نضع في أعلى الكود حلقة `for` تعدّ تصاعديًا حتى 50.

لكن يمكننا بعد ذلك أن نضع شرطًا في وسط الحلقة يتحقق مما إذا كان المستخدم قد أطلق النار خمس مرات، وإذا كان الأمر كذلك، نستخدم `break` لإيقاف الحلقة.

```javascript
for (let i = 0; i < 50; i++) {
  if (numShots >= 5) {
    break; // الخروج من الحلقة
  }
}
```
