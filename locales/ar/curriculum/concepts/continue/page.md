أحيانًا قد نرغب في تخطّي تكرار محدّد من تكرارات الحلقة بدلًا من الخروج منها بالكامل. تخيّل أننا نريد تنفيذ الأشياء للأعداد الفردية فقط.

نريد أن نستطيع أن نقول: إذا كان `i` (فهرس) عددًا فرديًّا، فلا تشغّل الحلقة هذه المرة.

لكننا لا نريد الخروج من الحلقة تمامًا، بل نريد فقط تخطّي هذا التكرار الواحد ثم النظر إلى التكرار التالي.

ولهذا، لدينا كلمة مفتاحية أخرى تُسمّى `continue`.

عندما يرى Jiki الكلمة `continue`، يقفز عائدًا إلى أعلى الحلقة ليبدأ التكرار التالي. لذا في حلقة `for-of`، إذا رأى `continue`، ينتقل إلى العنصر التالي في المصفوفة.

```javascript
for (let item of list) {
  if (item === "something") {
    continue; // يتخطّى بقية الحلقة عند "something"
  }
  // بقية الحلقة...
}
```

وفي حلقة `for`، يصل إلى خطوة الزيادة `i++` ثم يبدأ التكرار التالي.

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue; // يتخطّى بقية الحلقة للأعداد الزوجية
  }
  // بقية الحلقة...
}
```
