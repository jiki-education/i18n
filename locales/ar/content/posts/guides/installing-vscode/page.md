## مقدمة

Visual Studio Code (واختصارًا VS Code) هو محرر أكواد مجاني تُطوِّره Microsoft، يعمل على أنظمة Windows وmacOS وLinux. وهو المحرر الذي ننصح به أثناء تعلّمك البرمجة. إذا كنتَ غير متأكد مما يعنيه محرر الأكواد أو لماذا تحتاج إليه، فابدأ بدليلنا حول [استخدام محرر الأكواد](/guides/using-a-code-editor).

يأخذك هذا الدليل في جولة لتثبيت VS Code على كل نظام تشغيل. ابحث عن نظامك فيما يلي واتبع الخطوات. ما عليك فعل ذلك إلا مرة واحدة.

## Windows

1. افتح موقع [code.visualstudio.com](https://code.visualstudio.com) في متصفح الويب.
2. انقر على زر **Download for Windows**. يُنزِّل هذا الزر المُثبِّت الرسمي (ملف بصيغة `.exe`).
3. عند اكتمال التنزيل، افتح الملف لتشغيل المُثبِّت.
4. وافق على اتفاقية الترخيص، ثم استمر في النقر على **Next** لقبول الخيارات المُحدَّدة مُسبقًا. ننصح بإبقاء المربع الذي يُضيف VS Code إلى قائمة النقر بزر الفأرة الأيمن مُفعَّلًا، إذ سيكون مفيدًا لاحقًا.
5. انقر على **Install** ثم **Finish**. سيفتح VS Code تلقائيًّا عند جهوزيته.

## macOS

1. افتح موقع [code.visualstudio.com](https://code.visualstudio.com) في متصفح الويب.
2. انقر على زر **Download for macOS**. يُنزِّل هذا الزر ملفًا بصيغة `.zip` يحتوي على التطبيق.
3. افتح مجلد **Downloads** وانقر نقرًا مزدوجًا على الملف الذي نزَّلتَه لفك ضغطه. ستحصل على تطبيق باسم **Visual Studio Code**.
4. اسحب **Visual Studio Code** إلى مجلد **Applications**.
5. افتح مجلد **Applications** وانقر نقرًا مزدوجًا على **Visual Studio Code** لتشغيله. إذا سألك macOS عمَّا إذا كنتَ متأكدًا من رغبتك في فتحه، فانقر على **Open**.

## Linux

الطريقة الأكثر موثوقيةً لتثبيت VS Code على Linux هي تنزيل الحزمة الرسمية لتوزيعتك من Microsoft.

1. افتح موقع [code.visualstudio.com](https://code.visualstudio.com) في متصفح الويب.
2. انقر على **Download for Linux** واختر الحزمة التي تُناسب توزيعتك:
   - اختر الحزمة **.deb** على الأنظمة المُعتمِدة على Debian وUbuntu.
   - اختر الحزمة **.rpm** على الأنظمة المُعتمِدة على Fedora وRed Hat وopenSUSE.
3. افتح الحزمة التي نزَّلتها باستخدام مُثبِّت البرامج الخاص بنظامك وانقر على **Install**، أو ثبِّتها من الطرفية:
   - على Debian أو Ubuntu، شغِّل الأمر `sudo apt install ./<file>.deb` داخل المجلد الذي نزَّلتَ الملف فيه.
   - على Fedora أو Red Hat، شغِّل الأمر `sudo dnf install ./<file>.rpm` داخل المجلد الذي نزَّلتَ الملف فيه.
4. بعد اكتمال التثبيت، افتح VS Code من قائمة التطبيقات، أو بتنفيذ الأمر `code` في الطرفية.

## فتح VS Code

مهما كانت الطريقة التي استخدمتها لتثبيته، يُمكنك الآن فتح VS Code متى أردتَ كتابة الكود. على Windows وmacOS سيظهر إلى جانب تطبيقاتك الأُخرى، وعلى Linux سيكون موجودًا في قائمة التطبيقات.

هذا كل شيء. لديك الآن محرر أكواد احترافي مُثبَّت، وأنت جاهز للبدء في كتابة الكود.
