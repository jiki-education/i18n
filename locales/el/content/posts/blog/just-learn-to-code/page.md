Μία από τις πρώτες αποφάσεις που αντιμετωπίζουν οι περισσότεροι αρχάριοι είναι "Ποια γλώσσα να διαλέξω;". Οι περισσότεροι καταλήγουν σε JavaScript ή Python.

Εκείνη τη στιγμή συμβαίνει κάτι σημαντικό. Μετακινούνται από το "Θα μάθω προγραμματισμό" στο "Θα μάθω Python". Πριν από μία εβδομάδα ίσως δεν είχαν ακούσει ποτέ για την Python, και σίγουρα δεν έχουν πραγματική κατανόηση των διαφορών ανάμεσα σε JS, Python, R, Java ή τις δεκάδες άλλες κύριες γλώσσες. Αλλά ξαφνικά είναι έτοιμοι να υπερασπιστούν μέχρι τελικής πτώσης ότι "Είμαι άνθρωπος της Python".

Και δεν μπορώ να τους κατηγορήσω! Ένα από τα πιο μπερδεμένα και συγκεχυμένα μηνύματα που ακούνε οι αρχάριοι είναι ότι το να μάθεις προγραμματισμό είναι το ίδιο με το να μάθεις μια γλώσσα προγραμματισμού. Κι εμείς οι προγραμματιστές, που όλοι έχουμε μια αγαπημένη γλώσσα, βλέπουμε έναν ευάλωτο νεοφερμένο και αμέσως τον αναγνωρίζουμε ως πιθανό νεοφώτιστο στη δική μας γλώσσα. Λίγες ομάδες είναι πιο φυλετικές από τους προγραμματιστές όσον αφορά τη γλώσσα τους.

![Προγραμματιστές σε δύο θυμωμένες ομάδες που κραδαίνουν πανό για διαφορετικές γλώσσες προγραμματισμού, ενώ ένας μπερδεμένος αρχάριος καλύπτει τα αυτιά του στη μέση](/images/blog/just-learn-to-code-tribalism.webp)

Αλλά αυτό είναι ανοησία για έναν αρχάριο. Ένας αρχάριος δεν χρειάζεται να μάθει Python ή JavaScript ή οποιαδήποτε άλλη γλώσσα. Χρειάζεται να μάθει τις βασικές αρχές του προγραμματισμού και να χτίσει μια στέρεη βάση που θα καλύπτει όλες τις δεκάδες γλώσσες που θα καταλήξει να χρησιμοποιεί με τον καιρό.

Ειδικά στην εποχή του agentic coding, όπου θα μπορούσες να βάζεις TypeScript, Python, SQL, bash, JSON, Ruby και όσες άλλες γλώσσες θες σε παραγωγή την πρώτη σου εβδομάδα. Πρέπει να βοηθήσουμε τους αρχάριους να καταλάβουν τι συμβαίνει όσο το δυνατόν ευρύτερα, κι όχι να περιοριστούν σε μία συγκεκριμένη γλώσσα.

Σχεδιάσαμε το Jiki για να διδάσκει τις βασικές αρχές. Αυτή τη στιγμή χρησιμοποιεί μια ελαφρώς τροποποιημένη έκδοση της JavaScript. Αργότερα μέσα στη χρονιά θα προσθέσουμε Python και θα μπορείς να διαλέξεις (ή μπορούμε να στρίψουμε ένα νόμισμα για να διαλέξεις!), αλλά ειλικρινά δεν έχει σημασία.

Μάθε προγραμματισμό με το **[Jiki](https://jiki.io)**. Θα πάρει λίγο χρόνο. Έπειτα, όταν κατανοείς τον προγραμματισμό, χρησιμοποίησε το **[Exercism](https://exercism.org)** για να μάθεις γλώσσες. Θα είναι ΠΟΛΥ πιο γρήγορο και εύκολο αν έχεις τις βάσεις σου.

Και την επόμενη φορά που ένας αρχάριος σε ρωτήσει ποια γλώσσα να μάθει, πες του ότι δεν έχει σημασία. Απελευθέρωσέ τον από τα δεσμά και στείλ' τον στο Jiki για να αποκτήσει γερές βάσεις.
