Μάλλον μόλις είδες μια **πρόκληση** και αναρωτιέσαι τι είναι.

Οι προκλήσεις είναι **πιο δύσκολες, πιο ουσιαστικές ασκήσεις** που σε ωθούν πιο μακριά από τις κανονικές. Ενώ οι περισσότερες ασκήσεις επικεντρώνονται στην εξάσκηση μιας συγκεκριμένης έννοιας ή τεχνικής, οι προκλήσεις σου ζητούν να πας λίγο παραπέρα και να δοκιμάσεις πραγματικά τις δεξιότητές σου.

Σκέψου τις ασκήσεις σαν να χτίζουν κάθε δεξιότητα, και τις προκλήσεις σαν να πιέζουν αυτές τις δεξιότητες πιο πολύ. Είναι σχεδιασμένες για να σε **δοκιμάζουν** και να σου προσφέρουν μια πραγματική πρόκληση που νιώθεις ικανοποίηση όταν την αντιμετωπίζεις.

Οι προκλήσεις είναι αποκλειστικά για [συνδρομητές Premium](/premium)

## Πώς ξεκλειδώνονται;

Οι προκλήσεις ξεκλειδώνονται **σταδιακά καθώς προχωράς** μέσα στο μάθημα. Όσο μαθαίνεις νέες έννοιες και ολοκληρώνεις ασκήσεις, περισσότερες προκλήσεις γίνονται διαθέσιμες για σένα. Η ιδέα είναι ότι κάθε πρόκληση γίνεται διαθέσιμη μόλις έχεις πιθανώς αρκετές γνώσεις για να τα καταφέρεις καλά με αυτήν.

Μπορείς να χρησιμοποιήσεις **οποιαδήποτε έννοια έχεις μάθει** μέχρι εκείνο το σημείο για να λύσεις μια πρόκληση. Δεν υπάρχει περιορισμός για το ποιες τεχνικές θα χρησιμοποιήσεις. Αν την έχεις μάθει, είναι επιτρεπτό.

## Δεν εμποδίζουν την πρόοδό σου

Οι προκλήσεις δεν αποτελούν μέρος της βασικής ροής, επομένως **δεν εμποδίζουν την πρόοδό σου** μέσα στο μάθημα. Βρίσκονται δίπλα στη βασική διαδρομή και όχι πάνω σε αυτήν. Αν δεν έχεις διάθεση για μια πρόκληση, ή τη βρίσκεις δύσκολη, μπορείς απλά να συνεχίσεις με τις κανονικές ασκήσεις και να επιστρέψεις όποτε θέλεις.

Ποτέ δεν πρόκειται να κολλήσεις εξαιτίας μιας πρόκλησης. Υπάρχουν για να σε εμπλουτίσουν, όχι για να σε εμποδίσουν.

## Γιατί να ασχοληθείς μαζί τους;

Οι προκλήσεις είναι εκεί που πραγματικά μπορείς να **δοκιμάσεις την κατανόησή σου**. Άλλο είναι να δουλέψεις πάνω σε μια άσκηση όπου καθοδηγείσαι προς τη λύση, και άλλο να αντιμετωπίσεις κάτι πιο δύσκολο που σε ωθεί να εφαρμόσεις αυτά που ξέρεις.

Είναι εξαιρετικές για:

- **Χτίσιμο αυτοπεποίθησης**. Το να ολοκληρώσεις μια πρόκληση μοιάζει με πραγματικό επίτευγμα
- **Εμβάθυνση της κατανόησης**. Συχνά θα διαπιστώσεις ότι δουλεύοντας πάνω σε μια πρόκληση σε βοηθά να καταλάβεις καλύτερα προηγούμενες έννοιες
- **Διασκέδαση**. Είναι πραγματικά ευχάριστες, και είναι ικανοποιητικό να λύσεις μια δύσκολη

## Μερικές συμβουλές

- **Μην αγχώνεσαι γι' αυτές.** Είναι φτιαγμένες για να είναι προκλητικές, και είναι απολύτως εντάξει αν δεν τις καταφέρεις αμέσως.
- **Χρησιμοποίησε ό,τι ξέρεις.** Δεν χρειάζεσαι μυστικές τεχνικές, όλα όσα έχεις μάθει μέχρι τώρα είναι αρκετά.
- **Επέστρεψε σε αυτές.** Αν κολλήσεις, πήγαινε και μάθε λίγο ακόμα μέσα από τις κανονικές ασκήσεις, και μετά επέστρεψε και δοκίμασε ξανά. Πιθανότατα θα τη βρεις πιο εύκολη τη δεύτερη φορά.
- **Ξαναδές ολοκληρωμένες προκλήσεις.** Ακόμα και αφού έχεις ολοκληρώσει μία, μπορείς πάντα να επιστρέψεις και να προσπαθήσεις να βελτιώσεις τη λύση σου καθώς μαθαίνεις καινούργια πράγματα.

Οι προκλήσεις είναι εκεί για να σε ωθούν, να σε βοηθούν να αναπτυχθείς και, ας ελπίσουμε, να είναι αρκετά διασκεδαστικές. Απόλαυσέ τες!
