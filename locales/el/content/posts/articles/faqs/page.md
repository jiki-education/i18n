## Σχετικά με το μάθημα

### Πόσο κοστίζει;

Οι ασκήσεις του Learn to Code, που αποτελούν τον βασικό κορμό του προγράμματος εκμάθησης προγραμματισμού, είναι εντελώς δωρεάν. Χωρίς κάρτα, χωρίς δοκιμή, χωρίς κρυφούς όρους.

Το Jiki Premium κοστολογείται ανά χώρα και ξεκλειδώνει πλήρη πρόσβαση στο Learn to Build, στα Jiki Projects, στην απεριόριστη υποστήριξη Ask Jiki AI, σε τακτικές ζωντανές μεταδόσεις ερωτήσεων και απαντήσεων στις οποίες μπορείς να συμμετέχεις, σε πιστοποιητικά για τα μαθήματα, σε εμπειρία εκμάθησης χωρίς διαφημίσεις και σε πρώιμη πρόσβαση σε νέες λειτουργίες.

### Πόσο χρόνο θα χρειαστεί να αφιερώνω κάθε εβδομάδα στο μάθημα;

Μπορείς να αφιερώσεις όσο χρόνο θέλεις, λίγο ή πολύ. Οι περισσότεροι ολοκληρώνουν το Learn to Code σε 12 έως 20 εβδομάδες, με περίπου 5 έως 10 ώρες την εβδομάδα. Το Learn to Build είναι συνεχές, οπότε μπορείς να μπαινοβγαίνεις καθώς ανεβαίνουν νέα επεισόδια και να συμμετέχεις σε ζωντανές μεταδόσεις όποτε σου βολεύει.

### Πόσο δύσκολο είναι το μάθημα; Πόσο έξυπνος χρειάζεται να είμαι;

Το μάθημα είναι σχεδιασμένο για να είναι προσβάσιμο σε όλους, ανεξάρτητα από το υπόβαθρό σου. Δεν πιστεύουμε ότι χρειάζεται να είσαι "έξυπνος" για να μάθεις προγραμματισμό. Αλλά πρέπει να καταβάλεις προσπάθεια και να είσαι πρόθυμος να προκληθείς.

Αν καταβάλεις την προσπάθεια, ζητήσεις βοήθεια όταν κολλήσεις και αγκαλιάσεις την πρόκληση, θα εκπλαγείς με το πόσο μακριά μπορείς να φτάσεις σε σύντομο χρονικό διάστημα.

### Είναι το Jiki διαθέσιμο τώρα;

Ναι, μπορείς να εγγραφείς και να ξεκινήσεις το δωρεάν πρόγραμμα Learn to Code σήμερα.

Η πρώτη συνεδρία του Learn to Build θα γίνει στα μέσα Ιουνίου. Μπορείς να εγγραφείς για υπενθύμιση μόλις μπεις μέσα.

### Έχω ήδη εγγραφεί στο Bootcamp. Είναι διαφορετικό αυτό;

Σε ευχαριστούμε που είσαι μέλος του Bootcamp! Το Jiki είναι το επόμενο στάδιο στην εξέλιξη του Bootcamp μας. Οι περισσότερες ασκήσεις που έλυσες θα εμφανιστούν στο Jiki, μαζί με πολλές ακόμα. Επίσης, χωρίσαμε τα τρίωρα βίντεο σε μικρότερα τμήματα, διάρκειας 5-10 λεπτών, για να γίνει η παρακολούθηση ευκολότερη!

Ως μέλος του Bootcamp, θα λάβεις αυτόματα Jiki Premium for Life. Αυτό ισχύει τόσο για το αρχικό μάθημα Learn to Code όσο και για τα μελλοντικά μαθήματα.

## Jiki Premium

### Μπορώ να δοκιμάσω το Jiki δωρεάν;

Ναι! Μπορείς να εγγραφείς δωρεάν και να χρησιμοποιείς το βασικό πρόγραμμα για όσο θέλεις. Αναβάθμισε σε Premium όποτε χρειαστείς πλήρη πρόσβαση, χωρίς καμία δέσμευση.

### Υπάρχει ελάχιστη διάρκεια σύμβασης;

Δεν υπάρχει ελάχιστη διάρκεια σύμβασης. Το Premium χρεώνεται μηνιαία και μπορείς να το ακυρώσεις οποιαδήποτε στιγμή από τις ρυθμίσεις του λογαριασμού σου.

### Τι συμβαίνει αν ακυρώσω τη συνδρομή μου στο Premium;

Θα διατηρήσεις την πρόσβαση Premium μέχρι το τέλος της τρέχουσας περιόδου χρέωσής σου, και μετά ο λογαριασμός σου θα επιστρέψει στο βασικό πρόγραμμα. Δεν χάνεις καμία από την πρόοδό σου, απλώς χάνεις την πρόσβαση στις λειτουργίες που είναι αποκλειστικά για Premium.

### Προσφέρετε εκπτώσεις για φοιτητές ή για όσους δεν μπορούν να ανταποκριθούν στο κόστος του Premium;

Θέλουμε το Jiki να είναι προσβάσιμο σε όλους. Αν το κόστος αποτελεί εμπόδιο, [επικοινώνησε μαζί μας](/articles/support) και θα κάνουμε ό,τι μπορούμε για να βοηθήσουμε.

### Μπορώ να αναβαθμίσω ή να υποβαθμίσω αργότερα;

Φυσικά. Μπορείς να αναβαθμίσεις σε Premium οποιαδήποτε στιγμή από τον λογαριασμό σου και να ακυρώσεις εξίσου εύκολα όποτε θελήσεις.

## Έχεις ακόμα απορίες;

Η ερώτησή σου δεν απαντήθηκε εδώ; [Στείλε μας ένα email](mailto:hello@jiki.io) και θα σου απαντήσουμε.
