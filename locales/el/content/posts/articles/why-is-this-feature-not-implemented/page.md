Δοκίμασες να τρέξεις τον κώδικά σου και έλαβες ένα μήνυμα που λέει ότι κάτι δεν είναι διαθέσιμο σε αυτήν την έκδοση της γλώσσας; Συνέχισε να διαβάζεις για να καταλάβεις τι συμβαίνει!

Αν έλαβες ένα μήνυμα που λέει "This feature isn't available to you yet", αυτή είναι μια διαφορετική κατάσταση - διάβασε αντί γι' αυτό **[Πότε Θα Ξεκλειδωθεί Αυτή η Λειτουργία;](/articles/when-will-this-feature-unlock)**.

## Εισαγωγή

Χρησιμοποίησες μια λέξη-κλειδί ή μια έννοια που δεν υποστηρίζεται από τη δική μας έκδοση της γλώσσας. Μην ανησυχείς - δεν είναι bug!

Οι εκδόσεις της JavaScript και της Python που χρησιμοποιείς στο Jiki έχουν **σχεδιαστεί ειδικά από εμάς** για να σε βοηθήσουν να μάθεις. Έχουμε αφαιρέσει προσεκτικά ορισμένα χαρακτηριστικά για να μην πέσεις κατά λάθος πάνω σε πολύπλοκα ή μπερδεμένα σημεία της γλώσσας πριν είσαι έτοιμος γι' αυτά.

## Γιατί αποκλείουμε χαρακτηριστικά;

Οι γλώσσες προγραμματισμού έχουν σχεδιαστεί για **επαγγελματίες**. Περιέχουν προχωρημένα χαρακτηριστικά που βοηθούν τους έμπειρους προγραμματιστές να δουλεύουν πιο γρήγορα, καθώς και ιστορικό βάρος - χαρακτηριστικά που πιθανότατα θα έπρεπε να είχαν αφαιρεθεί χρόνια πριν, αλλά παραμένουν για να συνεχίσουν να λειτουργούν τα παλιά συστήματα.

Όταν μαθαίνεις, αυτά τα χαρακτηριστικά δημιουργούν σύγχυση. Αφαιρώντας τα, το Jiki σου επιτρέπει να εστιάσεις σε αυτό που έχει σημασία: **να μάθεις να σκέφτεσαι σαν προγραμματιστής**.

### Foot-guns

Ονομάζουμε κάποια χαρακτηριστικά **"foot-guns"** - πράγματα με τα οποία μπορείς κατά λάθος να πυροβολήσεις το πόδι σου. Αυτά είναι:

- **Πραγματικά προβληματικά** και καλύτερα να τα αποφεύγεις ακόμα κι αν είσαι επαγγελματίας
- **Μπερδεμένες οριακές περιπτώσεις** που αποσπούν την προσοχή από τις βασικές έννοιες
- **Ιστορικό βάρος** που υπάρχει μόνο για συμβατότητα με παλιότερες εκδόσεις

Αυτά αποκλείονται οριστικά από το Jiki γιατί απλά δεν αξίζουν τη σύγχυση που προκαλούν.

### Προχωρημένα χαρακτηριστικά

Άλλα χαρακτηριστικά αποκλείονται επειδή είναι **πολύ προχωρημένα** για το σημείο που βρίσκεσαι στο ταξίδι μάθησής σου. Αυτά δεν είναι κακά χαρακτηριστικά - απλά δε βοηθούν όταν μαθαίνεις τα βασικά.

Καθώς προχωράς στο Jiki, ορισμένα από αυτά τα χαρακτηριστικά θα ξεκλειδωθούν. Αλλά προς το παρόν, εστίασε στο να κατακτήσεις τα βασικά.

## Οι λεπτομέρειες

Δε χρειάζεται να το διαβάσεις αυτό εκτός αν σε ενδιαφέρει ενεργά τι συμβαίνει κάτω από το καπό και οι αποφάσεις που έχουμε πάρει.

### JavaScript

| Χαρακτηριστικό | Γιατί αποκλείεται |
| --- | --- |
| `var` | Χρησιμοποίησε `let` ή `const` αντ' αυτού. Το `var` έχει μπερδεμένους κανόνες εμβέλειας που προκαλούν bugs ακόμη και σε έμπειρους προγραμματιστές. |
| `with` | Αποδοκιμασμένο και μπερδεμένο. Δημιουργεί ασαφή κώδικα που είναι δύσκολο να τον κατανοήσεις. |
| `debugger` | Εργαλείο ανάπτυξης, δε χρειάζεται για μάθηση. |
| `void` | Σπάνια χρήσιμο και μπερδεύει τους αρχάριους. |
| `yield` | Προχωρημένο χαρακτηριστικό των γεννητριών. Θα μάθεις για τις γεννήτριες αργότερα στο ταξίδι σου. |
| `delete` | Μπορεί να προκαλέσει μπερδεμένη συμπεριφορά με πίνακες και αντικείμενα. |
| `import` / `export` | Χαρακτηριστικά συστήματος ενοτήτων. Το Jiki χειρίζεται τις ενότητες διαφορετικά για να κρατήσει τα πράγματα απλά. |
| Τελεστές bitwise (`&`, `\|`, `^`, `~`, `<<`, `>>`, `>>>`) | Δε χρειάζονται σχεδόν ποτέ και προκαλούν σύγχυση όταν μαθαίνεις. Αυτοί είναι για χειρισμό bit χαμηλού επιπέδου. |

### Python

| Χαρακτηριστικό | Γιατί αποκλείεται |
| --- | --- |
| `global` | Η τροποποίηση καθολικών μεταβλητών μέσα από συναρτήσεις οδηγεί σε μπερδεμένο κώδικα. Μάθε να περνάς τιμές ως παραμέτρους αντ' αυτού. |
| `nonlocal` | Προχωρημένο χαρακτηριστικό εμβέλειας για εμφωλευμένες συναρτήσεις. Δε χρειάζεται όταν μαθαίνεις τα βασικά. |
| `assert` | Εργαλείο αποσφαλμάτωσης που μπορεί να απενεργοποιηθεί στην παραγωγή. Μάθε σωστή διαχείριση σφαλμάτων αντ' αυτού. |

## Τι γίνεται αν χρειάζομαι ένα χαρακτηριστικό;

Κάθε άσκηση στο Jiki έχει σχεδιαστεί για να μπορεί να λυθεί με τα χαρακτηριστικά που έχεις διδαχθεί μέχρι εκείνο το σημείο. Αν βρίσκεις έναν περιορισμό, συνήθως υπάρχει ένας καλύτερος τρόπος να λύσεις το πρόβλημά σου χρησιμοποιώντας τα διαθέσιμα χαρακτηριστικά. Αυτό είναι μέρος της μάθησης - να ανακαλύπτεις πώς να δουλεύεις μέσα σε περιορισμούς.

Αν πιστεύεις πραγματικά ότι ένα χαρακτηριστικό θα έπρεπε να είναι διαθέσιμο στο επίπεδό σου, πες το μας! Πάντα βελτιώνουμε το τι περιλαμβάνεται με βάση τα σχόλια.
