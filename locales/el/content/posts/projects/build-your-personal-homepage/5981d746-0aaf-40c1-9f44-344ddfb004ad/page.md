## Εισαγωγή

Καλώς ήρθες στο πρώτο επεισόδιο αυτής της νέας σειράς, όπου βλέπουμε πώς χρησιμοποιούμε πράκτορες και πώς χρησιμοποιούμε τα LLM για να φτιάχνουμε πράγματα σε αυτή τη σύγχρονη εποχή, όπου ο προγραμματισμός έχει αλλάξει τόσο πολύ. Έχουμε κάνει πολλές τέτοιες συνεδρίες όλα αυτά τα χρόνια για το Exercism, αλλά αυτή είναι η πρώτη επίσημη ζωντανή συνεδρία Learn to Build για το Jiki.

Άσε με να σου εξηγήσω τι θα είναι αυτή η σειρά, τι καλύπτουμε σήμερα συγκεκριμένα, τι θα καλύψουμε σε όλη τη σειρά, και για ποιον είναι. Θα ξεκινήσω από αυτό το τελευταίο.

## Για ποιον είναι

Είναι ουσιαστικά για δύο ομάδες ανθρώπων. Για όσους είναι εντελώς καινούργιοι στον προγραμματισμό, καινούργιοι σε όλον αυτόν τον κόσμο, και απλώς θέλουν να ξεκινήσουν και να βρουν πώς μπορούν να αρχίσουν να μαθαίνουν. Αλλά είναι και για ανθρώπους, ίσως πολύ πιο έμπειρους, ακόμη και senior προγραμματιστές, που δεν έχουν μπει ακόμη στις αλλαγές που φέρνει ο προγραμματισμός με πράκτορες και θέλουν να μάθουν τι συμβαίνει, να δουν κάποια πράγματα στην πράξη, να τα συζητήσουν, και να χτίσουν μια πραγματική κατανόηση. Οπότε μπορεί να βρίσκεσαι οπουδήποτε πάνω σε αυτό το φάσμα, από την πρώτη σου μέρα στον προγραμματισμό, ίσως αποφάσισες να προγραμματίσεις σήμερα το πρωί, βρήκες το Jiki και να 'σαι εδώ, μέχρι κάποιον πραγματικά πολύ έμπειρο.

Σε αυτή τη συγκεκριμένη σειρά (θα υπάρξουν αρκετές σειρές) θα θεωρήσω ότι δεν ξέρεις τίποτα. Αν λοιπόν είσαι senior προγραμματιστής, θα λέω πολλά πράγματα που τα ξέρεις απ' έξω κι ανακατωτά, και ίσως σου φανούν λίγο βαρετά. Αν είναι η πρώτη σου μέρα, δεν θα υπάρχει τίποτα που να θεωρώ δεδομένο ότι το ξέρεις. Μπορεί κάποια πράγματα να σου φανούν δυσνόητα, αλλά αντιμετωπίζω αυτή τη συνεδρία σαν να είναι για σένα. Και αν δεν έχεις ξαναδοκιμάσει αυτόν τον νέο τρόπο προγραμματισμού και είσαι πιο έμπειρος, πάλι θα σου φανεί χρήσιμο.

Θα σου δείξω λίγο τι σημαίνει να προγραμματίζεις έτσι. Θα σου δείξω δύο τρία παραδείγματα με πράγματα που πρέπει να τακτοποιήσω αυτή τη στιγμή στο Jiki, και θα τα διορθώσω, σαν ένα μικρό προοίμιο. Μετά θα συζητήσουμε κάποιους από τους όρους που χρησιμοποιούμε και πώς όλα αυτά δένουν μεταξύ τους. Και μετά θα πάμε να φτιάξουμε κάτι. Θα φτιάξουμε μια νέα αρχική σελίδα.

Αυτό είναι κάτι που θέλω να ενθαρρύνω τους πάντες να κάνουν. Φτιάξε τον δικό σου νέο ιστότοπο. Μπορεί να είναι η αρχική σου σελίδα. Μπορεί να είναι κάτι άλλο. Ίσως απλώς ένα βιογραφικό σε κώδικα, ό,τι θέλεις. Μετά από αυτή τη συνεδρία, βάλε σε εφαρμογή όσα είδες εδώ και δοκίμασε πράγματα.

Εγώ θα χρησιμοποιήσω το Claude και κάποια πιο προχωρημένα εργαλεία, αλλά θα σου δείξω και πώς μπορείς να τα κάνεις όλα αυτά αν δεν έχεις χρήματα να ξοδέψεις. Αν θέλεις να δουλέψεις με πράκτορες δωρεάν, θα δούμε και αυτό.

### Τι πρέπει να έχεις ετοιμάσει από πριν;

Απολύτως τίποτα. Απλώς εμφανίζεσαι. Θα σου εξηγήσω εγώ τα πράγματα, και μετά θα δημοσιεύσω μια σειρά από οδηγούς που συνοδεύουν αυτό το επεισόδιο. Οδηγούς για το πώς εγκαθιστάς το OpenCode, που θα το δούμε παρακάτω, οδηγούς για τους διάφορους όρους γύρω από τα LLM και για το πώς λειτουργούν, και έναν οδηγό για το πώς χρησιμοποιείς το GitHub, για το οποίο θα μιλήσουμε επίσης. Θα μπορέσεις να αφιερώσεις δυο τρεις μέρες για να τα προλάβεις όλα και να τα δουλέψεις.

Αν έχεις μια ερώτηση που δεν την απαντάω σε αυτό το επεισόδιο, μπορείς πάντα να μπεις στο φόρουμ στο [forum.jiki.io](https://forum.jiki.io) και να τη ρωτήσεις εκεί. Εγώ είμαι εκεί. Είναι και άλλοι senior προγραμματιστές και άλλοι που παρακολουθούν, και μπορούν κι εκείνοι να απαντήσουν σε ερωτήσεις.

Κάνουν λάθη με συνέπεια. Κάποια είναι προφανή και αστεία, κάποια όχι. Αν θέλεις να είσαι σύγχρονος προγραμματιστής λογισμικού, μεγάλο μέρος της δουλειάς σου είναι να ψάχνεις αυτά τα λάθη. ### Τι σημαίνει i18n;

Σημαίνει internationalization (διεθνοποίηση). Το 18 είναι το πλήθος των γραμμάτων που μεσολαβούν ανάμεσα στο i και στο n. Είναι μια συντόμευση.

Αυτό που θέλω να σου δείξω είναι το εξής. Μπορώ να σύρω μέσα την εικόνα και να πω "διόρθωσε το λάθος emoji". Και αυτό θα φύγει, θα σκεφτεί και θα κάνει πολλά πράγματα. ## Να είσαι έξυπνος με το κόστος

Πριν πάρουμε ένα διαφορετικό παράδειγμα, άσε με να σου δείξω ένα πράγμα. Μπορώ να γράψω `usage` εδώ, και το usage μας δείχνει τι γίνεται από κάτω. Βλέπεις ότι αυτό πήρε 52 δευτερόλεπτα από την αρχή ως το τέλος για να το κάνει το Claude, και κόστισε 37 σεντς. Τώρα, εγώ είμαι στο Claude Max, που σημαίνει ότι έχω πολύ μεγάλο περιθώριο χρήσης στα διάφορα μοντέλα. Οπότε δεν χρεώνομαι 37 σεντς γι' αυτό. Απλώς περιλαμβάνεται στη μηνιαία συνδρομή μου.

![Η οθόνη χρήσης του Claude Code δείχνει συνολικό κόστος 0,38 δολαρίων και 52 δευτερόλεπτα χρόνου API για τη διόρθωση του emoji.](/images/projects/build-your-personal-homepage/setting-up-the-project/claude-code-usage.webp)

Αυτό όμως είναι κάτι που θέλω να το έχεις υπόψη σου από την αρχή, καθώς αρχίζουμε να μιλάμε γι' αυτά. Η διαδικασία να τα βρει όλα αυτά και να τα λύσει κόστισε 37 σεντς. Αν ήθελα, θα μπορούσα απλώς να πάω στο φόρουμ και να επεξεργαστώ το θέμα μόνος μου. Θα μπορούσα να διαλέξω το emoji, να γράψω "Indonesia", και να κάνω κλικ στη σημαία. Αυτό δεν θα μου κόστιζε 37 σεντς. Αν σκεφτείς κάθε ένα πράγμα που κάνω ως προγραμματιστής, όσες ώρες τη μέρα κι αν προγραμματίζουμε, μάλλον θέλουμε να είμαστε κάπως έξυπνοι με το για ποια πράγματα χρησιμοποιούμε αυτή την πανίσχυρη νοημοσύνη και ποια μπορούμε απλώς να τα κάνουμε μόνοι μας με το χέρι.

Αυτό ισχύει ιδιαίτερα για όσους από εσάς δεν πληρώνετε συνδρομή Claude Max και δεν έχετε πολλά χρήματα. Θα σου δείξω πώς μπορείς να τα κάνεις όλα αυτά δωρεάν. Όταν όμως είσαι σε δωρεάν πλάνα, θα έχεις περιορισμένη χρήση. Είναι αρκετά μεγάλη περιορισμένη χρήση. Είναι όλα όσα χρειάζεσαι. Θέλω όμως να μπεις στη νοοτροπία του να μη σπαταλάς αυτή τη χρήση σε πράγματα που μπορείς να κάνεις μόνος σου. Είναι πολύ καλύτερο για σένα να ερευνήσεις μόνος σου, να καταλάβεις τι συμβαίνει, να μάθεις κάτι στην πορεία, και μετά να διορθώσεις εκείνο το πράγμα. Αυτός είναι ο καλύτερος τρόπος για να μάθεις. Αν αρχίσεις να τα πετάς όλα σε αυτό, θα βρεθούμε σε δύσκολη θέση.

Άσε με να σου δείξω κάτι ακόμη. Αυτό σου δείχνει ποια είναι η μηνιαία σου χρήση. Αυτός είναι ο τελευταίος μήνας για μένα. Όπως λέω, είμαι σε αυτό το πλάνο Claude Max, οπότε πληρώνω απλώς ένα σταθερό ποσό 200 δολαρίων τον μήνα. Αν όμως δεν ήμουν στο Claude Max, αν πλήρωνα απευθείας, θα μου κόστιζε 35.000 δολάρια αυτόν τον μήνα. Αυτά είναι τρία δισεκατομμύρια tokens που χρησιμοποίησα αυτόν τον μήνα. Θα μιλήσουμε σε λίγο για το τι είναι τα tokens. Αλλά μπορείς πολύ γρήγορα να μαζέψεις μεγάλους λογαριασμούς.

### Τι γίνεται με το Ollama και τα άλλα τοπικά μοντέλα;

Αυτά δουλεύουν. Αν έχεις αρκετά ισχυρό υπολογιστή για να τρέξεις τοπικά μοντέλα, ένα καλό MacBook ή ένα καλό μηχάνημα με Windows και καλή GPU, μπορείς να τρέχεις μοντέλα στον υπολογιστή σου αντί να στέλνεις δεδομένα στο Claude και το Claude να σου στέλνει δεδομένα πίσω. Θα είναι όμως πολύ, πολύ πιο αργά. Εκείνο που μόλις είδαμε και πήρε 52 δευτερόλεπτα θα παίρνει 5 λεπτά, ή μισή ώρα. Ακόμη και σε ένα μηχάνημα τελευταίας τεχνολογίας μιλάμε για 10, 20, 30 φορές πιο αργά σε σχέση με το Claude ή κάτι αντίστοιχο.

### Δεν βγαίνει καμιά φορά φθηνότερα να προσλάβεις έναν junior προγραμματιστή αντί να πληρώνεις για ένα LLM;

Ναι, ακριβώς. Είναι πιο έξυπνα, είναι καλύτερα, αλλά είναι και πιο ακριβά και γενικά πιο αργά. Και πρέπει να θυμάσαι ότι το σημερινό μοντέλο αιχμής είναι το φθηνό μοντέλο του χρόνου. Αυτό ισχύει ήδη. Το Haiku είναι αντίστοιχο με το περσινό μοντέλο αιχμής. Άρα το Haiku είναι ήδη αρκετά καλό για πολλή δουλειά προγραμματισμού, παρόλο που είναι το φθηνό μοντέλο στο άλλο άκρο. Χρειάζεσαι εκείνο το ακριβό μοντέλο μόνο αν κάνεις κάτι που ήταν πραγματικά αδύνατο στο προηγούμενο μοντέλο, όπως το Opus. Θέλεις πραγματικά να πιάνεις το μοντέλο αιχμής μόνο σε συγκεκριμένες καταστάσεις.

### Για κάποιον έμπειρο, δεν είναι απογοητευτικό να πληρώνει για προγραμματισμό αντί να τον κάνει μόνος του;

Πληρώνω 200 δολάρια τον μήνα. Αν και είναι σημαντικό ποσό, είναι μικρό ποσό για την επιπλέον παραγωγικότητα που δημιουργεί. Νομίζω ότι φτάνω πια στο σημείο να είμαι τουλάχιστον μιάμιση φορά πιο παραγωγικός. Η απόδοσή μου είναι μιάμιση φορά αυτό που ήταν. Δεν ξέρω ποιος θα ήταν ο μισθός μου στην ανοιχτή αγορά, γιατί δεν έχω δουλέψει ποτέ σε μισθωτή θέση, αλλά φαντάζομαι ότι μου εξοικονομεί μια περιουσία αν αυτό είναι το μέτρο. Οπότε τα 200 δολάρια είναι φθηνά. Αν έπρεπε να πληρώνω 2.000 δολάρια τον μήνα γι' αυτό, μάλλον δεν θα άξιζε για μένα.

Είναι φοβερά απογοητευτικό πολλές φορές; Ναι. Αυτό όμως που συνειδητοποίησα είναι ότι απλώς με ανεβάζει ένα επίπεδο αφαίρεσης. Πριν, υπήρχε πολύς προγραμματισμός που θα έπρεπε να κάνω και που για μένα ήταν πραγματικά βαρετός. Μπορεί να είναι πολύ ενδιαφέρων για έναν junior ή έναν μεσαίου επιπέδου προγραμματιστή, αλλά για μένα ήταν υπερβολικά βαρετός. Τώρα δεν χρειάζεται να τον κάνω, και δεν χρειάζεται να έχω έναν junior ή έναν μεσαίου επιπέδου προγραμματιστή να διαχειρίζομαι. Μπορώ απλώς να το τελειώνω αυτό πολύ εύκολα χωρίς να χρειάζεται να έχω άλλους ανθρώπους να διαχειρίζομαι, που σημαίνει ότι είμαι ακόμη ελεύθερος να είμαι παραγωγικός με άλλους τρόπους. Οπότε το καθαρό όφελος αξίζει για μένα.

Νομίζω όμως ότι για πολλούς προγραμματιστές είναι πολύ λιγότερο διασκεδαστικό, πολύ λιγότερο ευχάριστο απ' ό,τι ήταν. Είναι επίσης απλώς η πραγματικότητα του κόσμου. Δεν έχουμε επιλογή. Ίσως κάποιοι έχουν την πολυτέλεια σε κάποιες δουλειές να μην το κάνουν αυτό. Αν πας 10 χρόνια μπροστά, δεν νομίζω ότι θα έχουν πολλοί αυτή την πολυτέλεια. Αν λοιπόν θέλεις να θωρακίσεις το μέλλον σου, ή θέλεις να προχωρήσεις στον κλάδο, το να γίνεις καλός σε αυτό είναι, νομίζω, το μυστικό.

## Δικαιώματα και αυτόματη λειτουργία

Και επειδή το είχα αφήσει σε αυτόματη λειτουργία, να δουλεύει ακούραστα, δεν με ρώτησε αν συμφωνώ. Οπότε το μπλόκαρε. Ρωτάει "θέλεις να προχωρήσω και να δημιουργήσω εκείνη την ανάρτηση στο φόρουμ;", λέω ναι, και τώρα θα πάει πραγματικά να το κάνει. ## Claude Code, Codex και OpenCode

Αυτή είναι η γενική μου επισκόπηση για το πώς δουλεύουν όλα αυτά. Τώρα θέλω να σου δείξω πώς μπορείς να τα στήσεις για τον εαυτό σου.

Υπάρχουν πολλοί διαφορετικοί πράκτορες και διαφορετικά εργαλεία που μπορείς να χρησιμοποιήσεις. Ας ξεκαθαρίσουμε λοιπόν τη γλώσσα μας εδώ. Το Claude Code, το παράθυρο μέσα στο οποίο με είδες μόλις να δουλεύω, είναι ένα εργαλείο προγραμματισμού με πράκτορες, ίσως μια πλατφόρμα προγραμματισμού με πράκτορες. Τρέχει στον υπολογιστή σου. Κανονικά τρέχει στο τερματικό, έτσι το έχω στημένο εγώ. Μπορούμε να το τρέξουμε και μέσα σε έναν επεξεργαστή κώδικα, που θα το δούμε σε λίγο. Και είναι η πύλη ανάμεσα σε σένα και τα μοντέλα. Σου έδειξα ότι μπορώ να αλλάζω ανάμεσα σε Opus, Sonnet, Haiku, και μπορώ να αλλάζω επίπεδα προσπάθειας.

Όλα αυτά συμβαίνουν στον τοπικό σου υπολογιστή. Μιλάς στον τοπικό σου υπολογιστή. Εκείνος στέλνει δεδομένα στην Anthropic, σε ένα από τα μοντέλα της. Αυτό που στέλνουν πίσω δεν είναι απλώς λίγο κείμενο που εμφανίζεται στην οθόνη. Στέλνουν πίσω ένα σωρό εντολές που το Claude Code μπορεί να ερμηνεύσει ώστε να κάνει πράγματα. Λένε: πήγαινε και τρέξε αυτό το script στον υπολογιστή του ανθρώπου. Πήγαινε και κοίταξε σε αυτόν τον φάκελο στον υπολογιστή του ανθρώπου. Πήγαινε σε αυτόν τον ιστότοπο εδώ και κάνε κάποια πράγματα. Όλες αυτές οι εντολές έρχονται πίσω από το Claude.

Δεν κάνουμε λοιπόν μια συζήτηση με το Opus ή με το Sonnet ή με το Haiku. Βάζουμε κάποιο κείμενο μέσα. Εκείνο το κείμενο πακετάρεται μαζί με ένα σωρό άλλα πράγματα. Πακετάρεται μαζί με κώδικα από το αποθετήριό μας, κώδικα που έχουμε γράψει ή που έχει μπει εκεί. Πακετάρεται μαζί με όλο το ιστορικό της συζήτησης, με τους στόχους που προσπαθούμε να πετύχουμε, με τις προτιμήσεις μας για το πώς μας αρέσει να δουλεύουμε. Όλα αυτά πακετάρονται, και μετά όλα αυτά στέλνονται στην Anthropic. Τα μοντέλα τους διαβάζουν όλα αυτά και μετά φέρνουν πίσω εντολές και λίγο κείμενο. Όλα αυτά επεξεργάζονται, και μετά γίνεται αυτός ο βρόχος, αυτός ο βρόχος με πράκτορες, όπου κάνει κάτι, γυρίζει πίσω στο Claude, το Claude γυρίζει και λέει εντάξει, τώρα κάνε αυτό. Όλα αυτά γίνονται μακριά από εμάς. Και στο τέλος, μας λέει: εντάξει, τελειώσαμε. Δεν μπορέσαμε να στείλουμε την ανάρτηση στο φόρουμ γι' αυτόν τον λόγο. Θέλεις να συνεχίσουμε; Υπάρχει όλος αυτός ο τεράστιος βρόχος που τρέχει στο παρασκήνιο.

Έχουμε λοιπόν δύο αποφάσεις. Η μία απόφαση είναι ποια μοντέλα θέλουμε να χρησιμοποιήσουμε. Θέλουμε να χρησιμοποιήσουμε την Anthropic, την OpenAI, ή άλλα μοντέλα στο παρασκήνιο; Και η δεύτερη απόφαση είναι με ποιο εργαλείο θέλουμε να αλληλεπιδρούμε. Αν χρησιμοποιώ το Claude Code, αλληλεπιδρώ πάντα με ένα από τα μοντέλα της Anthropic. Αν χρησιμοποιώ το Codex, που είναι η εκδοχή της OpenAI, αλληλεπιδρώ πάντα με ένα από τα μοντέλα της OpenAI, ένα από τα μοντέλα GPT.

Αυτό που θα σου προτείνω να χρησιμοποιήσεις είναι κάτι άλλο, που λέγεται OpenCode. Το OpenCode είναι, αν θέλεις, μια εκδοχή ανοιχτού κώδικα του Claude Code, μια εκδοχή ανοιχτού κώδικα του Codex. Είναι το περίβλημα, το εργαλείο που κάθεται στον υπολογιστή σου και κάνει όλον αυτόν τον βρόχο, που τα διαχειρίζεται όλα. Μπορεί όμως να μιλήσει σε οποιοδήποτε μοντέλο. Μπορεί να μιλάει στην Anthropic, στο Opus ή στο Sonnet. Μπορεί να μιλάει στο GPT-5 και σε όλα εκείνα. Μπορεί όμως να μιλάει και σε πολλά δωρεάν μοντέλα. Το ίδιο το OpenCode είναι δωρεάν, και έχει και μια σειρά από δωρεάν μοντέλα που μπορείς να χρησιμοποιήσεις.

Φτάνουμε στο OpenCode απλώς πηγαίνοντας σε ένα τερματικό και γράφοντας `opencode`, αφού πρώτα το εγκαταστήσουμε. Και μπορούμε να διαλέξουμε ανάμεσα σε πολλά μοντέλα. Μπορούμε να διαλέξουμε το Gemini, που είναι της Google. Μπορούμε να διαλέξουμε το Opus, για το οποίο μόλις μιλήσαμε, ή το Fable. Μπορούμε να διαλέξουμε το Grok, αν θέλεις να στηρίξεις τον Έλον Μασκ. Τα GPT. Το DeepSeek, ένα μοντέλο που βγήκε περίφημα από την Κίνα. Το Qwen, πολύ καλό για προγραμματισμό. Και όλες αυτές τις επιλογές στην κορυφή, που είναι οι δωρεάν. Αν λοιπόν δεν έχεις πολλά χρήματα, ή αν θέλεις απλώς να το δοκιμάσεις, ή αν η δουλειά σου δεν πληρώνει συνδρομή, μπορείς να πάρεις το OpenCode δωρεάν και μετά να διαλέξεις ένα από αυτά τα δωρεάν μοντέλα.

Έχω έναν οδηγό που θα δημοσιεύσω και που εξηγεί πώς εγκαθιστάς το OpenCode, πώς ξεκινάς δωρεάν, και ποια από αυτά τα μοντέλα μπορείς να χρησιμοποιήσεις. Προτείνω το DeepSeek V4 Flash (δωρεάν) για την ώρα, αλλά δεν τα έχω δοκιμάσει σχεδόν καθόλου, οπότε μπορείς να τα δοκιμάσεις μόνος σου και να δεις τι σου ταιριάζει.

Μια επιφύλαξη: αυτά τα δωρεάν δεν είναι μοντέλα αιχμής. Αν και το Big Pickle είναι μυστικό μοντέλο, οπότε μπορεί και να είναι μοντέλο αιχμής, δεν ξέρουμε. Τα υπόλοιπα όμως δεν είναι μοντέλα αιχμής. Δεν είναι τα κορυφαία, τα καλύτερα μοντέλα. Θα μοιάζουν πιο πολύ με το Haiku ή το Sonnet, μοντέλα χαμηλότερου επιπέδου. Αλλά για το σημείο στο οποίο βρίσκεσαι, νομίζω ότι αυτό είναι πολύ καλό. Γιατί τα βήματα που θέλεις να κάνεις είναι μικρά βηματάκια, όπου δεν θέλεις μια υπερνοημοσύνη να τα κάνει όλα για σένα. Θέλεις κάποιον με τον οποίο μπορείς να δουλεύεις και να μιλάς, όπου μπορείς να προχωράς βηματάκι βηματάκι, να ρωτάς πώς δουλεύουν τα πράγματα, και να μαθαίνεις.

## Tokens και context

Άσε με να σου δείξω το OpenCode μέσα στο αποθετήριο του translator. Αυτό δεν ξέρει τίποτα για το αποθετήριό μου. Μπορώ όμως να πω κάτι σαν "πόσες γλώσσες έχουμε μέχρι τώρα;" και αυτό θα φύγει. Έτσι μοιάζει το OpenCode. Έχουμε ένα κομμάτι που μιλάει στα αριστερά. Έχουμε το κομμάτι που γράφουμε κάτω αριστερά. Όταν τρέχει, έχουμε ένα κομμάτι στα δεξιά. Μπορούμε να πατήσουμε Ctrl+P για να δούμε διάφορες εντολές και πράγματα με τα οποία μπορείς να παίξεις. Βλέπεις ότι είναι πολύ γρήγορο. Σκέφτηκε για μερικά χιλιοστά του δευτερολέπτου, διάβασε κάποια πράγματα, το βρήκε, και γύρισε με 14 γλώσσες. Αν επισημάνεις κάτι, το αντιγράφει στο πρόχειρο, που είναι βολικό.

![Το OpenCode στο τερματικό απαντά στο "How many languages do we have so far;", με ένα πλαίσιο context στα δεξιά που δείχνει 10.054 tokens σε χρήση.](/images/projects/build-your-personal-homepage/setting-up-the-project/opencode-ui.webp)

Βλέπεις ότι είναι δωρεάν, οπότε δεν ξοδέψαμε τίποτα. Θέλω όμως να δώσεις λίγη προσοχή στους αριθμούς στα δεξιά. Δεν θα εξηγήσω σε βάθος πώς δουλεύουν τα LLM, γιατί είναι μια τρύπα κουνελιού που δεν αξίζει να μπούμε. Η θεμελιώδης μονάδα ενός LLM όμως είναι το token. Μπορείς να σκέφτεσαι ένα token σαν μια συλλαβή. Το "How" είναι μάλλον ένα token. Το "Language" είναι μάλλον τρία tokens: lang-u-age, κάπως έτσι. Το "DeepSeek" μάλλον δύο tokens. Το "V4" μάλλον δύο tokens.

Κάθε φορά που γράφεις κάτι, παίρνει αυτό που έγραψες, παίρνει και ό,τι άλλο χρειάζεται για να βρει την απάντηση, και τα στέλνει όλα στο μοντέλο. Το μοντέλο τα διαβάζει, τα στέλνει πίσω, μάλλον κάνει μια διευκρινιστική ερώτηση, και πάει κι έρχεται λίγο. Χρησιμοποιεί tokens. Ρωτήσαμε "πόσες γλώσσες έχουμε μέχρι τώρα;". Αυτό είναι ίσως 11 tokens, ίσως με τα κενά 15 tokens. Μέχρι να τελειώσει το διάβασμα, να πάρει όλα όσα χρειαζόταν, να τα στείλει, να κάνει δυο τρεις γύρους, χρησιμοποίησε 10.000 tokens. Ουσιαστικά λοιπόν αυτό έστειλε ένα δοκίμιο 3.000 λέξεων σε ένα μοντέλο και μετά γύρισε πίσω λίγα πράγματα.

Αν κάνουμε μεγαλύτερη ερώτηση, όπως "ποια είναι η διαδικασία για να προσθέσουμε μια νέα γλώσσα;", φεύγει και διαβάζει περισσότερα αρχεία, και βλέπεις τα tokens να ανεβαίνουν καθώς διαβάζει. Αυτό πρόσθεσε άλλα 6.000 tokens για να απαντήσει στην ερώτηση, και έχει πλέον χρησιμοποιήσει το 10% του context μας. Το context αυτού του μοντέλου, ο μέγιστος αριθμός tokens που μπορεί να έχει σε μία συζήτηση, είναι περίπου 170.000 tokens.

Όταν δουλεύεις με αυτά, πρέπει να το προσέχεις λίγο. Καθώς χρησιμοποιείς όλο και περισσότερα tokens, όλη η συζήτηση θα γίνεται πιο αργή, γιατί όλο αυτό το context περνάει στο μοντέλο κάθε φορά. Αν ρωτήσω άλλο ένα πράγμα, όλες αυτές οι πληροφορίες στέλνονται ξανά στο μοντέλο. Όλη η προηγούμενη συζήτηση, όλες οι προηγούμενες απαντήσεις. Τα πάντα στέλνονται σε κάθε βήμα της συζήτησης.

Ένα από τα άλλα μειονεκτήματα των δωρεάν μοντέλων είναι ότι τείνουν να έχουν μικρότερο όγκο συζήτησης που μπορείς να κάνεις. Το Opus έχει 1 εκατομμύριο tokens ανά συζήτηση. Αυτό εδώ θα είναι πιο κοντά στα 150.000 ή 170.000. Οπότε θέλεις να ξεκινάς συνέχεια νέες συζητήσεις. Αν γράψεις `/new`, αυτό θα σου δώσει νέα συζήτηση. Μηδενίζει τα tokens σου, αλλά τότε το μοντέλο σου δεν ξέρει και τίποτα για όσα μόλις έγιναν. Θέλεις λοιπόν να προσπαθήσεις να αποκτήσεις τη συνήθεια να κάνεις μικρές συζητήσεις για διαφορετικά πράγματα.

### Δουλεύουν κι ο Άρον κι η Νικόλ έτσι στο Jiki;

Ναι. Ο Άρον το χρησιμοποιεί σχεδόν αποκλειστικά για κάθε δουλειά front end που κάνει. Η Νικόλ κάνει το ίδιο για το μοντάζ των βίντεο. Όλα μας τα βίντεο γράφονται σε κώδικα. Δεν φτιάχνουμε βίντεο σε πρόγραμμα μοντάζ. Τα φτιάχνουμε σε κώδικα, και μετά δουλεύει με το Claude για να χτίσει όλα τα βίντεο σε κώδικα από εκεί και πέρα.

### Τα δωρεάν μοντέλα είναι στο cloud;

Ναι, τα δωρεάν μοντέλα είναι όλα στο cloud. Θα ήταν πάρα πολύ αργά στα δικά σας μηχανήματα.

### Θα πρότεινες το Mistral;

Δεν ξέρω και πολλά για μοντέλα εκτός Anthropic. Εγώ προσωπικά δουλεύω απλώς με το Claude, καθημερινά. Δεν το έχω χρησιμοποιήσει ποτέ, οπότε δεν ξέρω. Προσωπικά θα χρησιμοποιούσα απλώς το Claude, αλλά μάλλον θα το χρησιμοποιούσα μόνο με συνδρομή, όπου δεν πληρώνω ανά token.

## Φτιάχνοντας την πρώτη σου ιστοσελίδα

Το πρώτο μισό ήταν μια βαθιά ματιά στο τι είναι τα LLM, τι είναι ο προγραμματισμός με πράκτορες, ο σύγχρονος βρόχος που χρησιμοποιούμε εμείς ως προγραμματιστές. Αυτό είναι πραγματικά που ελπίζω, τους επόμενους μήνες και μέσα στη χρονιά, να το νιώσεις άνετα. Αρκετά άνετα ώστε να φτιάχνεις οτιδήποτε. Θέλω όμως πραγματικά να τονίσω, πριν προχωρήσουμε, αυτή την ιδέα ότι το σημαντικό είναι να καταλαβαίνεις εσύ τι γίνεται από κάτω.

Έχω επίγνωση ότι σου έδωσα πολλές πληροφορίες σε εκείνο το πρώτο μισό. Στο δεύτερο μισό λοιπόν θα δούμε πώς φτιάχνεις μια αρχική σελίδα για σένα. Σκεφτόμουν σήμερα ότι θα προλαβαίναμε και κάποια άλλα κομμάτια, αλλά νομίζω ότι θα τα αφήσουμε για την επόμενη συνεδρία. ## Τι είναι μια ιστοσελίδα

Θέλω να μιλήσω λίγο εδώ για το τι είναι μια ιστοσελίδα και πώς δουλεύει. Στο επόμενο διάστημα, όσο κι αν κρατήσει, θα κάνουμε πολλή JavaScript, CSS, περίπλοκα πράγματα. Σήμερα κάνουμε τα πιο βασικά. Αν ξέρεις οτιδήποτε για ιστότοπους, αυτό μάλλον θα σου φανεί πολύ βασικό. Αν δεν ξέρεις τίποτα, ελπίζω να είναι μια καλή εισαγωγή για όσα ακολουθούν.

Ας μιλήσουμε λίγο για το τι είναι μια τυπική, απλή ιστοσελίδα. Γι' αυτό μπορούμε να χρησιμοποιήσουμε τον υπάρχοντα προσωπικό μου ιστότοπο. Είναι αρκετά απλός. Είναι απλώς λίγο κείμενο σε μια σελίδα. Μπορείς να πας σε οποιονδήποτε ιστότοπο, να κάνεις δεξί κλικ και να πας στο View Page Source, και θα δεις κάτι σαν αυτό, που είναι ένα σωρό πράγματα. Αυτό είναι HTML.

![Ο πηγαίος κώδικας HTML του προσωπικού ιστότοπου του Jeremy, με το doctype, τις ετικέτες head, τις ετικέτες meta και τον τίτλο.](/images/projects/build-your-personal-homepage/setting-up-the-project/ihid-page-source.webp)

Η HTML είναι διάσημη για αυτό το μικρότερο-από στην αρχή και το μεγαλύτερο-από στο τέλος των διάφορων πραγμάτων. Αυτό είναι που λέμε ετικέτα head. Μετά έχουμε λίγη CSS. Η CSS αφορά το στιλ. Θα μιλήσουμε γι' αυτό σε λίγο. Και μετά έχουμε όλο το περιεχόμενο της σελίδας. Αυτή είναι η κεφαλίδα. Βλέπεις την κεφαλίδα εδώ να είναι μοβ. Έχει μια εικόνα μέσα. Το `img` σημαίνει image, δηλαδή εικόνα, με έναν σύνδεσμο προς μια εικόνα. Έχει λίγο κείμενο, ένα βιογραφικό σημείωμα για μένα, και μετά κι άλλο κείμενο χωρισμένο σε παραγράφους. Το `p` σημαίνει paragraph, δηλαδή παράγραφος. Λίγες ακόμη πληροφορίες, κάποιες επικεφαλίδες. Αυτή είναι επικεφαλίδα δεύτερου επιπέδου, αυτή είναι επικεφαλίδα πρώτου επιπέδου. Και αυτό εδώ κάτω είναι JavaScript, που θα σου φανεί κάπως οικείο αν έχεις κάνει τα Coding Fundamentals.

Όταν κάναμε το bootcamp πέρσι και κάναμε τα βασικά του web dev, αφιερώσαμε πολύ χρόνο κοιτάζοντας αυτή την HTML σε μεγάλο βάθος, και τη CSS σε μεγάλο βάθος. Φροντίζαμε να καταλάβεις όλες τις διαφορετικές ετικέτες και πώς δουλεύουν. Επίσης να καταλάβεις τη CSS και πώς μπορούμε να τη χρησιμοποιήσουμε για να δίνουμε στιλ στα πράγματα.

Αυτό είναι ένα παράδειγμα του πώς νομίζω ότι τα πράγματα έχουν αντιστραφεί. Τώρα πιστεύω ότι αυτό που θέλουμε να κάνουμε είναι απλώς να φτιάχνουμε πράγματα, και μετά να κοιτάμε αυτό που φτιάξαμε και να καταλαβαίνουμε πώς είναι. Αντί λοιπόν για αυτό που θα πρότεινα παλιότερα, και που στην πραγματικότητα θα ήσουν αναγκασμένος να κάνεις παλιότερα, δηλαδή να αρχίσεις να τα γράφεις όλα αυτά, αυτό που προτείνω τώρα είναι να βάλουμε απλώς το LLM μας να μας φτιάξει μια πολύ, πολύ βασική δομή που μπορούμε να χρησιμοποιήσουμε.

## Να καταλάβουμε τι έφτιαξε

Θέλω να αφιερώσουμε ένα λεπτό, και αυτή είναι η νοοτροπία στην οποία θέλω να είσαι πάντα, να αφιερώνεις ένα λεπτό για να κοιτάξεις τι συμβαίνει εδώ. Ο τρόπος με τον οποίο θέλω να σε ενθαρρύνω να το κάνεις, τώρα που το έφτιαξες, είναι να πεις:

> Εξήγησέ μου τι κάνει το κάθε κομμάτι.

Μπορείς να χρησιμοποιήσεις αυτόν τον βρόχο όχι μόνο για να το βάζεις να κάνει πράγματα, αλλά και για να καταλαβαίνεις, για να χτίζεις γνώση πάνω στο πώς δουλεύουν τα πράγματα. Δεν θα έπρεπε να είναι και τόσο σύνθετη ερώτηση γι' αυτό, αφού α) μόλις το έγραψε, και β) είναι πολύ απλό. Και εξηγεί. Ορίστε.

Η πρώτη γραμμή, η ετικέτα doctype, λέει στο πρόγραμμα περιήγησης ότι αυτό είναι έγγραφο HTML5. Τι γίνεται λοιπόν εδώ πραγματικά; Τι είναι αυτή η HTML; Λοιπόν, αυτό το πρόγραμμα περιήγησης είναι ο Chrome (υπάρχουν και άλλα). Ξέρει πώς να διαβάζει ένα αρχείο HTML και πώς να το βάζει στην οθόνη με τρόπο που να μπορείς να το δεις. Η HTML είναι μια προδιαγραφή. Σημαίνει hypertext markup language, δηλαδή γλώσσα σήμανσης υπερκειμένου. Μοιάζει έτσι, με ένα σωρό ετικέτες και κομμάτια πληροφορίας, και ο Chrome, ή οποιοδήποτε άλλο πρόγραμμα περιήγησης, μπορεί να διαβάσει αυτές τις ετικέτες και να τις βάλει σε μια οθόνη.

Ξέχνα για την ώρα το κομμάτι στην κορυφή. Κοίτα απλώς πιο κάτω, στο body. Βάζει μια επικεφαλίδα και βάζει κείμενο παραγράφου. Αυτό το `h1` σημαίνει επικεφαλίδα πρώτου επιπέδου. Και βλέπεις ότι, επειδή αυτή είναι επικεφαλίδα πρώτου επιπέδου, ο Chrome ξέρει να την κάνει λίγο μεγαλύτερη και λίγο πιο έντονη. Ενώ αυτό το `p` είναι παράγραφος. Ο Chrome ξέρει να το κάνει λίγο μικρότερο.

Θα μπορούσαμε, αν θέλαμε, να βάλουμε κάποιες άλλες ετικέτες εδώ. Αυτή είναι μια μη αριθμημένη λίστα, `ul`, και μέσα θα είχαμε στοιχεία λίστας, `li`. Ένα από τα πράγματα που έχουν συμβεί από τότε που άρχισα να χρησιμοποιώ το Claude είναι ότι δεν μπορώ πια να γράφω και πολύ καλά στο πληκτρολόγιο. Μπορούμε λοιπόν να συνδυάσουμε διάφορες ετικέτες, και αυτό θα μας δώσει κάποιες κουκκίδες.

Αυτή είναι λοιπόν η ανατομία, τα κόκαλα, μιας ιστοσελίδας. Κάθε ιστοσελίδα είναι ίδια. Αν πάμε στο jiki.io και δούμε τον πηγαίο κώδικα της σελίδας, βλέπεις ότι είναι ακριβώς το ίδιο. Είναι πάρα πολλές τέτοιες ετικέτες. Βλέπουμε ότι είναι το ίδιο. Μόλις χρησιμοποιήσαμε μια μη αριθμημένη λίστα, ένα στοιχείο λίστας, έναν σύνδεσμο με λίγο κείμενο και ένα εικονίδιο δίπλα του. Αυτό είναι η HTML. Όποτε φτιάχνεις οποιονδήποτε ιστότοπο, από τώρα μέχρι το τέλος της ιστορίας, πάντα βγάζεις HTML προς ένα πρόγραμμα περιήγησης.

Ας τελειώσουμε το διάβασμα αυτού που μας ετοίμασε τόσο ευγενικά. Τι έχουμε λοιπόν μετά; Έχουμε το doctype, που λέει ότι αυτό είναι έγγραφο HTML. Μετά λέμε εντάξει, εδώ ξεκινάει το έγγραφο HTML μας, και η γλώσσα αυτού του εγγράφου είναι τα αγγλικά.

Μετά έχουμε δύο μέρη. Έχουμε το head, και έχουμε το body.

Το πρώτο πράγμα στο head είναι το ποιους χαρακτήρες χρησιμοποιούμε, και χρησιμοποιούμε αυτό το σύνολο χαρακτήρων που λέγεται UTF-8. Καθένα από αυτά είναι ένας χαρακτήρας. Λέμε ότι μπορούμε να χρησιμοποιήσουμε οποιονδήποτε χαρακτήρα λατινικό, ρωμαϊκό, σαν αυτούς, ή θα μπορούσαμε να χρησιμοποιήσουμε και emoji εδώ. Αν πάρουμε ένα emoji, μπορούμε να το βάλουμε κατευθείαν σε αυτό το έγγραφο, και μετά να ανανεώσουμε, και έχουμε ένα emoji στη σελίδα. Αυτό σημαίνει. Λέει ότι αυτοί είναι όλοι οι χαρακτήρες που χρησιμοποιείς συνήθως. Αυτό είναι το στάνταρ σύνολο χαρακτήρων μας.

Έχουμε επίσης ένα viewport. Δεν χρειάζεται να μας απασχολήσει για την ώρα.

Και έχουμε έναν τίτλο. Ο τίτλος είναι Jeremy Walker. Αυτός ο τίτλος είναι ο τίτλος που εμφανίζεται στην κορυφή της καρτέλας. Ένα από τα πράγματα που θα σκέφτεσαι πολύ καθώς προγραμματίζεις είναι ποιους τίτλους θέλεις να εμφανίζονται εκεί, ώστε όταν οι άνθρωποι έχουν διάφορες καρτέλες ανοιχτές, να βλέπουν εκεί πάνω κάτι που θέλουν. Μπορούμε επίσης να αλλάξουμε πράγματα όπως το favicon. Βλέπεις ότι δεν το έχουμε κάνει ακόμη, οπότε δεν έχουμε εικονίδιο εκεί.

Αυτό το τμήμα head είναι όλα όσα δεν εμφανίζονται στην οθόνη. Όλα όσα μπορεί να κοιτάξουν οι μηχανές αναζήτησης, και άλλα τέτοια, ζουν στο head. Και μετά το body είναι όλα όσα βρίσκονται στον τετράγωνο χώρο από κάτω. Και αυτό είναι κυριολεκτικά μια επικεφαλίδα, μια παράγραφος και μια λίστα.

Αυτό λοιπόν μας λέει η εξήγηση. Η ετικέτα `html` είναι το ριζικό στοιχείο. Το head είναι μεταδεδομένα. Μεταδεδομένα σημαίνει απλώς δεδομένα που αφορούν τη σελίδα, όχι πράγματα που βλέπεις. Το charset είναι η κωδικοποίηση χαρακτήρων που κάνει τα emoji σου και τους χαρακτήρες κάποιων άλλων γλωσσών να εμφανίζονται. Το viewport δεν θέλουμε να μας απασχολήσει. Και μετά το body είναι τα υπόλοιπα που είδαμε.

Για όσους από εσάς γράφετε HTML εδώ και χρόνια, συγγνώμη που αυτά είναι τόσο βασικά για εσάς, αλλά κι εσείς κάποτε τα μάθατε από το μηδέν.

## Οι εργασίες σου

Το επόμενο που πρέπει να σκεφτούμε είναι πώς θέλουμε να είναι η προσωπική μας αρχική σελίδα. Είναι μια ερώτηση στην οποία θέλω να αφιερώσεις λίγο χρόνο. Θα σε ενθαρρύνω πολύ σε όλο αυτό το μάθημα να πάρεις ένα στιλό και ένα μπλοκ, να καθίσεις σε ένα ήσυχο μέρος, όσο πιο μακριά από οθόνη γίνεται, και απλώς να σκεφτείς.

Θα φτιάξουμε μια αρχική σελίδα για εμάς. Εκείνη η αρχική σελίδα πρέπει να έχει μερικά πράγματα. Πρέπει να έχει μια επισκόπηση για εμάς και για τα ενδιαφέροντά μας. Πρέπει να έχει μια σελίδα που να είναι το βιογραφικό μας. Θα έχει μια σελίδα για το χαρτοφυλάκιό μας, για όλα τα πρότζεκτ που φτιάχνουμε, και μετά θα οδηγεί σε άλλες σελίδες για εκείνα τα πρότζεκτ. Θα χτίσουμε λοιπόν έναν μεγάλο ιστότοπο με πολλές σελίδες, με τον καιρό. Τα περισσότερα θα τα κάνουμε στη δεύτερη συνεδρία. Σήμερα κάνουμε μόνο αυτή τη μία σελίδα επισκόπησης. Θέλω όμως να σκεφτείς, με στιλό και χαρτί, και να σχεδιάσεις πώς θα ήθελες να είναι οι διάφορες σελίδες.

Και σκέψου λίγο και το στιλ. Κοίτα τις σελίδες κάποιων άλλων. Βρες άλλους ανθρώπους στην κοινότητα του Exercism. Αν κοιτάξω τον Erik Schierboom, που δούλευε παλιότερα μαζί μας, έχει μια πολύ ξεκάθαρη βασική σελίδα προορισμού, και μετά μια σελίδα "about", που είναι αρκετά κομψή, με ένα ωραίο πραγματάκι που εμφανίζεται στο κάτω μέρος. Έχει κάποιες πληροφορίες για λογισμικό, μέρη όπου έχει δώσει ομιλίες, και μετά κάποιους συνδέσμους προς τα έξω. Μπορεί να εμπνευστείς αρκετά από αυτό. Ή αν κοιτάξουμε τον SleeplessByte. Ίσως θυμάσαι τον DJ αν ήσουν στα bootcamps, ή από τους μέντορες. Αυτή είναι η σελίδα του DJ. Πήγαινε λοιπόν να βρεις ανθρώπους που σε ενδιαφέρουν και εμπνεύσου από όσα έχουν κάνει. Σκέψου οπτικά τι είδους στιλ σου αρέσει. Και θα μιλήσουμε λίγο για το πώς φτιάχνουμε εικόνες και πώς μπορείς να χρησιμοποιήσεις την τεχνολογία για να φτιάξεις εικόνες.

Εξερεύνησε τις ιδέες διαφορετικών ανθρώπων. Εγώ πάντα μου αρέσει αρκετά μια πολύ μινιμαλιστική αίσθηση. Και για αυτό το πρότζεκτ, θα πάω τις επόμενες μέρες να σκεφτώ πώς θέλω να είναι και η δική μου νέα σελίδα προορισμού, γιατί θα φτιάξω αυτή την αρχική σελίδα για μένα. Θα σκεφτώ πώς χωρίζεται. Θέλω ένα τμήμα για τη φωτογραφία μου. Θέλω ένα τμήμα όπου θα μπορώ να έχω τα podcast μου και τα βίντεο και τα πράγματα που έχω φτιάξει. Θέλω λίγο βιογραφικό σημείωμα, και θέλω ένα βιογραφικό. Θα πάω λοιπόν να σκεφτώ αυτά τα πράγματα.

Οι εργασίες σου για αυτή την εβδομάδα είναι να πας να σκεφτείς αυτά, να τα σχεδιάσεις, και μετά να αρχίσεις να δομείς εκείνες τις σελίδες. Μπορείς να δημιουργήσεις πολλές σελίδες. Μπορούμε να δημιουργήσουμε άλλη μία σελίδα, ας την πούμε "το βιογραφικό μου", και μπορούμε να αντιγράψουμε και να επικολλήσουμε το περιεχόμενό μας μέσα, να σβήσουμε τα κομμάτια που δεν χρειαζόμαστε, και να αλλάξουμε τον τίτλο σε "Το βιογραφικό του Jeremy". Έχουμε πλέον τη σελίδα index, αλλά μπορούμε τώρα να πάμε και στο resume.html και να το έχουμε ως άλλη μία σελίδα.

Αυτή την εβδομάδα λοιπόν:

- Σκέψου τις διάφορες σελίδες που θα θέλεις, και το διαφορετικό περιεχόμενο που θα βάλεις σε αυτές τις σελίδες.
- Εγκατέστησε το VS Code.
- Εγκατέστησε το OpenCode και στήσε ένα μοντέλο.
- Δουλεύοντας με το OpenCode, ετοίμασε μερικές από αυτές τις διαφορετικές σελίδες.

Μην ασχοληθείς ακόμη με το στιλ. Δεν θέλω να μπλέξεις με αυτό τώρα. Μπορείς να παίξεις αν θέλεις, πάντα ενθαρρύνω τους ανθρώπους να είναι περίεργοι, αλλά θα ήθελα να σου διδάξω ποιοι νομίζω ότι είναι οι καλύτεροι τρόποι για να το κάνεις στον σύγχρονο κόσμο. Σε καμία περίπτωση μην αρχίσεις να χρησιμοποιείς frameworks JavaScript ή οτιδήποτε άλλο. Μείνε απλώς σε λιτή HTML, και μετά θα προσθέτουμε στρώσεις σε κάθε συνεδρία μέχρι να γίνει όλο και πιο ισχυρό και όλο και πιο σύνθετο. Έτσι θα καταλάβεις πώς γίνονται όλα.

Αν σε ενδιαφέρει, πήγαινε να ερευνήσεις λίγο περισσότερο για την HTML. Βρες ποιες είναι οι διάφορες ετικέτες και τι σημαίνουν. Η έρευνα στις μέρες μας μπορεί να είναι τόσο απλή όσο το να ρωτήσεις:

> Πες μου τις 20 πιο συνηθισμένες ετικέτες.

Και μετά:

> Πες μου σε τι χρησιμεύει η καθεμία.

Έτσι ερευνώ εγώ τα πράγματα.

Θα κάνουμε την επόμενη συνεδρία σε λίγες μέρες. Μέχρι τότε, ελπίζω να έρθεις με το OpenCode εγκατεστημένο, το VS Code εγκατεστημένο, και μια σειρά από σελίδες. Την επόμενη φορά θα αρχίσουμε να συνδέουμε αυτές τις σελίδες μεταξύ τους, θα προσθέσουμε πλοήγηση, θα προσθέσουμε λίγο στιλ, και θα κάνουμε επίσης deploy όλο αυτό στο GitHub, και ίσως σου πάρουμε ακόμη και ένα δικό σου domain, ώστε να έχεις τον προσωπικό σου ιστότοπο σε ένα domain δωρεάν. Ίσως θέλεις να γραφτείς και στο GitHub αυτή την εβδομάδα, στο github.com. Θα δημοσιεύσω οδηγούς για το VS Code, το OpenCode και το GitHub, και μπορείς να τους ακολουθήσεις.

Εδώ τελειώνει αυτή η πρώτη συνεδρία. Ευχαριστώ που παρακολούθησες. Ελπίζω να ήταν ενδιαφέρουσα. Ελπίζω να σου άρεσε. Αν έχεις οποιαδήποτε ερώτηση για όσα καλύψαμε, μπες στο φόρουμ. Θα είμαι εκεί, και ανυπομονώ να απαντήσω σε ερωτήσεις και να τις εξερευνήσω. Δεν έχω απαραίτητα όλες τις απαντήσεις. Μου αρέσει κι εμένα να μαθαίνω. Οπότε ρώτα ό,τι σε ενδιαφέρει. Και ανυπομονώ να σε δω στην επόμενη συνεδρία.
