## Εισαγωγή

Το WSL (το **Windows Subsystem for Linux**, δηλαδή το Υποσύστημα Windows για Linux) είναι μια λειτουργία των Windows, που δημιουργήθηκε από τη Microsoft, και τρέχει ένα πραγματικό σύστημα Linux μέσα στον υπολογιστή σου με Windows. Το χρειάζεσαι επειδή τα περισσότερα εργαλεία προγραμματισμού έχουν φτιαχτεί για Linux και macOS (και λειτουργούν καλύτερα εκεί), και το WSL είναι ο τρόπος που οι προγραμματιστές σε Windows αποκτούν πρόσβαση σε όλα αυτά. Είναι ο τρόπος που προτείνει η ίδια η Microsoft για ανάπτυξη λογισμικού στα Windows. Η εγκατάστασή του διαρκεί περίπου δεκαπέντε λεπτά, από τα οποία το μεγαλύτερο μέρος είναι αναμονή, και χρειάζεται να την κάνεις μόνο μία φορά.

## Πριν ξεκινήσεις

Χρειάζεσαι:

- **Windows 10 (έκδοση 2004 ή νεότερη) ή Windows 11.** Οποιοδήποτε μηχάνημα Windows των τελευταίων ετών είναι εντάξει.
- **Πρόσβαση διαχειριστή** στον υπολογιστή. Αν είναι οικογενειακός υπολογιστής, ίσως χρειαστείς το άτομο που τον έστησε να πληκτρολογήσει τον κωδικό του.

## Εγκατάσταση του WSL

1. Κάνε κλικ στο κουμπί **Έναρξη** και πληκτρολόγησε "powershell". Θα δεις να εμφανίζεται το **Windows PowerShell**.
2. Μην το ανοίξεις απλώς. Αντίθετα, κάνε δεξί κλικ σε αυτό και επίλεξε **Εκτέλεση ως διαχειριστής**. Τα Windows θα σε ρωτήσουν αν θέλεις να επιτρέψεις να γίνουν αλλαγές: κάνε κλικ στο **Ναι**.
3. Στο μπλε παράθυρο που θα εμφανιστεί, πληκτρολόγησε το ακόλουθο και πάτα Enter:
   ```
   wsl --install
   ```
4. Τα Windows θα κατεβάσουν και θα ρυθμίσουν τα πάντα, συμπεριλαμβανομένου ενός συστήματος Linux που ονομάζεται **Ubuntu** (η πιο δημοφιλής έκδοση του Linux). Αυτό μπορεί να πάρει μερικά λεπτά.
5. Όταν σου ζητηθεί, κάνε **επανεκκίνηση** του υπολογιστή σου.

## Ρύθμιση του Ubuntu

Μετά την επανεκκίνηση, ένα παράθυρο τερματικού θα ανοίξει αυτόματα για να ολοκληρώσει τη ρύθμιση του Ubuntu. (Αν δεν συμβεί, κάνε κλικ στο Έναρξη, πληκτρολόγησε "ubuntu" και άνοιξέ το.)

Θα σου ζητήσει να δημιουργήσεις ένα **όνομα χρήστη** και έναν **κωδικό πρόσβασης** για το σύστημα Linux:

1. Πληκτρολόγησε ένα όνομα χρήστη (με πεζά, χωρίς κενά) και πάτα Enter.
2. Πληκτρολόγησε έναν κωδικό πρόσβασης και πάτα Enter, και μετά πληκτρολόγησέ τον ξανά για επιβεβαίωση.

Κάτι που ξεγελάει τους πάντες εδώ: **όταν πληκτρολογείς τον κωδικό, δεν εμφανίζεται τίποτα στην οθόνη**. Χωρίς τελείες, χωρίς αστεράκια, τίποτα. Αυτό είναι ένα χαρακτηριστικό ασφαλείας του Linux, όχι βλάβη. Η πληκτρολόγησή σου καταγράφεται, οπότε απλώς πληκτρολόγησε τον κωδικό και πάτα Enter.

Μην ξεχάσεις αυτόν τον κωδικό. Θα τον χρειαστείς περιστασιακά όταν εγκαθιστάς πράγματα.

## Έλεγχος ότι λειτουργεί

Κλείσε τα πάντα, και μετά κάνε κλικ στο **Έναρξη**, πληκτρολόγησε "ubuntu" και άνοιξέ το. Θα πρέπει να δεις ένα παράθυρο με μια προτροπή που καταλήγει σε `$`, η οποία σε περιμένει να πληκτρολογήσεις. Συγχαρητήρια: αυτό είναι ένα πραγματικό τερματικό Linux, και τώρα έχεις το ίδιο περιβάλλον ανάπτυξης με τους επαγγελματίες.

Δοκίμασε να πληκτρολογήσεις `ls` και να πατήσεις Enter. Θα εμφανίσει τα αρχεία του τρέχοντος φακέλου (δε θα είναι πολλά ακόμα).

## Χρήση του WSL από το VS Code

Αν έχεις [εγκατεστημένο το VS Code](/guides/installing-vscode), μπορεί να συνδεθεί με το WSL, ώστε ο επεξεργαστής κώδικα και το τερματικό Linux να συνεργάζονται:

1. Άνοιξε το VS Code.
2. Άνοιξε το πάνελ Επεκτάσεων (το εικονίδιο με τα τέσσερα τετράγωνα στα αριστερά, ή Ctrl+Shift+X), αναζήτησε **WSL** και εγκατέστησε την επέκταση που έχει φτιάξει η Microsoft.
3. Πάτα Ctrl+Shift+P, πληκτρολόγησε "WSL" και επίλεξε **WSL: Connect to WSL**. Το VS Code θα επανεκκινηθεί, συνδεδεμένο με το Ubuntu.

Από εδώ και στο εξής, κάθε τερματικό που ανοίγεις μέσα στο VS Code (μενού Terminal και μετά New Terminal) είναι ένα τερματικό Linux. Αυτή είναι η ρύθμιση που προτείνουμε για τους υπόλοιπους οδηγούς μας.

## Αν κάτι πάει στραβά

Το πιο συνηθισμένο πρόβλημα είναι ένα σφάλμα που αναφέρει **εικονικοποίηση** (ή "VT-x", "AMD-V", ή "virtual machine platform"). Το WSL βασίζεται σε μια δυνατότητα υλικού που είναι απενεργοποιημένη σε ορισμένους υπολογιστές. Η ενεργοποίησή της σημαίνει ότι πρέπει να αλλάξεις μια ρύθμιση στο BIOS του υπολογιστή σου, η οποία διαφέρει ανά κατασκευαστή. Αναζήτησε το μοντέλο του φορητού υπολογιστή σου μαζί με "enable virtualisation" για οδηγίες, ή ρώτησε στο <a href="https://forum.jiki.io" target="_blank" rel="noopener noreferrer">φόρουμ μας</a> και θα σε βοηθήσουμε.

Για οτιδήποτε άλλο, ο <a href="https://learn.microsoft.com/en-us/windows/wsl/install" target="_blank" rel="noopener noreferrer">επίσημος οδηγός εγκατάστασης WSL της Microsoft</a> έχει μια ενότητα αντιμετώπισης προβλημάτων, και ξανά, το φόρουμ είναι πάντα εκεί.
