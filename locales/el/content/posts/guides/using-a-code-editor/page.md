## Εισαγωγή

Όταν αρχίζεις να γράφεις κώδικα στον δικό σου υπολογιστή, χρειάζεσαι κάπου να τον γράψεις. Αυτό το «κάπου» είναι ένας επεξεργαστής κώδικα. Είναι ένα από τα πρώτα εργαλεία που θα χρειαστείς, και εκεί θα περάσεις πολλές ώρες στην πορεία σου. Πιθανότατα θα αλλάξεις και θα δοκιμάσεις καινούριους όσο περνάει ο καιρός, οπότε αξίζει να καταλάβεις τι είναι και πώς να διαλέξεις έναν καλό για να ξεκινήσεις.

## Ένας επεξεργαστής κώδικα δεν είναι πρόγραμμα επεξεργασίας κειμένου

Είναι εύκολο να υποθέσεις ότι οποιοδήποτε πρόγραμμα σου επιτρέπει να πληκτρολογείς κάνει τη δουλειά. Το πιο συνηθισμένο λάθος είναι να χρησιμοποιήσεις ένα πρόγραμμα επεξεργασίας κειμένου όπως το Microsoft Word ή τα Έγγραφα Google. Αυτά είναι φτιαγμένα για να γράφεις έγγραφα που θα διαβάσουν άνθρωποι, οπότε αλλάζουν σιωπηλά ό,τι πληκτρολογείς. Μετατρέπουν τα ίσια εισαγωγικά σε καμπύλα «έξυπνα» εισαγωγικά, διορθώνουν αυτόματα τις λέξεις σου και αποθηκεύουν κρυφή μορφοποίηση. Όλα αυτά χαλάνε τον κώδικα.

Ο επεξεργαστής κώδικα είναι ένα είδος επεξεργαστή κειμένου. Δουλεύει με απλό κείμενο και δεν προσθέτει ποτέ κρυφή μορφοποίηση, οπότε αυτό που πληκτρολογείς είναι ακριβώς αυτό που βλέπει ο υπολογιστής. Η διαφορά είναι ότι ο επεξεργαστής κώδικα είναι ένας επεξεργαστής κειμένου φτιαγμένος ειδικά για κώδικα. Πάνω στο απλό κείμενο, καταλαβαίνει τη δομή αυτού που γράφεις και σε βοηθάει με τρόπους που ένα πρόγραμμα επεξεργασίας κειμένου δεν θα μπορούσε ποτέ:

- Η **επισήμανση σύνταξης** χρωματίζει τα διαφορετικά μέρη του κώδικά σου ώστε να είναι πιο εύκολο να τον διαβάσεις και να εντοπίσεις λάθη.
- Η **αυτόματη στοίχιση** κρατάει τον κώδικά σου τακτοποιημένο, κάτι που έχει μεγάλη σημασία σε πολλές γλώσσες.
- Οι **υποδείξεις σφαλμάτων** επισημαίνουν προβλήματα, συχνά πριν καν τρέξεις το πρόγραμμα.
- Η **αυτόματη συμπλήρωση** σου προτείνει τη συνέχεια αυτού που πληκτρολογείς, ώστε να γράφεις πιο γρήγορα και να κάνεις λιγότερα ορθογραφικά.
- Οι **επεκτάσεις** σου επιτρέπουν να προσθέτεις υποστήριξη για νέες γλώσσες και εργαλεία καθώς προχωράς.

## Αυτό που προτείνουμε εμείς

Υπάρχουν πολλοί καλοί επεξεργαστές κώδικα και δεν μπορείς να κάνεις κακή επιλογή εδώ. Τούτου λεχθέντος, εμείς προτείνουμε το **Visual Studio Code**, που συνήθως συντομεύεται σε VS Code. Είναι δωρεάν, τρέχει σε Windows, macOS και Linux, είναι φιλικό για αρχάριους και είναι ένας από τους πιο διαδεδομένους επεξεργαστές στον κόσμο, οπότε σχεδόν οποιοσδήποτε οδηγός θα βρεις θα υποθέτει ότι το χρησιμοποιείς.

Όταν είσαι έτοιμος να το εγκαταστήσεις, ακολούθησε τον οδηγό μας για την [εγκατάσταση του VS Code](/guides/installing-vscode).

## Άλλοι επεξεργαστές για τους οποίους μπορεί να ακούσεις

Δεν χρειάζεσαι κανέναν από τους παρακάτω για να ακολουθήσεις το Jiki, αλλά θα τους συναντήσεις, οπότε ορίστε μια γρήγορη ξενάγηση στους πιο συνηθισμένους:

- <a href="https://code.visualstudio.com" target="_blank" rel="noopener noreferrer">Visual Studio Code (VS Code)</a> είναι ο δωρεάν, cross-platform επεξεργαστής που προτείνουμε.
- <a href="https://www.sublimetext.com" target="_blank" rel="noopener noreferrer">Sublime Text</a> είναι ένας γρήγορος, ελαφρύς επεξεργαστής που είναι δημοφιλής εδώ και πολλά χρόνια.
- <a href="https://zed.dev" target="_blank" rel="noopener noreferrer">Zed</a> είναι ένας νεότερος, πολύ γρήγορος επεξεργαστής που εστιάζει στην ταχύτητα και τη συνεργασία.
- <a href="https://www.jetbrains.com/ides/" target="_blank" rel="noopener noreferrer">JetBrains IDEs</a> (όπως το <a href="https://www.jetbrains.com/pycharm/" target="_blank" rel="noopener noreferrer">PyCharm</a> και το <a href="https://www.jetbrains.com/idea/" target="_blank" rel="noopener noreferrer">IntelliJ IDEA</a>) είναι ισχυρά, βαρύτερα εργαλεία που απευθύνονται σε επαγγελματίες προγραμματιστές που δουλεύουν πάνω σε μεγάλα έργα.
- Το <a href="https://www.vim.org" target="_blank" rel="noopener noreferrer">Vim</a> και το <a href="https://neovim.io" target="_blank" rel="noopener noreferrer">Neovim</a> είναι επεξεργαστές που ελέγχονται αποκλειστικά με το πληκτρολόγιο και ζουν μέσα στο τερματικό. Είναι πολύ αγαπητοί από έμπειρους προγραμματιστές, αλλά έχουν απότομη καμπύλη εκμάθησης.

Η συμβουλή μας όσο μαθαίνεις είναι απλή: ξεκίνα με το VS Code, εξοικειώσου με τη συγγραφή κώδικα και εξερεύνησε τους άλλους αργότερα, όταν θα ξέρεις τι σου αρέσει.
