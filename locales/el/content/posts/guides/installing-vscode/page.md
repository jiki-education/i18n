## Εισαγωγή

Το Visual Studio Code (VS Code) είναι ένας δωρεάν επεξεργαστής κώδικα της Microsoft που τρέχει σε Windows, macOS και Linux. Είναι ο επεξεργαστής που συνιστούμε όσο μαθαίνεις να προγραμματίζεις. Αν δεν είσαι σίγουρος/η για το τι είναι ένας επεξεργαστής κώδικα ή γιατί τον χρειάζεσαι, ξεκίνα με τον οδηγό μας για [τη χρήση ενός επεξεργαστή κώδικα](/guides/using-a-code-editor).

Αυτός ο οδηγός σε καθοδηγεί στην εγκατάσταση του VS Code σε κάθε λειτουργικό σύστημα. Βρες το σύστημά σου παρακάτω και ακολούθησε τα βήματα. Χρειάζεται να το κάνεις μόνο μία φορά.

## Windows

1. Άνοιξε το [code.visualstudio.com](https://code.visualstudio.com) στον περιηγητή σου.
2. Κάνε κλικ στο κουμπί **Download for Windows**. Αυτό κατεβάζει τον επίσημο εγκαταστάτη (ένα αρχείο `.exe`).
3. Όταν ολοκληρωθεί η λήψη, άνοιξε το αρχείο για να εκτελέσεις τον εγκαταστάτη.
4. Αποδέξου τη συμφωνία άδειας χρήσης, και μετά συνέχισε να κάνεις κλικ στο **Next** για να αποδεχτείς τις προεπιλεγμένες επιλογές. Συνιστούμε να αφήσεις τσεκαρισμένο το κουτί που προσθέτει το VS Code στο μενού δεξιού κλικ, καθώς θα σου είναι χρήσιμο αργότερα.
5. Κάνε κλικ στο **Install** και μετά στο **Finish**. Το VS Code θα ανοίξει όταν είναι έτοιμο.

## macOS

1. Άνοιξε το [code.visualstudio.com](https://code.visualstudio.com) στον περιηγητή σου.
2. Κάνε κλικ στο κουμπί **Download for macOS**. Αυτό κατεβάζει ένα αρχείο `.zip` που περιέχει την εφαρμογή.
3. Άνοιξε τον φάκελο **Downloads** και κάνε διπλό κλικ στο κατεβασμένο αρχείο για να το αποσυμπιέσεις. Θα πάρεις μια εφαρμογή με το όνομα **Visual Studio Code**.
4. Σύρε το **Visual Studio Code** μέσα στον φάκελο **Applications**.
5. Άνοιξε τον φάκελο **Applications** και κάνε διπλό κλικ στο **Visual Studio Code** για να το εκκινήσεις. Αν το macOS σε ρωτήσει αν είσαι σίγουρος/η ότι θέλεις να το ανοίξεις, κάνε κλικ στο **Open**.

## Linux

Ο πιο αξιόπιστος τρόπος για να εγκαταστήσεις το VS Code σε Linux είναι να κατεβάσεις το επίσημο πακέτο για τη διανομή σου από τη Microsoft.

1. Άνοιξε το [code.visualstudio.com](https://code.visualstudio.com) στον περιηγητή σου.
2. Κάνε κλικ στο **Download for Linux** και διάλεξε το πακέτο που ταιριάζει στη διανομή σου:
   - Διάλεξε το πακέτο **.deb** σε συστήματα βασισμένα σε Debian και Ubuntu.
   - Διάλεξε το πακέτο **.rpm** σε συστήματα βασισμένα σε Fedora, Red Hat και openSUSE.
3. Άνοιξε το κατεβασμένο πακέτο με τον εγκαταστάτη λογισμικού του συστήματός σου και κάνε κλικ στο **Install**, ή εγκατέστησέ το από το τερματικό:
   - Σε Debian ή Ubuntu, εκτέλεσε `sudo apt install ./<file>.deb` στον φάκελο όπου το κατέβασες.
   - Σε Fedora ή Red Hat, εκτέλεσε `sudo dnf install ./<file>.rpm` στον φάκελο όπου το κατέβασες.
4. Μόλις εγκατασταθεί, άνοιξε το VS Code από το μενού εφαρμογών σου, ή εκτελώντας `code` στο τερματικό.

## Άνοιγμα του VS Code

Ανεξάρτητα από τον τρόπο που το εγκατέστησες, μπορείς τώρα να ανοίγεις το VS Code όποτε θέλεις να γράψεις κώδικα. Σε Windows και macOS θα εμφανιστεί δίπλα στις άλλες εφαρμογές σου, και στο Linux θα βρίσκεται στο μενού εφαρμογών σου.

Αυτό ήταν. Τώρα έχεις εγκαταστήσει έναν κανονικό επεξεργαστή κώδικα και είσαι έτοιμος/η να ξεκινήσεις να γράφεις κώδικα.
