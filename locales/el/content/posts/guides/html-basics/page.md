## Εισαγωγή

Σε αυτόν τον οδηγό θέλω να μιλήσω λίγο για το τι είναι στην πραγματικότητα μια ιστοσελίδα και πώς λειτουργεί. Θα μείνουμε στα πιο βασικά πράγματα. Αν ξέρεις ήδη λίγη HTML, μάλλον θα σου φανεί πολύ βασικό. Αν όχι, αυτό θα είναι μια καλή εισαγωγή για ό,τι ακολουθήσει.

## Τι είναι πραγματικά μια ιστοσελίδα

Μια ιστοσελίδα είναι απλώς ένα αρχείο κειμένου. Όταν επισκέπτεσαι έναν ιστότοπο, ο browser σου λαμβάνει ένα αρχείο HTML, το διαβάζει και το σχεδιάζει για να δημιουργήσει τη σελίδα που βλέπεις.

Μπορείς να το αποδείξεις στον εαυτό σου τώρα αμέσως. Πήγαινε σε οποιονδήποτε ιστότοπο, κάνε δεξί κλικ οπουδήποτε στη σελίδα και διάλεξε **Προβολή πηγαίου κώδικα** (View Page Source). Αυτή είναι η HTML. Σε έναν μεγάλο ιστότοπο θα φαίνεται χαοτική, ένα σωρό πράγματα, αλλά όλα είναι φτιαγμένα από τις ίδιες λιγοστές δομικές μονάδες που θα δούμε παρακάτω.

Το HTML σημαίνει **HyperText Markup Language** (Γλώσσα Σήμανσης Υπερκειμένου). «Σήμανση» σημαίνει απλώς ότι παίρνουμε κάποιο κείμενο και το μαρκάρουμε με επιπλέον πληροφορίες για το τι είναι το κάθε κομμάτι. Ο browser, είτε είναι ο Chrome είτε οτιδήποτε άλλο, διαβάζει αυτά τα μαρκαρίσματα και τα χρησιμοποιεί για να αποφασίσει πώς να βάλει τα πάντα στην οθόνη.

## Ετικέτες

Η HTML είναι διάσημη για τις **ετικέτες** της, που έχουν ένα `<` στην αρχή και ένα `>` στο τέλος. Ανάμεσα σε αυτές τις γωνιακές αγκύλες βρίσκεται το πράγμα για το οποίο είναι η ετικέτα. Μετά έχουμε κάποιο περιεχόμενο και έπειτα μια ετικέτα κλεισίματος, που είναι ίδια με την αρχική, αλλά με μια κάθετο.

Ας δούμε ένα παράδειγμα:

```html
<p>Hello there.</p>
```

Το `p` σημαίνει παράγραφος. Γράφοντας αυτό, λέμε στον browser ότι θέλουμε να εμφανίσει μια παράγραφο στην οθόνη και ότι το κείμενο αυτής της παραγράφου είναι «Hello there.»

Οι ετικέτες μπορούν επίσης να έχουν επιπλέον κομμάτια πληροφορίας που λέγονται **ιδιότητες** (attributes) και βρίσκονται μέσα στην ετικέτα ανοίγματος. Ένας σύνδεσμος είναι καλό παράδειγμα:

```html
<a href="https://jiki.io">Visit Jiki</a>
```

Για να δημιουργήσουμε έναν σύνδεσμο χρησιμοποιούμε την ετικέτα `a` (που σημαίνει anchor, δηλαδή άγκυρα, για [λίγο παράξενους ιστορικούς λόγους](https://thehistoryoftheweb.com/brief-history-hypertext/)). Ένας σύνδεσμος συνήθως έχει μια ιδιότητα `href`, που δηλώνει πού οδηγεί ο σύνδεσμος, και το κείμενο ανάμεσα στις ετικέτες είναι το κομμάτι πάνω στο οποίο κάνεις κλικ.

Ορισμένες ετικέτες δεν περικλείουν περιεχόμενο, επομένως δεν έχουν ετικέτα κλεισίματος. Μια εικόνα είναι το κλασικό παράδειγμα:

```html
<img src="photo.jpg" alt="A photo of me on a mountain" />
```

Το `img` σημαίνει εικόνα. Η ιδιότητα `src` δείχνει προς το αρχείο της εικόνας και η ιδιότητα `alt` περιγράφει την εικόνα για τους ανθρώπους που χρησιμοποιούν αναγνώστες οθόνης. Είναι επίσης αυτό που εμφανίζεται αν η εικόνα αποτύχει να φορτώσει.

## Η ανατομία μιας σελίδας

Κάθε ιστοσελίδα έχει τον ίδιο σκελετό, τα ίδια κόκαλα. Ορίστε η πιο λιτή **έγκυρη** σελίδα που μπορείς να φτιάξεις (μπορείς να φτιάξεις μη έγκυρες σελίδες με λιγότερη HTML, τις οποίες ο browser θα εμφανίσει, αλλά ας ξεκινήσουμε όπως θέλουμε να συνεχίσουμε, φερόμενοι σαν υπεύθυνοι προγραμματιστές!):

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Jeremy Walker</title>
  </head>
  <body>
    <h1>Jeremy Walker</h1>
    <p>I build things on the web.</p>
  </body>
</html>
```

Ας τη διαβάσουμε από πάνω.

Η γραμμή `<!doctype html>` λέει στον browser ότι αυτό είναι ένα σύγχρονο έγγραφο HTML. Είναι ένα απαραίτητο συντακτικό κομμάτι. Γράψ' το μία φορά στην κορυφή και ξέχασέ το.

Η ετικέτα `html` είναι το ριζικό στοιχείο που περικλείει ολόκληρο το έγγραφο. Η ιδιότητα `lang="en"` λέει στους browsers και στις μηχανές αναζήτησης ότι η σελίδα είναι γραμμένη στα αγγλικά.

Μέσα σε αυτήν, έχουμε δύο μέρη: το **head** και το **body**.

### Το head

Το head είναι ό,τι **δεν** εμφανίζεται στην οθόνη. Είναι μεταδεδομένα, και μεταδεδομένα σημαίνει απλώς δεδομένα σχετικά με τη σελίδα και όχι πράγματα που βλέπεις. Στο παράδειγμά μας υπάρχουν δύο πράγματα μέσα του:

- `<meta charset="UTF-8" />` λέει ποιο σύνολο χαρακτήρων χρησιμοποιεί η σελίδα. Το UTF-8 είναι το πρότυπο σύνολο χαρακτήρων και καλύπτει σχεδόν τα πάντα: λατινικά γράμματα, τονισμένους χαρακτήρες, άλλα αλφάβητα, ακόμα και emoji. Αν επικολλήσεις ένα emoji στην HTML σου, αυτή είναι η γραμμή που το κάνει να εμφανίζεται σωστά. Να τη βάζεις πάντα.
- Το `<title>` ορίζει το κείμενο που εμφανίζεται στην κορυφή της καρτέλας του browser. Είναι επίσης αυτό που χρησιμοποιούν οι μηχανές αναζήτησης ως επικεφαλίδα για τη σελίδα σου. Κάτι που θα σκέφτεσαι συχνά όσο προγραμματίζεις είναι τι θες να φαίνεται εκεί πάνω όταν κάποιος έχει είκοσι καρτέλες ανοιχτές.

Συχνά θα δεις μία ακόμα γραμμή στο head, που αξίζει να αναγνωρίζεις:

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

Αυτή λέει στα τηλέφωνα να εμφανίσουν τη σελίδα σε λογικό μέγεθος αντί να είναι τελείως σμικρυμένη. Δεν χρειάζεται να ανησυχήσουμε για κάτι παραπάνω προς το παρόν. Βάλ' την και προχώρα.

### Το body

Το body είναι ό,τι πραγματικά βλέπεις, τα πάντα μέσα στον μεγάλο ορθογώνιο χώρο κάτω από τις καρτέλες και τη γραμμή διευθύνσεων. Κάθε επικεφαλίδα, παράγραφος, εικόνα και σύνδεσμος ζει μέσα στο body. Το υπόλοιπο αυτού του οδηγού αφορά τις ετικέτες που μπαίνουν εκεί.

## Το index.html

Πριν περάσουμε στις ετικέτες, υπάρχει ένα ακόμα πράγμα που αξίζει να ξέρεις. Υπάρχει μια πολύ παλιά σύμβαση ότι ένα αρχείο με το όνομα `index.html` είναι η πρώτη σελίδα ενός ιστότοπου. Αν πας σε ένα domain χωρίς να προσθέσεις τίποτα μετά από αυτό, ο ιστότοπος κοιτάζει αν υπάρχει ένα αρχείο που λέγεται `index.html`, και αν υπάρχει, απλά σου δείχνει τα περιεχόμενά του. Δεν υπάρχει τίποτα μαγικό στο ίδιο το αρχείο. Είναι απλώς ένα πρότυπο που ακολουθούν σχεδόν όλοι οι ιστότοποι, οπότε η αρχική σου σελίδα θα πρέπει να βρίσκεται σε ένα αρχείο με αυτό το όνομα.

## Οι ετικέτες που θα χρησιμοποιήσεις πρώτα

Μπορείς να φτιάξεις μια πραγματικά χρήσιμη σελίδα με λιγότερες από δέκα ετικέτες. Ας τις δούμε, περίπου με τη σειρά που θα τις χρησιμοποιήσεις.

### Επικεφαλίδες

Οι επικεφαλίδες έρχονται σε έξι επίπεδα, από `h1` μέχρι `h6`:

```html
<h1>Jeremy Walker</h1>
<h2>About me</h2>
<h3>My photography</h3>
```

Το `h1` είναι η κύρια επικεφαλίδα της σελίδας και κανονικά θα πρέπει να υπάρχει μόνο μία. Χρησιμοποίησε `h2` για επικεφαλίδες ενοτήτων, `h3` για υποενότητες μέσα σε αυτές και ούτω καθεξής. Επειδή το `h1` είναι επικεφαλίδα επιπέδου ένα, ο browser ξέρει να την κάνει λίγο μεγαλύτερη και λίγο πιο έντονη.

Διάλεγε τα επίπεδα επικεφαλίδων με βάση το νόημα, όχι το μέγεθος. Δίνουν στη σελίδα σου μια διάρθρωση, λίγο σαν κεφάλαια και ενότητες σε ένα βιβλίο.

### Παράγραφοι

Η ετικέτα `p` σηματοδοτεί μια παράγραφο κειμένου και σχεδόν όλες οι λέξεις σε οποιαδήποτε σελίδα ζουν μέσα σε μία:

```html
<p>I have been building things on the web for thirty years.</p>
<p>These days I spend most of my time working on Jiki.</p>
```

Κάθε παράγραφος έχει τη δική της ετικέτα και ο browser προσθέτει κενό ανάμεσά τους αυτόματα.

### Λίστες

Υπάρχουν δύο είδη λίστας. Μια **μη αριθμημένη λίστα** (`ul`) σου δίνει κουκκίδες και μια **αριθμημένη λίστα** (`ol`) σου δίνει αριθμούς. Μέσα σε οποιαδήποτε από τις δύο, κάθε καταχώριση είναι ένα **στοιχείο λίστας** (`li`):

```html
<ul>
  <li>Photography</li>
  <li>Podcasting</li>
  <li>Teaching people to code</li>
</ul>
```

Αντικατέστησε το `ul` με `ol` και οι κουκκίδες γίνονται 1, 2, 3.

### Σύνδεσμοι

Οι σύνδεσμοι είναι αυτό που κάνει τον ιστό ιστό. Η ετικέτα `a` μετατρέπει οτιδήποτε σε κάτι που μπορείς να κάνεις κλικ:

```html
<p>You can find my code on <a href="https://github.com/ihid">GitHub</a>.</p>
```

Οι σύνδεσμοι μπορούν να οδηγούν σε άλλους ιστότοπους ή σε άλλες σελίδες του δικού σου ιστοτόπου. Αν έχεις ένα `resume.html` δίπλα στο `index.html` σου, μπορείς να συνδεθείς σε αυτό με `<a href="resume.html">My resume</a>`.

### Εικόνες

Η ετικέτα `img` βάζει μια εικόνα στη σελίδα:

```html
<img src="images/me.jpg" alt="Jeremy standing on a hill in the Lake District" />
```

Το `src` μπορεί να είναι ένα αρχείο στον δικό σου ιστότοπο ή μια πλήρης διαδικτυακή διεύθυνση. Να συμπληρώνεις πάντα το κείμενο `alt` με μια πραγματική περιγραφή της εικόνας.

### Έμφαση

Δύο μικρές ετικέτες σου επιτρέπουν να δίνεις έμφαση σε λέξεις μέσα στο κείμενό σου. Το `strong` σηματοδοτεί κάτι ως σημαντικό και οι browsers το εμφανίζουν έντονα. Το `em` δηλώνει έμφαση και οι browsers το εμφανίζουν πλάγια:

```html
<p>The struggle is where the <strong>learning</strong> happens, so <em>write your own solutions</em>.</p>
```

## Δίνοντας δομή στη σελίδα σου

Οι ετικέτες που είδαμε μέχρι τώρα περιγράφουν μεμονωμένα κομμάτια περιεχομένου. Υπάρχει μια δεύτερη οικογένεια ετικετών που περιγράφουν τις περιοχές μιας σελίδας. Αυτές συχνά ονομάζονται **σημασιολογικές ετικέτες**, επειδή δίνουν νόημα σε κάθε περιοχή αντί να αλλάζουν την εμφάνιση:

- Το `header` περικλείει την πάνω περιοχή της σελίδας, συνήθως το όνομα του ιστοτόπου σου και το λογότυπο.
- Το `nav` περικλείει την πλοήγησή σου, το σύνολο των συνδέσμων προς τις άλλες σελίδες του ιστοτόπου σου.
- Το `main` περικλείει το κύριο περιεχόμενο της σελίδας. Θα πρέπει να υπάρχει μόνο ένα.
- Το `section` ομαδοποιεί ένα ξεχωριστό κομμάτι περιεχομένου, συνήθως με τη δική του επικεφαλίδα.
- Το `article` περικλείει ένα αυτοτελές κομμάτι, όπως μια ανάρτηση ιστολογίου ή μια είδηση.
- Το `footer` περικλείει την κάτω περιοχή, συνήθως πνευματικά δικαιώματα και συνδέσμους επικοινωνίας.

Μια προσωπική αρχική σελίδα που χρησιμοποιεί αυτές τις ετικέτες θα μπορούσε να έχει αυτή τη μορφή:

```html
<body>
  <header>
    <h1>Jeremy Walker</h1>
    <nav>
      <a href="index.html">Home</a>
      <a href="resume.html">Resume</a>
      <a href="portfolio.html">Portfolio</a>
    </nav>
  </header>
  <main>
    <section>
      <h2>About me</h2>
      <p>...</p>
    </section>
    <section>
      <h2>My projects</h2>
      <p>...</p>
    </section>
  </main>
  <footer>
    <p>Get in touch at jeremy@example.com.</p>
  </footer>
</body>
```

Καμία από αυτές τις ετικέτες δεν αλλάζει πολύ την εμφάνιση της σελίδας σου από μόνη της. Γιατί να ασχοληθείς λοιπόν; Επειδή η δομή με νόημα βοηθάει οτιδήποτε διαβάζει τη σελίδα σου και δεν είναι άνθρωπος που κοιτάζει μια οθόνη. Οι αναγνώστες οθόνης χρησιμοποιούν αυτές τις ετικέτες για να επιτρέψουν σε τυφλούς χρήστες να μεταβούν κατευθείαν στην πλοήγηση ή στο κύριο περιεχόμενο. Οι μηχανές αναζήτησης τις χρησιμοποιούν για να καταλάβουν περί τίνος πρόκειται η σελίδα σου. Και όταν αργότερα θελήσεις να δώσεις στυλ στη σελίδα σου, το να είναι καλά οργανωμένη κάνει τα πάντα πολύ πιο εύκολα.

Αν ένα κομμάτι της σελίδας δεν ταιριάζει σε κανένα από αυτά τα νοήματα, υπάρχουν δύο γενικά δοχεία: το `div` για ένα μπλοκ περιεχομένου και το `span` για μερικές λέξεις μέσα σε κείμενο. Δεν σημαίνουν τίποτα απολύτως, και γι' αυτό ακριβώς πρέπει να προτιμάς πρώτα τις ετικέτες με νόημα.

## Περισσότερες ετικέτες για να αναγνωρίζεις

Δεν χρειάζεται να τις αποστηθίσεις, αλλά θα τις συναντήσεις καθώς κοιτάς σελίδες άλλων, οπότε αξίζει να ξέρεις ότι υπάρχουν:

- Το `blockquote` για μια παράθεση από κάπου αλλού.
- Το `code` για ένα απόσπασμα code μέσα σε κείμενο και το `pre` για ένα μπλοκ προδιαμορφωμένου κειμένου.
- Το `table`, με `tr` για κάθε γραμμή και `td` για κάθε κελί, για πραγματικά πινακοποιημένα δεδομένα.
- Τα `form`, `input`, `label` και `button` για τη συλλογή δεδομένων από επισκέπτες.
- Τα `video` και `audio` για την ενσωμάτωση πολυμέσων.
- Το `br` για αλλαγή γραμμής μέσα σε κείμενο. Χρησιμοποίησέ το σπάνια. Αν θέλεις νέα παράγραφο, χρησιμοποίησε μια νέα `p`.

Υπάρχουν πάνω από εκατό ετικέτες συνολικά, αλλά αυτές που είδαμε σε αυτόν τον οδηγό καλύπτουν τη συντριπτική πλειονότητα όσων θα δεις και θα γράψεις. Όταν συναντήσεις κάποια που δεν αναγνωρίζεις, αναζήτησέ την στο [MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element), που είναι η αναφορά που χρησιμοποιούν οι επαγγελματίες.

## Πού να πας μετά

Ο καλύτερος τρόπος για να εμπεδωθούν όλα αυτά είναι να φτιάξεις κάτι. Δημιούργησε ένα `index.html`, δώσε του τον σκελετό από αυτόν τον οδηγό και δόμησε μια σελίδα για τον εαυτό σου με επικεφαλίδες, παραγράφους, λίστες και συνδέσμους. Μετά άνοιξέ το στον browser σου και ρίξε μια ματιά σε αυτό που έφτιαξες.

Μόλις νιώσεις άνετα, συνήθισε να βλέπεις τον πηγαίο κώδικα των ιστοσελίδων που επισκέπτεσαι. Θα αρχίσεις να αναγνωρίζεις τις ετικέτες παντού και θα δεις ότι ακόμα και οι πιο πολύπλοκοι ιστότοποι είναι χτισμένοι ακριβώς από τα ίδια κομμάτια που μόλις έμαθες.

Η σελίδα σου θα φαίνεται πολύ απλή προς το παρόν, και αυτό είναι εντάξει. Η HTML δίνει στη σελίδα τη δομή της. Το να την κάνεις να φαίνεται όμορφη είναι δουλειά της CSS, που είναι ο επόμενος προορισμός μας.
