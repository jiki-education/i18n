Σε αυτή την άσκηση, ο στόχος σου είναι να δημιουργήσεις συναρτήσεις που ελέγχουν αν μια συμβολοσειρά περιέχει γράμματα ή/και αριθμούς.

Θα χρειαστεί να γράψεις τρεις βοηθητικές συναρτήσεις:

- `isAlpha(string)` (είναι αλφαβητικό): ελέγχει αν μια συμβολοσειρά αποτελείται μόνο από γράμματα ASCII (π.χ. "A", "a", "Hello")
- `isNumeric(string)` (είναι αριθμητικό): ελέγχει αν μια συμβολοσειρά αποτελείται μόνο από αριθμητικούς χαρακτήρες (π.χ. "0", "1", "456")
- `isAlphanumeric(string)` (είναι αλφαριθμητικό): ελέγχει αν μια συμβολοσειρά αποτελείται μόνο από γράμματα ή αριθμούς ASCII (π.χ. "Hello", "42", "Hello42")

Για κάθε άλλο σύμβολο (π.χ. "! ?") ή χαρακτήρα που δεν είναι ASCII (π.χ. "じき", "正直"), και οι τρεις συναρτήσεις θα πρέπει να επιστρέφουν «ψευδές».

Στη συνέχεια, γράψε μια συνάρτηση `whatAmI(string)` (τι είμαι) που χρησιμοποιεί αυτές τις βοηθητικές συναρτήσεις για να κατατάξει μια συμβολοσειρά:

- Οι συμβολοσειρές με μόνο γράμματα θα πρέπει να επιστρέφουν `"Alpha"`
- Οι συμβολοσειρές με μόνο αριθμούς θα πρέπει να επιστρέφουν `"Numeric"`
- Οι συμβολοσειρές με γράμματα και αριθμούς θα πρέπει να επιστρέφουν `"Alphanumeric"`
- Οτιδήποτε άλλο θα πρέπει να επιστρέφει `"Unknown"`

### Επιπλέον δοκιμασίες

Υπάρχουν πολλοί σωστοί τρόποι να λύσεις αυτή την άσκηση. Αν θέλεις, μπορείς να δοκιμάσεις να χρησιμοποιήσεις την εντολή `continue`, αλλά υπάρχουν και πολλές άλλες καλές λύσεις.

Υπάρχει επίσης μια επιπλέον δοκιμασία που σε προκαλεί να λύσεις όλο το πρόβλημα σε το πολύ 42 γραμμές κώδικα. Αυτός ο στόχος δεν οδηγεί απαραίτητα στην πιο ποιοτική λύση. Μερικές επιπλέον γραμμές πιθανώς δίνουν μια πιο προσεγμένη λύση, ενώ υπάρχουν και πιο σύντομες λύσεις. Είναι όμως ένας καλός στόχος για να βελτιώσεις τις ικανότητές σου.
