Τώρα που μπορείς να επεξεργαστείς μία μόνο μαντεψιά, ήρθε η ώρα να επεξεργαστείς ένα ολόκληρο παιχνίδι!

Δημιούργησε μια συνάρτηση που ονομάζεται `processGame` (επεξεργασία παιχνιδιού), η οποία δέχεται δύο εισόδους:

1. Τη μυστική λέξη-στόχο.
2. Μια λίστα με τις μαντεψιές που έχει κάνει ο παίκτης.

Πρέπει να υπολογίσεις την κατάσταση κάθε γραμμής και μετά να καλέσεις τη συνάρτηση `colorRow(row, states)` (χρωματισμός γραμμής) με τον αριθμό της γραμμής (`1-6`) και μια λίστα με τις καταστάσεις για κάθε γράμμα.

Για παράδειγμα, αν η πρώτη μαντεψιά ήταν σωστή:

```
colorRow(1, ["correct", "correct", "correct", "correct", "correct"])
```
