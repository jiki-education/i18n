title: "Αναζήτηση ώρας"
description: "Αναζήτησε την τρέχουσα ώρα για μια πόλη."
en_md5: 8353eee229bee19f27557a7f56933a6a
---

Δημιούργησε μια συνάρτηση με το όνομα `getTime` (πάρε την ώρα) που παίρνει ως είσοδο μια πόλη, χρησιμοποιεί τη συνάρτηση `fetch` (φέρε) για να πάρει την ώρα σε αυτή την πόλη και μετά την επιστρέφει ως μέρος μιας συμβολοσειράς.

Το URL του API είναι "https://timeapi.io/api/time/current/city".
Οι παράμετροι για το `fetch` θα πρέπει να έχουν ένα `key` (κλειδί) "city" με τιμή τη συμβολοσειρά που περνάς στη `getTime`.

Θα πρέπει να μετατρέψεις την απόκριση σε μια συμβολοσειρά με μορφή όπως: "The time on this Sunday in Amsterdam is 00:28"

Αν η απόκριση περιέχει ένα κλειδί "error", επίστρεψε αντ' αυτού το μήνυμα σφάλματος.
