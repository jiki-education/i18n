Την τελευταία φορά που είδες τον τοίχο, πρόσθεσες ένα επάνω στρώμα για να τον ολοκληρώσεις. Σε αυτή την άσκηση, βασίζεσαι σε αυτό και χτίζεις έναν ολόκληρο τοίχο από το μηδέν, με 55 τούβλα συνολικά.

Ο τελικός τοίχος πρέπει να μοιάζει κάπως έτσι:

<img src="/static/images/exercise-assets/build-wall/completed-wall.webp" alt="Ολοκληρωμένος τοίχος" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Αυτά που πρέπει να ξέρεις:

- **Κάθε** τούβλο έχει ύψος 10 και πλάτος 20.
- Τα τούβλα μπορούν να ξεκινούν ή να τελειώνουν **έξω** από τον καμβά αν χρειαστεί, αλλά δεν πρέπει να βρίσκονται **εντελώς** έξω από τον καμβά.
- Οι σειρές εναλλάσσονται: άλλες ξεκινούν από την αριστερή άκρη (5 τούβλα) και άλλες ξεκινούν εκτός οθόνης προς τα αριστερά (6 τούβλα). (Η κάτω σειρά έχει 5, η πάνω σειρά έχει 6)
- Η συνάρτηση `rectangle` (ορθογώνιο) μπορεί να εμφανιστεί μόνο μία φορά στον κώδικά σου!

Ο στόχος αυτής της άσκησης είναι να πειραματιστείς με τη χρήση των μπλοκ `repeat` και των συνθηκών μαζί. Υπάρχουν πολλοί διαφορετικοί τρόποι για να λύσεις αυτή την άσκηση. Η πρόκλησή σου είναι να τη λύσεις με τρόπο που δίνει καθαρό, ικανοποιητικό κώδικα.

Μια καλή ερώτηση που μπορείς να κάνεις στον εαυτό σου είναι: "Πώς θα έκανε κάτι τέτοιο ένας χτίστης στον πραγματικό κόσμο;"
