Καλώς ήρθες στο Wordle! Το παιχνίδι λειτουργεί ως εξής: υπάρχει μια σωστή μυστική λέξη και έχεις 6 μαντεψιές για να τη βρεις. Σε κάθε μαντεψιά, αν ένα γράμμα είναι σωστό, γίνεται πράσινο. Αν υπάρχει στη λέξη αλλά σε λάθος θέση, γίνεται κίτρινο. Αν λείπει, γίνεται γκρι.

Η αποστολή σου είναι να φτιάξεις μια συνάρτηση που ονομάζεται `processGuess` (επεξεργασία της μαντεψιάς) και δέχεται δύο εισόδους: τη μυστική λέξη-στόχο και τη μαντεψιά που έκανε ο παίκτης. Θα πρέπει να υπολογίσεις την κατάσταση κάθε γράμματος και μετά να καλέσεις τη συνάρτηση `colorRow(1, states)` (χρωμάτισε τη γραμμή) με μια λίστα καταστάσεων για κάθε γράμμα: είτε `"correct"`, είτε `"present"`, είτε `"absent"`.

Για παράδειγμα, αν η μαντεψιά ήταν σωστή, θα καλούσες:

```
colorRow(1, ["correct", "correct", "correct", "correct", "correct"])
```

Έχεις επίσης πρόσβαση στη συνάρτηση `push(list, element)` (προσθήκη στη λίστα), η οποία προσθέτει ένα στοιχείο σε μια λίστα και επιστρέφει τη νέα λίστα.
