Μέχρι τώρα, όταν κοιτούσες γύρω σου, έλεγχες για λέξεις. Τώρα όμως αναβαθμίσαμε τους λαβυρίνθους ώστε να χρησιμοποιούν emoji! Επομένως, πρέπει να ενημερώσεις τον κώδικά σου ώστε να χειρίζεται τα εξής:

- `"star"` (Εκεί όπου ξεκινάς)
- `"flag"` (Εκεί όπου προσπαθείς να φτάσεις)
- `"white square"` (Ένα κενό τετράγωνο όπου μπορείς να μπεις)
- `"fire"` (Πρόσεξε!)
- `"poop"` (Μπλιαχ!)
- `"brick"` (Ένας τοίχος)

Σκορπίσαμε επίσης μερικά επιπλέον emoji στους λαβυρίνθους για να τα μαζέψεις. Κάθε φορά που ο χαρακτήρας σου βρίσκει ένα emoji που δεν περιλαμβάνεται στην παραπάνω λίστα, πρέπει να το προσθέτει στο σύνολό του.

Για να σε βοηθήσουμε, προσθέσαμε:

- Μια νέα κατεύθυνση προς την οποία μπορείς να κοιτάξεις (`"down"`!). Αυτή σου λέει τι βρίσκεται στο τρέχον τετράγωνο.
- Μια νέα συνάρτηση `removeEmoji()` (αφαίρεση emoji) που αφαιρεί όποιο emoji βρίσκεται στο τρέχον τετράγωνο από τον ασπροπίνακα. Μην προσπαθήσεις να μαζέψεις κάποιο ειδικό emoji από την παραπάνω λίστα!

Μόλις μπεις στο τετράγωνο τερματισμού, θα πρέπει να χρησιμοποιήσεις τη συνάρτηση `announceEmojis(result)` (ανακοίνωση emoji), περνώντας της ένα λεξικό που αντιπροσωπεύει το πλήθος των emoji που έχεις συλλέξει.

Τώρα θα ήταν μια καλή στιγμή να χρησιμοποιήσεις τη συνάρτηση `hasKey()` (ύπαρξη κλειδιού)!
