私が子どものころ、毎日学校へ持っていくお弁当箱にお昼ごはんを詰めていました。母はいつも、私のために品物を出しておいてくれました（大きいものから小さいものの順に、きれいに並べて）。できるだけたくさんお弁当箱に詰め込もうとしましたが、入る量にはもちろん限りがありました。入りきらなかったものは、ロッカーに置いておくのではなく、リュックサックに入れて一日中持ち歩くことになりました。

この演習での目標は、何をお弁当箱に入れられて、何をリュックサックに入れなければならないかを見きわめるアルゴリズムを作ることです。

書くのは、`packLunch(items, capacity)`（お弁当箱に詰め込む）という、2つの入力を受け取る関数です。1つ目の入力は品物の配列（大きい順）で、2つ目はお弁当箱の大きさを表す`capacity`（容量）という数値です。

品物の配列は入れ子の配列です。それぞれの品物も、2つの要素を持つ配列になっています。要素は品物の名前と、その大きさです。品物はいつも大きいものから小さいものの順に並んでいます。たとえば、品物の配列はこのようになります。

```javascript
[
  ["Water bottle", 20],
  ["Crisps", 10],
  ["Peanut Butter Sandwich", 8],
  ["Chocolate bar", 6],
  ["Satsuma", 3]
]
```

お弁当箱には最大容量があります。どの品物がお弁当箱に入るかを考えましょう。できるだけたくさんの品物を詰め込み、残りはすべてリュックサックに入れます。

関数は、2つの要素を持つ配列を返します。1つ目の要素はお弁当箱に入れる品物の配列で、2つ目はリュックサックに入れる品物の配列です。どちらの配列も、小さいものから大きいものの順に並べます。

たとえば、上の配列で容量が20のときは、次のように返します。

```javascript
return [
  ["Satsuma", "Chocolate bar", "Peanut Butter Sandwich"],
  ["Crisps", "Water bottle"]
]
```

### 役に立つメソッド

このセクションのどの演習でも同じですが、配列を作るには`.push(element)`メソッドを使います。

また、`[...].toReversed()`という新しいメソッドもあります。配列のすべての要素を逆順に並べたコピーを作ります。たとえば、次のとおりです。

```
["A", 1, true].toReversed()
// [true, 1, "A"]
```

使う必要はありませんが、便利かもしれません。
