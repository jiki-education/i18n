これから『詩の冒険』という、ロボットが詩を朗読するゲームを作ります。まず最初のステップとして、ロボットが歩きながら言葉を集め、最後に詩を朗読できるようにプログラムします。

それぞれのマスには、次の4つのうちのどれかが入っています。

1. 何もない（`""`）
2. 詩に出てくる**言葉**。
3. 葉っぱや蝶のような風景（絵文字）。
4. チェッカーフラッグ（`🏁`）。これはロボットに止まるように伝えます。

手助けのために、いくつかの関数が用意されています。まず`move()`関数です。これは詩のロボットに次のマスへ進むように伝え、そこにあったものを返します。次に`isEmoji(thing)`関数です。これは、渡した文字列が絵文字かどうかを真偽値で返します。そして最後に`recite(poem)`関数があります。これは、最後にできあがった詩を朗読するために使います。

ここでの仕事は、道を歩いて詩を組み立て、それを朗読することです。

## ルール

- **言葉**は詩に加えられ、**それぞれの間にスペース**が入ります。
- **風景**は詩の一部ではないので、無視します。
- **アポストロフィ**は単独のマスにあり、両側の言葉をつなぎます。`heart`、`'`、`s`の順なら`heart's`になります。
- **カンマ**も単独のマスにあります。前の言葉にくっつきますが、そのあとにはスペースが入ります。
- 詩人は、**チェッカーフラッグ**にたどり着くか、**7つの言葉**を集め終えたときのどちらか早いほうで歩くのをやめます。
- 詩人は、どんなふうに止まったとしても、止まった時点で集めたものを朗読します。`recite()`を呼び出せるのは**1回**だけです。

## 制限

この演習にはたくさんの解き方がありますが、最近学んだ`continue`と`break`というキーワードを使ってほしいので、いくつかのルールを設けます。

1. 解答では、`continue`と`break`の両方を使う必要があります。
2. 解答では`&&`や`!`を使えません。
3. ヘルパー関数は書けません。
4. インデントは2段階までです。

```javascript

// 許可される例：インデント2段階
repeat() {
  if(...) {
    //...
  }
}

// 許可されない例：インデント3段階
repeat() {
  if(...) {
    if(...) {
    }
  }
}
```

つまり、できあがる解答はかなり「平坦」な形になります。
