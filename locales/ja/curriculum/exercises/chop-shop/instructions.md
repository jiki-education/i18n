品質よりもスピードを重視する小さなヘアサロンを経営しています。

お客さんの仕上がりは少し粗いかもしれませんが、椅子に長く座っている必要はありません。

スタイリングから本格的なヘアカットまで、いくつかのサービスを提供しています。サービスによって、かかる時間は違います。

予約の仕組みはなく、先着順で対応しています。

一日の終わりが近づいてくると、あとから来るお客さんに対応する時間があるかどうかを知る方法が必要になります。

`canFitIn`（この人を入れられるかどうか）という関数を書きましょう。この関数は、3つの入力を受け取ります。

- 1つ目は、すでに順番待ちしているヘアカットの一覧です（文字列の配列）。
- 2つ目は、新しく来たお客さんが希望するヘアカットです（文字列）。
- 3つ目は、その日にあと何分残っているかです（数値）。

そのお客さんを入れられるかどうかを、真偽値で返します。

提供しているスタイルは、次のとおりです。

- Mohawk：20分
- Slicked-Back Pixie：15分
- Bob：25分
- Shave and Polish：15分
- Afro Trim：45分
- Up-do：30分

### 入れ子の配列

これは、要素として別の配列を含む配列を扱う最初の演習です。これを「入れ子の配列」と呼びます。

入れ子の配列は、ほかの配列と基本的に同じです。ただ、中に入っているのが文字列や数値ではなく、別の配列になっています。

`cuts`（ヘアカットの一覧）という配列を見てみましょう。この配列には、ヘアカットごとの配列が入っています。それぞれの配列は、名前と所要時間という2つの要素を持っています。

この場合は、まず内側の配列（名前と所要時間のペア）に注目して、それらがもう1つの配列にまとまっていると考えるのがわかりやすいです。

インデックスの仕組みはほかの場所と変わりませんが、次のようにつなげて書くこともできます…

```javascript
let cuts = [
  ["Mohawk", 20],
  ["Slicked-Back Pixie", 15],
  ["Bob", 25],
  //...
]

cuts[0] // ["Mohawk", 20]
cuts[0][0] // "Mohawk"
cuts[0][1] // 20
cuts[2][0] // "Bob"
```
