毎日お店にふらっと立ち寄って、夕食に必要な材料を買い集めるのが好きなタイプですよね。いい運動にもなりますし、近所の店主とおしゃべりするきっかけにもなります。

毎日、レシピを選んで、冷蔵庫の中身を確認して、買う必要があるものをメモします。

そこで、プログラムを書いて面倒な作業をやってもらうことで、暮らしを少し楽にすることにしました！　プログラムが、リストにあるものと冷蔵庫の中身を照らし合わせて、その違いを出力してくれます。

この演習でやることは、`shoppingList(fridgeContents, recipeItems)`（買い物リスト）という関数を書くことです。この関数は2つの入力を受け取ります。1つは冷蔵庫の中身を表す文字列の配列で、もう1つはレシピの材料を表す文字列の配列です。そして、買う必要があるものを文字列の配列として返します。

たとえば、次のとおりです。

```javascript
let fridgeContents = ["tomatoes", "leaves", "milk"]
let recipeItems = ["beef", "tomatoes", "peppers"]

shoppingList(fridgeContents, recipeItems)
// ["beef", "peppers"]
```

### `push`メソッド

この演習を解くには、`.push(element)`メソッドを使って配列に要素を足していく必要があります。コードの中で新しく作れる配列は1つだけです。やり方がよくわからないときは、前の動画をもう一度見てみましょう。
