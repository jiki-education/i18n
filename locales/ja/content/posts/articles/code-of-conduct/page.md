## はじめに

Jikiは、共感的な対話を中心としたプラットフォームです。誰であれ、歓迎されていない、サポートされていない、侮辱された、あるいは差別されていると感じさせるようなコミュニケーションは、許容しません。

## 不快な思いをしたり、目撃した場合

虐待、ハラスメント、差別を目撃したり経験したり、不安や動揺を感じた場合は、abuse@jiki.ioまでメールでご連絡ください。ご報告を真摯に受け止めます。

## 執行

私たちは行動規範（CoC）違反を積極的に監視し、違反の報告を非常に重く受け止めています。これまでにも、違反が原因でコントリビューター、メンター、ユーザーを禁止したことがあります。

CoC違反の報告を受けた後、当該人物のJiki上および関連するコミュニケーションチャネルでの会話履歴を確認し、その人物が意図的にCoCを破ったのか、それともうっかり一線を越えてしまったのかを理解しようと努めます。通常、報告された人物に連絡を取り、懸念事項について話し合い、違反を繰り返すと禁止処分になることを警告します。違反は発生していないと判断し、対応が不要と判断する場合もあれば、初回の違反で禁止処分にする場合もあります。公正を期すよう努めますが、コミュニティの文化を守ることを優先して判断します。

Jiki Ltdの経営陣は、CoC違反に関して適切と判断するあらゆる措置を講じる権利を留保します。

## 詳細

Jikiは、以下のような違いに関係なく、誰にとっても安全な場所であるべきです。

- 性別、性自認、性表現
- 性的指向
- 障害
- 身体的外見（体型を含むがこれに限定されない）
- 人種
- 年齢
- 宗教
- その他、思いつくあらゆる事柄。

このコミュニティの一員として、以下のことに同意していただきます。

- 私たちは、全員が一丸となって、安全と包括性に取り組んでいます。
- 私たちは、虐待、ハラスメント、差別を一切許容しません。
- 私たちは、個人の境界線とアイデンティティを尊重します。
- 私たちは、攻撃的または抑圧的とみなされる可能性のある言葉遣い（組織的なものであれ、そうでないものであれ）—例えば、性差別的、人種差別的、同性愛嫌悪的、トランスフォビック、障害者差別的、階級差別的な言葉など—を控えます。これには、さまざまな差別用語も含まれます（ただし、これに限りません）。
- 私たちは、不快な話題をユーモアの材料として使うことを避けます。

私たちは、積極的に以下のことを目指しています。

- 安全なコミュニティであること
- 互いに支え合い励まし合うネットワークを育むこと
- 責任感のある多様な表現を奨励すること

私たちは、以下のことを非難します。

- ストーカー行為、晒し行為（個人情報の暴露）、またはプライベートな情報の公開
- 暴力、暴力の脅迫、暴力的な言葉遣い
- 人々の安全を脅かすあらゆる行為
- 性差別的、人種差別的、同性愛嫌悪的、トランスフォビック、障害者差別的、またはその他の差別的・攻撃的な性質を持つ行為や言動。
- 歓迎されない、示唆的、軽蔑的、不適切なニックネームや用語の使用。
- 他者への敬意の欠如（冗談、ほのめかし、軽視する態度）、および意見の相違に対する敬意の欠如。
- 脅迫やハラスメント（オンラインまたは対面）。ハラスメントの解釈については、[Citizen Code of Conduct](https://github.com/stumpsyn/policies/blob/master/citizen_code_of_conduct.md)をご覧ください。
- 不適切な注意や接触。
- 建設的な批判と中傷の違いを理解しないこと。

これらのことは許容されません。

自分の行動が他者にどのような影響を与えるかを意識してください。誰かが不快に感じたら、その行動をやめてください。

もし、攻撃的な発言をしてしまい、それを指摘された場合は、以下のことを試してみてください。

- 中断せずに耳を傾けてください。
- 相手の話を信じ、相手の言い分を否定しようとしないでください。
- 今後同じ過ちを犯さないようにするためのヒントや助言を求めてください。
- 謝罪し、許しを請うてください。
