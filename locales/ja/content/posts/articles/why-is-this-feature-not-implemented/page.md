コードを実行しようとして、このバージョンの言語では利用できないというメッセージが表示されましたか？　続きを読んで、何が起きているのか確認してみましょう！

もし「この機能はまだご利用いただけません」というメッセージが表示された場合は、別の状況です。代わりに **[この機能がアンロックされるのはいつですか？](/articles/when-will-this-feature-unlock)** をお読みください。

## はじめに

Jikiのバージョンの言語ではサポートされていないキーワードや概念を使おうとされましたね。ご心配なく。これはバグではありません！

Jikiで使用しているJavaScriptとPythonのバージョンは、学習を助けるために**特別に設計**されています。複雑で混乱を招く部分に、準備が整う前に誤って飛び込んでしまわないように、特定の機能を注意深く除外してあります。

## 機能を除外する理由

プログラミング言語は、**プロフェッショナル**向けに設計されています。経験豊富な開発者の作業を速くする高度な機能や、歴史的な負の遺産（おそらく何年も前に削除されるべきだったのに、古いシステムが動き続けるために残っている機能）が含まれています。

学習中は、これらの機能が混乱を生みます。Jikiはそれらを取り除くことで、重要なことに集中できるようにしてくれます。つまり、**プログラマーのように考えることを学ぶ**ことです。

### 自滅の元になりやすい機能

誤って自分の足を撃ってしまうような機能を、**「自滅の元になりやすい機能」**と呼んでいます。それは以下のようなものです：

- **本当に問題があり**、プロでさえ避けるべきもの
- **混乱させるエッジケース**で、核心概念から注意をそらすもの
- **後方互換性のためだけに存在する歴史的な負の遺産**

これらは、引き起こす混乱に見合う価値がないため、Jikiでは永久に除外されています。

### 高度な機能

その他の機能は、学習の段階において**高度すぎる**ために除外されています。これらは悪い機能ではありません。基本を学んでいる段階では、単に助けにならないだけです。

Jikiを進めていくにつれて、一部の機能はアンロックされます。しかし今は、基本をマスターすることに集中しましょう。

## 具体的な内容

内部で何が起きているのか、またどのような判断がなされたのかに興味がなければ、このセクションを読む必要はありません。

### JavaScript

| 機能 | 除外理由 |
| --- | --- |
| `var` | 代わりに`let`または`const`を使用してください。`var`は混乱させるスコープのルールがあり、経験豊富な開発者でもバグを引き起こします。 |
| `with` | 非推奨で混乱を招きます。解釈が難しい曖昧なコードを作り出します。 |
| `debugger` | 開発ツールであり、学習には不要です。 |
| `void` | めったに役立たず、初心者には混乱を招きます。 |
| `yield` | 高度なジェネレーター機能です。ジェネレーターについては後ほど学習します。 |
| `delete` | 配列やオブジェクトで混乱を招く動作を引き起こす可能性があります。 |
| `import` / `export` | モジュールシステムの機能です。Jikiでは物事をシンプルに保つために、モジュールの扱いを変えています。 |
| ビット演算子（`&`・`|`・`^`・`~`・`<<`・`>>`・`>>>`） | ごくまれにしか必要とされず、学習中は混乱を招きます。低レベルのビット操作のためのものです。 |

### Python

| 機能 | 除外理由 |
| --- | --- |
| `global` | 関数内からグローバル変数を変更すると混乱を招くコードになります。代わりに値を引数として渡す方法を学びましょう。 |
| `nonlocal` | 入れ子関数のための高度なスコープ機能です。基本を学ぶ際には不要です。 |
| `assert` | 本番環境で無効化できるデバッグツールです。代わりに適切なエラーハンドリングを学びましょう。 |

## 機能が必要な場合

Jikiの演習は、その時点までに学んだ機能だけで解けるように設計されています。制限にぶつかったら、たいていは利用可能な機能を使って問題を解決する、より良い方法があります。それが学習の一部です。制約の中でうまくやる方法を見つけることです。

もし、今のレベルで本当に利用できるべきだと思う機能があれば、お知らせください！　フィードバックをもとに、何を含めるか常に見直しています。
