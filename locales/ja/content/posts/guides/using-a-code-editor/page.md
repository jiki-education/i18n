## はじめに

自分のコンピューターでコードを書き始めるときには、コードを書くための「場所」が必要です。それがコードエディタです。プログラミングの旅で最初に手にするツールの一つであり、キャリアを通じて長い時間を過ごす場所になります。時間が経つにつれて、別のエディタに切り替えたり、新しいものを試してみたくなることも多いので、コードエディタが何なのか、最初に使うのに良いものをどう選ぶかを理解しておくことはとても大切です。

## コードエディタはワードプロセッサではない

文字を入力できるプログラムなら何でも使えると思いがちですが、それは誤解です。特によくある間違いは、Microsoft WordやGoogle Docsのようなワードプロセッサを使ってしまうことです。これらは人が読むための文書を作るために作られているので、入力した内容をこっそりと変えてしまいます。たとえば、まっすぐな引用符がカーリー引用符（「スマートクォート」）に変換されたり、単語が自動修正されたり、目に見えない書式情報が保存されたりします。こうした変更がコードを壊してしまうのです。

コードエディタはテキストエディタの一種です。プレーンテキストを扱い、隠れた書式を追加しないので、入力した内容がそのままコンピューターに伝わります。コードエディタと普通のテキストエディタの違いは、コードを書くために特別に設計されている点です。プレーンテキストに加えて、書いているものの構造を理解し、ワードプロセッサでは決してできない方法で助けてくれます。

- **シンタックスハイライト**：コードの各部分を色分けして、読みやすくし、間違いを見つけやすくします。
- **オートインデント**：コードの行頭を自動的に揃えてくれます。多くの言語ではこれがとても重要です。
- **エラーヒント**：プログラムを実行する前に、よくある問題を指摘してくれます。
- **オートコンプリート**：入力中の内容の続きを提案してくれるので、速く入力でき、タイプミスも減ります。
- **拡張機能**：新しい言語やツールのサポートを追加でき、スキルアップに合わせて機能を拡張できます。

## おすすめのエディタ

優れたコードエディタはたくさんあり、どれを選んでも大きな間違いにはなりません。とはいえ、**Visual Studio Code**（通称 VS Code）をおすすめします。無料で、Windows、macOS、Linux で動作し、初心者にも使いやすく、世界中で最も広く使われているエディタの一つです。そのため、ほとんどのチュートリアルでも VS Code を使うことを前提に書かれています。

インストールの準備ができたら、[VS Codeのインストールガイド](/guides/installing-vscode)をご覧ください。

## 他のエディタについて

Jikiの学習を進めるうえで、これらのエディタは必要ありませんが、これから耳にする機会があると思います。そこで、代表的なものを簡単に紹介しておきます。

- <a href="https://code.visualstudio.com" target="_blank" rel="noopener noreferrer">Visual Studio Code (VS Code)</a>は、おすすめの無料クロスプラットフォームエディタです。
- <a href="https://www.sublimetext.com" target="_blank" rel="noopener noreferrer">Sublime Text</a>は、高速で軽量なエディタで、長年にわたり人気があります。
- <a href="https://zed.dev" target="_blank" rel="noopener noreferrer">Zed</a>は、新しい世代の非常に高速なエディタで、スピードとコラボレーションに重点を置いています。
- <a href="https://www.jetbrains.com/ides/" target="_blank" rel="noopener noreferrer">JetBrains IDEs</a>（<a href="https://www.jetbrains.com/pycharm/" target="_blank" rel="noopener noreferrer">PyCharm</a>や<a href="https://www.jetbrains.com/idea/" target="_blank" rel="noopener noreferrer">IntelliJ IDEA</a>など）は、大規模なプロジェクトに取り組むプロのエンジニア向けの、多機能でリッチなツールです。
- <a href="https://www.vim.org" target="_blank" rel="noopener noreferrer">Vim</a>と<a href="https://neovim.io" target="_blank" rel="noopener noreferrer">Neovim</a>は、ターミナル上で動作するキーボード駆動のエディタです。経験豊富なエンジニアに愛されていますが、習得には時間がかかります。

学習中のアドバイスはシンプルです。まずは VS Code から始めて、コードを書くことに慣れ、自分の好みがわかってきたら他のエディタも試してみてください。
