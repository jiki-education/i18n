## はじめに

このガイドでは、ウェブページとは実際には何なのか、そしてそれがどう動くのかについて、少しお話ししたいと思います。扱うのは、できるだけ基本的なことだけです。すでにHTMLを少し知っている人には、かなり基本的に感じられるかもしれません。まだ知らない人には、この先のすべてにつながる良い入門になるはずです。

## ウェブページとは何か

ウェブページは、ただのテキストファイルです。あるウェブサイトを訪れると、ブラウザにHTMLファイルが送られ、ブラウザがそれを読み取って描き出し、目に見えるページを作ります。

これは今すぐ自分で確かめられます。どのウェブサイトでもいいので開き、ページのどこかで右クリックし、**ページのソースを表示**（View Page Source）を選んでみましょう。それがHTMLです。大きなサイトでは、たくさんのコードが並んでいて圧倒されるかもしれませんが、それもすべて、このあと見ていくほんのいくつかの構成要素からできています。

HTMLは**HyperText Markup Language**（ハイパーテキストマークアップ言語）の略です。「マークアップ」とは、テキストに、その各部分が何なのかという追加情報を付け加えるという意味です。Chromeであれほかのブラウザであれ、ブラウザはその印を読み取り、それをもとに、画面上にすべてをどう配置するかを決めます。

## タグ

HTMLは**タグ**で有名です。タグは、先頭に`<`、末尾に`>`が付きます。この山括弧の間に、そのタグが何についてのものかを書きます。そのあとに内容が続き、最後に閉じタグを書きます。閉じタグは開始タグと同じですが、スラッシュが付きます。

例を見てみましょう。

```html
<p>Hello there.</p>
```

`p`はparagraphの略で、段落という意味です。こう書くことで、画面上に段落を描画してほしいということ、そしてその段落のテキストが"Hello there."であることをブラウザに伝えています。

タグには、**属性**と呼ばれる追加情報を持たせることもできます。属性は開始タグの中に書きます。リンクが良い例です。

```html
<a href="https://jiki.io">Visit Jiki</a>
```

リンクを作るには`a`タグを使います（これはanchor、つまり錨の略で、[少し変わった歴史的な理由](https://thehistoryoftheweb.com/brief-history-hypertext/)があります）。リンクには通常`href`属性があり、リンク先を指定します。タグの間のテキストが、クリックする部分になります。

一部のタグは内容を囲まないため、閉じタグがありません。画像がその典型例です。

```html
<img src="photo.jpg" alt="A photo of me on a mountain" />
```

`img`はimage（画像）の略です。`src`属性は画像ファイルを指し、`alt`属性はスクリーンリーダーを使う人に向けて画像を説明します。画像の読み込みに失敗したときに表示されるのもこのテキストです。

## ページの骨組み

どのウェブページも、同じ骨組み、同じ骨を持っています。こちらが、作れる中で最も最小限の**正しい**ページです（もっと少ないHTMLで、正しくないページも作れますし、ブラウザはそれも表示してくれます。でも、これからも続けていくつもりなら、責任あるエンジニアらしく、最初から正しく始めましょう！）。

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Jeremy Walker</title>
  </head>
  <body>
    <h1>Jeremy Walker</h1>
    <p>I build things on the web.</p>
  </body>
</html>
```

上から順に見ていきましょう。

`<!doctype html>`の行は、これが現代のHTML文書であることをブラウザに伝えます。これは必ず必要な定型文です。先頭に一度書いたら、あとはもう気にしなくて大丈夫です。

`html`タグは、文書全体を包むルート要素です。`lang="en"`属性は、そのページが英語で書かれていることをブラウザや検索エンジンに伝えます。

その中には、**head**と**body**という2つの部分があります。

### head

headに入るのは、画面に**表示されない**ものすべてです。これはメタデータです。メタデータとは、目に見えるものではなく、ページについてのデータのことです。この例では、2つのものが入っています。

- `<meta charset="UTF-8" />`は、そのページが使う文字のセットを指定します。UTF-8は標準的な文字セットで、ほとんどすべてをカバーします。ラテン文字、アクセント記号付きの文字、ほかの文字体系、絵文字まで含まれます。HTMLに絵文字を貼り付けたとき、それが正しく表示されるようにするのがこの行です。必ず入れておきましょう。
- `<title>`は、ブラウザのタブの上部に表示されるテキストを設定します。検索エンジンがページの見出しとして使うのもこれです。コーディングをしていると、誰かがタブを20個開いているときに、ここに何を表示したいかをよく考えるようになります。

headには、もう1行よく見かけるものがあります。見分けられるようになっておく価値があります。

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

これは、スマートフォンでページを極端に縮小するのではなく、適切なサイズで表示するように伝えます。今はこれ以上気にする必要はありません。入れて先に進みましょう。

### body

bodyは、実際に目にするものすべて、タブとアドレスバーの下にある大きな四角い領域に入るものすべてです。すべての見出し、段落、画像、リンクはbodyの中にあります。このガイドの残りでは、そこに入れるタグについて見ていきます。

## index.html

タグの話に入る前に、もう一つ知っておく価値のあることがあります。`index.html`という名前のファイルがウェブサイトの最初のページになる、というとても古くからの慣習があります。ドメインのあとに何も付けずにアクセスすると、そのウェブサイトは`index.html`というファイルがあるかどうかを探し、あればその中身をそのまま表示します。ファイル自体に特別な力があるわけではありません。ほとんどすべてのウェブサイトが従っている標準的な決まりごとにすぎません。なので、ホームページはこの名前のファイルに置くようにしましょう。

## まず使うことになるタグ

10個に満たないタグで、本当に役に立つページが作れます。使う順番にだいたい沿って、見ていきましょう。

### 見出し

見出しには6つのレベルがあり、`h1`から`h6`まであります。

```html
<h1>Jeremy Walker</h1>
<h2>About me</h2>
<h3>My photography</h3>
```

`h1`はページのメイン見出しで、通常は1つだけにします。セクションの見出しには`h2`、その中の小見出しには`h3`、というように使います。`h1`はレベル1の見出しなので、ブラウザはそれを少し大きく、少し太く表示すべきだと判断します。

見出しのレベルは、見た目の大きさではなく意味で選びましょう。見出しは、本の章や節のように、ページのアウトラインを作ってくれます。

### 段落

`p`タグはテキストの段落を表し、どのページでも、ほとんどすべての言葉はこの中に入っています。

```html
<p>I have been building things on the web for thirty years.</p>
<p>These days I spend most of my time working on Jiki.</p>
```

段落ごとにタグを付けます。段落の間のスペースは、ブラウザが自動で入れてくれます。

### リスト

リストには2種類あります。**順序なしリスト**（`ul`）は箇条書きの点になり、**順序ありリスト**（`ol`）は番号になります。どちらでも、各項目は**リスト項目**（`li`）になります。

```html
<ul>
  <li>Photography</li>
  <li>Podcasting</li>
  <li>Teaching people to code</li>
</ul>
```

`ul`を`ol`に変えると、点が1、2、3の番号になります。

### リンク

リンクがあるからこそ、ウェブはウェブになっています。`a`タグは、どんなものでもクリックできるものに変えます。

```html
<p>You can find my code on <a href="https://github.com/ihid">GitHub</a>.</p>
```

リンクは、ほかのウェブサイトを指すことも、自分のサイトの別のページを指すこともできます。`index.html`の隣に`resume.html`があれば、`<a href="resume.html">My resume</a>`でリンクできます。

### 画像

`img`タグは、ページに画像をのせます。

```html
<img src="images/me.jpg" alt="Jeremy standing on a hill in the Lake District" />
```

`src`には、自分のサイトのファイルでも、完全なウェブアドレスでも指定できます。`alt`テキストには、必ずその画像を本当に説明する内容を書きましょう。

### 強調

2つの小さなタグで、テキストの中の言葉を強調できます。`strong`は重要なものを表し、ブラウザは太字で表示します。`em`は強勢的な強調を表し、ブラウザは斜体で表示します。

```html
<p>The struggle is where the <strong>learning</strong> happens, so <em>write your own solutions</em>.</p>
```

## ページに構造を与える

ここまで見てきたタグは、個々の内容を表すものでした。それとは別に、ページの領域を表すタグの一族があります。これらはよく**セマンティックタグ**と呼ばれます。見た目を変えるのではなく、それぞれの領域に意味を与えるタグだからです。

- `header`はページの上部の領域を囲みます。通常はサイト名やロゴが入ります。
- `nav`はナビゲーション、つまりサイト内のほかのページへのリンクのまとまりを囲みます。
- `main`はページのメインコンテンツを囲みます。1つだけにします。
- `section`は、まとまった1つの内容をグループ化します。通常はそれ自身の見出しを持ちます。
- `article`は、ブログ記事やニュース記事のような、それだけで完結するまとまりを囲みます。
- `footer`はページの下部の領域を囲みます。通常は著作権表示や連絡先へのリンクが入ります。

これらを使った個人ホームページは、こんな形になるかもしれません。

```html
<body>
  <header>
    <h1>Jeremy Walker</h1>
    <nav>
      <a href="index.html">Home</a>
      <a href="resume.html">Resume</a>
      <a href="portfolio.html">Portfolio</a>
    </nav>
  </header>
  <main>
    <section>
      <h2>About me</h2>
      <p>...</p>
    </section>
    <section>
      <h2>My projects</h2>
      <p>...</p>
    </section>
  </main>
  <footer>
    <p>Get in touch at jeremy@example.com.</p>
  </footer>
</body>
```

これらのタグは、それだけではページの見た目をほとんど変えません。では、なぜわざわざ使うのでしょうか？　意味を持った構造は、画面を見ている人間以外の、ページを読むあらゆるものの助けになるからです。スクリーンリーダーはこれらのタグを使って、目の不自由なユーザーがナビゲーションやメインコンテンツに直接ジャンプできるようにします。検索エンジンは、ページが何についてのものかを理解するために使います。そして、あとでページのスタイルを整えるときにも、よく整理されているとすべてがぐっと楽になります。

ページのあるまとまりがこれらのどれにも当てはまらない場合、汎用的なコンテナが2つあります。まとまった内容には`div`、テキスト中のいくつかの単語には`span`です。これらにはまったく意味がありません。だからこそ、まずは意味のあるタグを選ぶようにしましょう。

## 覚えておきたいほかのタグ

これらを暗記する必要はありませんが、ほかの人のページを見ていると出会うので、存在だけでも知っておく価値があります。

- `blockquote`は、どこかからの引用に使います。
- `code`はテキスト中の短いコードに、`pre`は整形済みテキストのまとまりに使います。
- `table`は、本当に表形式のデータに使います。行には`tr`、セルには`td`を使います。
- `form`、`input`、`label`、`button`は、訪問者からの入力を受け取るために使います。
- `video`と`audio`は、メディアを埋め込むために使います。
- `br`は、テキスト内の改行に使います。使うのはまれにしましょう。新しい段落が欲しいときは、新しい`p`を使います。

タグは全部で100以上ありますが、このガイドで紹介したタグで、目にするもの、書くもののほとんどをカバーできます。知らないタグに出会ったら、[MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element)で調べましょう。プロも使っているリファレンスです。

## 次に進むには

ここで学んだことを身につける一番の方法は、何かを作ってみることです。`index.html`を作り、このガイドの骨組みを入れ、見出し、段落、リスト、リンクを使って自分についてのページを組み立ててみましょう。できたらブラウザで開いて、作ったものを見てみましょう。

慣れてきたら、訪れたウェブサイトのソースを見る習慣をつけましょう。あちこちでタグを認識できるようになり、どんなに洗練されたサイトでも、今覚えたのとまったく同じ部品からできていることがわかります。

作ったページは今のところ、とても地味に見えるでしょう。それで大丈夫です。HTMLはページに構造を与えるものだからです。見た目を良くするのはCSSの仕事で、次はそこへ進みます。
