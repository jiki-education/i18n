Unaweza kutumia keyword `break` popote ndani ya mwili wa kitanzi chochote.

Sehemu iliyo kati ya mabano ya kukunja, hiyo ndiyo mwili wa kitanzi. Na Jiki atakapoona hivyo, atatoka kwenye kitanzi mara moja na kuendelea na msimbo wowote ulio chini ya kitanzi.

Kwa hiyo, ikiwa tuna hitaji linalosema endesha kitanzi hiki mara 50, lakini tunataka kusimama ikiwa mtumiaji amepiga risasi mara tano, tunaweza kuwa na `for` kitanzi juu kinachohesabu kuelekea 50.

Lakini basi tunaweza kuwa na sharti katikati ya kitanzi linalokagua ikiwa mtumiaji amepiga risasi mara tano, na ikiwa amepiga, tunatumia `break` (vunja, yaani toka kwenye kitanzi) kusimamisha kitanzi.

```javascript
for (let i = 0; i < 50; i++) {
  if (numShots >= 5) {
    break; // toka kwenye kitanzi
  }
}
```
