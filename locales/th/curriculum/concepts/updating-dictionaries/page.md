คุณรู้วิธีสร้างพจนานุกรม (_dictionary_) และดึงค่าออกมาได้แล้ว แต่ถ้าข้อมูลเปลี่ยนล่ะ จะเกิดอะไรขึ้น อีกสักวันเราก็ต้องอายุมากขึ้น จาก `42` ก็กลายเป็น `43`

แล้วเราเปลี่ยนค่าพจนานุกรมได้ยังไง ก็ใช้วิธีที่คล้ายกับตอนที่เราหาค่ามาก คุณรู้อยู่แล้วว่าเราใช้วงเล็บเหลี่ยมดึงค่าออกมา ก็ใช้วงเล็บเหลี่ยมตามด้วยเครื่องหมายเท่ากับเพื่อเปลี่ยนค่าพจนานุกรมได้เหมือนกัน Jiki เดินไปที่กล่องของ `person` หยิบหน้าสมุดสันห่วงออกมา หาคีย์ `"age"` เจอ แล้วลบ `42` ที่เขียนอยู่ตรงนั้นออก เขียน `43` ลงไปแทนที่ จากนั้นก็เอาหน้าสมุดใส่กลับเข้าไปในกล่อง นี่คือการเปลี่ยนตัวพจนานุกรมเอง

```javascript
person["age"] = 43
```

Jiki ไม่ได้สร้างพจนานุกรมใหม่ แต่เปลี่ยนสมุดเล่มที่อยู่ในกล่องอยู่แล้ว

แล้วถ้าอยากเพิ่มข้อมูลที่ยังไม่มีอยู่ก่อนล่ะ ก็ทำแบบเดียวกันได้เลย

ถ้าคุณระบุคีย์ที่ยังไม่มีอยู่ Jiki ก็จะเพิ่มคีย์ใหม่เข้าไปที่บรรทัดล่างสุดพร้อมกับค่านั้น

ในกรณีนี้ Jiki จะเปิดสมุดขึ้นมา มองหา `"country"` เห็นว่าไม่มี แล้วเพิ่มบรรทัดใหม่ไว้ที่บรรทัดล่างสุด โดยให้ `"country"` อยู่ทางซ้าย และ `"England"` อยู่ทางขวา

```javascript
person["country"] = "England"
```

ไวยากรณ์ (_syntax_) ก็เหมือนกับการเปลี่ยนค่าเป๊ะๆ Jiki จัดการทั้งสองแบบให้เอง ถ้าคีย์มีอยู่แล้ว Jiki ก็เปลี่ยนค่าให้ ถ้ายังไม่มี Jiki ก็เพิ่มให้ คุณไม่ต้องทำอะไรเป็นพิเศษเลย

และเหมือนกับที่คุณเริ่มจากอาร์เรย์ว่างแล้วค่อยๆ ใส่ของเข้าไป คุณก็เริ่มจากพจนานุกรมว่างแล้วเพิ่มคีย์ทีละตัวได้เหมือนกัน นี่ก็เป็นรูปแบบที่พบได้บ่อยมาก คุณจะเห็นแบบนี้อยู่ตลอด

การใช้พจนานุกรมที่พบบ่อยอย่างหนึ่งคือการนับจำนวนสิ่งของต่างๆ คุณกำหนดให้คีย์เป็นสิ่งที่เราอยากนับ และให้ค่าเป็นจำนวนที่นับได้ ลองนึกภาพว่าคุณกำลังดูนกอยู่ และอยากรู้ว่าเห็นนกแต่ละชนิดไปแล้วกี่ตัว ครั้งแรกที่เห็นนกชนิดหนึ่ง คุณก็ตั้งจำนวนของนกชนิดนั้นเป็นหนึ่ง จากนั้นทุกครั้งที่เห็นอีก คุณก็ดึงค่าปัจจุบันออกมาแล้วบวกเพิ่มอีกหนึ่ง เพื่อให้รูปแบบนี้ทำงานได้ เราต้องมีวิธีตรวจสอบว่าพจนานุกรมมีคีย์นั้นอยู่แล้วหรือเปล่า ถ้ามีก็บวกเพิ่มอีกหนึ่ง ถ้ายังไม่มีก็ต้องเริ่มนับที่หนึ่งก่อน

และเพื่อทำแบบนั้น เรามีเมธอดอยู่ในพจนานุกรม นั่นคือเมธอด `has` (มี)

คุณแค่ระบุคีย์ที่สนใจลงไป Jiki ก็จะตรวจสอบว่าพจนานุกรมมีคีย์นั้นหรือไม่ แล้วคืนค่าเป็นจริงหรือเท็จตามผลที่ได้

```javascript
person.has("age") // true
```

พอเอามารวมกัน รูปแบบการนับก็จะหน้าตาแบบนี้

```javascript
if (counts.has(letter)) {
  counts[letter] = counts[letter] + 1
} else {
  counts[letter] = 1
}
```
