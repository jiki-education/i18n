จนถึงตอนนี้ เวลาที่คุณเขียนฟังก์ชัน แต่ละฟังก์ชันก็แทบจะยืนอยู่ได้ด้วยตัวเอง และมีตรรกะทั้งหมดที่ต้องใช้ในการทำงานอยู่ในตัว

ตอนนี้เราจะมาดูการแยกฟังก์ชันออกเป็นชิ้นเล็กลง เพื่อให้ได้ฟังก์ชันเล็กๆ ที่ทำงานร่วมกัน แทนที่จะเป็นฟังก์ชันใหญ่ๆ ที่มีอะไรเกิดขึ้นเยอะแยะ

ตามหลักทั่วไปในการเขียนโปรแกรม เราอยากให้แต่ละฟังก์ชันทำงานให้น้อยที่สุดเท่าที่จะทำได้ เราเรียกสิ่งนี้ว่าฟังก์ชันที่มีความรับผิดชอบเดียว (_single responsibility_) แต่ละฟังก์ชันควรทำแค่อย่างเดียว และใช้ฟังก์ชันอื่นรับผิดชอบส่วนย่อยต่างๆ ของงานนั้น

ลองมาดูตัวอย่างกัน

สมมติว่าเรามีฟังก์ชันหนึ่งที่มีหน้าที่คืนค่าสตริงที่อธิบายชื่อคนๆ หนึ่ง

เวอร์ชันง่ายๆ จะหน้าตาแบบนี้ เรามีลูปนับจำนวน ซึ่งเป็นสิ่งที่คุณเคยเขียนมาแล้ว จากนั้นก็มี template string ที่ประกอบผลลัพธ์เข้าด้วยกัน

```javascript
function describeName(name) {
  let length = 0
  for (const letter in name) {
    length += 1
  }
  return `This name is ${length} letters long`
}
```

แบบนี้ใช้งานได้ดี แต่โค้ดนี้ทำสองอย่างอยู่ในตัว คือทำสิ่งหนึ่งที่ค่อนข้างทั่วไป คือการนับ และอีกสิ่งหนึ่งที่เฉพาะเจาะจงมาก คือการสร้างสตริงนี้ขึ้นมาในรูปแบบใดรูปแบบหนึ่ง

จะดีกว่ามากถ้าเราแยกส่วนนี้ออกเป็นสองฟังก์ชัน ฟังก์ชันหนึ่งรับผิดชอบการนับ และอีกฟังก์ชันรับผิดชอบการอธิบายชื่อในรูปแบบเฉพาะนี้

```javascript
// นับตัวอักษรเฉยๆ
function countLetters(str) {
  let count = 0
  for (const letter in str) {
    count += 1
  }
  return count
}

// จัดรูปแบบข้อความให้สวยงามเฉยๆ
function describeName(name) {
  const count = countLetters(name)
  return `The name has ${count} letters`
}
```

จากนั้นเราก็นำฟังก์ชันนับแบบทั่วไปตัวนั้นกลับมาใช้ใหม่ได้ ทั้งในการจัดรูปแบบสตริงนี้ และในที่อื่นๆ ที่เราต้องการ เมื่อไหร่ก็ตามที่ต้องนับตัวอักษรในสตริง ฟังก์ชันนี้ก็แยกออกมาจากทุกอย่างที่เกี่ยวกับการแสดงผลโดยสิ้นเชิง

คุณอ่านทั้งสองฟังก์ชันแยกกันได้เลย และเข้าใจทันทีว่าแต่ละตัวทำอะไร

เมื่อฟังก์ชันของคุณซับซ้อนขึ้นและมีจำนวนมากขึ้น เทคนิคนี้คือความแตกต่างระหว่างโค้ดที่เป็นระเบียบอ่านง่าย กับความสับสนวุ่นวายเต็มไปหมด

มีอีกเรื่องที่ควรพูดถึงอีกรอบตรงนี้ นั่นคืออะไรก็ตามที่คุณสร้างขึ้นในฟังก์ชัน ฟังก์ชันอื่นจะเข้าถึงไม่ได้ เว้นแต่คุณจะตั้งใจคืนค่าออกมา

ดังนั้นถ้าคุณลองอ้างอิงตัวแปร `count` (จำนวน) จากใน `describeName` (อธิบายชื่อ) คุณทำไม่ได้ เพราะตัวแปรนี้เป็นของฟังก์ชันอีกตัวหนึ่ง

ในภาษา JavaScript เราสร้างตัวแปรไว้ข้างบนสุดเหนือทุกอย่างได้ ซึ่งตัวแปรพวกนั้นจะถูกแชร์ใช้ร่วมกันระหว่างฟังก์ชัน แต่ขอแนะนำจริงๆ ว่าไม่ควรทำ เว้นแต่จะมีเหตุผลที่ดีจริงๆ

ยิ่งคุณทำให้แต่ละฟังก์ชันเป็นอิสระจากกันมากเท่าไหร่ ซึ่งคำทางเทคนิคที่ใช้เรียกก็คือฟังก์ชันบริสุทธิ์ (_pure function_) โค้ดของคุณก็จะยิ่งสะอาดขึ้น และบัคที่คุณสร้างขึ้นมาหรือต้องเจอก็จะยิ่งน้อยลง
