บางครั้งเราอาจอยากข้ามการวนรอบใดรอบหนึ่งของลูป แทนที่จะออกจากลูปไปทั้งลูป ลองนึกภาพว่าเราอยากทำอะไรบางอย่างกับตัวเลขคี่เท่านั้น

เราอยากบอกได้ว่า ถ้า `i` (ตัวนับ) เป็นเลขคี่ รอบนี้ก็ไม่ต้องรันลูป

แต่เราไม่ได้อยากออกจากลูปไปเลย เราอยากข้ามแค่การวนรอบนี้รอบเดียว แล้วไปดูรอบถัดไป

และสำหรับเรื่องนี้ เรามีคีย์เวิร์ดอีกตัวหนึ่งชื่อ `continue`

เมื่อ Jiki เจอ `continue` Jiki จะกระโดดกลับไปที่ด้านบนของลูปเพื่อเริ่มการวนรอบถัดไปทันที ดังนั้นในลูปแบบ for-of ถ้า Jiki เจอ `continue` Jiki ก็จะไปยังสมาชิกตัวถัดไปในอาร์เรย์

```javascript
for (let item of list) {
  if (item === "something") {
    continue; // ข้ามส่วนที่เหลือของลูปสำหรับ "something"
  }
  // ส่วนที่เหลือของลูป...
}
```

ในลูปแบบ for Jiki จะไปถึงขั้นตอนเพิ่มค่าของ `i++` แล้วเริ่มการวนรอบถัดไป

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue; // ข้ามส่วนที่เหลือของลูปเมื่อเป็นเลขคู่
  }
  // ส่วนที่เหลือของลูป...
}
```
