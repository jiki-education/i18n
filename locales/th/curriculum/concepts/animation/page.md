ที่ผ่านมา เวลาเราใช้ลูป `repeat` (ทำซ้ำ) วาดรูปต่างๆ สิ่งใหม่ที่เราวาดแต่ละครั้งจะเพิ่มอะไรบางอย่างเข้าไปในภาพ ถ้าเราวาดอิฐใหม่ลงไปในกำแพง ก้อนอิฐนั้นก็เติมช่องว่างให้เต็ม ถ้าเราวาดวงกลม 10 วง เราก็เห็นวงกลม 10 วงบนหน้าจอ เหมือนภาพวาดภาพหนึ่ง พอทาสีลงบนผนังแล้ว สีนั้นไม่หายไปตอนที่เราทาสีใหม่ข้างๆ สียังอยู่ตรงนั้น แต่ถ้าเราอยากทำให้อะไรสักอย่างดูเหมือนกำลังเคลื่อนไหวล่ะ

เคยเห็นสมุดพลิกภาพไหม ตอนเด็กๆ สมุดแบบนี้ฮิตมาก ตอนนี้ไม่ค่อยมีแล้ว สมุดพลิกภาพเป็นสมุดเล่มเล็กๆ ที่แต่ละหน้ามีภาพวาดต่างกันนิดหน่อย พอพลิกหน้าเร็วๆ ตาของเราจะเห็นภาพเปลี่ยนไป สมองก็คิดว่ามีอะไรกำลังเคลื่อนไหว จริงๆ แล้วไม่มีอะไรเคลื่อนไหวเลย เป็นแค่ภาพหลายๆ ภาพที่ต่างกันนิดหน่อย เรียงต่อกันไป และแอนิเมชันในโค้ดก็ทำงานแบบเดียวกันทุกประการ กลเม็ดเดียวกันเลย ก่อนที่เราจะวาดฉากใหม่ เราทาสีพื้นหลังให้ทั่วทั้งผืนผ้าใบ คล้ายกับเราเริ่มหน้าสมุดพลิกภาพขึ้นมาใหม่สักหน้า แล้วเราก็เปลี่ยนฉากนิดหน่อยให้ดูเหมือนมีการเคลื่อนไหว

ดังนั้น ถ้าเราหยิบโค้ดคุ้นเคยที่วาดวงกลมเรียงข้ามหน้าจอขึ้นมา แล้วตั้งตัวแปร `position` (ตำแหน่ง) ไว้ตัวหนึ่ง กับมีโค้ดบล็อก `repeat` ที่วาดวงกลมแล้วเลื่อน `position` ไปทางขวาอีกหนึ่ง ถ้าเรารันโค้ดบล็อก `repeat` นั้น 100 ครั้ง เราจะเห็นวงกลม 100 วงเรียงข้ามหน้าจอ

```javascript
let position = 0
repeat(100) {
  circle(position, 50, 5, "blue")
  position = position + 1
}
```

ทีนี้ลองดูว่าเกิดอะไรขึ้นถ้าเราเพิ่มสี่เหลี่ยมธรรมดาๆ หนึ่งรูปก่อนวาดวงกลมในแต่ละรอบ

```javascript
let position = 0
repeat(100) {
  rectangle(0, 0, 100, 100, "white")
  circle(position, 50, 5, "blue")
  position = position + 1
}
```

แทนที่จะเห็นวงกลมเรียงเป็นทาง ตาของเราก็ถูกหลอกให้เห็นวงกลมวงเดียวที่ดูเหมือนลอยไปข้ามหน้าจอ

ทุกครั้งที่เราวนรอบลูป เราทาพื้นหลังใหม่ทั้งผืน ปิดทับทุกอย่างที่เคยอยู่ตรงนั้น แล้ววาดวงกลมลงในตำแหน่งใหม่

แต่ละรอบของลูปก็เหมือนหน้าสมุดพลิกภาพหน้าใหม่หนึ่งหน้า

และสิ่งสำคัญที่ต้องเข้าใจตรงนี้คือ เราไม่ได้เลื่อนวงกลมไปไหน วงกลมไม่ใช่สิ่งของที่เลื่อนไถลข้ามจอ เป็นแค่ภาพวาดภาพหนึ่งเท่านั้น ทุกครั้งที่วนรอบลูป เราทาทับภาพวาดเดิม แล้ววาดภาพใหม่เอี่ยมขึ้นมาอีกหนึ่งภาพ เลื่อนไปทางขวานิดหน่อย ตาของเราประกอบทุกอย่างเข้าด้วยกันแล้วเห็นเป็นการเคลื่อนไหว แต่จริงๆ แล้วเป็นแค่ภาพวาดแยกกันหลายภาพ เรียงต่อกันไป

เราใช้ไอเดียนี้สร้างพระอาทิตย์ตกได้ ทำให้ดวงอาทิตย์เคลื่อนที่ เปลี่ยนขนาด เปลี่ยนสี ทั้งหมดใช้เทคนิคเดียวกัน กำหนดตัวแปรขึ้นมาสักสองสามตัว ทาพื้นหลังใหม่ แล้ววาดทุกอย่างลงไป เปลี่ยนค่าตัวแปร แล้วก็ทำซ้ำ
