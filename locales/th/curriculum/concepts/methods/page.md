จนถึงตอนนี้ เวลาที่เราคิดถึงสตริงหรือตัวเลข เรามองว่ามันเป็นอะไรที่ค่อนข้างนิ่ง

และถึงแม้จะเป็นแบบนั้น ข้างในสตริงกับตัวเลขก็ยังมีความสามารถมากมายที่สร้างมาไว้ให้ Jiki (จิ๊กิ) ใช้ได้

และจากนี้ไป เราจะมาเรียนเรื่องความสามารถพวกนี้ ความสามารถที่ติดมากับค่าพวกนี้ ซึ่งทำให้ชีวิตง่ายขึ้นเยอะ

ความสามารถที่เราจะมาดูกันมีอยู่สองแบบ คือ พร็อพเพอร์ตี้ (_property_) และเมธอด (_method_)

เมธอดคือฟังก์ชันที่สังกัดอยู่กับสตริง

ดังนั้นแทนที่เราจะต้องเขียนฟังก์ชันที่เอาสตริงใส่เข้าไปเป็นอินพุต เราก็เรียกใช้เมธอดบนสตริงได้เลย

ตัวอย่างเช่น ยังจำฟังก์ชันที่ใช้ตรวจว่าสตริงมีตัวอักษรตัวหนึ่งอยู่ข้างในไหมได้ไหม สตริงมีเมธอดที่เรียกว่า `includes` (ตรวจว่ามีข้อความนั้นอยู่ข้างในไหม) ที่ทำแบบนั้นให้อยู่แล้ว และเราเรียกใช้ได้ด้วยไวยากรณ์จุด (_dot syntax_) แบบเดียวกับที่เห็นในพร็อพเพอร์ตี้

สิ่งที่ต่างจากพร็อพเพอร์ตี้ก็คือ เวลาเขียนเมธอด เราจะเขียนเหมือนฟังก์ชัน คือมีวงเล็บและมีอินพุต

เราก็เขียนแบบนี้ได้

```javascript
"Jeremy".includes("e") // true
```

แล้วเราจะได้ `true` กลับมา เพราะ `"Jeremy"` มี `"e"` อยู่ข้างใน

เมธอดต่างจากพร็อพเพอร์ตี้ตรงที่เมธอดไม่ใช่ข้อเท็จจริงที่นิ่งอยู่กับที่ แต่เป็นฟังก์ชันจริงๆ เรามองเมธอดเป็นเหมือนฟังก์ชันที่มีกล่องในตัวบรรจุสตริงไว้ข้างในก็ได้

ส่วนว่าข้างในทำงานยังไง ตอนนี้ยังไม่ต้องสนใจ อีกสักพักกว่าจะได้สร้างเมธอดเอง สิ่งเดียวที่ต้องรู้คือ เราเรียกใช้เมธอดด้วยการใส่จุด แล้วตามด้วยไวยากรณ์ฟังก์ชันปกติ

อีกเรื่องที่ควรรู้เกี่ยวกับสตริงคือ เมธอดไม่เปลี่ยนอะไรข้างในสตริงเลย ตัวอย่างเช่น มีเมธอด `toUpperCase` (แปลงเป็นตัวพิมพ์ใหญ่) ซึ่งคืนค่าสตริงที่ตัวอักษรทุกตัวเป็นตัวพิมพ์ใหญ่ แต่นั่นไม่ได้เปลี่ยนสตริงตัวเดิม สตริงตัวเดิมยังมี `"Jeremy"` ที่เขียนด้วย J ตัวใหญ่แค่ตัวเดียวอยู่ Jiki จึงสร้างสตริงใหม่ที่ตัวพิมพ์ใหญ่ทั้งอันขึ้นมาแทน

```javascript
const name = "Jeremy"
const bigName = name.toUpperCase()

log(bigName) // "JEREMY"
log(name) // "Jeremy"
```
