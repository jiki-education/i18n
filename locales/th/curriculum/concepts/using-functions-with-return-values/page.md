ที่ผ่านมาเราได้ดูฟังก์ชันที่ลงมือทำอะไรบางอย่างในโลกจริงไปแล้ว อย่างฟังก์ชัน `circle` (วงกลม) ก็วาดวงกลมให้ ฟังก์ชัน `move` (เคลื่อนที่) ก็ขยับตัวละครของคุณ แต่ฟังก์ชันบางตัวทำงานต่างออกไป แทนที่จะไปทำอะไรข้างนอก ฟังก์ชันพวกนี้ให้อะไรบางอย่างกลับมา ซึ่งคุณเอาไปใช้ในโค้ดได้ เมื่อฟังก์ชันให้อะไรบางอย่างกลับมาให้ Jiki (จิ๊กิ) เอาไปใช้ในโค้ด เราบอกว่าฟังก์ชันนี้กำลังคืนค่า (_return_) อะไรบางอย่าง ฟังก์ชันคืนอะไรบางอย่างออกมาให้ Jiki ลองนึกว่าเครื่องพวกนี้มีรางคืนค่าติดอยู่ด้านหนึ่ง เรามีช่องใส่ที่ค่อยใส่ของเข้าไปอยู่แล้ว แต่เครื่องยังมีช่องส่งออกอีกหนึ่งช่อง หรือมีรางคืนค่าที่บางอย่างไหลย้อนออกมาได้ เมื่อ Jiki กดปุ่มบนเครื่อง เครื่องก็ทำงานส่งเสียงหึ่งๆ แล้วสุดท้ายก็มีอะไรบางอย่างโผล่ออกมาจากรางนั้น อาจเป็นตัวเลข อาจเป็นสตริง เป็นอะไรก็ได้ที่ Jiki รับไว้ได้และเอาไปใช้ได้

ฟังก์ชันส่วนใหญ่ อาจจะสัก 95% ของทั้งหมด คืนค่าอะไรบางอย่างออกมา อาจจะคำนวณเลขให้คุณแล้วคืนค่าออกมา หรือเอาสตริงหลายๆ อันมาต่อกันแล้วให้สตริงที่ได้กลับมา หรือบางทีก็คืนเวลาปัจจุบันให้คุณทุกครั้งที่รันเครื่องนั้น มาดูตัวอย่างสุดท้ายนี้กัน สมมติว่าเรามีฟังก์ชันชื่อ `getCurrentTime` (ดูเวลาปัจจุบัน) ทุกครั้งที่ Jiki รันเครื่อง แผ่นกระดาษก็จะไหลออกมาจากรางคืนค่า โดยมีเวลาเขียนอยู่บนแผ่น อาจจะเป็น 14:35

แล้วเราก็เอาค่าที่คืนออกมานั้นใส่ลงในกล่องได้ด้วย `let`

```javascript
let time = getCurrentTime()
```

Jiki จะรันเครื่อง ดึงเวลาปัจจุบันออกมาจากราง แล้วเก็บไว้ในกล่องที่ชื่อ `time`

สิ่งสำคัญที่ต้องเข้าใจคือ แผ่นกระดาษที่ Jiki ใส่ลงในกล่องถูกตรึงไว้ ณ วินาทีนั้น ถึงเวลาในโลกจริงจะเปลี่ยนไประหว่างที่โปรแกรมกำลังรัน กล่องก็ยังมีแผ่นกระดาษที่เขียนว่า 14:35 อยู่เหมือนเดิม เมื่ออะไรบางอย่างเข้าไปอยู่ในกล่องแล้ว สิ่งนั้นก็ถูกตรึงไว้ตรงนั้น ไม่ได้เปลี่ยนไปเองด้วยเวทมนตร์ ถ้าอยากเอาเวลาปัจจุบันใส่กล่องอีกครั้งในอนาคต เราก็ต้องเรียกใช้ฟังก์ชัน `getCurrentTime` อีกครั้งเพื่อเอาเวลานั้นมา

ฟังก์ชันส่วนใหญ่ที่คืนค่าอะไรบางอย่างก็มีช่องใส่ด้วยเหมือนกัน ตัวอย่างเช่น เราอาจมีฟังก์ชัน `join` (เชื่อมสตริงเข้าด้วยกัน) ที่รับสตริงสองอันเข้าไปทางช่องใส่ แล้วคืนค่าออกมาเป็นสองสตริงนั้นเชื่อมกันโดยมีช่องว่างคั่น ดังนั้นถ้าเราใช้เครื่อง `join` โดยใส่ `"Hello"` กับ `"World"` เข้าไป ทางรางก็จะมีสตริงเดียวที่เขียนว่า `"Hello World"` ไหลออกมา

```javascript
join("Hello", "World"); // "Hello World"
```
