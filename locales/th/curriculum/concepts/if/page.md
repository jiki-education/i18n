มีคีย์เวิร์ดตัวหนึ่งที่ช่วยให้เราบอก Jiki (จิ๊กิ) ได้ว่าให้ทำอะไรบางอย่างเฉพาะในบางสถานการณ์ สมมติว่าคุณกำลังเขียนโค้ดเพื่อเฝ้าประตูทางเข้าผับ คุณอาจจะเป็นยามหน้าผับก็ได้ และ Jiki ควรเปิดประตูก็ต่อเมื่อคนที่มาแต่งตัวเหมาะสมเท่านั้น หรือบางทีคุณอาจกำลังเขียนโค้ดที่คุณต้องโบกธงตาหมากรุกตอนจบการแข่งขัน แต่ Jiki ต้องรู้ว่า Jiki ควรโบกธงเฉพาะรอบสุดท้ายเท่านั้น ในสถานการณ์แบบนี้ เราจะใช้คีย์เวิร์ด `if`

เราใช้คีย์เวิร์ด `if` คล้ายกับคีย์เวิร์ด `repeat` มาก เราใสข้อมูลบางอย่างไว้ในวงเล็บธรรมดา ในกรณีนี้ ข้อมูลนั้นคือเงื่อนไข (_condition_) ที่เรากำลังตรวจสอบ แล้วเราใส่โค้ดบล็อกไว้ในวงเล็บปีกกา ซึ่งเราจะรันก็ต่อเมื่อเงื่อนไขนั้นเป็นจริง

```javascript
if (condition) {
}
```

แล้วเงื่อนไขพวกนี้หน้าตาเป็นยังไง โดยปกติแล้ว มักเป็นการเปรียบเทียบ (_comparison_) บางอย่าง เราเปรียบเทียบตัวเลขหรือสตริงสองค่า แล้วตรวจว่าผลลัพธ์เป็นจริงหรือเท็จ

ลองคิดว่าสิ่งเหล่านี้เป็นเงื่อนไข (_statement_) แบบที่คุณพูดออกมาได้เลย สามน้อยกว่าห้า อันนี้จริง เจ็ดน้อยกว่าสอง อันนี้เท็จ

เราใช้สัญลักษณ์ในการเขียนการเปรียบเทียบพวกนี้ คุณคงคุ้นเคยกับสัญลักษณ์เหล่านี้จากวิชาคณิตศาสตร์อยู่แล้ว เรามี น้อยกว่า มากกว่า น้อยกว่าหรือเท่ากับ มากกว่าหรือเท่ากับ และยังมีการตรวจสอบว่าสองสิ่งเหมือนกันไหม คือเท่ากันหรือเปล่า ตัวนี้ต่างจากที่คุณน่าจะเคยชินอยู่เล็กน้อย เพราะเราใช้เครื่องหมายเท่ากับสามตัวติดกันเพื่อดูว่าสองสิ่งเหมือนหรือต่างกัน

และสิ่งนี้ช่วยให้เราไม่สับสนกับตอนที่เรากำหนดค่าหรือเปลี่ยนค่าตัวแปร ซึ่งเราใช้เครื่องหมายเท่ากับตัวเดียวแปลว่าเอาใส่ลงในกล่อง จำไว้แค่ว่าเปรียบเทียบใช้เครื่องหมายเท่ากับสามตัว

เราเปรียบเทียบสตริงก็ได้ เช่น `"hello"` เท่ากับ `"hello"` อันนี้จริง ทั้งสองสตริงเหมือนกัน แต่ระวังตรงนี้นะ เพราะ Jiki เปรียบเทียบอักขระ (_character_) ทุกตัวในสตริงทั้งสอง บนกระดาษทั้งสองแผ่น ดังนั้น `"Hello"` ที่ขึ้นต้นด้วย H ตัวใหญ่ จึงไม่เท่ากับ `"hello"` ที่ขึ้นต้นด้วย h ตัวเล็ก ทั้งสองเป็นสตริงที่ต่างกัน ถ้าเอามาเปรียบเทียบกันผลก็เป็นเท็จ เพราะ H ตัวใหญ่กับ h ตัวเล็กเป็นอักขระที่ต่างกัน

อีกอย่างนะ จริงกับเท็จ เรียกกันว่า บูลีน (ค่าความจริง) ซึ่งเป็นอีกคำที่ฟังดูเป็นศัพท์เทคนิค แต่จริงๆ ง่ายมาก นี่เป็นแค่วิธีพูดแบบทางการว่าสิ่งหนึ่งเป็นจริงหรือเป็นเท็จ ถ้าคุณเจอคำว่าบูลีน ก็หมายความแค่ว่าจริงหรือเท็จ มาดูกันว่าใช้งานจริงเป็นยังไง สมมติว่าเรากำลังสร้างหุ่นยนต์ยามหน้าผับให้คลับแห่งหนึ่ง และเราจะบอกว่ายามควรเปิดประตูก็ต่อเมื่อคนที่มาอายุ 21 ปีขึ้นไป เรามีฟังก์ชัน `askAge` (ถามอายุ) ที่ใช้ดูอายุของใครสักคน แล้วเราเก็บผลลัพธ์ไว้ในตัวแปรชื่อ `age` (อายุ) จากนั้นเราก็บอกได้ว่า ถ้า `age` มากกว่า 20 เราก็เปิดประตู ดังนั้นถ้า `askAge` คืนค่า 30 เราก็เปิด และถ้าคืนค่า 12 เราไม่เปิด

```javascript
let age = askAge()
if (age >= 21) {
  openDoor()
}
```
