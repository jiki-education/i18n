ลูปตัวต่อไปที่เราควรรู้จักคือลูป while (ขณะที่)

ลูปแบบนี้บอกว่า "ขณะที่เงื่อนไขบางอย่างยังเป็นจริง ก็ให้วนลูป" ตัวอย่างเช่น เราอาจมีกฎว่าในเกม Space Invaders ยิงได้แค่ห้าครั้ง เราก็จะมีลูปที่บอกว่า ขณะที่จำนวนครั้งที่ยิงยังน้อยกว่าห้า ก็ให้รันลูปที่เปิดให้ผู้เล่นได้เล่นเกม

```javascript
while (numShots < 5) {
  // ยิงเอเลี่ยน
  numShots++
}
```

ทุกครั้งที่มีคนยิง เราจะเพิ่ม `numShots` ขึ้นหนึ่ง และสุดท้ายเราจะไปถึงห้า แล้วลูปก็จะจบ

ทีนี้ ปัญหาอย่างหนึ่งของลูป while คือ เราอาจสร้างบัคที่ทำให้ลูปไม่รู้จักจบได้ง่ายมาก เราเรียกสิ่งนี้ว่า ลูปอนันต์ (_infinite loop_) และลูปอนันต์ก็เป็นบัคที่พบบ่อยที่สุดชนิดหนึ่งในโปรแกรม

เวลาคอมพิวเตอร์ของคุณช้าลง พัดลมเริ่มหมุน ทุกอย่างเริ่มมีเสียงดัง นั่นมักเป็นเพราะมีใครสักคนทิ้งลูปอนันต์ที่ไม่มีวันจบไว้ในโค้ด
