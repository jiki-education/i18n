ลองนึกภาพว่าคุณมีชื่อ Jeremy และอยากดึงอักษรตัวแรก J ออกมาจากชื่อนี้ เราจะทำยังไงกันดี

เรามองสตริงเป็นตัวอักษรที่เรียงต่อกันเป็นชุดก็ได้ สตริง `"Jeremy"` จึงมีตัวอักษรหกตัว คือ J-E-R-E-M-Y และแต่ละตัวมีตำแหน่งของตัวเอง `"J"` อยู่ที่ตำแหน่งแรก ส่วน `"y"` อยู่ที่ตำแหน่งสุดท้าย

ทีนี้ ในภาษา JavaScript และภาษาโปรแกรมส่วนใหญ่ ตำแหน่งเหล่านี้เริ่มนับจากศูนย์ ตัวอักษรตัวแรก `"J"` จึงอยู่ที่ตำแหน่งที่ศูนย์ ตัวถัดมาคือ `"e"` ซึ่งอยู่ที่ตำแหน่งที่หนึ่ง `"r"` ที่ตำแหน่งที่สอง `"e"` ที่ตำแหน่งที่สาม `"m"` ที่ตำแหน่งที่สี่ และ `"y"` ที่ตำแหน่งที่ห้า

การเริ่มนับจากศูนย์แบบนี้ค่อนข้างแปลก และพูดตามตรง ชีวิตน่าจะง่ายกว่านี้มากถ้าเราเริ่มนับจากหนึ่งเหมือนในโลกปกติ แต่เราไม่ได้ทำแบบนั้น ในภาษาโปรแกรมส่วนใหญ่ เราเริ่มนับจากศูนย์แทน เราจึงต้องเรียนรู้ที่จะนับแบบนี้ให้ได้

ถ้าเราอยากได้ตัวอักษรที่ตำแหน่งใดตำแหน่งหนึ่ง เราก็ใช้เครื่องหมายวงเล็บเหลี่ยม แล้วใส่ตัวเลขไว้ข้างใน

ดังนั้นถ้าเราเขียน `"Jeremy"[0]` ก็เท่ากับเรากำลังบอกว่า ขอตัวอักษรตัวแรกของคำว่า `"Jeremy"` หน่อย

ถ้าเราเขียน `"Jeremy"[1]` ก็เท่ากับเรากำลังบอกว่า ขอตัวอักษรตัวที่สอง

```javascript
"Jeremy"[0] // "J"
"Jeremy"[1] // "e"
```

และเราทำแบบนี้กับตัวแปรก็ได้ด้วย ถ้าเราสร้างตัวแปรที่ชื่อ `name` (ชื่อ) แล้วกำหนดค่าให้เป็นสตริง `"Jeremy"` เราก็เขียน `name[0]` ได้ และจะได้ `"J"` กลับมาเหมือนเดิม

```javascript
let name = "Jeremy"
name[0] // "J"
```

มีเรื่องหนึ่งที่ต้องเข้าใจให้ชัด สิ่งที่ได้กลับมาจาก `name[0]` ก็เป็นแค่อีกสตริงหนึ่งเท่านั้น เป็นแผ่นกระดาษอีกแผ่นที่มีตัว J เขียนอยู่ ไม่มีอะไรพิเศษเลย เป็นสตริงเหมือนกับที่ `"Jeremy"` เป็นสตริง

แค่บังเอิญว่าแผ่นนี้มีตัวอักษรอยู่ตัวเดียวแทนที่จะเป็นหกตัว

และการทำแบบนี้ก็ไม่ได้ส่งผลกับสตริงตัวเดิมเลย เราไม่ได้ฉีกตัว J ออกมาหรืออะไรทำนองนั้น เราแค่หาว่าตัวอักษรตัวไหนที่เราต้องการ แล้วสร้างสตริงใหม่ที่ใส่ตัวนั้นเข้าไป
