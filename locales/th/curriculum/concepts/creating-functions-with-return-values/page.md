ตอนนี้คุณรู้วิธีสร้างฟังก์ชันแบบมีอินพุตและไม่มีอินพุตแล้ว เหลืออีกเรื่องสุดท้ายให้เรียน แล้วคุณก็จะเป็นผู้เชี่ยวชาญเรื่องการสร้างฟังก์ชัน เรื่องนั้นก็คือวิธีสร้างรางคืนค่าให้ฟังก์ชันของคุณ

คุณเคยใช้ฟังก์ชันที่คืนค่ากลับมาหลายตัวแล้ว `isAlienAbove` (มีมนุษย์ต่างดาวอยู่ข้างบนหรือไม่) คืนค่าจริงหรือเท็จให้คุณ `Math.randomInt(1, 10)` (Math คือคณิตศาสตร์ ส่วน randomInt คือการสุ่มจำนวนเต็ม) คืนค่าตัวเลขสุ่มกลับมาให้คุณ

เมื่อ Jiki (จิ๊กิ) เรียกใช้ฟังก์ชันเหล่านี้ จะมีบางอย่างเด้งออกมาจากรางคืนค่า แล้ว Jiki ก็เอาสิ่งนั้นไปใช้ต่อได้เลย

ดังนั้นเพื่อทำแบบนี้ เราต้องมีคีย์เวิร์ดใหม่เพิ่มอีกตัว นั่นก็คือคีย์เวิร์ด `return`

คีย์เวิร์ด `return` บอก Jiki จิ๋ว ให้ดันบางอย่างออกมาจากรางคืนค่า

<img
  class="concept-image"
  src="/static/images/concept-assets/creating-functions-with-return-values/return-keyword-push.webp"
  alt="Jiki จิ๋วอยู่ข้างในเครื่อง กำลังดันค่า 42 ออกมาทางรางคืนค่า"
  width="500"
  height="335"
/>

เรามาสร้างฟังก์ชันกัน ตั้งชื่อว่า `meaningOfLife` (ความหมายของชีวิต) หน้าที่ของฟังก์ชันนี้คือคืนค่าเลข `42` กลับไปเสมอ ฟังก์ชันนี้ไม่มีอินพุตเลย เราเขียนแบบนี้

```javascript
function meaningOfLife() {
  return 42
}
```

<img
  class="concept-image"
  src="/static/images/concept-assets/creating-functions-with-return-values/meaning-of-life-42.webp"
  alt="เครื่อง meaningOfLife กำลังส่งเลข 42 ออกมาจากรางคืนค่าของตัวเอง"
  width="500"
  height="323"
/>

ทีนี้ ไม่ว่าเราใช้ `meaningOfLife()` ที่ไหนในโค้ด เราจะได้เลข `42` กลับมาใช้เหมือนค่าอื่นๆ เราใส่ไว้ในกล่องด้วย `let` ได้ ส่งต่อเป็นอินพุตให้ฟังก์ชันอื่นได้ หรือเอาไปเปรียบเทียบในคำสั่งเงื่อนไข (_if statement_) ก็ได้

ฟังก์ชันที่มีการคืนค่าก็รับอินพุตได้เหมือนกัน คุณอาจเขียนฟังก์ชัน `ageBracket(age)` (ช่วงอายุ) ที่คืนค่า `"Sorry, too young"` เมื่อ `age` น้อยกว่า 18 และคืนค่า `"Welcome"` ในกรณีอื่น ใครที่เรียกใช้ก็จะได้สตริงที่ฟังก์ชันคืนค่ากลับไป

```javascript
function ageBracket(age) {
  if (age >= 18) {
    return "Welcome"
  }
  return "Sorry, too young"
}
```
