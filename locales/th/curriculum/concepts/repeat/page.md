จนถึงตอนนี้ เราเขียนทุกอย่างแบบเส้นตรง โดย Jiki (จิ๊กิ) ทำตามคำสั่งแต่ละอันจากบนลงล่างตามลำดับ

ตอนนี้เราจะมาดูว่า Jiki จะหลุดออกจากลำดับบนลงล่างที่ตายตัวนี้ได้อย่างไร และที่สำคัญคือเราจะบอกให้ Jiki รันโค้ดส่วนเดิมซ้ำหลายๆ ครั้งติดกันได้อย่างไร

ยกตัวอย่างเช่น ลองจินตนาการว่าคุณอยู่ในเขาวงกตและอยากเดินไปข้างหน้า 10 ก้าว มีฟังก์ชัน `walk` ที่ช่วยเรื่องนี้ได้ แต่ถ้าไม่มีฟังก์ชันนั้นล่ะ ถ้าคุณมีแค่ฟังก์ชัน `move` (ขยับ) ล่ะ

แทนที่จะเขียน `move` ติดกัน 10 ครั้ง ซึ่งซ้ำซากมาก สิ่งที่เราอยากทำได้ก็คือพูดว่า "เฮ้ Jiki ทำสิ่งที่บอกต่อไปนี้ 10 ครั้ง

`Move`"

การทำแบบนี้ในโค้ด เราต้องใช้คีย์เวิร์ด (_keyword_) ตัวแรกของเรา และคีย์เวิร์ดก็คือคำสั่งที่ Jiki เข้าใจ คีย์เวิร์ดหน้าตาคล้ายเครื่องนิดหน่อย แต่ไม่ใช่เครื่อง เวลา Jiki เห็นคีย์เวิร์ด Jiki จะไม่มองหาเครื่องบนชั้นวาง แต่รู้เลยว่าต้องทำอะไรสักอย่างแทน เรื่องนี้ฝังอยู่ในสมองของ Jiki อยู่แล้ว และมีคีย์เวิร์ดต่างกันประมาณ 20 ตัวที่เราจะได้เรียนรู้ตลอดคอร์ส ตัวแรกก็คือคีย์เวิร์ด `repeat`

คีย์เวิร์ด `repeat` ทำอย่างที่พูดไปเมื่อกี้เป๊ะๆ คีย์เวิร์ดนี้บอก Jiki ว่า "ทำสิ่งที่บอกต่อไปนี้ซ้ำตามจำนวนนี้" ลองดูโค้ดนี้ก่อน อย่างแรกเลย เราจะใช้คีย์เวิร์ด `repeat` เพื่อบอก Jiki ว่าจะทำอะไรสักอย่างหลายครั้ง จากนั้นเราใส่จำนวนครั้งที่อยากให้ Jiki ทำซ้ำลงในวงเล็บธรรมดา แล้วก็มีวงเล็บปีกกาเหล่านี้ และข้างในวงเล็บปีกกาก็คือสิ่งที่เราอยากให้ Jiki ทำซ้ำ ทีนี้ รูปแบบนี้เจอบ่อยสุดๆ ในการเขียนโปรแกรม เราระบุคีย์เวิร์ด มักจะพร้อมข้อมูลบางอย่าง เช่น จำนวนครั้งที่จะทำอะไรสักอย่างในกรณีนี้ แล้วตามด้วยโค้ดบล็อก (_code block_) ในวงเล็บปีกกา กลับมาที่โลกเขาวงกตกัน แทนที่จะเขียน `move` `move` `move` `move` เราก็เขียน repeat `move` สี่ครั้งได้

```javascript
repeat(4) {
  move()
}
```

Jiki จะเห็นโค้ดนั้นแล้วใช้เครื่อง `move` สี่ครั้งติดกัน

และเราไม่ได้จำกัดว่าจะมีของแค่อย่างเดียวในวงเล็บปีกกาเหล่านั้น Jiki ทำหลายอย่างซ้ำๆ ได้ เราบอกให้ Jiki `move` แล้วก็ `turnLeft` และทำทั้งหมดนั้นซ้ำสี่ครั้งได้ ถ้า Jiki เห็นโค้ดนี้ Jiki จะใช้เครื่อง `move` แล้วก็เครื่อง `turnLeft` แล้วก็เครื่อง `move` แล้วก็เครื่อง `turnLeft` แล้วก็เครื่อง `move` ไปเรื่อยๆ จนกว่าจะทำครบทั้งสองอย่างสี่ครั้ง

```javascript
repeat(4) {
  move()
  turnLeft()
}
```

เราเรียกคำสั่งที่ทำซ้ำแบบนี้ว่า ลูป (_loop_) และมีลูปหลายแบบให้เราใช้ ซึ่งแต่ละแบบทำงานต่างกันเล็กน้อย

มีอีกเรื่องที่ต้องรู้ นั่นคือการทำให้โค้ดเรียบร้อยเป็นสิ่งจำเป็นมากเมื่อใช้ลูป เมื่อโค้ดมีโครงสร้างที่ดูดี จะทำให้เห็นง่ายมากว่าเกิดอะไรขึ้น แต่ถ้าไม่ทำ ถ้าลืมย่อหน้าให้สวยๆ หรือย่อหน้าไม่สม่ำเสมอ ทุกอย่างจะสับสนเร็วมาก ในคอร์สนี้เราจึงมีกฎอยู่ข้อหนึ่งเสมอ คุณต้องวางวงเล็บปีกกาเปิดไว้บรรทัดเดียวกับคำสั่ง `repeat` (_statement_) เสมอ ต้องวางวงเล็บปีกกาปิดไว้บรรทัดของตัวเองหลังคำสั่ง และต้องย่อหน้าโค้ดที่อยู่ระหว่างสองวงเล็บด้วยการเว้นวรรค 2 ครั้ง แบบนี้ทุกอย่างจะเรียบร้อยมาก และถ้าลืมหรือลองใช้รูปแบบอื่น คุณจะเจอข้อผิดพลาด
