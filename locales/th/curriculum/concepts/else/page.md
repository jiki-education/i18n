คำสั่งเงื่อนไขช่วยให้เราตรวจสอบเงื่อนไขและรันโค้ดเฉพาะเมื่อบางสิ่งเป็นจริง ตอนนี้เรามาทำความรู้จักคู่หูของ if กันดีกว่า นั่นก็คือ `else`

ด้วยคำสั่งเงื่อนไข (_if statement_) Jiki (จิ๊กิ) จะรันโค้ดบล็อกเมื่อเงื่อนไขเป็นจริง และจะข้ามโค้ดบล็อกนั้นไปเมื่อเงื่อนไขเป็นเท็จ แต่ถ้าเราอยากให้ Jiki ทำอย่างหนึ่งเมื่อเงื่อนไขเป็นจริง และทำอีกอย่างหนึ่งเมื่อเงื่อนไขเป็นเท็จล่ะ นั่นแหละคือหน้าที่ของ else เราใส่ส่วน else (_else clause_) ต่อจากวงเล็บปีกกาปิดของ if ได้ แล้ว Jiki จะรันส่วนนั้นถ้าเงื่อนไขของ if เป็นเท็จ ย้อนกลับไปที่ตัวอย่างพนักงานเฝ้าหน้าผับ ตอนนี้เราเลือกได้ว่าจะเปิดประตูหรือจะบอกให้ใครสักคนกลับไป ซึ่งน่าจะดีกว่าการเมินเขาเฉยๆ แบบที่เราทำอยู่ก่อนหน้านี้ ลองนึกภาพว่าเป็นทางแยกบนถนน Jiki มาถึงทางแยกนี้ ตรวจสอบเงื่อนไข แล้วก็เลือกไปทางหนึ่งถ้าเงื่อนไขเป็นจริง หรือไปอีกทางหนึ่งถ้าเป็นเท็จ แต่ Jiki ไม่เคยไปทั้งสองทาง

```javascript
if (age >= 21) {
  openDoor()
} else {
  turnAway()
}
```

แต่ถ้าเรามีความเป็นไปได้มากกว่าสองอย่างล่ะ ลองนึกว่าพนักงานเฝ้าหน้าผับของเรากำลังขายตั๋วอยู่ อายุต่ำกว่าสิบสาม ได้ตั๋วเด็ก ระหว่างสิบสามถึงยี่สิบ ได้ตั๋ววัยรุ่น ยี่สิบขึ้นไป ได้ตั๋วผู้ใหญ่ ตอนนี้เรามีผลลัพธ์ต่างกันสามแบบแล้ว สำหรับกรณีนี้ เราเพิ่มคำสั่งเงื่อนไขอีกอันต่อจาก else ได้ เราก็พูดได้ว่า "ถ้าเป็นอย่างนี้ ก็ทำอย่างนี้ else if อย่างนี้ ก็ทำอย่างนั้น else ก็ทำอีกอย่างหนึ่ง" ในตัวอย่างนี้ Jiki จะเห็น if แล้วตรวจสอบเงื่อนไขแรกก่อน สิบหกน้อยกว่าสิบสามไหม ไม่ Jiki จึงไปต่อที่ else if สิบหกน้อยกว่ายี่สิบไหม ใช่ นั่นเป็นจริง Jiki ก็รันบล็อกนั้นแล้วออกตั๋ววัยรุ่นให้ แต่แค่นั้นก็จบ Jiki ไม่ตรวจสอบอย่างอื่นต่อเลย Jiki ไม่ได้ดู else ตัวสุดท้ายนั้นเลยด้วยซ้ำ เมื่อ Jiki เจอเงื่อนไขที่เป็นจริง Jiki จะรันบล็อกนั้นและข้ามทุกอย่างที่อยู่ข้างล่างลงไป

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

นี่คือสิ่งสำคัญที่ต้องเข้าใจ มีเพียงบล็อกเดียวเท่านั้นที่รัน Jiki ไล่ลงไปตามเงื่อนไขนี้ทีละข้อ เจอเงื่อนไขแรกที่เป็นจริง รันบล็อกนั้น แล้วก็ไปต่อ

ทีนี้ มีอีกเรื่องที่ต้องเข้าใจให้จริงๆ เพราะเรื่องนี้ทำให้หลายคนพลาด มีความแตกต่างที่ละเอียดอ่อนแต่สำคัญมาก ระหว่างการเขียนคำสั่งเงื่อนไขสองอันแยกกัน กับการใช้ else if ลองนึกว่าเรากำลังเขียนโปรแกรมที่ให้รางวัลพื้นฐานหรือรางวัลโบนัส ขึ้นอยู่กับคะแนนของใครสักคน ดูความเป็นไปได้สองแบบนี้ แบบหนึ่งใช้ else if อีกแบบใช้คำสั่ง `if` สองอันแยกกัน จะเกิดอะไรขึ้นต่างกัน

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

ในกรณีแรกที่ใช้ else if เราตรวจสอบว่าคะแนนสูงไหมแล้วให้รางวัลไป แล้วก็ไม่รัน else if อีก ดังนั้นถ้าใครได้คะแนนเกินหนึ่งร้อยก็จะได้แค่รางวัลโบนัส

แต่ในตัวอย่างที่สอง if ทั้งสองอันเป็นอิสระจากกันโดยสิ้นเชิง ทั้งคู่จะรันและทั้งคู่จะเป็นจริง คนคนนี้จึงได้สองรางวัล แบบแรกได้หนึ่งรางวัล แบบที่สองได้สองรางวัล ลองหยุดคิดสักครู่เพื่อให้แน่ใจว่าเข้าใจเรื่องนี้จริงๆ

นอกจากนี้ ก็น่าสนใจว่าทั้งสองแบบอาจถูกก็ได้ ขึ้นอยู่กับว่าออกแบบเกมมาอย่างไร ผู้เล่นอาจได้ทั้งรางวัลปกติและรางวัลโบนัส หรืออาจได้เลื่อนขึ้นเป็นรางวัลโบนัสอย่างเดียว โค้ดทั้งสองแบบไม่ได้ถูกหรือผิด แค่มีประโยชน์ในสถานการณ์ที่ต่างกัน แต่เราต้องรู้ว่าเราตั้งใจจะใช้แบบไหน
