ถ้าให้คุณเปิดประตูเฉพาะตอนที่มีคนอายุเกิน 20 คุณคงรู้ว่าต้องทำยังไง แต่ถ้าต้องเช็กว่าคนคนนั้นอายุเกิน 20 **และ** ใส่ชุดถูกต้องด้วยล่ะ นั่นแปลว่าคุณต้องเช็กเงื่อนไขสองข้อที่ต่างกันพร้อมกัน แล้วจะทำยังไงดี

บางทีคุณอาจใช้คำสั่งเงื่อนไขซ้อนกัน (_nested if statement_) คล้ายกับลูปซ้อนกันที่เราเคยเจอมาก่อน ก็เขียนว่า ถ้า `age` มากกว่า `20` ก็เข้าไปในโค้ดบล็อกนี้ แล้วก็มี if อีกอันที่เช็กว่า `outfit` เท่ากับ `"disco"` แล้วก็วงเล็บปีกกาอีกอันกับโค้ดบล็อกใหม่อีกอัน แบบนั้นก็ใช้ได้ แต่พอลองเขียนจริงจะเริ่มรก โดยเฉพาะตอนที่คุณต้องมีเงื่อนไขเยอะๆ

โชคดีที่ยังมีวิธีที่ง่ายกว่านั้น นั่นคือเรามีเงื่อนไขที่มีหลายส่วนได้ แทนที่จะตรวจแค่เรื่องเดียวในเงื่อนไข เราตรวจสอง สาม หรือหลายอย่างพร้อมกันก็ได้ และเพื่อทำแบบนั้น เราต้องใช้คีย์เวิร์ด `and` แต่น่าเสียดายที่คีย์เวิร์ด และ ของ JavaScript ไม่ได้ใช้คำว่า `and` อย่างที่บางภาษาใช้กัน แต่ต้องเขียนเครื่องหมายและ (`&`) สองตัววางติดกันแทน ตรงนี้คุณต้องจำไว้ให้ดี น่ารำคาญหน่อย แต่ก็เป็นแบบนี้แหละ เดี๋ยวคุณก็ชินเอง

เราก็ใช้วิธีนี้สร้างเงื่อนไขที่ซับซ้อนขึ้นได้ เราบอกได้ว่า ถ้า `age` มากกว่า `20` และ `outfit` เป็น `"disco"` ก็ไปต่อ แต่ถ้า `age` น้อยกว่า `20` หรือ `outfit` ไม่ใช่ `"disco"` เงื่อนไขทั้งหมด ทั้งก้อนที่เราตรวจสอบ ก็เป็นเท็จ ถ้าคุณเคยเรียนตรรกศาสตร์ หรือเคยต่อวงจรอิเล็กทรอนิกส์ หรือเคยเรียนคณิตศาสตร์ขั้นสูงมาก่อน เรื่องนี้จะรู้สึกเป็นธรรมชาติมากสำหรับคุณ ถ้าไม่เคยก็ไม่ต้องกังวล เดี๋ยวคุณก็เข้าใจได้เร็ว

```javascript
if (age > 20 && outfit === "disco") {
  openDoor()
}
```

มีจุดหนึ่งที่ทำให้คนสะดุด ทั้งเวลาใช้คำว่า และ และเวลาใช้คำว่า หรือ นั่นคือ แต่ละฝั่งของ และ/หรือ (_and/or_) ต้องเป็นการเปรียบเทียบที่สมบูรณ์ เพราะฉะนั้น ถึงจะเปรียบเทียบตัวแปรตัวเดียวกันทั้งสองฝั่ง ก็ต้องเขียนซ้ำ คุณเขียน `if age is greater than 13 and less than 20` ไม่ได้ ต้องเขียนเป็น `if age is greater than 13 and age is less than 20` ทั้งสองฝั่งต้องเป็นการเปรียบเทียบที่สมบูรณ์

```javascript
if (age > 13 && age < 20)
```
