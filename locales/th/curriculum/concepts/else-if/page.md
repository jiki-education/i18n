เราเคยเห็นแล้วว่า `if` และ `else` ให้ทางเลือกสองทาง คือทำอย่างหนึ่งเมื่อเงื่อนไขเป็นจริง และทำอีกอย่างเมื่อเงื่อนไขเป็นเท็จ แต่ถ้าเรามีความเป็นไปได้มากกว่าสองทางล่ะ

ลองนึกภาพยามหน้าประตูของเรากำลังขายตั๋ว อายุต่ำกว่าสิบสามปีได้ตั๋วเด็ก ระหว่างสิบสามถึงยี่สิบปีได้ตั๋ววัยรุ่น ยี่สิบปีขึ้นไปได้ตั๋วผู้ใหญ่ ตอนนี้เรามีผลลัพธ์สามแบบแล้ว สำหรับแบบนี้ เราเพิ่มคำสั่งเงื่อนไข (_if statement_) อีกอันต่อจาก else ได้ เราก็พูดได้ว่า "ถ้าเงื่อนไขนี้เป็นจริง ก็ทำอย่างนี้ else ถ้าเงื่อนไขนี้เป็นจริง ก็ทำอย่างนั้น else ก็ทำอีกอย่างหนึ่ง" ในตัวอย่างนี้ Jiki (จิ๊กิ) จะเห็น if แล้วตรวจเงื่อนไขแรกก่อน สิบหกน้อยกว่าสิบสามไหม ไม่ ดังนั้น Jiki ก็ไปต่อที่ else if สิบหกน้อยกว่ายี่สิบไหม ใช่ เงื่อนไขนี้เป็นจริง Jiki จึงรันโค้ดบล็อกนั้นแล้วแจกตั๋ววัยรุ่น แต่แค่นั้นก็จบ Jiki ไม่ตรวจอะไรอย่างอื่นต่อเลย ไม่มองด้วยซ้ำว่า else ตัวสุดท้ายเขียนว่าอะไร พอ Jiki เจอเงื่อนไขที่เป็นจริงแล้ว Jiki จะรันโค้ดบล็อกนั้นและข้ามทุกอย่างที่อยู่ข้างล่างไป

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

นี่คือสิ่งสำคัญที่ต้องเข้าใจ มีเพียงโค้ดบล็อกเดียวเท่านั้นที่รัน Jiki จะไล่ตรวจลงมาทีละเงื่อนไขตามลำดับนี้ เจอเงื่อนไขแรกที่เป็นจริง รันโค้ดบล็อกนั้น แล้วไปต่อ

มีอีกเรื่องที่ต้องเข้าใจให้ดี เพราะหลายคนติดตรงนี้ มีความต่างที่ละเอียดอ่อนแต่สำคัญมาก ระหว่างการเขียนคำสั่ง if สองอันแยกกัน กับการใช้ else if ลองนึกภาพว่าเรากำลังเขียนโปรแกรมที่ให้รางวัลพื้นฐานหรือรางวัลพิเศษ ขึ้นอยู่กับคะแนนของใครสักคน ลองดูความเป็นไปได้สองแบบนี้ แบบหนึ่งใช้ else if อีกแบบใช้ `if` สองอันแยกกัน เกิดอะไรขึ้นต่างกันบ้าง

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

ในกรณีแรกที่ใช้ else if เราเช็กว่าคะแนนสูงไหมก่อน แล้วให้รางวัลพิเศษ จากนั้นก็ไม่รัน else if ต่อ คนที่มีคะแนนเกินหนึ่งร้อยจึงได้แค่รางวัลพิเศษ

แต่ในตัวอย่างที่สอง if สองอันเป็นอิสระจากกันโดยสิ้นเชิง ทั้งคู่จะรันและทั้งคู่เป็นจริง คนคนนี้จึงได้สองรางวัล แบบแรกได้หนึ่งรางวัล แบบที่สองได้สองรางวัล ลองหยุดคิดสักครู่เพื่อให้แน่ใจว่าเข้าใจเรื่องนี้จริงๆ

น่าสนใจเหมือนกันว่า ทั้งสองแบบอาจถูกก็ได้ ขึ้นอยู่กับว่าเกมออกแบบมาแบบไหน บางทีผู้เข้าแข่งขันอาจได้ทั้งรางวัลปกติและรางวัลพิเศษ หรือบางทีอาจอัปเกรดเป็นรางวัลพิเศษไปเลย โค้ดทั้งสองแบบไม่ได้ถูกหรือผิด แค่มีประโยชน์ในสถานการณ์ที่ต่างกัน แต่เราต้องรู้ว่าเราตั้งใจจะใช้แบบไหน
