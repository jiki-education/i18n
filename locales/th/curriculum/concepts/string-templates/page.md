เราใช้สิ่งที่เรียกว่า template literals เพื่อแทรกสตริงเข้าไปในสตริงอื่นได้

ดังนั้น แทนที่จะนำสตริงมาต่อกัน เราสามารถมีสตริงหรือเทมเพลตที่มีช่องสำหรับสตริงอื่นอยู่ข้างในได้

เมื่อจะทำแบบนี้ เราใช้แบ็กทิก (*backticks*) แทนเครื่องหมายคำพูด

อย่างที่ชื่อบอกไว้ แบ็กทิกก็คือเครื่องหมายติกที่หันไปทางด้านหลัง แต่คุณอาจไม่เคยใช้มาก่อนเลยก็ได้ ดังนั้นจึงต้องหาปุ่มที่ถูกต้องบนคีย์บอร์ด

เราใช้แบ็กทิกสร้างเทมเพลตที่เก็บสตริงอื่นไว้ข้างในได้ จากนั้น เมื่อต้องการแทรกสตริงเข้าไปในเทมเพลต เราใช้ไวยากรณ์ (*syntax*) แปลกๆ อีกอย่างหนึ่ง นั่นคือเครื่องหมายดอลลาร์กับวงเล็บปีกกา ตัวอย่างเช่น ถ้าอยากได้ผลแบบเดียวกับ `"hello " + name` ที่เราเพิ่งเห็นตอนพูดถึงการเชื่อมสตริง เราก็เขียนแบบนี้ได้

```javascript
`hello ${name}` // "hello Jeremy" or "hello Jiki"
```

และนั่นก็ทำแบบเดียวกับการนำสตริงมาต่อกันเลย

แต่เมื่อคุณมีหลายสตริงที่ต้องประกอบเข้าไว้ในที่เดียว วิธีนี้อาจมีประสิทธิภาพกว่ามาก

คุณอาจต้องใช้เวลาสักนิดในการทำความคุ้นเคยกับไวยากรณ์แบบนี้ แต่จริงๆ ก็ไม่มีอะไรซับซ้อนเลย
