ฟังก์ชันที่คุณสร้างมาถึงตอนนี้ทำสิ่งเดิมเป๊ะๆ ทุกครั้ง `turnAround` (หันกลับ) หันซ้ายสองครั้งเสมอ `shootIfAlienAbove` (ยิงถ้ามีเอเลี่ยนอยู่ด้านบน) ก็ตรวจสอบแล้วยิงเสมอ

แต่ลองคิดถึงฟังก์ชันที่คุณใช้มาตลอดทั้งคอร์สดูสิ ว่าฟังก์ชันพวกนั้นทำสิ่งที่ต่างกันออกไปได้อย่างไรตามค่าที่ใส่เข้าไป `Rectangle` รับค่าตำแหน่งซ้าย ตำแหน่งบน ความกว้าง และความสูงเข้ามา แล้ววาดสี่เหลี่ยมที่ต่างกันออกไปตามที่คุณกำหนด

ตอนนี้เราจะมาเพิ่มช่องใส่ให้ฟังก์ชันที่คุณสร้างเองบ้าง

การทำแบบนี้ต้องรู้สองเรื่อง เรื่องแรกคือหน้าตาของมันจริงๆ ว่าต้องเขียนอะไร ส่วนเรื่องที่สองคือสิ่งที่เกิดขึ้นจริงๆ ข้างใน

เรื่องแรกตรงไปตรงมาอยู่แล้ว แค่เติมวงเล็บธรรมดาเข้าไป แล้วต่อด้วยชื่อของค่าที่คุณอยากใส่เข้าไป

ลองนึกภาพว่าเรากำลังสร้างฟังก์ชันที่ต้องยิงหลายๆ ครั้ง เราจะเรียกฟังก์ชันนี้ว่า `shootMany` (ยิงหลายครั้ง)

เราเขียนแบบนี้

```javascript
function shootMany(numShots) {
  // ...
}
```

เมื่ออยากใช้ฟังก์ชันนี้ ก็เรียกใช้พร้อมกับจำนวนครั้งที่อยากยิง

```javascript
shootMany(5)
shootMany(2)
```

ทีนี้ นี่คือจุดสำคัญ เมื่อโค้ดรัน ไม่ว่าคุณจะใส่ค่าอะไรเข้าไปในช่องใส่ `5` หรือ `2` Jiki (จิ๊กิ) จิ๋วที่สวมหมวกอยู่ข้างในฟังก์ชันจะหยิบค่านั้นมาใส่ในกล่องที่ชื่อ `numShots` (จำนวนครั้งที่ยิง) แล้วยกกล่องนั้นขึ้นไปวางบนชั้นวางข้างในฟังก์ชัน ให้คุณใช้ในโค้ดของฟังก์ชัน

เมื่อเราเขียน `shootMany(5)` เพื่อใช้ฟังก์ชัน Jiki ที่อยู่ข้างนอกจะไปหยิบ `5` มาใส่ในช่องใส่ของ `shootMany` ข้างในเครื่อง Jiki จิ๋วจะหยิบ `5` นั้นออกมาใส่ในกล่องที่ชื่อ `numShots` เพราะนั่นคือชื่อที่คุณตั้งให้กับช่องใส่ช่องนั้น แล้วยกกล่องนั้นไปวางบนชั้นวางข้างในฟังก์ชันในเครื่อง

แล้วในฟังก์ชัน คุณก็ใช้กล่อง `numShots` ได้เหมือนกับกล่องอื่นๆ ทั่วไป ชื่อ `numShots` ไม่มีอะไรวิเศษเลย เราจะตั้งชื่อเป็นอะไรก็ได้ทั้งนั้น ชื่อนี้ทำหน้าที่แค่บอก Jiki จิ๋วให้สร้างกล่องที่ติดป้ายชื่อนี้ขึ้นมาข้างในฟังก์ชันเสมอ แล้วเอาค่าที่ส่งเข้ามาในช่องนั้นใส่ลงไปในกล่อง

และเมื่อมีค่าในกล่องแล้ว คุณก็ทำอะไรก็ได้เหมือนที่ทำกับกล่องทั่วไป คุณจะใช้กล่อง `numShots` เป็นส่วนหนึ่งของลูป `repeat` เพื่อยิงให้ได้จำนวนครั้งที่ถูกต้องก็ได้ และคุณยังมีช่องใส่ได้มากกว่าหนึ่งช่องด้วย แค่คั่นด้วยเครื่องหมายจุลภาค `,` ดังนั้นถ้าเรามีฟังก์ชันชื่อ `drawStar` (วาดดาว) ที่วาดดาวโดยอิงจากตำแหน่งมุมบนซ้าย ก็เขียนแบบนี้

```javascript
function drawStar(left, top) {
  // ...
}
```
