HSL ให้วิธีคิดเรื่องสีที่ต่างจาก RGB ไปเลย HSL ย่อมาจากฮิว (_hue (H)_) ความอิ่มตัว (_saturation (S)_) และความสว่าง (_lightness (L)_) เรามีฟังก์ชันชื่อ `hsl` ที่รับตัวเลขสามตัว ตัวหนึ่งสำหรับฮิว ตัวหนึ่งสำหรับความอิ่มตัว และอีกตัวสำหรับความสว่าง แล้วคืนค่าออกมาเป็นสี งั้นเรามาแยกดูกันว่าคำสามคำนี้หมายถึงอะไร

```javascript
hsl(hue, saturation, lightness)
```

ฮิวคือเฉดสีที่คุณต้องการ โดยมีค่าตั้งแต่ 0 ไปจนถึง 360 ลองนึกถึงรุ้งกินน้ำดู นี่คือวิธีที่เรามองเรื่องนี้ ทางซ้ายมือเป็นสีแดง แล้วก็มีสีส้ม สีเหลือง สีเขียว สีน้ำเงิน สีม่วง และจริงๆ แล้วก็วนกลับมาที่สีแดงอีกครั้ง ถ้าคุณใส่ 0 คุณก็เริ่มที่ทางซ้าย ซึ่งก็คือสีแดง ถ้าใส่ `120` คุณก็กำลังขอสีเขียว `230` คือสีน้ำเงิน คุณยังมองสิ่งนี้เป็นวงล้อสีก็ได้ ซึ่งนั่นคือสิ่งที่ 360 หมายถึงจริงๆ นั่นคือจำนวนองศาของวงกลมเต็มวง ปกติเราแค่เปิดตารางหาตัวเลขที่ต้องการ ไม่ต้องกังวลว่าจะต้องจำทั้งหมดนี้ แต่การรู้ว่าเกิดอะไรขึ้นข้างในก็เป็นเรื่องดี นั่นแหละคือฮิว ซึ่งก็คือเฉดสี ต่อไปคือความอิ่มตัว ซึ่งบอกว่าสีนั้นสดแค่ไหน ค่านี้อยู่ระหว่าง 0 ถึง 100 ที่ 0 คุณจะได้สีเทาเฉยๆ ไม่มีสี ไม่มีโทนอะไรอยู่ในนั้นเลย ที่ 100 คุณจะได้สีเต็มๆ สดและจัดจ้าน แล้วก็มีความสว่าง ความสว่างบอกว่าสีนั้นสว่างแค่ไหน และค่านี้ก็อยู่ระหว่าง 0 ถึง 100 เช่นกัน ที่ 0 คุณจะได้สีดำ ไม่ว่าคุณจะเลือกฮิวไหน ก็ได้สีดำ เพราะไม่มีแสงอยู่ในนั้นเลย ที่ 100 คุณจะได้สีขาว ไม่ว่าอย่างอื่นจะเป็นยังไง สีก็เต็มไปด้วยแสง จึงออกมาเป็นสีขาว ส่วน 50 คือตรงกลางพอดี เป็นสีปกติ เราจึงมองความสว่างเป็นแถบเลื่อนสำหรับทำให้สีสว่างขึ้นหรือมืดลงก็ได้

ดังนั้นถ้าเราอยากได้วงกลมสีแดงปกติ ซึ่งถ้าใช้ RGB เราจะเขียนว่า 255, 0, 0 คือแดงเต็มที่ ไม่มีเขียว ไม่มีน้ำเงิน ในที่นี้เราจะใช้ 0, 100, 50 คือ 0 สำหรับฮิวแดง 100 สำหรับความอิ่มตัว สีเต็มที่ และ 50 สำหรับความสว่าง ซึ่งเป็นระดับความสว่างปกติ ถ้าเราอยากทำให้เป็นวงกลมสีเขียว ก็แค่เปลี่ยนฮิวเป็น `120` ถ้าอยากได้เขียวเข้มกว่านี้ ก็ลดความสว่างลงมาเหลือ `25`

```javascript
hsl(0, 100, 50) // แดง
hsl(120, 100, 50) // เขียว
hsl(120, 100, 25) // เขียวเข้ม
```

ถ้าอยากให้เขียวหม่นลง ก็ลดสีลงบ้าง ลดความอิ่มตัวลง เช่น ลดลงมาเหลือ `30`

ถ้าอยากได้สีชมพูสดๆ ฮิวประมาณ 300 คือสีชมพู จากนั้นเพิ่มความอิ่มตัวขึ้นไปที่ 100 ให้สีสดจริงๆ และเพิ่มความสว่างขึ้นไปที่ประมาณ 60 ด้วย

HSL เก่งมากเมื่อคุณอยากไล่สีไปเรื่อยๆ ถ้าอยากได้รุ้งกินน้ำ ก็แค่เพิ่มฮิวไปเรื่อยๆ
