เราเข้าถึงตัวอักษรตัวเดียวของสตริงได้ด้วยวงเล็บเหลี่ยม ตอนนี้เราจะมาดูวิธีวนลูปผ่านสตริง เพื่อดึงตัวอักษรออกมาทีละตัว

และเพื่อทำแบบนั้น เราต้องใช้ลูปชนิดใหม่ จนถึงตอนนี้เราใช้ลูป repeat กันมาแล้ว ตอนนี้เราจะมาใช้สิ่งที่เรียกว่าลูป `for of` (ลูปที่ไล่วนผ่านสมาชิกแต่ละตัวของชุดข้อมูลทีละตัว) นั่นคือคีย์เวิร์ดใหม่ 2 ตัว คือ `for` และ `of`

คีย์เวิร์ด `for` เป็นตัวที่เราจะเจอในอีกหลายที่ข้างหน้า `for` ใช้เดี่ยวๆ ได้ หรือใช้คู่กับ `in` หรือ `of` ตอนนี้เราจะโฟกัสที่ตัวสุดท้าย คือ `of`

เรามาดูโค้ดกันหน่อย

เริ่มจากการสร้างตัวแปร `name` (ชื่อ) ขึ้นมาเก็บสตริง `"Jeremy"` (ชื่อ เจเรมี) ไว้ ไม่มีอะไรใหม่ตรงนี้

จากนั้นก็มาถึงบรรทัดของลูป ซึ่งมีอะไรเกิดขึ้นเยอะแยะ เรามาค่อยๆ ไล่ดูไปทีละส่วน

```javascript
let name = "Jeremy"
for (let letter of name) {
  // ...
}
```

อย่างแรกเลย เรามีคีย์เวิร์ด `for` ซึ่งบอก Jiki ว่าเราอยากวนลูป Jiki จึงมองไปข้างหน้า เจอ `of` ก็รู้ว่าเราอยากวนลูปแบบ "for of"

นั่นหมายความว่า แทนที่เราจะใช้ลูป repeat ที่บอกว่า "วน 10 ครั้ง" เรากลับบอกว่า "วนผ่านตัวอักษรทุกตัวในสตริง" นี่แหละคือความหมายของ "for of"

จากนั้นก็มีส่วน `let letter` (ประกาศตัวแปรชื่อ letter) ตรงนี้เหมือนกับ `let name` ข้างบนเป๊ะๆ เราแค่สร้างตัวแปรที่ชื่อ `letter` ขึ้นมา

ข้อต่างคือ แทนที่เราจะระบุตรงๆ ว่าอะไรอยู่ในตัวแปร เราบอก Jiki ให้ใส่ตัวอักษรแต่ละตัวในสตริงลงไปทีละตัว

Jiki เห็น `for` ตรวจว่ามี `of` แล้วก็ลงมือ Jiki ดูตัวอักษรตัวแรกในสตริง ซึ่งในที่นี้คือ `"J"` แล้วใส่ลงในกล่องใหม่ที่ชื่อ `letter` ตรงนี้จะเรียกเป็นอะไรก็ได้ ไม่จำเป็นต้องใช้ `letter` เราแค่เลือกเรียกเป็น `letter` ในตัวอย่างนี้

จากนั้น Jiki ก็รันโค้ดในวงเล็บปีกกา ซึ่งตรงนี้ทำอะไรก็ได้เหมือนกับที่ทำได้ในโค้ดส่วนอื่น ข้อต่างมีอย่างเดียว คือโค้ดบล็อกนี้จะรันหนึ่งครั้งต่อตัวอักษรหนึ่งตัวในสตริง และมีตัวแปรนี้ให้ใช้

ทุกครั้งที่ Jiki มาถึงวงเล็บปีกกาปิด Jiki จะทิ้งกล่อง `letter` ใบเดิม แล้วสร้างกล่องใหม่ที่ใส่ตัวอักษรถัดไปลงไป ดังนั้นครั้งแรก Jiki จะทิ้ง `"J"` แล้วใส่ `"e"` ลงในกล่องแทน จากนั้นก็ทำแบบเดียวกันกับ `"r"` ต่อด้วย `"e"` ต่อด้วย `"m"` ต่อด้วย `"y"` หกตัวอักษร ก็วนลูปหกรอบ ต้องใช้เวลาสักพักกว่าจะชินกับไวยากรณ์ (_syntax_) แต่ก็ไม่ใช่แนวคิดที่ยากอะไร
