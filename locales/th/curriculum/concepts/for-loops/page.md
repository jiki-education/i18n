คุณอาจจำได้ว่าจริงๆ แล้วลูป `repeat` ไม่มีอยู่ใน JavaScript เลย นี่เป็นแค่สิ่งที่เพิ่มเข้ามาเพื่อให้ชีวิตคุณง่ายขึ้นนิดหน่อยตอนที่เราเริ่มต้นกัน

แล้วเราใช้อะไรแทนล่ะ ก็เราใช้ลูป `for` ธรรมดา ซึ่งหน้าตาเป็นแบบนี้

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

จะเห็นได้ว่าทำไมตอนวันแรกๆ สิ่งนี้อาจดูน่ากลัวไปสักหน่อยสำหรับคุณ

แต่ตอนนี้คุณมีความรู้ครบทุกอย่างที่ต้องใช้เพื่อทำความคุ้นเคยกับเรื่องนี้แล้ว งั้นเราแยกออกมาดูทีละส่วนกัน

ลูป for มีสามองค์ประกอบด้วยกัน คือค่าเริ่มต้น (_initializer_) เงื่อนไข และการเพิ่มค่า (_increment_)

ค่าเริ่มต้น หรือท่อน `let i = 0` ตรงนี้ จะทำงานตอนเริ่มต้นของลูปทั้งหมด ทำงานแค่ครั้งเดียว และตรงนี้จะสร้างกล่องที่ชื่อ `i` (ชื่อตัวแปร) ขึ้นมาโดยตั้งค่าเป็นศูนย์ `i` เป็นแค่ตัวอักษรที่ใช้ติดตามค่าต่างๆ ขณะที่เราเขียนลูป และตามธรรมเนียมแล้วเรามักใช้ `i` หรือ `x` กัน

ส่วนถัดไปก่อนถึงเงื่อนไขจะทำงานทุกครั้งก่อนการวนรอบแต่ละรอบ

ถ้าเงื่อนไขเป็นจริง เราก็รันลูปอีกครั้ง

ถ้าไม่จริง เราก็ไม่รัน

และสุดท้ายคือการเพิ่มค่า นั่นก็คือ `i++`

`i++` มีความหมายเหมือนกับ `i = i + 1` เป๊ะๆ เป็นแค่การเขียนแบบย่อ วิธีหนึ่งในการเพิ่ม `i` ขึ้นทีละหนึ่งในแต่ละครั้ง

ในตัวอย่างนี้ เราจะตั้ง `i` เป็นศูนย์ เราตรวจสอบว่า `i` น้อยกว่าสองหรือไม่ ซึ่งก็ใช่อย่างนั้น เราจึงรันลูป

แล้วพอจบก็เพิ่ม `i` ขึ้นหนึ่ง ทำให้ `i` กลายเป็นหนึ่ง ศูนย์บวกหนึ่งเท่ากับหนึ่ง

แล้วเราก็วนกลับไปอีกครั้ง เราตรวจสอบว่าหนึ่งน้อยกว่าสองหรือไม่

ใช่ ก็รันลูป แล้วพอจบก็เพิ่ม `i` อีกครั้ง ตอนนี้เลยเป็นสอง หนึ่งบวกหนึ่งเท่ากับสอง

```javascript
i = 0
i < 2 // true - รันลูป
...   // ทำการวนรอบ
i = i + 1 // 1

i < 2 // true - รันลูป
...   // ทำการวนรอบ
i = i + 1 // 2

i < 2 // false - ออกจากลูป
```

แล้วเราก็ไปครั้งที่สาม คราวนี้เราตรวจสอบว่าสองน้อยกว่าสองหรือไม่ ซึ่งไม่ใช่ เราจึงไม่รันลูป และจริงๆ แล้วเราก็จบการทำงานกับลูปตรงนี้เลย เราก็แค่ไปทำโค้ดที่อยู่ข้างล่างต่อ ดังนั้นเราจึงรันลูปไปสองครั้ง และนี่เป็นเรื่องที่มีประโยชน์มากที่ควรรู้ ตราบใดที่เราเริ่มจากศูนย์และมีเงื่อนไข `i < n` ตัวเลข `n` ก็คือจำนวนครั้งที่ลูปจะรัน

ลูปนี้จึงเทียบได้กับการสั่ง repeat 2

จะเห็นว่าไม่ได้ยากเลย แต่วิธีนี้ซับซ้อนกว่าการเขียน repeat 2 เฉยๆ มาก ข้อดีของลูป for คือคุณทำอะไรก็ได้ในสามช่องนั้น จะเริ่มจากตัวเลขอื่น จะนับขึ้นทีละมากกว่าหนึ่ง จะนับถอยหลัง หรือจะใช้เงื่อนไขที่ขึ้นกับอย่างอื่นที่ไม่ใช่แค่ตัวนับง่ายๆ ก็ได้ ความยืดหยุ่นนี้เองที่ทำให้ลูป for เป็นม้าศึกของ JavaScript
