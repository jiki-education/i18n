คุณรู้แล้วว่าสตริงคืออะไร สตริงคือแผ่นกระดาษที่มีข้อความอยู่บนนั้น

จนถึงตอนนี้ สตริงทุกตัวที่คุณใช้ล้วนเป็นสตริงที่คุณพิมพ์ออกมาตรงๆ ทั้งนั้น เกิดอะไรขึ้นถ้าคุณอยากสร้างสตริงขึ้นมาจากตัวแปรหรือเงื่อนไข? แล้วเราจะทำแบบนั้นได้ยังไง

มีอยู่สองวิธี

วิธีแรกเรียกว่าการเชื่อมสตริง (_string concatenation_) ซึ่งเป็นวิธีพูดแบบหรูๆ ที่ชวนสับสนนิดหน่อย หมายถึงการเอาสตริงสองตัวมาบวกกัน

ลองนึกภาพว่าคุณมีคำสองคำ คือ `"hello"` (สวัสดี) และ `"world"` (โลก) แล้วคุณอยากสร้างสตริงที่มี `"hello world"` อยู่ข้างใน

คุณจะเขียน `"hello world"` ออกมาตรงๆ เป็นสตริงเดียวก็ได้ แต่คุณก็เขียน `"hello " + "world"` แทนก็ได้เหมือนกัน และจะได้สตริงเดียวกันออกมา

แน่นอนว่าในสถานการณ์แบบนี้ วิธีนั้นยังไม่ได้มีประโยชน์มากนัก แต่ถ้าเรามีตัวแปรที่เก็บชื่อของใครสักคนไว้ แล้วเราอยากทักทายคนคนนั้นล่ะ

ลองนึกภาพว่าเรามีตัวแปรตัวหนึ่งชื่อ `name` (ชื่อ) ที่บางครั้งเก็บ `"Jeremy"` (ชื่อของ Jeremy) และบางครั้งก็เก็บ `"Jiki"` (ชื่อของ Jiki อ่านว่า จิ๊กิ) เราอยากพูดว่า `"hello Jeremy"` หรือ `"hello Jiki"` โดยใช้ตัวแปรตัวนั้น

เราทำแบบนี้ได้ด้วยแนวคิดการเชื่อมสตริง

```javascript
"hello " + name // "hello Jeremy" หรือ "hello Jiki"
```

ผลลัพธ์ที่ได้ก็จะเป็น `"hello Jeremy"` หรือ `"hello Jiki"` หรือจะเป็นการทักทายใครคนอื่นก็ได้ ขึ้นอยู่กับว่ามีอะไรอยู่ในกล่อง `name`
