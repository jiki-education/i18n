یکی از اولین تصمیم‌هایی که بیشتر مبتدیان با آن روبرو می‌شوند این است که «چه زبانی را باید انتخاب کنم؟». بیشترشان به JavaScript یا Python می‌رسند.

در این نقطه، اتفاق مهمی می‌افتد. آنها از حالت «قرار است برنامه‌نویسی یاد بگیرم» به حالت «قرار است Python یاد بگیرم» می‌روند. یک هفته پیش شاید هرگز نام Python را نشنیده بودند و مطمئناً درکی واقعی از تفاوت‌های بین JS یا Python یا R یا Java یا ده‌ها زبان اصلی دیگر ندارند. اما ناگهان حاضرند تا پای جان از این موضع دفاع کنند که «من آدم Python هستم».

واقعاً نمی‌توانم بهشان خرده بگیرم! یکی از گیج‌کننده‌ترین و مخلوط‌شده‌ترین پیام‌هایی که به مبتدیان داده می‌شود این است که یادگیری برنامه‌نویسی همان یادگیری یک زبان برنامه‌نویسی است. و ما توسعه‌دهنده‌ها که همه یک زبان محبوب داریم، یک تازه‌کار آسیب‌پذیر را می‌بینیم و بلافاصله او را به‌عنوان گرویده‌ای بالقوه به زبان خودمان شناسایی می‌کنیم. گروه‌های کمی به اندازه‌ی برنامه‌نویسان درباره‌ی زبانشان قبیله‌ای رفتار می‌کنند.

![دو گروه خشمگین از برنامه‌نویسان که پرچم‌های زبان‌های برنامه‌نویسی مختلف را تکان می‌دهند، در حالی که یک مبتدی گیج در وسط گوش‌هایش را گرفته است](/images/blog/just-learn-to-code-tribalism.webp)

اما این برای یک مبتدی بی‌معنی است. یک مبتدی نیازی به یادگیری Python یا JavaScript یا هیچ زبان دیگری ندارد. او باید مبانی برنامه‌نویسی را یاد بگیرد و یک پایه‌ی محکم بسازد که همه‌ی ده‌ها زبانی را که در نهایت با گذشت زمان استفاده خواهد کرد، پوشش دهد.

به‌ویژه در دوران کدنویسی عامل‌محور که ممکن است در همان هفته‌ی اول، TypeScript، Python، SQL، bash، JSON، Ruby و چندین زبان دیگر را به مرحله‌ی تولید برسانید. ما باید به مبتدیان کمک کنیم تا آنچه را که اتفاق می‌افتد در گسترده‌ترین سطح ممکن درک کنند، نه اینکه به یک زبان خاص محدود شوند.

ما جیکی را طوری طراحی کرده‌ایم که مبانی را آموزش دهد. الان از نسخه‌ای کمی تغییر یافته از JavaScript استفاده می‌کند. بعداً در سال جاری Python را هم اضافه می‌کنیم و شما می‌توانید انتخاب کنید (یا ما برایتان شیر یا خط می‌اندازیم تا انتخاب کنید!)، اما راستش مهم نیست.

با **[جیکی](https://jiki.io)** برنامه‌نویسی را یاد بگیرید. کمی طول می‌کشد. بعد، وقتی برنامه‌نویسی را فهمیدید، از **[Exercism](https://exercism.org)** برای یادگیری زبان‌ها استفاده کنید. اگر مبانی را جا انداخته باشید، خیلی سریع‌تر و آسان‌تر خواهد بود.

و دفعه‌ی بعد که یک مبتدی از شما پرسید چه زبانی را باید یاد بگیرد، به او بگویید مهم نیست. او را از این بند رها کنید و به‌جایش به سمت جیکی راهنمایی‌اش کنید تا مبانی را محکم یاد بگیرد.
