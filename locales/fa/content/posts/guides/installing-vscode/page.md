## مقدمه

Visual Studio Code (VS Code) یک ویرایشگر کد رایگان ساخته‌ی مایکروسافت است که روی ویندوز، macOS و لینوکس اجرا می‌شود. این ویرایشگری است که توصیه می‌کنیم در زمان یادگیری برنامه‌نویسی از آن استفاده کنید. اگر مطمئن نیستید ویرایشگر کد چیست یا چرا به آن نیاز دارید، ابتدا راهنمای ما درباره‌ی [استفاده از ویرایشگر کد](/guides/using-a-code-editor) را بخوانید.

این راهنما شما را در مراحل نصب VS Code روی هر سیستم‌عامل راهنمایی می‌کند. سیستم خود را در پایین پیدا کنید و مراحل را دنبال کنید. فقط یک‌بار لازم است این کار را انجام دهید.

## ویندوز

۱. [code.visualstudio.com](https://code.visualstudio.com) را در مرورگر وب خود باز کنید.
۲. روی دکمه‌ی «**Download for Windows**» کلیک کنید. با این کار نصب‌کننده‌ی رسمی (یک فایل `.exe`) دانلود می‌شود.
۳. زمانی که دانلود به پایان برسد، فایل را باز کنید تا نصب‌کننده اجرا شود.
۴. توافق‌نامه‌ی مجوز را بپذیرید، سپس روی «**Next**» کلیک کنید تا گزینه‌های پیش‌فرض را بپذیرید. توصیه می‌کنیم کادری که VS Code را به منوی راست‌کلیک شما اضافه می‌کند، علامت‌دار باقی بگذارید، چون بعداً به کارتان می‌آید.
۵. روی «**Install**» کلیک کنید، سپس «**Finish**». VS Code وقتی آماده شود باز می‌شود.

## macOS

۱. [code.visualstudio.com](https://code.visualstudio.com) را در مرورگر وب خود باز کنید.
۲. روی دکمه‌ی «**Download for macOS**» کلیک کنید. با این کار یک فایل `.zip` حاوی برنامه دانلود می‌شود.
۳. پوشه‌ی «**Downloads**» خود را باز کنید و روی فایل دانلودشده دوبار کلیک کنید تا از حالت فشرده خارج شود. برنامه‌ای با نام «**Visual Studio Code**» دریافت می‌کنید.
۴. «**Visual Studio Code**» را به پوشه‌ی «**Applications**» بکشید.
۵. پوشه‌ی «**Applications**» خود را باز کنید و روی «**Visual Studio Code**» دوبار کلیک کنید تا اجرا شود. اگر macOS از شما پرسید که آیا مطمئن هستید می‌خواهید آن را باز کنید، روی «**Open**» کلیک کنید.

## لینوکس

مطمئن‌ترین روش نصب VS Code روی لینوکس، دانلود بسته‌ی رسمی مایکروسافت برای توزیع لینوکسی‌تان است.

۱. [code.visualstudio.com](https://code.visualstudio.com) را در مرورگر وب خود باز کنید.
۲. روی «**Download for Linux**» کلیک کنید و بسته‌ای را انتخاب کنید که با توزیع شما متناسب باشد:
   - در سیستم‌های مبتنی بر Debian و Ubuntu، بسته‌ی «**.deb**» را انتخاب کنید.
   - در سیستم‌های مبتنی بر Fedora، Red Hat و openSUSE، بسته‌ی «**.rpm**» را انتخاب کنید.
۳. بسته‌ی دانلودشده را با نصب‌کننده‌ی نرم‌افزاری سیستم خود باز کنید و روی «**Install**» کلیک کنید، یا آن را از طریق ترمینال نصب کنید:
   - در Debian یا Ubuntu، در پوشه‌ای که فایل را دانلود کرده‌اید، دستور `sudo apt install ./<file>.deb` را اجرا کنید.
   - در Fedora یا Red Hat، در پوشه‌ای که فایل را دانلود کرده‌اید، دستور `sudo dnf install ./<file>.rpm` را اجرا کنید.
۴. پس از نصب، VS Code را از طریق منوی برنامه‌هایتان باز کنید، یا با اجرای دستور `code` در ترمینال.

## باز کردن VS Code

به هر شکلی که نصب کرده باشید، از این پس می‌توانید هر زمان که خواستید VS Code را برای نوشتن کد باز کنید. در ویندوز و macOS در کنار برنامه‌های دیگرتان ظاهر می‌شود، و در لینوکس در منوی برنامه‌هایتان قرار می‌گیرد.

همین‌طور تمام. اکنون یک ویرایشگر کد مناسب نصب کرده‌اید و آماده‌اید تا شروع به نوشتن کد کنید.
