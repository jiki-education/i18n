در این تمرین، کار شما کشیدن یک نماد آب‌وهوایی برای یک روز بارانی است که خورشید از پشت ابر‌ها بیرون زده باشد. وقتی تمام شد، باید شبیه این شود:

<img src="/static/images/exercise-assets/cloud-rain-sun/finished.webp" alt="صحنه‌ی تمام‌شده‌ی ابر، باران و خورشید" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.3); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

ما یک قالب برای شما کشیده‌ایم. شکل‌هایتان باید درست درون خطوط قرار بگیرند. ما همچنین پایه‌ی ابر را برای آسان‌تر شدن کارتان در کد قرار داده‌ایم. **نمی‌توانید این خط را تغییر دهید** (می‌بینید که خاکستری شده است و یک نماد قفل در کنارش قرار دارد).

به تابع‌های `circle` (دایره) و `ellipse` (بیضی) نیاز دارید. فقط باید از بیضی‌ها برای قطره‌های باران استفاده کنید. اگر آن‌ها را برای خورشید یا ابر استفاده کنید، کار نخواهد کرد.

### پیدا کردن مختصات درست

در این تمرین **می‌توانید** نشانگر را روی فضای رسم ببرید تا مختصات را پیدا کنید. و باز هم، همه‌ی اعدادی که به کار می‌برید **بر ۵ بخش‌پذیرند، با یک استثنا**. شعاع افقی قطره‌های باران `3` است. هر عدد دیگری، از جمله شعاع عمودی قطره‌های باران، بر ۵ بخش‌پذیر است.

خوش بگذرد!
