شما در حال ساختن یک بازی رباتیک شعر به اسم «ماجراهای شعر» هستید. به عنوان اولین قدم، باید ربات را طوری برنامه‌ریزی کنید که هنگام راه رفتن، کلمه‌ها را جمع کند و در پایان شعر را بخواند.

در هر خانه یکی از این چهار مورد قرار دارد:

1. هیچ (`""`)
2. یک **کلمه** از شعر.
3. منظره‌ای مثل یک برگ یا یک پروانه (یک ایموجی).
4. یک پرچم شطرنجی (`🏁`) که به ربات می‌گوید بایستد.

چند تابع در اختیار دارید که کمکتان می‌کنند. اول، یک تابع `move()` دارید که به ربات شاعر می‌گوید به خانه‌ی بعدی برود و هر چه را که روی آن خانه بود برمی‌گرداند. یک تابع `isEmoji(thing)` دارید که یک مقدار منطقی برمی‌گرداند و به شما می‌گوید رشته‌ای که به آن می‌دهید ایموجی است یا نه. و در نهایت، یک تابع `recite(poem)` دارید که باید آن را با شعر نهایی به کار ببرید.

کار شما این است که در مسیر قدم بزنید، شعر را بسازید و بعد آن را بخوانید.

## قوانین

- **کلمه‌ها** به شعر اضافه می‌شوند و بین هر کدام یک **فاصله** می‌آید.
- **منظره‌ها** جزئی از شعر نیستند و باید نادیده گرفته شوند.
- **آپاستروف** روی خانه‌ی خودش قرار می‌گیرد و کلمه‌های دو طرفش را به هم می‌چسباند. `heart` و بعد `'` و بعد `s` می‌شود `heart's`.
- **کاما** هم روی خانه‌ی خودش قرار می‌گیرد. به کلمه‌ی قبل از خودش می‌چسبد، اما بعد از آن همچنان یک فاصله هست.
- شاعر وقتی به **پرچم شطرنجی** برسد از راه رفتن می‌ایستد، یا به محض اینکه **هفت کلمه** جمع کرده باشد. هر کدام که زودتر پیش بیاید.
- هر وقت شاعر بایستد، و هر طور که ایستاده باشد، آنچه را که جمع کرده است می‌خواند. شما فقط **یک بار** می‌توانید `recite()` را فراخوانی کنید.

## محدودیت‌ها

راه‌های زیادی برای حل این تمرین وجود دارد، اما می‌خواهیم از کلیدواژه‌های `continue` و `break` که به‌تازگی یاد گرفته‌اید استفاده کنید؛ پس چند قاعده وجود دارد:

1. راه‌حل شما باید هم از `continue` و هم از `break` استفاده کند.
2. نمی‌توانید در راه‌حل خود از `&&` یا `!` استفاده کنید.
3. نمی‌توانید هیچ تابع کمکی بنویسید.
4. فقط دو سطح تورفتگی مجاز است:

```javascript

// مجاز - 2 سطح تورفتگی
repeat() {
  if(...) {
    //...
  }
}

// مجاز نیست - 3 سطح تورفتگی
repeat() {
  if(...) {
    if(...) {
    }
  }
}
```

یعنی راه‌حلی که به آن می‌رسید کاملاً «تخت» است.
