До сих пор мы рассматривали функции, которые что-то делают в окружающем мире. Например, функция `circle` (круг) рисует круг. Функция `move` (двигаться) перемещает вашего персонажа. Но некоторые функции работают иначе. Вместо того чтобы делать что-то во внешнем мире, они отдают вам что-то обратно, и это можно использовать в своём коде. Когда функция отдаёт что-то Jiki для использования в коде, мы говорим, что она возвращает (англ. _return_) значение. Она возвращает что-то обратно Jiki. Можно представить, что у таких автоматов есть лоток для выдачи. У нас уже есть приёмные отверстия, в которые мы кладём входные данные, но у автомата может быть и одно выходное отверстие, лоток, из которого что-то выпадает обратно. Когда Jiki нажимает кнопку на автомате, автомат жужжит, и в конце из лотка что-то выпадает. Это может быть число. Это может быть строка. Это что-то, что Jiki может поймать и использовать.

Большинство функций, наверное 95% из них, что-то возвращают. Одни могут выполнить для вас вычисления и вернуть результат. Другие могут склеить несколько строк и отдать вам получившуюся строку. А может быть, автомат каждый раз выдаёт вам текущее время. Давайте посмотрим на этот последний пример. Допустим, у нас есть функция `getCurrentTime` (получить текущее время). Каждый раз, когда Jiki запускает автомат, из лотка выезжает листок бумаги, на котором написано время, например 14:35.

А затем мы можем положить возвращённое значение в коробку с помощью `let`:

```javascript
let time = getCurrentTime()
```

Jiki запустит автомат, достанет из лотка текущее время и сохранит его в коробке с именем `time`.

Здесь важно понимать: листок бумаги, который Jiki кладёт в коробку, фиксируется в этот самый момент. Даже если настоящее время меняется, пока ваша программа работает, в коробке по-прежнему лежит тот самый листок с надписью 14:35. Когда что-то попало в коробку, оно там и остаётся неизменным. Оно не меняется волшебным образом. Если в будущем мы захотим снова положить в коробку текущее время, нам нужно снова воспользоваться функцией `getCurrentTime`, чтобы его получить.

У большинства функций, которые что-то возвращают, есть и входные данные. Например, у нас может быть функция `join` (соединить), которая принимает на вход две строки и возвращает их соединёнными через пробел. Так что если мы запустим автомат `join` со строками `"Hello"` и `"World"` на входе, из лотка выпадет одна строка с надписью `"Hello World"`.

```javascript
join("Hello", "World"); // "Hello World"
```
