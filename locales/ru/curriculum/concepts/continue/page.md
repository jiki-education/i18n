Иногда нам нужно пропустить отдельную итерацию цикла, а не прерывать его целиком. Представьте, что мы хотим делать что-то только для нечётных чисел.

Мы хотим уметь сказать: если `i` (счётчик) нечётное, то на этот раз цикл не выполняем.

Но полностью выходить из цикла мы не хотим. Нам нужно пропустить только эту одну итерацию и затем посмотреть на следующую.

И для этого есть ещё одно ключевое слово: `continue`.

Когда Jiki видит `continue`, он просто возвращается к началу цикла и берётся за следующую итерацию. Так, в цикле for-of, увидев `continue`, он переходит к следующему элементу массива.

```javascript
for (let item of list) {
  if (item === "something") {
    continue; // Пропускает остаток цикла для "something"
  }
  // Остальная часть цикла...
}
```

В цикле for он выполняет шаг с `i++`, а затем начинает следующую итерацию.

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue; // Пропускает остаток цикла для чётных чисел
  }
  // Остальная часть цикла...
}
```
