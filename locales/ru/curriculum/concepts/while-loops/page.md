Следующий цикл, с которым мы познакомимся, называется while.

Он говорит: «Пока выполняется некоторое условие, выполняй цикл». Например, в игре «Space Invaders» может быть правило: стрелять можно только пять раз. Тогда у нас появится цикл, который говорит: пока количество выстрелов меньше пяти, выполняй цикл, который позволяет человеку играть.

```javascript
while (numShots < 5) {
  // выстрелить по пришельцу
  numShots++
}
```

Каждый раз, когда кто-то стреляет, мы увеличиваем `numShots` на единицу. Рано или поздно счётчик дойдёт до пяти, и цикл завершится.

Есть у циклов while одна проблема: довольно легко получить баг, из-за которого цикл никогда не завершится. Такие циклы называют бесконечными (англ. _infinite loops_), и это один из самых распространённых багов в программах.

Когда компьютер начинает тормозить, вентиляторы гудят, всё вокруг шумит, это часто означает, что кто-то оставил в коде бесконечный цикл, который никогда не завершается.
