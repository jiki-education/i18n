Вы, возможно, помните, что цикла repeat в JavaScript на самом деле нет. Это просто штука, которую добавили, чтобы вам было немного проще на старте.

Так что же мы используем вместо него? Обычный цикл `for`, и выглядит он так.

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

Теперь понятно, почему в первый же день это могло вас слегка напугать.

Но сейчас у вас есть все знания, чтобы с этим освоиться. Давайте разберём его по частям.

У цикла `for` три составляющие: инициализатор (англ. _initializer_), условие и инкремент (англ. _increment_).

Инициализатор, вот эта часть `let i = 0`, выполняется в самом начале цикла. Всего один раз, и здесь он создаёт коробку под названием `i` (счётчик), в которой лежит ноль. Здесь `i` означает просто букву, которой мы отмечаем значение по мере выполнения цикла; традиционно для этого берут `i` или `x`.

Следующая часть, условие, проверяется каждый раз перед очередной итерацией цикла.

Если условие истинно, мы снова выполняем цикл.

Если нет, то не выполняем.

И наконец, инкремент, то есть `i++`.

`i++` означает то же самое, что `i = i + 1`. Это просто сокращение, способ каждый раз увеличивать `i` на единицу.

Итак, в этом примере мы задаём `i` равным нулю. Проверяем, меньше ли `i` двух. Так и есть, поэтому выполняем цикл.

А в конце увеличиваем `i` на единицу, и `i` становится единицей. Ноль плюс один равно единице.

И потом идём на второй круг. Проверяем, меньше ли единица двух.

Меньше. Так и есть, выполняем цикл. А в конце снова увеличиваем `i`. Теперь `i` равно двум, один плюс один равно двум.

```javascript
i = 0
i < 2 // true - запускаем цикл
...   // выполняем итерацию
i = i + 1 // 1

i < 2 // true - запускаем цикл
...   // выполняем итерацию
i = i + 1 // 2

i < 2 // false - выходим из цикла
```

Затем идём на третий круг. На этот раз проверяем, меньше ли два двух; нет, не меньше, поэтому цикл не выполняем, и на этом цикл, собственно, закончен. Просто переходим к коду ниже. Итак, цикл выполнился дважды, и это полезно запомнить: если мы начинаем с нуля и условие имеет вид `i < n`, то число `n` и есть количество выполнений цикла.

То есть это то же самое, что написать repeat 2.

Так что ничего сложного, но это гораздо более громоздко, чем просто написать repeat 2. Преимущество цикла `for` в том, что в эти три ячейки можно положить что угодно. Можно начать с другого числа, считать с шагом больше единицы, считать в обратную сторону или использовать условие, которое зависит не от простого счётчика, а от чего-то другого. Именно эта гибкость делает циклы `for` рабочей лошадкой JavaScript.
