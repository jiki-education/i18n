Вы уже видели, как `if` и `else` дают вам два пути: сделать одно, когда условие истинно, и другое, когда оно ложно. А что, если возможностей больше двух?

Представьте, что наш вышибала продаёт билеты. Если вам меньше тринадцати, вы получаете детский билет. От тринадцати до двадцати вам положен подростковый билет. А с двадцати начинается взрослый. Вот у вас уже три разных исхода. Для этого можно добавить ещё одну условную конструкцию после `else`. То есть сказать: «Если вот так, делай это. Иначе если вот так, делай то. Иначе делай вот это». В нашем примере Jiki увидит `if` и проверит первое условие. Шестнадцать меньше тринадцати? Нет. Значит, он переходит к `else if`. Шестнадцать меньше двадцати? Да, это истина. Он выполняет этот блок и выдаёт подростковый билет. И на этом всё. Больше он ничего не проверяет. На последний `else` он даже не смотрит. Как только Jiki находит истинное условие, он выполняет этот блок и пропускает всё остальное, что идёт ниже.

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

Это главное, что нужно понять. Выполняется всегда только один блок. Jiki идёт по этой цепочке сверху вниз, находит первое истинное условие, выполняет этот блок и двигается дальше.

А теперь момент, на котором многие спотыкаются, и его стоит понять как следует. Между двумя отдельными конструкциями `if` и связкой `else if` есть тонкая, но очень важная разница. Представьте, что мы пишем программу, которая выдаёт обычный или бонусный приз в зависимости от набранных очков. Посмотрите на два варианта. В одном используется `else if`, в другом два отдельных `if`. Чем будет отличаться результат?

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

В первом случае, с `else if`, мы проверяем, набрано ли много очков, и выдаём бонусный приз, а до `else if` дело уже не доходит. Так что человек с результатом больше ста получает только бонусный приз.

А во втором примере два `if` полностью независимы. Оба выполнятся, и оба условия окажутся истинными. Значит, здесь человек получит два приза. В первом случае один приз. Во втором два. Ненадолго остановитесь и убедитесь, что вам это действительно понятно.

И ещё интересное наблюдение: оба варианта могут быть правильными, в зависимости от того, как устроена игра. Может быть, участник получает и обычный приз, и бонусный, а может, его просто повышают до бонусного. Ни один из кусков кода не правильный и не неправильный. Просто каждый удобен в своей ситуации. Но вам нужно понимать, какой именно вы собираетесь использовать.
