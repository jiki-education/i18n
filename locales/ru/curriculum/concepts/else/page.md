Условные конструкции позволяют проверять условия и выполнять код только тогда, когда что-то истинно. А теперь давайте познакомимся с напарником `if` по преступлениям. Это ключевое слово `else`.

В условной конструкции (англ. *if statement*) Jiki выполняет блок кода, когда условие истинно, и пропускает этот блок, когда оно ложно. А что, если вы хотите, чтобы при истинном условии Jiki делал одно, а при ложном другое? Для этого и нужно else. Мы можем поставить ветку else (англ. *else clause*) после закрывающей фигурной скобки if, и Jiki выполнит её, если условие в if окажется ложным. Вернёмся к примеру с вышибалой в клубе: теперь у нас есть выбор, открыть дверь или не пустить человека внутрь, а это, пожалуй, лучше, чем полностью его игнорировать, как мы делали раньше. Представьте себе развилку на дороге. Jiki подходит к этой развилке, проверяет условие и может пойти в одну сторону, если оно истинно, или в другую, если ложно. Но он никогда не идёт сразу в обе стороны.

```javascript
if (age >= 21) {
  openDoor()
} else {
  turnAway()
}
```

А что, если вариантов больше двух? Представьте, что наш вышибала продаёт билеты. До тринадцати лет вы получаете детский билет. От тринадцати до двадцати вам положен подростковый. А с двадцати лет билет уже взрослый. Итак, у нас три разных исхода. Для такого случая можно добавить ещё одну условную конструкцию после else. То есть мы можем сказать: «Если так, сделай это. Иначе если так, сделай то. Иначе сделай вот это». В нашем примере Jiki увидит if и проверит первое условие. Шестнадцать меньше тринадцати? Нет. Значит, он переходит к else if. Шестнадцать меньше двадцати? Да, это истинно. Он выполняет этот блок и выдаёт подростковый билет. И на этом всё: больше он ничего не проверяет. Он даже не смотрит на последний else. Как только Jiki находит истинное условие, он выполняет этот блок и пропускает всё остальное, что идёт ниже.

```javascript
if (age < 13) {
  childTicket()
} else if (age < 20) {
  teenTicket()
} else {
  adultTicket()
}
```

Вот главное, что нужно понять: выполняется только один блок. Jiki двигается по цепочке условий сверху вниз, находит первое истинное условие, выполняет этот блок и идёт дальше.

А теперь одна вещь, которую важно понять как следует, потому что именно на ней чаще всего спотыкаются. Есть тонкая, но очень важная разница между двумя отдельными if и конструкцией else if. Представьте, что мы пишем программу, которая выдаёт обычный или бонусный приз в зависимости от набранных очков. Посмотрите на два варианта. В одном используется else if, в другом два отдельных `if`. Чем же будут отличаться результаты?

```javascript
if (score > 100) {
  bonusPrize()
} else if (score > 50) {
  basicPrize()
}
```

```javascript
if (score > 100) {
  bonusPrize()
}
if (score > 50) {
  basicPrize()
}
```

В первом случае, с else if, мы проверяем, не набрал ли человек много очков, выдаём приз, и дальше else if уже не выполняется. Значит, человек с результатом больше ста получает только бонусный приз.

А во втором примере два if полностью независимы. Оба выполнятся, и оба условия окажутся истинными. Так что здесь человек получит два приза. В первом случае один приз. Во втором два приза. Задержитесь на минутку и убедитесь, что вам это действительно понятно.

Заметим также: оба варианта могут быть правильными, в зависимости от того, как устроена игра. Может быть, участник получает и обычный приз, и бонусный, а может быть, ему просто выдаётся бонусный вместо обычного. Ни один из этих кусков кода не правильный и не неправильный. Просто они полезны в разных ситуациях. Но нужно понимать, какой именно из них вы собираетесь использовать.
