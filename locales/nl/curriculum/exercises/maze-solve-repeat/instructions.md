Je hebt een werkende oplossing voor een doolhof gekregen, maar die is erg lang en vol herhaling. Het is jouw taak om de code aan te passen zodat die **zo min mogelijk regels** telt.

Het geheim daarvan is het gebruik van `repeat`-lussen (_loops_ in het Engels) om de code korter te maken. Weet je nog dat een `repeat`-lus deze syntaxis heeft?

```javascript
repeat(3) {
  // Wat je hier maar wilt herhalen.
}
```

Je taak is dus om de code zo kort mogelijk te maken: **22 regels code**. Dat betekent dat je moet nadenken over wanneer een `repeat`-lus handig is en wanneer niet. Let op: lege regels en regels met alleen een commentaar tellen niet mee voor het doel, dus zet gerust wat ruimte tussen je code om hem leesbaarder te maken!

Veel succes!
