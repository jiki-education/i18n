## परिचय

WSL (Windows Subsystem for Linux) Windows का एक ऐसा फीचर है जिसे Microsoft ने बनाया है। यह आपकी Windows मशीन के अंदर एक असली Linux सिस्टम चलाता है। आपको इसकी ज़रूरत इसलिए है क्योंकि ज़्यादातर प्रोग्रामिंग टूल पहले Linux और macOS के लिए बनाए जाते हैं (और उन पर सबसे अच्छे से काम करते हैं), और WSL के ज़रिए Windows पर डेवलपर इन सब तक पहुँच पाते हैं। खुद Microsoft भी Windows पर डेवलपमेंट के लिए यही तरीका सुझाता है। इसे इंस्टॉल करने में लगभग पंद्रह मिनट लगते हैं, जिसमें से ज़्यादातर समय इंतज़ार का होता है, और यह काम आपको सिर्फ एक बार करना है।

## शुरू करने से पहले

आपको चाहिए:

- **Windows 10 (वर्जन 2004 या बाद का) या Windows 11।** पिछले कुछ सालों का कोई भी Windows मशीन ठीक रहेगा।
- कंप्यूटर पर **एडमिनिस्ट्रेटर पहुँच।** अगर यह परिवार का कंप्यूटर है, तो हो सकता है कि जिसने इसे सेटअप किया हो, उसे अपना पासवर्ड टाइप करना पड़े।

## WSL इंस्टॉल करना

1. **Start** बटन पर क्लिक कीजिए और "powershell" टाइप कीजिए। आपको **Windows PowerShell** दिखेगा।
2. उसे सीधे मत खोलिए। इसके बजाय, उस पर राइट क्लिक कीजिए और **Run as administrator** चुनिए। Windows आपसे पूछेगा कि क्या आप इसे बदलाव करने की अनुमति देना चाहते हैं: **Yes** पर क्लिक कीजिए।
3. जो नीली विंडो खुले, उसमें नीचे दिया गया टाइप कीजिए और Enter दबाइए:
   ```
   wsl --install
   ```
4. Windows सब कुछ डाउनलोड और सेटअप कर देगा, जिसमें **Ubuntu** नाम का एक Linux सिस्टम भी शामिल है (यह Linux का सबसे लोकप्रिय वर्जन है)। इसमें कुछ मिनट लग सकते हैं।
5. जब वह आपसे कहे, तो **अपना कंप्यूटर रीस्टार्ट कीजिए**।

## Ubuntu सेटअप करना

रीस्टार्ट के बाद, Ubuntu का सेटअप पूरा करने के लिए अपने आप एक टर्मिनल विंडो खुलेगी। (अगर न खुले, तो Start पर क्लिक कीजिए, "ubuntu" टाइप कीजिए, और उसे खोलिए।)

यह आपसे अपने Linux सिस्टम के लिए एक **यूज़रनेम** और **पासवर्ड** बनाने को कहेगी:

1. यूज़रनेम टाइप कीजिए (सिर्फ छोटे अक्षर, बिना स्पेस के) और Enter दबाइए।
2. पासवर्ड टाइप कीजिए और Enter दबाइए, फिर पुष्टि के लिए उसे दोबारा टाइप कीजिए।

यहाँ एक चीज़ सबको उलझा देती है: **जब आप पासवर्ड टाइप करते हैं, तो स्क्रीन पर कुछ नहीं दिखता।** न कोई डॉट, न तारे, कुछ नहीं। यह Linux की एक सुरक्षा खूबी है, कोई खराबी नहीं। आपकी टाइपिंग दर्ज हो रही होती है, इसलिए बस पासवर्ड टाइप कीजिए और Enter दबाइए।

इस पासवर्ड को मत भूलिए। चीज़ें इंस्टॉल करते समय कभी-कभी इसकी ज़रूरत पड़ेगी।

## जाँच करना कि यह काम करता है

सब कुछ बंद कीजिए, फिर **Start** पर क्लिक कीजिए, "ubuntu" टाइप कीजिए और उसे खोलिए। आपको एक विंडो दिखनी चाहिए जिसमें `$` पर खत्म होने वाला प्रॉम्प्ट आपके टाइप करने का इंतज़ार कर रहा होगा। बधाई हो: यह एक असली Linux टर्मिनल है, और अब आपके पास वही डेवलपमेंट वातावरण है जो पेशेवर लोग इस्तेमाल करते हैं।

`ls` टाइप कीजिए और Enter दबाइए। यह आपके मौजूदा फोल्डर की फाइलों की सूची दिखाता है (अभी ज़्यादा नहीं होंगी)।

## VS Code से WSL इस्तेमाल करना

अगर आपने [VS Code इंस्टॉल](/guides/installing-vscode) कर रखा है, तो वह WSL से कनेक्ट हो सकता है ताकि आपका एडिटर और आपका Linux टर्मिनल साथ काम करें:

1. VS Code खोलिए।
2. Extensions पैनल खोलिए (बाईं तरफ चार वर्गों वाला आइकॉन, या Ctrl+Shift+X दबाइए), **WSL** खोजिए, और Microsoft का बनाया हुआ एक्सटेंशन इंस्टॉल कीजिए।
3. Ctrl+Shift+P दबाइए, "WSL" टाइप कीजिए, और **WSL: Connect to WSL** चुनिए। VS Code दोबारा खुलेगा और Ubuntu से कनेक्ट होगा।

अब से, आप VS Code के अंदर जो भी टर्मिनल खोलेंगे (Terminal मेनू, फिर New Terminal) वह Linux टर्मिनल होगा। यही सेटअप हम अपनी बाकी की गाइडों के लिए सलाह देते हैं।

## अगर कुछ गड़बड़ हो तो

सबसे आम समस्या वर्चुअलाइज़ेशन (या "VT-x", "AMD-V", या "वर्चुअल मशीन प्लेटफॉर्म") का ज़िक्र करने वाली एरर है। WSL एक हार्डवेयर फीचर पर निर्भर करता है जो कुछ कंप्यूटरों पर बंद रहता है। इसे चालू करने का मतलब है आपके कंप्यूटर के BIOS की एक सेटिंग बदलना, जो हर निर्माता के हिसाब से अलग होती है। अपने लैपटॉप के मॉडल नाम के साथ "enable virtualisation" खोजिए निर्देशों के लिए, या <a href="https://forum.jiki.io" target="_blank" rel="noopener noreferrer">हमारे फोरम</a> पर पूछिए और हम आपकी मदद करेंगे।

बाकी किसी भी चीज़ के लिए, Microsoft की <a href="https://learn.microsoft.com/en-us/windows/wsl/install" target="_blank" rel="noopener noreferrer">आधिकारिक WSL इंस्टॉलेशन गाइड</a> में ट्रबलशूटिंग सेक्शन है, और फिर से, फोरम हमेशा मौजूद है।
