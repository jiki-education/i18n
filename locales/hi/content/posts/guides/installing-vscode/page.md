## परिचय

Visual Studio Code (VS Code) एक मुफ्त कोड एडिटर है जिसे Microsoft ने बनाया है और यह Windows, macOS, और Linux पर चलता है। जब आप कोडिंग सीख रहे हों तो हम इसी एडिटर की सलाह देते हैं। अगर आपको नहीं पता कि कोड एडिटर क्या होता है या आपको इसकी ज़रूरत क्यों है, तो पहले [कोड एडिटर का उपयोग करना](/guides/using-a-code-editor) पर हमारी गाइड पढ़िए।

यह गाइड आपको हर ऑपरेटिंग सिस्टम पर VS Code इंस्टॉल करने का तरीका बताती है। नीचे अपना सिस्टम ढूँढिए और बताए गए चरणों का पालन कीजिए। आपको यह सिर्फ एक बार करना है।

## Windows

1. अपने वेब ब्राउज़र में [code.visualstudio.com](https://code.visualstudio.com) खोलिए।
2. **Download for Windows** बटन पर क्लिक कीजिए। इससे आधिकारिक इंस्टॉलर (एक `.exe` फ़ाइल) डाउनलोड होगी।
3. डाउनलोड पूरा होने पर, इंस्टॉलर चलाने के लिए फ़ाइल खोलिए।
4. लाइसेंस एग्रीमेंट स्वीकार कीजिए, फिर डिफ़ॉल्ट विकल्पों को चुनने के लिए **Next** पर क्लिक करते जाइए। हमारी सलाह है कि 'VS Code को राइट क्लिक मेनू में जोड़ें' वाले बॉक्स पर टिक रहने दीजिए, क्योंकि बाद में यह काम आता है।
5. **Install** पर क्लिक कीजिए, फिर **Finish** पर। VS Code तैयार होने पर खुल जाएगा।

## macOS

1. अपने वेब ब्राउज़र में [code.visualstudio.com](https://code.visualstudio.com) खोलिए।
2. **Download for macOS** बटन पर क्लिक कीजिए। इससे एक `.zip` फ़ाइल डाउनलोड होगी जिसमें ऐप है।
3. अपना **Downloads** फ़ोल्डर खोलिए और डाउनलोड हुई फ़ाइल पर डबल क्लिक करके उसे अनज़िप कीजिए। आपको **Visual Studio Code** नाम की एक ऐप मिलेगी।
4. **Visual Studio Code** को अपने **Applications** फ़ोल्डर में खींचकर डालिए।
5. अपना **Applications** फ़ोल्डर खोलिए और **Visual Studio Code** पर डबल क्लिक करके उसे लॉन्च कीजिए। अगर macOS पूछे कि क्या आप वाकई इसे खोलना चाहते हैं, तो **Open** पर क्लिक कीजिए।

## Linux

1. अपने वेब ब्राउज़र में [code.visualstudio.com](https://code.visualstudio.com) खोलिए।
2. **Download for Linux** पर क्लिक कीजिए और वह पैकेज चुनिए जो आपके डिस्ट्रिब्यूशन से मेल खाता हो:
   - Debian और Ubuntu आधारित सिस्टम पर **.deb** पैकेज चुनिए।
   - Fedora, Red Hat, और openSUSE आधारित सिस्टम पर **.rpm** पैकेज चुनिए।
3. डाउनलोड हुए पैकेज को अपने सिस्टम के सॉफ्टवेयर इंस्टॉलर से खोलकर **Install** पर क्लिक कीजिए, या टर्मिनल से इंस्टॉल कीजिए:
   - Debian या Ubuntu पर, जिस फ़ोल्डर में आपने इसे डाउनलोड किया है, वहाँ `sudo apt install ./<file>.deb` चलाइए।
   - Fedora या Red Hat पर, जिस फ़ोल्डर में आपने इसे डाउनलोड किया है, वहाँ `sudo dnf install ./<file>.rpm` चलाइए।
4. एक बार इंस्टॉल हो जाने पर, VS Code को अपने एप्लिकेशन मेनू से खोलिए, या टर्मिनल में `code` चलाकर खोलिए।

## VS Code खोलना

चाहे आपने इसे कैसे भी इंस्टॉल किया हो, अब आप जब चाहें कोड लिखने के लिए VS Code खोल सकते हैं। Windows और macOS पर यह आपकी बाकी एप्लिकेशन्स के साथ दिखने लगेगा, और Linux पर यह आपके एप्लिकेशन मेनू में होगा।

बस हो गया। अब आपके पास एक सही कोड एडिटर इंस्टॉल है और आप कोड लिखना शुरू करने के लिए तैयार हैं।
