## परिचय

जब आप अपने कंप्यूटर पर कोड लिखना शुरू करते हैं, तो आपको उसे लिखने के लिए एक जगह चाहिए होती है। वह "जगह" एक कोड एडिटर होता है। यह उन पहले टूल्स में से एक है जिन्हें आप बार-बार इस्तेमाल करेंगे और अपने करियर में इस पर काफ़ी समय बिताएँगे। समय के साथ आप शायद इसे बदलेंगे और नए एडिटर आज़माएँगे, इसलिए यह समझना ज़रूरी है कि यह क्या है और शुरुआत के लिए एक अच्छा एडिटर कैसे चुनें।

## कोड एडिटर कोई वर्ड प्रोसेसर नहीं है

यह मान लेना आसान है कि कोई भी प्रोग्राम जो आपको टाइप करने दे, काम कर जाएगा। सबसे आम गलती है Microsoft Word या Google Docs जैसे वर्ड प्रोसेसर का इस्तेमाल करना। ये लोगों के पढ़ने के लिए दस्तावेज़ बनाने के लिए बने हैं, इसलिए ये आपके टाइप किए हुए को चुपचाप बदल देते हैं। ये सीधे डबल कोट्स को घुँघराले "smart" कोट्स में बदल देते हैं, आपके शब्दों को ऑटोकरेक्ट करते हैं, और छिपी हुई फ़ॉर्मेटिंग सेव कर लेते हैं। ये सब कोड को बिगाड़ देते हैं।

कोड एडिटर एक किस्म का टेक्स्ट एडिटर होता है। यह प्लेन टेक्स्ट के साथ काम करता है और कभी भी छिपी हुई फ़ॉर्मेटिंग नहीं जोड़ता, इसलिए आप जो टाइप करते हैं, कंप्यूटर वही देखता है। अंतर यह है कि कोड एडिटर एक ऐसा टेक्स्ट एडिटर है जो खास तौर पर कोड के लिए बनाया गया है। प्लेन टेक्स्ट के अलावा, यह आप जो लिख रहे हैं उसकी संरचना को समझता है और आपकी ऐसे तरीकों से मदद करता है जो किसी वर्ड प्रोसेसर के लिए संभव नहीं:

- **Syntax highlighting** आपके कोड के अलग-अलग हिस्सों को अलग-अलग रंगों में दिखाता है ताकि उसे पढ़ना और गलतियाँ पकड़ना आसान हो।
- **Auto indentation** आपके कोड की पंक्तियों को सलीके से एक-दूसरे के अनुसार रखता है, जो कई भाषाओं में बहुत ज़रूरी है।
- **Error hints** अक्सर प्रोग्राम चलाने से पहले ही समस्याओं की ओर इशारा कर देते हैं।
- **Autocomplete** आप जो टाइप कर रहे हैं उसका बाकी हिस्सा खुद-ब-खुद सुझाता है, जिससे आप तेज़ी से लिख पाते हैं और टाइपिंग की गलतियाँ कम होती हैं।
- **Extensions** के ज़रिए आप आगे चलकर नई भाषाओं और टूल्स का सपोर्ट जोड़ सकते हैं।

## हमारी सिफारिश

बहुत सारे अच्छे कोड एडिटर हैं और आप यहाँ कोई गलत चुनाव नहीं कर सकते। फिर भी, हम **Visual Studio Code** की सिफारिश करते हैं, जिसे आमतौर पर छोटा करके VS Code कहा जाता है। यह मुफ़्त है, Windows, macOS और Linux पर चलता है, शुरुआती लोगों के लिए अनुकूल है, और दुनिया में सबसे अधिक इस्तेमाल किए जाने वाले एडिटरों में से एक है। इसलिए आपको जो भी ट्यूटोरियल मिलेगा, वह मानकर चलेगा कि आप इसी का इस्तेमाल कर रहे हैं।

जब आप इसे इंस्टॉल करने के लिए तैयार हों, तो [VS Code इंस्टॉल करने](/guides/installing-vscode) पर हमारी गाइड देखें।

## दूसरे एडिटर जिनके बारे में आप सुन सकते हैं

Jiki के साथ आगे बढ़ने के लिए आपको इनमें से किसी की ज़रूरत नहीं है, लेकिन आप इनके बारे में सुनेंगे, इसलिए यहाँ आम एडिटरों का एक संक्षिप्त परिचय है:

- <a href="https://code.visualstudio.com" target="_blank" rel="noopener noreferrer">Visual Studio Code (VS Code)</a> एक मुफ़्त, क्रॉस-प्लेटफ़ॉर्म एडिटर है जिसकी हम सिफारिश करते हैं।
- <a href="https://www.sublimetext.com" target="_blank" rel="noopener noreferrer">Sublime Text</a> एक तेज़ और हल्का एडिटर है जो कई सालों से लोकप्रिय है।
- <a href="https://zed.dev" target="_blank" rel="noopener noreferrer">Zed</a> एक नया और बहुत तेज़ एडिटर है जिसका ध्यान गति और सहयोग पर है।
- <a href="https://www.jetbrains.com/ides/" target="_blank" rel="noopener noreferrer">JetBrains IDEs</a> (जैसे <a href="https://www.jetbrains.com/pycharm/" target="_blank" rel="noopener noreferrer">PyCharm</a> और <a href="https://www.jetbrains.com/idea/" target="_blank" rel="noopener noreferrer">IntelliJ IDEA</a>) शक्तिशाली और भारी टूल हैं जो बड़े प्रोजेक्ट पर काम करने वाले पेशेवर डेवलपरों के लिए बने हैं।
- <a href="https://www.vim.org" target="_blank" rel="noopener noreferrer">Vim</a> और <a href="https://neovim.io" target="_blank" rel="noopener noreferrer">Neovim</a> कीबोर्ड से चलने वाले एडिटर हैं जो टर्मिनल में रहते हैं। ये अनुभवी डेवलपरों को बहुत पसंद हैं, लेकिन इन्हें सीखने में शुरुआत में काफ़ी मेहनत लगती है।

जब आप सीख रहे हों तो हमारी सलाह सीधी-सादी है: VS Code से शुरुआत कीजिए, कोड लिखने में सहज हो जाइए, और बाद में जब आपको पता चल जाए कि आपको क्या पसंद है, तब दूसरे एडिटर आज़माइए।
