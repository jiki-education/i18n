上一次你看到這道牆時，你在最上面加了一層，把它完成。這次的練習，你要更進一步，從零開始砌出整道牆，總共 55 塊磚。

完成後的牆應該長這樣：

<img src="/static/images/exercise-assets/build-wall/completed-wall.webp" alt="完成後的牆" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

你需要知道的事：

- **每一**塊磚都是高 10、寬 20。
- 需要的話，磚塊可以從畫布**外面**開始，或在畫布**外面**結束，但不能**完全**在畫布外。
- 每一列會交替：一列從左邊邊緣開始（5 塊磚），下一列從畫布左側外開始（6 塊磚）。（最下面一列是 5 塊，最上面一列是 6 塊）
- `rectangle`（長方形）函式在你的程式碼中只能出現一次！

這個練習的目的，是要讓你試著把 `repeat` 區塊和條件式搭配使用。這道練習有很多種解法，你的挑戰是找出一個能寫出乾淨、令人滿意程式碼的解法。

一個值得問自己的好問題是：「現實世界裡的砌磚師傅會怎麼做呢？」
