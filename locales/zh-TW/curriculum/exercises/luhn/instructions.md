我們剛剛看過如何驗證書籍的 ISBN 號碼。另外還有一個常見的公式，在很多情境下都能用來檢查號碼，那就是盧恩公式（英文：_Luhn formula_）。它最有名的用途，就是抓出信用卡號碼裡打錯的數字。

### 盧恩檢查

盧恩檢查有好幾個步驟：

- 從**最右邊**的數字開始往左移動，把**每隔一個的數字加倍**。
- 如果加倍後的數字大於 9，就減去 9。
- 然後把所有數字加起來。
- 如果總和能被 10 整除，這個號碼就是有效的。

舉例來說，`"067"`會像這樣一步步處理：

```
0   6   7     // 原始數字
0  12   7     // 從右邊數來每隔一個的數字加倍
0   3   7     // 12 大於 9，所以減去 9 → 3
       10     // 把這些數字加起來
     true     // 10 能被 10 整除，所以 067 是有效的
```

### 你的任務

建立一個叫做`valid`（有效）的函式，它接收一個字串，如果通過盧恩檢查就回傳`true`，沒有通過就回傳`false`。

這些號碼會以字串的形式提供，為了方便閱讀，裡面可能夾帶空格（例如`"4539 1488 0343 6467"`）。這些空格要忽略掉。

幾個重要的提醒：

- 輸入可能包含空格，你應該忽略它們。
- 如果輸入包含其他任何字元，你應該回傳 false。
- 去掉空格之後，長度小於或等於 1 的字串**不**是有效的。
