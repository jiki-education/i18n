你的任務是製作一段持續 100 次疊代的日落動畫。它看起來應該像下面這樣（那種閃爍感就跟翻頁書一模一樣！）：

<img src="/static/images/exercise-assets/sunset/example.webp" alt="日落" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 16px;" />

我們已經幫你把初始場景畫好了。你需要用上一支影片學到的翻頁書風格，讓幾個東西動起來：

- **太陽的大小**：一開始的半徑是 5，每次疊代增加 0.2。
- **太陽的位置**：初始中心點是 (50, 10)，每次疊代要在天空中下降 1。
- **太陽的顏色**：用 RGB 從黃色漸變到橘色。數值你可以自己挑，但我們建議從`255, 237, 0`開始，並把綠色調低，效果會很好看。
- **天空的顏色**：用 HSL 讓天空的顏色動起來。你需要在整段動畫中逐漸提高色相（英文：_hue_）。挑你覺得好看的數值就好。上面的動畫裡我們選了粉紅色的日落，但你也可以試試各種不同的氛圍！

記住：用翻頁書風格做動畫，其實就是把整個場景重新畫在前一版上面。

祝你好運喔！
