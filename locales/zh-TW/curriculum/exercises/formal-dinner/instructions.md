你又做起副業，當起了門口保全。這是「After Party」結束後的晚上，又有另一場熱鬧的聚會。這次是正式晚宴，所以今晚與其說你是「門口那個壯漢」，不如說是「拿著板夾、穿著體面西裝背心的人」。

這裡絕對不是讓你**只**喊名字的場合。事實上，在這裡根本不能直呼其名。在這裡，大家一律以稱謂（英文：_honorific_）加上姓氏相稱（Miss、Mr、Dr 等）。

主辦單位把座位表交給你，分成 2 個獨立的陣列。一個放賓客的全名，另一個放每位賓客所坐的那一桌的名稱（以樹木和花命名）。就和「After Party」一樣，這 2 個陣列是一一對應的：第一個陣列中第 3 位的賓客，就會坐在第二個陣列中第 3 位的桌子。

所以當 Mr Pitt 翩然而至時，你得判斷出他就是你名單上的「Brad Pitt」，然後告訴他，他坐在哪一桌。

寫一個叫做 `tableFor`（查出賓客坐在哪一桌）的函式。這個函式有 3 個輸入：

- 第一個是賓客全名的陣列，內容是字串
- 第二個是桌名的陣列，順序和賓客相同
- 第三個是進場的賓客，格式是稱謂加上姓氏（例如「Mr Pitt」）

回傳這位賓客所坐的桌子名稱。如果對方根本不在座位表上，就改回傳字串 `"No table found"`（這裡可不接受想碰運氣混進來的人喔！）。

稱謂永遠剛好只有 1 個詞，後面全部都是賓客的姓氏。大多數姓氏只有 1 個詞，但有幾個氣派的姓氏會長到 2 個詞。

不過還是要小心。很多姓氏長得和其他姓氏很像。

### 字串與陣列的方法與屬性

除了你在上一個練習學到的`.length`屬性，還有 4 個方法可能對你有幫助。這個練習有很多種解法，但用這些方法能讓你寫出最短的解答。

`"...".split(substring)`會用另一個字串把一段字串切開。例如：

```js
`"Jeremy".split("e")`
// ["J", "r", "my"]
```

`[...].slice(start)`會取出一部分陣列，從索引`start`開始，一路取到陣列結尾。取出的元素會被複製到一個全新的陣列，再回傳給你。實際上，這等於丟掉最前面的`start`個元素。例如：

```js
["Jeremy", "Erik", "Aron", "DJ", "Glenn", "Isaac", "Bethany"].slice(2)
// ["Aron", "DJ", "Glenn", "Isaac", "Bethany"]
```

`[...].join(string)`會用你提供的字串把陣列裡的元素接在一起。例如：

```js
["Jeremy", "Erik", "Aron", "DJ", "Glenn", "Isaac", "Bethany"].join(" likes ")
// Jeremy likes Erik likes Aron likes DJ likes Glenn likes Isaac likes Bethany
```

`"...".endsWith(string)`會告訴你一個字串是不是以另一個字串結尾。例如：

```js
"Jeremy".endsWith("emy")
// true

"Jeremy".endsWith("Jer")
// false
```
