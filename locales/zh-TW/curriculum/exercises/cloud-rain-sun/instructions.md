在這個練習中，你的任務是畫出一個雨天氣象圖示，太陽從雲層後面探出頭來。完成後，看起來應該像這樣：

<img src="/static/images/exercise-assets/cloud-rain-sun/finished.webp" alt="完成的雲、雨和太陽場景" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.3); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

我們已經幫你畫好範本了。你畫的形狀應該剛好落在線的內側。我們也把雲的底部加進了程式碼裡，讓你輕鬆一點。**你不能更改這一行**（你會看到它是灰色的，旁邊還有一個鎖頭符號）。

你會需要 `circle`（圓形）和 `ellipse`（橢圓）這兩個函式。只有雨滴要用橢圓來畫。如果你用橢圓畫太陽或雲，就行不通了。

### 算出正確的座標

在這個練習中，你**可以**把滑鼠移到繪圖區上，找出座標。同樣地，用到的所有數字**都能被 5 整除，只有一個例外**。雨滴的水平半徑是 `3`。其他每個數字，包括雨滴的垂直半徑，都能被 5 整除。
