你經營一間小型美髮沙龍，講求速度勝過品質。客人剪完可能有點不夠精緻，但至少不用在椅子上坐太久。

你提供幾種不同的服務，從單純造型到完整剪髮都有，每種服務需要花費的時間不同。店裡採先來後到的順序，沒有預約制度。

一天快接近尾聲時，你需要一個方法，判斷自己還有沒有時間服務新進門的客人。

寫一個叫做`canFitIn`（能不能排得下）的函式，它接受 3 個輸入：

- 第一個是目前已經在排隊名單上的髮型（字串陣列）
- 第二個是新客人想剪的髮型（字串）
- 第三個是今天還剩下幾分鐘（數字）

回傳一個布林值，表示你能不能把這位客人排進去。

你提供的造型有：

- Mohawk：20 分鐘
- Slicked-Back Pixie：15 分鐘
- Bob：25 分鐘
- Shave and Polish：15 分鐘
- Afro Trim：45 分鐘
- Up-do：30 分鐘

### 巢狀陣列

這是第一個你會遇到「陣列裡還裝著其他陣列」的練習。我們把這種結構叫做「巢狀陣列」。巢狀陣列和其他陣列沒什麼不同，只是它裝的不是字串或數字，而是其他陣列。

來看看`cuts`（各種髮型的資料）這個陣列吧。它裡面裝著其他陣列，每個髮型各一個，而每個陣列都有 2 個元素：名稱和所需時間。

這裡最簡單的想法是，先看內層的陣列，也就是一組組「名稱加所需時間」的配對，再想像它們全部被收進另一個陣列裡。

索引的運作方式和其他地方一樣，但你可以像下面這樣，把索引一層一層串接起來……

```javascript
let cuts = [
  ["Mohawk", 20],
  ["Slicked-Back Pixie", 15],
  ["Bob", 25],
  //...
]

cuts[0] // ["Mohawk", 20]
cuts[0][0] // "Mohawk"
cuts[0][1] // 20
cuts[2][0] // "Bob"
```
