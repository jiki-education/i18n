在你完成的第一個繪圖練習裡，你用了`rectangle`（長方形）函式來填補牆上的一些空隙。這次的練習，我們要更進一步，用迴圈幫牆加上最上面那一層。

除了最上面那一層之外，其他層都已經完成了。你要補上最後一層的 5 塊磚。完成之後，牆應該長這樣：

<img src="/static/images/exercise-assets/finish-wall/completed-wall.webp" alt="完成的牆" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

你需要知道的事：

- 每塊磚高 10、寬 20。
- `rectangle`函式在你的程式碼裡只能出現一次！
- 正確的顏色是 `"brick"`。

把最近用過的概念拿出來重複運用，你就沒問題了。祝你好運喔！
