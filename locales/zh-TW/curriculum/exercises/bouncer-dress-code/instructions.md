你又回來做保鑣這份兼職了，而今晚你工作的地方服裝規定很嚴格。

你的工作就是查看對方穿著什麼、年紀多大，再決定該怎麼做。這次你要遵守的規則又更「有趣」了一些。

### 規則

- 任何穿著**正式**或**體面**服裝的人都能進場（不管他們在不在賓客名單上），還會被招待開胃小點。
- 穿著**正式**服裝的**成年人**（18 歲以上）**還會**被招待香檳。
- 穿著其他服裝的**孩童**（未滿 18 歲），**只有**在賓客名單上時才能進場。
- 其他人一律會被請離開。

服裝規定的分類：

- **正式**指的是`"ballgown"`或`"tuxedo"`
- **體面**指的是`"suit"`或`"dress"`

### 你的能力

你有三個可以取得資料的函式：

- `getOutfit()`（取得服裝）會回傳對方穿著的服裝名稱（例如`"ballgown"`、`"suit"`、`"denim"`）
- `getAge()`（取得年齡）會回傳對方的年齡。
- `onGuestList()`（查詢賓客名單）會回傳對方是否在賓客名單上。

在解法中，每個「取得資料」的函式都只能使用一次（不然如果你一直問人家的名字之類的，對方會覺得很煩！）

接下來，你還有一些可以採取的動作：

- `offerChampagne()`（請喝香檳）請對方喝一杯香檳
- `offerCanapes()`（請吃小點）請對方吃一些開胃小點（鮭魚塔塔）
- `letIn()`（放行）讓對方進場
- `turnAway()`（拒絕入場）請對方離開

### 有效率地寫程式

這題有很多種解法。你的目標是把這些規則組合起來，讓程式碼**讀起來清楚易懂**。盡可能減少重複的地方。
