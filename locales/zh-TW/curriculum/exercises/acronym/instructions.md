你已經解過簡單的三字母縮寫了，像是把`Portable Network Graphics`變成`PNG`。

不過，這個練習要更進一步，處理各種縮寫，不只是三個字母的。而且這要難得多……

你的任務是寫一個叫做`acronym(phrase)`的函式，它會接收一個詞句，然後回傳它的縮寫。

## 規則

新的單字會從**空格**或**連字號**（`-`）之後開始。其他字元（逗號、撇號、底線、驚嘆號等）**不**算是分隔符號，也永遠不會成為縮寫的一部分。只有字母才算數。

| 詞句                      | 縮寫    |
| ------------------------- | ------- |
| As Soon As Possible       | ASAP    |
| Liquid-crystal display    | LCD     |
| Thank George It's Friday! | TGIF    |

## 提醒

我們還沒有給你那些課程後面才會看到、比較進階的 JavaScript 方法（沒有能神奇地把字母變成大寫的方法，也沒有能告訴你某個字元到底是不是字母的方法）。你得先自己把這些輔助函式都做出來，才能把整個東西組合起來。

這題比聽起來還難喔。祝你玩得開心！
