小時候，我每天都會自己把便當盒裝好帶去學校。媽媽會先把物品擺出來給我（按照從大到小排得整整齊齊），我就會盡量把最多的物品塞進便當盒裡，不過便當盒能裝的量就是有限。裝不下的物品，我只好放進背包，一整天背著到處跑，而不能留在學校的置物櫃裡。

在這道練習裡，你的任務是設計一個演算法，算出哪些物品能放進便當盒、哪些得放進背包。

你的任務是寫一個叫做`packLunch(items, capacity)`（裝便當）的函式，它接受兩個輸入：物品的陣列（由大到小排列），以及便當盒的大小`capacity`（容量），也就是一個數字。

物品的陣列是一個巢狀陣列，每個物品本身也是一個陣列，裡面有兩個元素：物品的名稱和它的大小。這些物品一律從最大排到最小。舉例來說，物品的陣列可能長這樣：

```javascript
[
  ["Water bottle", 20],
  ["Crisps", 10],
  ["Peanut Butter Sandwich", 8],
  ["Chocolate bar", 6],
  ["Satsuma", 3]
]
```

便當盒有最大容量。你需要判斷哪些物品能放進便當盒，並盡可能塞進最多的物品。其餘的物品都要放進背包。

你的函式應該回傳一個包含兩個元素的陣列。第一個元素是放進便當盒的物品陣列，第二個是放進背包的物品陣列。兩個陣列都要由小到大排列。

舉例來說，以上面的陣列、容量 20 來說，你應該要回傳：

```javascript
return [
  ["Satsuma", "Chocolate bar", "Peanut Butter Sandwich"],
  ["Crisps", "Water bottle"]
]
```

### 有幫助的方法

和這一節的其他練習一樣，你會需要用`.push(element)`方法來建立你的陣列。

你還有一個新方法，叫做`[...].toReversed()`，它會建立一個陣列副本，把裡面所有元素倒過來排。舉例來說：

```
["A", 1, true].toReversed()
// [true, 1, "A"]
```

你不一定要用它，不過它可能很實用。
