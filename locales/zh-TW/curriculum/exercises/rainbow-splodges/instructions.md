這個練習的任務，就是讓畫布上充滿色彩繽紛的彩虹斑塊！

你需要畫出**200 個圓形**，每個圓形的半徑、位置和顏色都要隨機。結果應該會像這樣：

<img src="/static/images/exercise-assets/rainbow-splodges/example.webp" alt="彩虹斑塊" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.1); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

只有三條規則：

1. 把飽和度和亮度維持在 20 到 80 之間。你可以固定用同一個值（也許兩個都設 50，看起來應該會比較好看），也可以更大膽一點，讓兩個值都隨機變化。
2. 圓形的半徑要大於 1、小於 30（不然圓形會變得超級大！）。你可以挑選不同的範圍，但不能超出這個範圍。
3. 圓形不能超出畫布外，但很多圓形應該要碰到邊緣。

發揮創意吧。試試看不同的風格，看看哪一種你覺得最酷。玩得開心喔！
