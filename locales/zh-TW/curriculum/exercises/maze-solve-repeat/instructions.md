你已經拿到一個能解開迷宮的解法，但它非常冗長又重複。你的任務是把程式碼縮到**盡可能少的行數**。

當中的訣竅，就是用 `repeat` 迴圈（英文：_loops_）來讓程式碼變短。舉例來說，記得 `repeat` 迴圈有這樣的語法：

```javascript
repeat(3) {
  // 把你想重複的內容寫在這裡。
}
```

你在這裡的任務，就是把程式碼寫得越短越好，目標是 **22 行程式碼**。這代表你要思考什麼時候適合用 `repeat` 迴圈，什麼時候不適合。注意，空白行和只有註解的行不算在目標行數內，所以你可以儘管把程式碼排得寬鬆一點，讓它更好讀！

祝你好運！
