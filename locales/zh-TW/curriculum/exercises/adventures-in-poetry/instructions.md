你正在做一款叫做「詩歌歷險記」的機器人詩歌遊戲。第一步，你要寫程式讓機器人一邊走、一邊收集詞，最後再把整首詩朗誦出來。

每一格裡會是四種東西的其中一種：

1. 什麼都沒有（`""`）
2. 詩裡的**詞**。
3. 風景，例如葉子或蝴蝶（emoji）。
4. 格子旗（`🏁`），它會告訴機器人該停下來了。

為了幫你，你有幾個函式可以用。第一個是`move()`函式，它會叫詩人機器人往前走一格，並回傳那一格上的東西。再來是`isEmoji(thing)`函式，它會回傳一個布林值，告訴你傳進去的字串是不是 emoji。最後是`recite(poem)`函式，你要用它來朗誦最後完成的詩。

你的任務就是走完整條路徑，把詩一點一點拼湊起來，然後朗誦它。

## 規則

- **詞**要放進詩裡，每個詞之間要加一個**空格**。
- **風景**不屬於詩的一部分，要忽略。
- **撇號**自己單獨佔一格，它會把左右兩邊的詞接起來。先`heart`，再`'`，再`s`，就會變成`heart's`。
- **逗號**也是自己單獨佔一格。它會緊貼在前一個詞後面，但後面還是要有一個空格。
- 詩人走到**格子旗**時就會停下來，或者收集到 7 個詞也會停。看哪一個先發生。
- 無論詩人什麼時候停下來、又是怎麼停下來的，都會朗誦自己收集到的內容。`recite()`只能呼叫**一次**。

## 限制

這道練習有很多種解法，但我們希望你用上最近學到的`continue`和`break`關鍵字，所以有幾條規則：

1. 你的解法必須同時用到`continue`和`break`。
2. 你的解法不能使用`&&`或`!`。
3. 不能寫任何輔助函式。
4. 只能有 2 層縮排：

```javascript

// 可以 - 2 層縮排
repeat() {
  if(...) {
    //...
  }
}

// 不行 - 3 層縮排
repeat() {
  if(...) {
    if(...) {
    }
  }
}
```

也就是說，你寫出來的解法會相當「扁平」。
