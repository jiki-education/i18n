有時候，我們會想跳過迴圈裡的某一次疊代，而不是直接跳出整個迴圈。想像一下，我們只想對奇數做處理。

我們希望能夠這樣說：如果`i`（索引）是奇數，這次就不要執行迴圈。

但我們並不想完全離開迴圈，只想跳過這一輪疊代，然後接著看下一輪。

為此，我們還有另一個關鍵字，叫做`continue`。

當 Jiki 看到`continue`時，他會直接跳回迴圈的最上方，開始下一輪疊代。所以在 for-of 迴圈裡，如果他看到`continue`，就會繼續處理陣列裡的下一個項目。

```javascript
for (let item of list) {
  if (item === "something") {
    continue; // 遇到 "something" 時跳過迴圈剩下的部分
  }
  // 迴圈剩下的部分...
}
```

在`for`迴圈裡，他會執行到`i++`這個遞增動作，然後開始下一輪疊代。

```javascript
for (let i = 0; i < 10; i++) {
  if (i % 2 === 0) {
    continue; // 遇到偶數時跳過迴圈剩下的部分
  }
  // 迴圈剩下的部分...
}
```
