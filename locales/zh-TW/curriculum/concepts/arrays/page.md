你已經使用過數字、字串和布林值（也就是 true 和 false 的高級說法），我們把這些不同的東西稱為資料型態（英文：_data types_）。現在，我們要加入第一個複合資料型態（英文：_compound data type_）了。

這是一種可以包含多個東西，而不只是一個東西的資料型態，這個資料型態就叫做陣列（英文：_array_）。

當你聽到陣列這個詞時，我希望你想像一條實體的鏈子，把許多東西串在一起。

它串起來的東西可以是任何東西，像是字串、數字、布林值，甚至是其他的陣列，或是你還沒學過的東西，不過我們現在先別擔心這個。

這條鏈子裡的所有東西都是有順序的，也就是它們被串起來的順序。

所以，一個陣列包含了許多東西，但它是一個完整的元素（英文：_element_），一個完整的東西，也就是一個裡面有許多元素的陣列。

Jiki 可以拿起這個陣列，也就是這條鏈子，然後把它放進一個盒子裡，就像他可以把字串或數字放進盒子裡一樣。

他可以把它放進機器的投入口。他也可以從出料口把它拿出來。這個陣列是一個完整的東西，而 Jiki 處理它的方式，就跟他處理字串、數字，以及你目前為止看過的其他所有東西完全一樣。

現在，在程式碼中，陣列看起來也有點像一條鏈子。它的兩端各有一個方括號，然後裡面有許多被串在一起的項目，並用逗號分隔。

舉例來說，如果我們想建立一個包含幾位導師名字的陣列，我們可以準備一個叫做`mentors`（導師）的盒子，然後把這條鏈子放進去。

我們會寫下`let mentors =`，就跟我們處理其他盒子的方式完全一樣，接著會有一個左方括號、許多元素（他們的名字用逗號分隔），然後是一個右方括號。當 Jiki 看到這個時，他會去拿 4 張紙，每個名字寫在一張紙上，接著拿出一條新的鏈子把它們全部串在一起，最後他會把這條鏈子放進`mentors`盒子裡。

你可以把任何東西放進陣列裡，像是字串、數字、布林值，甚至是混合不同的東西。

這些都是完全合法的陣列的不同範例。

你也可以建立一個空的陣列。它就是一條沒有元素的鏈子。它仍然是一個真實存在的東西。它仍然有兩端。它仍然是一條鏈子。只是它裡面沒有任何項目而已。不過，你還是可以把這個空陣列放進盒子裡，之後再拿出來使用。

所以，你可以使用方括號語法來建立陣列，但我們實際上要怎麼使用它們呢？我們要怎麼檢查裡面有什麼，並把東西拿出來呢？嗯，就跟我們之前想從字串中拿出字母的方式完全一樣。我們可以使用裡面帶有數字的方括號語法。

讓我們回到導師的名單。如果我們想拿出第一個，我們會寫`mentors[0]`。記住，在 JavaScript 中我們是從 0 開始計算的喔。

我們也可以用跟之前疊代字串完全一樣的方式，使用`for-of`來疊代陣列。

陣列的運作方式完全相同。唯一的差別在於，這次我們拿出來的不是字母，而是陣列裡的項目。在這個例子中，就是導師的名字。

所以，我們第一次感謝某人時，我們感謝`"DJ"`。第二次時，我們感謝`"Becky"`，以此類推。

我們也可以在陣列上使用`length`屬性，就像我們在字串上學到的一樣。如果我們在`mentors`盒子裡有一個包含 4 個字串的陣列，並寫下`mentors.length`，它就會回傳 4。

我們也可以在陣列上以完全相同的方式使用`includes`。我們可以寫`mentors.includes("DJ")`，它就會回傳`true`。但如果我們寫`mentors.includes("Frank")`，它就會回傳`false`。

一切的運作方式都跟字串完全一樣。只是我們現在處理的是陣列的元素，而不是字串的字母。
