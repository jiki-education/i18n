你已經知道怎麼建立字典，也知道怎麼從字典裡把值拿出來。但如果資料變了呢？總有一天我會變老，不再是`42`，而是`43`。

那我們要怎麼更新字典呢？其實方法跟我們平常找東西的方式很像。你知道我們是用方括號把值取出來的，其實只要在方括號後面加一個等號，就可以更新字典。Jiki 會走到`person`這個盒子前面，把筆記本那一頁拿出來，找到`"age"`這個鍵，把原本的`42`擦掉，改寫上`43`，然後再把那一頁放回盒子裡。這就是直接改變字典本身。

```javascript
person["age"] = 43
```

Jiki 不是在建立一個新的字典，他改的是本來就放在盒子裡的那本筆記本。

那如果你想加上原本沒有的資料呢？做法完全一樣喔。

如果你指定的鍵不存在，Jiki 就會在最下面新增一個鍵，把這個值放進去。

所以在這個例子裡，他會打開筆記本，找找看有沒有`"country"`，發現沒有，就在最下面加一行新的：左邊是`"country"`，右邊是`"England"`。

```javascript
person["country"] = "England"
```

你看，語法跟改變一個值的時候一模一樣。這兩種情況 Jiki 都會自動處理：鍵已經存在，他就更新；鍵不存在，他就新增。你不需要做任何特別的事。

就像你可以從一個空的陣列開始，把東西一個一個放進去，你也可以從一個空的字典開始，一個一個把鍵加進去。這同樣是非常常見的模式，你之後會一直看到。

字典一個很常見的用途是拿來計數。你可以把想計算的東西當成鍵，把數量當成值。想像你在賞鳥，想記錄每一種鳥各看到了幾隻。第一次看到某種鳥時，把牠的數量設成 1；之後每再看到一次，就把目前的值拿出來加 1。

要讓這個模式成立，我們需要一個方法來檢查字典裡是不是已經有這個鍵：如果有，就把它加 1；如果沒有，就從 1 開始算。

要做到這件事，字典上有一個方法，叫做`has`（有沒有）。

你指定一個想查的鍵，Jiki 就會檢查字典裡有沒有這個鍵，然後根據結果回傳 true 或 false。

```javascript
person.has("age") // true
```

把這些組合起來，計數的模式就會長這樣：

```javascript
if (counts.has(letter)) {
  counts[letter] = counts[letter] + 1
} else {
  counts[letter] = 1
}
```
