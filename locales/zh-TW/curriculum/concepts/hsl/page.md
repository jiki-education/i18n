HSL 讓我們可以用一種跟 RGB 完全不同的方式來思考顏色。HSL 這三個字母分別代表色相（英文：_hue (H)_）、飽和度（英文：_saturation (S)_）和明度（英文：_lightness (L)_）。我們有一個叫做`hsl`的函式，它接收三個數字，分別是色相、飽和度和明度，然後回傳一個顏色。那我們就來拆解一下這三個詞的意思吧。

```javascript
hsl(hue, saturation, lightness)
```

色相就是你想要的色調，範圍從 0 到 360。也許你可以想像一道彩虹，我自己就是這樣理解的。最左邊是紅色，接著是橘色、黃色、綠色、藍色、紫色，最後其實又繞回紅色。所以如果你寫 0，就是從最左邊開始，也就是紅色。如果你寫`120`，就是在要綠色。`230`是藍色。你也可以把它想成一個色輪，360 其實就是這個意思，它是圓一圈的度數。我自己每次都是直接查我想要的數字，所以不用太擔心記不記得住，不過知道背後在幹嘛也挺好的。這就是色相，也就是色調。接下來是飽和度，也就是顏色有多鮮豔，範圍從 0 到 100。0 的時候只會得到灰色，裡面完全沒有顏色，也沒有任何色調。100 的時候會得到飽滿、鮮豔、充滿活力的顏色。再來是明度。明度就是顏色有多亮，範圍同樣從 0 到 100。0 的時候會得到黑色。不管你選了哪個色相，結果都是黑色，因為裡面沒有光。而 100 的時候會得到白色。不管其他部分是什麼，只要充滿了光，就是白色。50 剛好位在中間，是一般的顏色。所以你可以把它想成一根滑桿，用來把顏色調亮或調暗。

所以如果我們想要一個普通的紅色圓形，用 RGB 的話會寫成 255、0、0，也就是全紅、沒有綠、沒有藍，而在這裡我們要用 0、100、50。0 是紅色色相，100 是飽和度，也就是全彩，50 是明度，代表一般的明亮程度。如果想把這個圓形變成綠色，只要把色相改成`120`就好。如果想讓它變成比較深的綠色，把明度調低到`25`就行。

```javascript
hsl(0, 100, 50) // 紅色
hsl(120, 100, 50) // 綠色
hsl(120, 100, 25) // 深綠色
```

如果想讓綠色黯淡一點，可以拿掉一些顏色、一些飽和度，比如把飽和度降到`30`。

如果你想要鮮豔的桃紅色，色相設在 300 左右就是粉紅色，接著把飽和度提高到 100，讓顏色更鮮豔，再把明度也拉高到 60 左右。

當你想讓顏色不斷循環變換時，HSL 就非常好用。想要彩虹的話，只要一直增加色相就行了。
