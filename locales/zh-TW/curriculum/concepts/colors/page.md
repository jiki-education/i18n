如果你曾經用程式碼做任何視覺相關的東西（就算你想當資料科學家、覺得畫圖這些東西有點無聊，用視覺來傳達資料也是一項關鍵技能），表達顏色有兩種不同的方式。你已經用過像 red 或 yellow 這樣用名稱指定的顏色，把它們當成繪圖函式的最後一個輸入，這確實是快速使用顏色的好方法，但限制也不少。我們能用的具名顏色只有少少幾種。所以現在我們要來看兩種方式，它們可以表達任何你想要的顏色，分別叫做 RGB 和 HSL。

RGB 讓我們把顏色想成紅色、綠色和藍色的混合。這就是 RGB 代表的意思：紅色（英文：_red (R)_）、綠色（英文：_green (G)_）、藍色（英文：_blue (B)_）。如果你記得在學校調顏料，概念很類似，只是我們混合的不是顏料，而是光。

在很多練習裡，你會用到一個叫做`rgb`的函式，它會接收三個數字當作輸入，一個代表紅色、一個代表綠色、一個代表藍色，然後回傳一個顏色。

你可以用的輸入數字範圍從 0 到`255`。0 代表我不想要這個顏色，而`255`代表盡可能混入最多的這個顏色。所以如果我們用`rgb`函式，輸入`255`、0 和 0，意思就是我要全部的紅色。記住，`255`是你最多能放進去的數字。但我們不要任何綠色或藍色，所以那兩個都是 0。這樣我們就會得到紅色，我們可以把它存進一個變數，然後像之前用具名字串那樣，在`circle`函式裡使用它。那如果我們用`rgb`函式，輸入 0、`255`、0 呢？意思就是不要紅色、全部綠色、不要藍色。這樣我們就會得到一個綠色的圓。那如果我們想要黃色呢？黃色是紅色和綠色的混合。所以我們可以說：給我全部的紅色、全部的綠色，不要藍色，這樣就會得到黃色。我們也可以用更小的數字。如果我們想要一些紅色、不要綠色、很多藍色，就會得到紫色。很多紅色、一點綠色、再多一點藍色，就會得到粉紅色。這就是 RGB。我們混合紅、綠、藍，得到不同的組合。

```javascript
let red = rgb(255, 0, 0)
let green = rgb(0, 255, 0)

```

現在來看 HSL，它給我們一種完全不同的思考顏色的方式。HSL 代表色相（英文：_hue (H)_）、飽和度（英文：_saturation (S)_）和亮度（英文：_lightness (L)_）。和 RGB 類似，你會有一個叫做`hsl`的函式，它接收三個數字，一個是色相、一個是飽和度、一個是亮度，然後回傳一個顏色。我們來拆解一下這三個詞的意思。

色相就是你要的色調（英文：_shade_），範圍從 0 到 360。你可以想像一道彩虹，我自己就是這樣理解的。最左邊是紅色，接著是橘色、黃色、綠色、藍色、紫色，最後其實又繞回紅色。所以如果你說 0，就是從最左邊開始，那是紅色。如果你說`120`，就是綠色。`230`是藍色。你也可以把它想成一個色環（英文：_color wheel_），360 其實就是這個意思。它代表圓一圈的度數。我自己每次想用什麼數字也都是直接查一下，所以不用太擔心要把它背起來，不過知道這是怎麼回事還是挺不錯的。這就是色相，也就是色調。接下來是飽和度，代表顏色有多鮮豔，範圍從 0 到 100。0 的時候只會得到灰色，裡面完全沒有顏色、沒有任何彩度。100 的時候會得到飽滿、鮮豔、生動的顏色。接著是亮度。亮度代表顏色有多亮，範圍同樣從 0 到 100。0 的時候會得到黑色，不管你選了什麼色相，結果都是黑色，因為裡面沒有光。100 的時候會得到白色，不管其他條件是什麼，它就是充滿光，所以是白色。50 正好在中間，也就是一般的顏色。所以你可以把它想成一個滑桿（英文：_slider_），用來把顏色調亮或調暗。

所以如果我們想要一個普通的紅色圓，用 RGB 的話會寫成 255、0、0，也就是全部的紅色、沒有綠色、沒有藍色；在這裡我們會用 0、100、50。色相 0 代表紅色，飽和度 100 代表完整色彩，亮度 50 則是一般的亮度。如果想讓它變成綠色的圓，只要把色相改成`120`就好。如果想讓它變成更深的綠色，可以把亮度降到`25`。

如果想讓綠色看起來更黯淡，可以抽掉一些色彩、一些飽和度，比如把它降到`30`。

如果你想要明亮搶眼的桃紅色，色相大約 300 就是粉紅色，接著把飽和度提高到 100，讓它真正鮮豔，再把亮度也提升到 60 左右。

```javascript
let red = hsl(0, 100, 50)
let green = hsl(120, 100, 50)
let darkGreen = hsl(120, 100, 25)
let dullGreen = hsl(120, 30, 50)
let hotPink = hsl(300, 100, 60)
```

所以我們有兩種表達顏色的方式，它們在不同的情況下都很好用。當你想調整某個特定的成分，像是多少紅色、多少綠色、多少藍色，RGB 就很好用。當你想讓顏色循環變化時，HSL 就很好用。如果你想要一道彩虹，只要不斷增加色相就可以了。
