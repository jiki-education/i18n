我們程式裡的每個值都有型別。`"7"`是字串，`7`是數字。它們看起來幾乎一模一樣，但 Jiki 對待它們的方式完全不同。你不能把字串`"7"`和數字`3`相加，還期待得到`10`，因為其中一個是一段文字，另一個是一個數量。

我們常常需要把一個值從某種型別搬到另一種型別。這叫做型別轉換（英文：_type conversion_），其中有兩種轉換你會經常用到。

### 把字串轉成數字

當你從字串裡讀出字元時，每個字元本身其實都是字串，即使它看起來像數字也一樣。在你能對它做任何算術運算之前，得先把它變成真正的數字。我們用`Number()`來做這件事。

```javascript
Number("7")
// 7

Number("42")
// 42
```

一旦你手上是真正的數字，就可以把它相加、相乘，做各種運算。

```javascript
let digit = Number("7")
let doubled = digit * 2
// 14
```

如果你交給`Number()`的東西不是有效的數字，例如`Number("cat")`，那你根本不會拿回數字，所以最好確認你只給它真的由數字組成的字串。

### 把數字轉成字串

反過來也一樣好用。有時候你手上有一個數字，卻想把它當成文字來看待，也許是要接到另一個字串後面，也許是想看看它的每一位數字。我們用`String()`來做這件事，它是`Number()`的鏡像。

```javascript
String(42)
// "42"

let count = 7
String(count)
// "7"
```

現在它是字串了，你就可以對它使用所有常用的字串工具，例如一個字元一個字元地讀取，或是檢查它的長度。
