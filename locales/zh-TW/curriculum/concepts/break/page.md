`break`關鍵字可以用在任何迴圈主體裡的任何地方。

大括號之間的那部分，就是主體。當 Jiki 看到它時，就會立刻跳出迴圈，繼續執行迴圈下方的程式碼。

所以，如果有一項限制說這個迴圈要跑 50 次，但使用者射擊 5 次後我們就想停下來，我們可以在最上面放一個`for`迴圈，讓它一路往上數到 50。

然後我們可以在迴圈中間放一個條件，檢查使用者是不是已經射擊 5 次；如果已經 5 次了，就用`break`（中斷）把迴圈停下來。

```javascript
for (let i = 0; i < 50; i++) {
  if (numShots >= 5) {
    break; // 跳出迴圈
  }
}
```
