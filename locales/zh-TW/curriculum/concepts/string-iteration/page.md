你可以用方括號取得字串裡的單一字母。接下來，我們來看看怎麼走過整個字串，把每個字母一個一個拿出來。

要做到這件事，我們需要一種新的迴圈。到目前為止，我們用的是 repeat 迴圈，現在我們要用的是另一種迴圈，叫做`for of`（逐一走過集合裡的每個元素）。這是兩個新的關鍵字：`for`和`of`。

`for`這個關鍵字，接下來我們還會在很多地方看到。它可以單獨出現，也可以跟`in`或`of`搭配。現在我們先專注在最後那個`of`。

我們來看一段程式碼吧。

我們先建立一個叫做`name`（名字）的變數，裡面放的是`"Jeremy"`（一個名字）這個字串。這裡沒有什麼新東西。

接著是迴圈那一行，這一行做了不少事，所以我們慢慢來講。

```javascript
let name = "Jeremy"
for (let letter of name) {
  // ...
}
```

首先，是`for`這個關鍵字。它在告訴 Jiki，我們想要做迴圈。所以 Jiki 會往後看，看到`of`，就知道我們想做的是「for of」迴圈。

意思是，我們不是用 repeat 迴圈說「重複跑 10 次」，而是說「把字串裡的所有字母都走過一遍」。這就是「for of」的意思。

接著是`let letter`（宣告一個變數）這部分。這跟上面`let name`做的事情一模一樣，我們只是建立一個叫做`letter`的變數。

差別在於，我們沒有明講裡面要放什麼，而是告訴 Jiki，把字串裡的每個字母一個一個放進去。

所以 Jiki 看到`for`，確認一下有沒有`of`，然後就開始了。他看字串裡的第一個字母，在這裡是`"J"`，把它放進一個叫做`letter`的新盒子。順帶一提，這個名字想叫什麼都可以，不一定要叫`letter`，我們只是在這裡決定叫它`letter`。

接著他會執行大括號裡的程式碼。你在這裡能做的事，跟在程式碼其他任何地方能做的事一模一樣。唯一的差別是，這段程式碼會針對字串裡的每個字母各執行一次，而且它可以取用這個變數。

每次 Jiki 走到結尾的大括號，就會把`letter`這個盒子丟掉，換一個新的，裝進下一個字母。所以第一次，他會把`"J"`丟掉，改放一個`"e"`進盒子。接著`"r"`、`"e"`、`"m"`、`"y"`也一樣。六個字母，迴圈跑六次。這種語法需要一點時間習慣，但概念其實不難。
