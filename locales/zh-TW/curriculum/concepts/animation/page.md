到目前為止，當我們用`repeat`（重複）迴圈畫東西時，我們每畫一個新東西，都只是在畫面上多加了點什麼。如果我們在牆上畫了一塊新磚，它就補上了一個缺口。如果我們畫了 10 個圓圈，螢幕上就會看到 10 個圓圈。這就像畫圖一樣。顏料一旦塗到牆上，不會因為你在旁邊畫了別的東西就消失，它會一直留在那裡。但如果我們想讓某個東西看起來像在移動呢？

你看過翻頁書嗎？我小時候這種書很流行，現在比較少了。翻頁書是一本小書，每一頁的圖都有一點點不同。當你快速翻動書頁時，眼睛會看到圖在變化，大腦就會以為有東西在動。它其實沒有在動，只是很多張稍微不同的圖畫，一張接著一張。程式裡的動畫正是同樣的原理，訣竅完全一樣：在畫新的場景之前，我們先用背景色把整塊畫布塗掉，有點像翻頁書翻到全新的一頁，然後再對場景做一點小改變，讓它看起來像在移動。

所以，如果我們拿一段熟悉的程式，在螢幕上畫圓圈，設定一個`position`（位置）變數，還有一個`repeat`區塊，每次畫一個圓圈，然後把`position`往右移 1。如果我們把那個`repeat`區塊執行 100 次，就會在螢幕上看到 100 個圓圈。

```javascript
let position = 0
repeat(100) {
  circle(position, 50, 5, "blue")
  position = position + 1
}
```

現在看看，如果我們只是在每次畫圓圈之前，先加上一個普通的長方形，會發生什麼事。

```javascript
let position = 0
repeat(100) {
  rectangle(0, 0, 100, 100, "white")
  circle(position, 50, 5, "blue")
  position = position + 1
}
```

現在不再是一串圓圈了，我們的眼睛會被騙過去，看到一個圓圈像是滑過整個螢幕。

每次跑迴圈，我們都塗上一整片全新的背景，蓋掉之前所有的東西，然後把圓圈畫在新的位置。

迴圈每跑一輪，就像翻頁書裡新的一頁。

這裡最關鍵的是：我們並沒有在移動那個圓圈。圓圈不是一個會滑過去的物件，它只是一張圖。每次跑迴圈，我們都蓋掉舊的圖，再畫一張全新的、稍微偏右的圖。你的眼睛把這些圖拼在一起，就看見了移動，但實際上，那只是一張又一張分開的圖畫。

你可以用這個概念做出夕陽。讓太陽移動、改變它的大小、改變它的顏色，用的都是同一套技巧：設定幾個變數，塗上全新的背景，畫上所有東西。更新變數，然後再重複一次。
