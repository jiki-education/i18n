假設我們想要種出一排花。我們可以這樣寫。我們先設定一個位置，種下一朵花，把位置增加 10，然後重複這個過程，最後就會得到一整排整整齊齊的花。

```javascript
let x = 10
repeat(5) {
  plant(x, 50, 10)
  x = x + 10
}
```

我們現在有一個能畫出一排花的迴圈。要怎麼用它畫出四排呢？或者說，我們可以做什麼來畫出四排？

一種做法是直接把那個迴圈複製貼上四次，然後分別修改每一段最上方的位置。這樣確實可行，也沒什麼問題。但這樣很重複，而且有更好的做法。我們都知道，當程式碼出現重複，就可以用迴圈來簡化。

所以在這裡，我們可以把一個迴圈放進另一個迴圈裡。一個迴圈負責每一排，另一個負責那一排上的花。那我們先在原本的程式碼外面加一層 repeat 迴圈，讓你實際感受一下。而且我們先只重複一次。也就是告訴 Jiki，把外層大括號裡的所有事情做一次。所以這跟完全沒有這層外層迴圈的效果一模一樣。叫 Jiki 把某件事重複一次，就等於叫他在不用 repeat 的情況下做一次。不過這段程式碼就是這樣運作的。它是正當、有效的程式碼。我們把一個迴圈放進了另一個迴圈裡。

那現在把外層迴圈改成重複兩次會怎樣呢？這樣一來，Jiki 就會把「`plant`五次」這整件事執行兩遍。他會種下 10 朵花。但這些花全都會在同一排上。

同樣地，我們每一次都要把位置往右移一點。畫完一整排之後，我們也同樣要把垂直的位置往下移。那要怎麼做呢？我們可以在外層多加一個變數來記錄上方位置，在`plant`函式裡使用它，然後每畫完一排就把它增加 10。

想一想每個當下這個值是多少。上方位置一開始是 10。在我們種下前五朵花的時候，它都維持不變，而左邊的位置則持續增加。接著我們把上方位置再加上 10，然後在低一點的地方再種下五朵花。我們把左邊的位置重新設回 10，然後再讓它一次次增加。

現在我們可以說「重複四次」，就會得到四排、每排五株的花喔。

```javascript
let y = 10
repeat(4) {
  let x = 10
  repeat(5) {
    plant(x, y, 10)
    x = x + 10
  }
  y = y + 10
}
```

最關鍵的一點是，Jiki 一定要先把內層迴圈（英文：_inner loop_）裡的所有工作做完，才會回到外層迴圈（英文：_outer loop_）。他不會在兩者之間來回跳。他會把內層迴圈完整跑完，然後才前進到外層迴圈的下一個步驟。

在這種情況下，你可以把外層迴圈想成是在控制每個群組，也就是每一排。內層迴圈則是在控制那個群組裡的每一個項目，也就是那一排裡的每一朵花。所以在我們的例子裡，外層迴圈做出四排，內層迴圈則在每個群組裡放入五株植物、五個項目。
