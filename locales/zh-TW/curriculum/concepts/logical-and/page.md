如果我請你只在對方超過 20 歲時才開門，你大概知道該怎麼做。但如果還要確認對方超過 20 歲，*而且*穿著正確的服裝呢？也就是說，你得同時檢查兩個不同的條件。你會怎麼做呢？

也許你可以用一個巢狀（英文：_nested_）的條件式，有點像我們之前用過的巢狀迴圈。你可以這樣寫：如果`age`大於`20`，就進入這個程式區塊，接著再一個`if`，判斷`outfit`是否等於`"disco"`，再來一個大括號和一個新的程式區塊。這樣行得通，但會變得很亂，尤其是當你想放進很多條件的時候。

還好，有更簡單的做法，就是讓條件可以包含多個部分。條件裡不只能檢查一件事，我們可以檢查兩件、三件，甚至更多。要做到這件事，我們得用`and`這個關鍵字。可惜的是，在 JavaScript 裡，這個關鍵字其實不是寫成 and，有些語言才是那樣。你得改成把兩個「&」符號（英文：_ampersands_）並排放在一起。這個只能靠你自己記住。很煩，但就是這樣，用久了你就習慣了喔。

我們可以用它寫出更複雜的條件。我們可以這樣寫：如果`age`大於`20`，而且`outfit`是`"disco"`，就繼續下去。如果`age`小於`20`，或者`outfit`不是`"disco"`，那整個敘述、整個條件就是`false`。如果你學過邏輯，也許是玩過電子電路，或學過比較進階的數學，那你會覺得這很自然。如果沒有，你很快就能上手。

```javascript
if (age > 20 && outfit === "disco") {
  openDoor()
}
```

不管是`and`還是`or`，都有一個地方容易讓人卡住：`and`／`or`（和／或）的每一邊都必須是完整的比較。所以，即使兩邊比較的是同一個變數，還是得把它重複寫一次。你不能寫`if age is greater than 13 and less than 20`，要寫`if age is greater than 13 and age is less than 20`。兩邊都必須是完整的比較。

```javascript
if (age > 13 && age < 20)
```
