我們可以用一種叫做模板字面量（英文：_template literals_）的東西，把字串放進另一個字串裡。

所以，不一定要把字串一個一個接起來。我們可以準備一個字串，也就是模板，在裡面預留空位，把其他字串放進去。

要做到這件事，我們要用的不是引號，而是反引號（英文：_backticks_）。

顧名思義，反引號就是往後傾的撇號，不過你以前可能完全沒用過它，所以得先在鍵盤上找到對應的按鍵。

我們用反引號做出一個可以容納其他字串的模板。接著，要把字串放進模板裡，就得用上另一種看起來有點古怪的語法：錢字號加上大括號。舉例來說，要做出跟剛才串接一樣的`"hello " + name`效果，我們可以這樣寫：

```javascript
`hello ${name}` // "hello Jeremy" 或 "hello Jiki"
```

這跟把字串加在一起，做的完全是同一件事。

但如果你有很多字串都要拼進同一個地方，這種做法就有效率得多。

這個語法你可能要花一點時間才會習慣，不過它其實並沒有那麼複雜喔。
