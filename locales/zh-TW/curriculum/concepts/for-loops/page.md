你可能還記得，JavaScript 裡其實並沒有 repeat 迴圈。這只是為了讓你在剛開始學習時輕鬆一點，而特別加入的功能喔。

那麼，我們實際上該用什麼呢？我們會使用一般的`for`迴圈，它看起來像這樣：

```javascript
for (let i = 0; i < 5; i++) {
  // ...
}
```

你可以想像，如果第一天就看到這個，可能會覺得有點嚇人吧。

不過，你現在已經具備了所有需要的知識，絕對能輕鬆掌握它。我們來把它拆解開來看看吧！

一個`for`迴圈包含三個部分：初始值設定（英文：_initializer_）、條件，以及遞增（英文：_increment_）。

初始值設定就是`let i = 0`這個部分，它會在整個迴圈開始時執行。它只會執行一次，而在這裡，它建立了一個名為`i`（索引）的盒子，並將它的值設定為 0。`i`只是一個用來在迴圈執行時追蹤值的字母，傳統上我們通常會使用`i`或`x`來做這件事。

接下來的部分是條件，它會在每次迴圈疊代之前執行。

如果條件為 true，我們就會再次執行迴圈。

如果不是，我們就不執行。

最後則是遞增，也就是`i++`。

`i++`的意思就等於`i = i + 1`。這只是一種簡寫，代表每次都把`i`增加 1。

所以在這個例子中，我們會把`i`設定為 0。接著檢查`i`是否小於 2，結果是小於 2，所以我們執行迴圈。

然後在最後，我們把`i`增加 1，所以`i`變成了 1。0 加 1 等於 1。

接著我們再來一次。我們檢查 1 是否小於 2。

沒錯，所以我們執行迴圈。然後在最後，我們再次把`i`增加 1。所以現在它變成了 2，1 加 1 等於 2。

```javascript
i = 0
i < 2 // true - 執行迴圈
...   // 執行疊代
i = i + 1 // 1

i < 2 // true - 執行迴圈
...   // 執行疊代
i = i + 1 // 2

i < 2 // false - 離開迴圈
```

然後我們進行第三次。這次我們檢查 2 是否小於 2，結果不是，所以我們不執行迴圈，事實上，我們的迴圈已經結束了。我們只需繼續執行下方的任何程式碼即可。所以我們總共執行了兩次迴圈，這是一個很實用的觀念喔。只要我們從 0 開始，並且條件是`i < n`，數字`n`就是迴圈會執行的次數。

所以這就跟寫 repeat 2 是一樣的意思。

所以這並不難，只是比單純寫 repeat 2 要來得複雜許多。`for`迴圈的優勢在於，你可以在那三個位置裡做任何事情。你可以從不同的數字開始、每次增加超過 1、倒數遞減，或是使用不只依賴簡單計數器的條件。正是這種彈性，讓`for`迴圈成為了 JavaScript 的主力喔。
