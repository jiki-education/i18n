## 簡介

當你開始在自己的電腦上寫程式時，你需要一個地方來寫。那個「地方」就是程式碼編輯器。它會是你最先拿起的工具之一，也是你往後職涯中會花上大量時間的地方。隨著時間過去，你很可能會不斷更換、嘗試新的編輯器，所以值得先搞懂它是什麼，以及一開始該怎麼挑一款好用的。

## 程式碼編輯器不是文書處理軟體

很容易以為，任何能讓你打字的程式都可以勝任。最常見的錯誤，就是拿 Microsoft Word 或 Google Docs 這類文書處理軟體來寫程式。它們是為了讓人閱讀的文件而打造的，所以會悄悄改動你打出來的內容。它們會把直引號變成彎曲的「智慧」引號、自動修正你的用字，還會儲存隱藏的格式。這些都會把程式碼弄壞。

程式碼編輯器是文字編輯器的一種。它處理純文字，從不加入隱藏的格式，所以你打出來的內容，就是電腦看到的內容。差別在於，程式碼編輯器是專門為程式碼打造的文字編輯器。除了處理純文字，它還看得懂你正在寫的內容的結構，並提供文書處理軟體永遠做不到的協助：

- **語法突顯**會為程式碼的不同部分上色，讓你更容易閱讀，也更容易看出錯誤。
- **自動縮排**會讓你的程式碼整齊對齊，這在許多程式語言裡非常重要。
- **錯誤提示**會指出問題，而且常常在你執行程式之前就先提醒你。
- **自動完成**會建議你接下來要打的內容，讓你寫得更快、打錯字更少。
- **擴充功能**讓你能隨著學習成長，加入對新語言與新工具的支援。

## 我們推薦的編輯器

好的程式碼編輯器很多，在這裡你怎麼選都不會錯。話雖如此，我們推薦 **Visual Studio Code**，通常簡稱 VS Code。它免費、能在 Windows、macOS 和 Linux 上執行、對初學者很友善，而且是全世界最廣為使用的編輯器之一，所以你找到的教學幾乎都會假設你用的是它。

準備好要安裝時，請跟著我們的[安裝 VS Code](/guides/installing-vscode)指南操作。

## 你可能聽過的其他編輯器

跟著 Jiki 學習並不需要用到這些編輯器，但你之後一定會遇到它們，所以這裡快速介紹幾個常見的：

- <a href="https://code.visualstudio.com" target="_blank" rel="noopener noreferrer">Visual Studio Code（VS Code）</a>是我們推薦的免費、跨平台編輯器。
- <a href="https://www.sublimetext.com" target="_blank" rel="noopener noreferrer">Sublime Text</a> 是輕巧快速的編輯器，多年來一直很受歡迎。
- <a href="https://zed.dev" target="_blank" rel="noopener noreferrer">Zed</a> 是比較新的編輯器，速度非常快，主打速度與協作。
- <a href="https://www.jetbrains.com/ides/" target="_blank" rel="noopener noreferrer">JetBrains IDEs</a>（例如 <a href="https://www.jetbrains.com/pycharm/" target="_blank" rel="noopener noreferrer">PyCharm</a> 和 <a href="https://www.jetbrains.com/idea/" target="_blank" rel="noopener noreferrer">IntelliJ IDEA</a>）是功能強大、也比較笨重的工具，針對的是開發大型專案的專業開發者。
- <a href="https://www.vim.org" target="_blank" rel="noopener noreferrer">Vim</a> 和 <a href="https://neovim.io" target="_blank" rel="noopener noreferrer">Neovim</a> 是以鍵盤操作、活在終端機裡的編輯器。它們深受經驗豐富的開發者喜愛，但學習曲線很陡。

學習期間，我們的建議很簡單：從 VS Code 開始，把寫程式寫到順手，等你清楚自己喜歡什麼之後，再去探索其他編輯器吧。
