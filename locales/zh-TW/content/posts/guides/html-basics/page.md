## 簡介

在這份指南裡，我想稍微聊聊網頁到底是什麼，以及它是怎麼運作的。我們只會談最基礎的東西。如果你已經懂一些 HTML，這份指南對你來說大概會非常基礎。如果你完全不懂，那它會是接下來所有內容的絕佳入門。

## 網頁到底是什麼

網頁其實就是一個文字檔。當你造訪一個網站時，瀏覽器會收到一個 HTML 檔案，它會讀取這個檔案並把它描繪出來，變成你眼前看到的頁面。

你現在就可以自己驗證這件事。隨便打開一個網站，在頁面上任何地方按右鍵，然後選擇**檢視網頁原始碼**（View Page Source）。那就是 HTML。在大型網站上，它看起來會很嚇人、密密麻麻一大堆，但這全部都是由我們下面要看的少數幾個積木搭建而成的。

HTML 是**超文本標記語言**（HyperText Markup Language）的縮寫。「Markup」的意思就是，我們拿一段文字，在上面加上標記，補上額外的資訊，說明每一部分是什麼。瀏覽器，不管是 Chrome 還是其他任何一種，都會讀取這些標記，並用它們來決定該怎麼把每樣東西放上螢幕。

## 標籤

HTML 最有名的就是**標籤**，開頭是 `<`，結尾是 `>`。在這對尖括號之間，是這個標籤所指的東西。接著是一些內容，最後是結束標籤，它和開始標籤一樣，只是多了一個斜線。

來看個例子：

```html
<p>Hello there.</p>
```

`p`代表 paragraph（段落）。這樣寫，就是在告訴瀏覽器：我們希望它在螢幕上呈現一個段落，而這個段落裡的文字是「Hello there.」。

標籤也可以帶有一些額外的資訊，稱為**屬性**，它們放在開始標籤裡面。連結就是個很好的例子：

```html
<a href="https://jiki.io">Visit Jiki</a>
```

要建立連結，我們使用 `a`標籤（它代表 anchor（錨點），出於一些[有點奇怪的歷史原因](https://thehistoryoftheweb.com/brief-history-hypertext/)）。連結通常會有一個 `href`屬性，說明這個連結連到哪裡，而標籤之間的文字就是你點擊的部分。

有些標籤不包住任何內容，所以沒有結束標籤。圖片就是最典型的例子：

```html
<img src="photo.jpg" alt="A photo of me on a mountain" />
```

`img`代表 image（圖片）。`src`屬性指向圖片檔案，`alt`屬性則是為使用螢幕閱讀器的人描述這張圖片。如果圖片載入失敗，顯示出來的也是這段文字。

## 頁面的構造

每一個網頁都有同樣的骨架，同樣的骨頭。下面是你所能做出、最精簡的**合法**頁面（你可以用更少的 HTML 做出不合法、瀏覽器卻照樣會呈現的頁面，不過我們就從一開始當個負責任的開發者吧，之後也一直這樣下去！）：

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Jeremy Walker</title>
  </head>
  <body>
    <h1>Jeremy Walker</h1>
    <p>I build things on the web.</p>
  </body>
</html>
```

我們從最上面開始讀。

`<!doctype html>`這一行告訴瀏覽器，這是一份現代 HTML 文件。這是必要的固定樣板。在檔案最上面寫一次，然後就可以忘了它。

`html`標籤是包住整份文件的根元素。`lang="en"`屬性告訴瀏覽器和搜尋引擎，這個頁面是用英文寫的。

在它裡面有兩個部分：**head** 和 **body**。

### head

head 是所有**不會**出現在螢幕上的東西。它是中繼資料，而中繼資料指的就是關於這個頁面的資料，而不是你看到的內容。在我們的範例裡，它裡面有兩樣東西：

- `<meta charset="UTF-8" />`說明這個頁面使用哪一組字元集。UTF-8 是標準字元集，幾乎涵蓋所有東西：拉丁字母、帶重音的字元、其他字母系統，甚至 emoji。如果你把 emoji 貼進 HTML 裡，就是這一行讓它能正常顯示。永遠要記得加上它。
- `<title>`設定顯示在瀏覽器分頁最上方的那段文字。搜尋引擎也會把它當作你頁面的標題。寫程式的時候，你會發現自己常常在想一件事：當別人的瀏覽器開了 20 個分頁時，你希望那上面顯示什麼。

你經常會在 head 裡看到另一行，這一行值得認識一下：

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

這一行告訴手機，用合理的大小顯示頁面，而不是把它縮到最小。目前這樣就夠了，不需要再為它多操心。加上它，然後繼續往下就好。

### body

body 就是你實際看到的一切，也就是分頁和網址列下方那塊大方框裡的所有東西。每一個標題、段落、圖片和連結都住在 body 裡面。這份指南接下來要講的，就是放進 body 裡的那些標籤。

## index.html

在進入標籤之前，還有一件事值得知道。長久以來有個慣例：叫做`index.html`的檔案就是網站的首頁。如果你只輸入一個網域、後面什麼都不加，網站就會去看看有沒有`index.html`這個檔案；如果有，就直接把它的內容顯示給你。這個檔案本身沒有任何神奇之處。它只是幾乎每個網站都遵守的標準，所以你的首頁就應該放在這個名字的檔案裡。

## 你會最先用到的標籤

用不到 10 個標籤，你就能做出一個真正有用的頁面。我們來看看這些標籤，大致按照你會用到的順序來介紹。

### 標題

標題分成六個層級，從 `h1` 到 `h6`：

```html
<h1>Jeremy Walker</h1>
<h2>About me</h2>
<h3>My photography</h3>
```

`h1`是頁面的主標題，通常只應該有一個。用 `h2`標示章節標題，用 `h3`標示章節裡的小節，依此類推。因為 `h1`是第一層標題，瀏覽器就知道要把它弄得大一點、粗一點。

選擇標題層級時，要看的是意義，不是大小。它們會給你的頁面一個大綱，有點像書裡的章和節。

### 段落

`p`標籤標示一段文字，幾乎所有頁面上的文字都住在段落裡面：

```html
<p>I have been building things on the web for thirty years.</p>
<p>These days I spend most of my time working on Jiki.</p>
```

每一個段落都有自己的標籤，瀏覽器會自動在段落之間加上間距。

### 清單

清單有兩種。**無序清單**（`ul`）會給你項目符號，**有序清單**（`ol`）會給你編號。不管哪一種，裡面的每一個項目都是**清單項目**（`li`）：

```html
<ul>
  <li>Photography</li>
  <li>Podcasting</li>
  <li>Teaching people to code</li>
</ul>
```

把 `ul`換成 `ol`，項目符號就會變成 1、2、3。

### 連結

連結就是讓網路變成一張網的東西。`a`標籤能把任何東西變成可以點擊的內容：

```html
<p>You can find my code on <a href="https://github.com/ihid">GitHub</a>.</p>
```

連結可以指向其他網站，也可以指向你自己網站上的其他頁面。如果你的 `index.html`旁邊有一個 `resume.html`，你就可以用 `<a href="resume.html">My resume</a>`連到它。

### 圖片

`img`標籤會在頁面上放一張圖片：

```html
<img src="images/me.jpg" alt="Jeremy standing on a hill in the Lake District" />
```

`src`可以是你自己網站上的檔案，也可以是一個完整的網址。`alt`文字一定要填上真正描述這張圖片的內容。

### 強調

有兩個小標籤可以讓你在文字裡強調某些詞。`strong`標示某件事很重要，瀏覽器會用粗體顯示。`em`標示語氣上的強調，瀏覽器會用斜體顯示：

```html
<p>The struggle is where the <strong>learning</strong> happens, so <em>write your own solutions</em>.</p>
```

## 給頁面一個結構

到目前為止看過的標籤，描述的都是個別的內容。還有另一類標籤，描述的是頁面上的各個區域。這些通常被稱為**語意標籤**，因為它們為每個區域賦予意義，而不是改變任何東西的外觀：

- `header`包住頁面最上方的區域，通常是你的網站名稱和標誌。
- `nav`包住你的導覽，也就是連到網站上其他頁面的那組連結。
- `main`包住頁面的主要內容。只應該有一個。
- `section`把一塊獨立的內容群組起來，通常有它自己的標題。
- `article`包住一篇獨立的內容，例如一篇部落格文章或一則新聞。
- `footer`包住頁面最下方的區域，通常是版權和聯絡連結。

用這些標籤寫成的個人首頁，可能會長這樣：

```html
<body>
  <header>
    <h1>Jeremy Walker</h1>
    <nav>
      <a href="index.html">Home</a>
      <a href="resume.html">Resume</a>
      <a href="portfolio.html">Portfolio</a>
    </nav>
  </header>
  <main>
    <section>
      <h2>About me</h2>
      <p>...</p>
    </section>
    <section>
      <h2>My projects</h2>
      <p>...</p>
    </section>
  </main>
  <footer>
    <p>Get in touch at jeremy@example.com.</p>
  </footer>
</body>
```

這些標籤本身都不太會改變頁面的外觀。那為什麼還要用它們？因為帶有意義的結構，能幫助所有閱讀你頁面的東西，而不只是盯著螢幕看的人類。螢幕閱讀器用這些標籤，讓視障使用者能直接跳到導覽或主要內容。搜尋引擎用它們來了解你的頁面在講什麼。而且之後要為頁面加上樣式時，把它整理好會讓一切輕鬆很多。

如果頁面上的某個部分不屬於上述任何一種，還有兩個通用的容器：`div`用來裝一整塊內容，`span`用來裝文字中的幾個詞。它們本身不帶任何意義，這正是為什麼你應該先選用那些有意義的標籤。

## 其他值得認識的標籤

你不需要背這些標籤，但當你在看別人寫的頁面時一定會遇到，所以知道它們存在是值得的：

- `blockquote`用來標示引自別處的引文。
- `code`用來標示文字中的一小段程式碼，`pre`用來標示一整塊預先格式化好的文字。
- `table`，用 `tr`表示每一列、`td`表示每一格，用在真正屬於表格的資料上。
- `form`、`input`、`label` 和 `button` 用來向訪客收集輸入。
- `video` 和 `audio` 用來嵌入媒體內容。
- `br`用來在文字中換行。少用它。如果你想要一個新段落，就用一個新的 `p`。

標籤總共有一百多個，但這份指南裡介紹的，已經涵蓋了你會看到和寫出的絕大多數。當你遇到不認識的標籤時，就去 [MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element) 查，那是專業人士使用的參考資料。

## 接下來該往哪裡走

要讓這些東西真正記住，最好的方法就是動手做點東西。建立一個 `index.html`，套用這份指南裡的骨架，然後用標題、段落、清單和連結，做出一頁關於你自己的介紹。接著在瀏覽器裡打開它，看看你做出了什麼。

等你熟悉之後，養成查看造訪過的網站原始碼的習慣。你會開始到處認出這些標籤，也會發現即使是最精緻的網站，都是由你剛剛學會的同樣那些零件組成的。

你的頁面現在看起來會非常樸素，這沒關係。HTML 給頁面結構。讓它好看則是 CSS 的工作，那也是我們接下來要前進的方向。
