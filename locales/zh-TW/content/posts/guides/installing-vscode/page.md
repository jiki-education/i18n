## 簡介

Visual Studio Code（VS Code）是 Microsoft 推出的免費程式碼編輯器，可以在 Windows、macOS 和 Linux 上執行。這是我們推薦你在學寫程式時使用的編輯器。如果你還不確定什麼是程式碼編輯器，或不知道自己為什麼需要它，可以先讀我們的[使用程式碼編輯器](/guides/using-a-code-editor)指南。

這份指南會帶你一步一步在各個作業系統上安裝 VS Code。先在下面找到你的系統，再照著步驟做吧。這件事你只需要做一次。

## Windows

1. 用瀏覽器開啟 [code.visualstudio.com](https://code.visualstudio.com)。
2. 點擊**Download for Windows**（下載 Windows 版）按鈕。這會下載官方安裝程式（一個 `.exe` 檔）。
3. 下載完成後，開啟這個檔案來執行安裝程式。
4. 接受授權合約，然後一直點擊**Next**（下一步），沿用預設選項就好。我們建議把「將 VS Code 加入右鍵選單」的方塊保持勾選，之後會很方便。
5. 點擊**Install**（安裝），再點擊**Finish**（完成）。VS Code 準備好時就會自動開啟。

## macOS

1. 用瀏覽器開啟 [code.visualstudio.com](https://code.visualstudio.com)。
2. 點擊**Download for macOS**（下載 macOS 版）按鈕。這會下載一個內含應用程式的 `.zip` 檔。
3. 開啟你的**Downloads**資料夾，對下載好的檔案按兩下解壓縮。你會得到一個叫做**Visual Studio Code**的應用程式。
4. 把**Visual Studio Code**拖進你的**Applications**資料夾。
5. 開啟**Applications**資料夾，對**Visual Studio Code**按兩下啟動它。如果 macOS 問你是不是確定要開啟，點擊**Open**（開啟）。

## Linux

在 Linux 上安裝 VS Code，最可靠的方式是從 Microsoft 下載適合你發行版的官方套件。

1. 用瀏覽器開啟 [code.visualstudio.com](https://code.visualstudio.com)。
2. 點擊**Download for Linux**（下載 Linux 版），然後選擇符合你發行版的套件：
   - 如果系統是以 Debian 或 Ubuntu 為基礎，請選擇 **.deb** 套件。
   - 如果系統是以 Fedora、Red Hat 或 openSUSE 為基礎，請選擇 **.rpm** 套件。
3. 用系統的軟體安裝程式開啟下載的套件，然後點擊**Install**（安裝）；或者從終端機安裝：
   - 在 Debian 或 Ubuntu 上，在你下載檔案的資料夾裡執行`sudo apt install ./<file>.deb`。
   - 在 Fedora 或 Red Hat 上，在你下載檔案的資料夾裡執行`sudo dnf install ./<file>.rpm`。
4. 安裝好之後，從應用程式選單開啟 VS Code，或在終端機執行`code`。

## 開啟 VS Code

不管你是用哪種方式安裝的，現在只要想寫程式，隨時都可以開啟 VS Code。在 Windows 和 macOS 上，它會和其他應用程式一起出現。在 Linux 上，它會放在你的應用程式選單裡。

就是這麼簡單。你現在已經裝好一個正式的程式碼編輯器，可以開始寫程式了。
