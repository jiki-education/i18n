大家好！

過去兩年，我一直在打造**[Jiki](https://jiki.io)**，從一個想法開始，辦了一場訓練營來驗證我的想法，然後和 Aron 與 Nicole 一起把一個（我希望是超讚的）產品做了出來。

我想跟你說說這段旅程。Jiki 為什麼存在、我們為什麼投入時間和心力，以及我希望它會帶我們走向何方。

## 在 Jiki 之前，先有 Exercism

如果你還不知道，過去十年我一直在打造**[Exercism](https://exercism.org)**。Exercism 是一個幫助開發者精進技能、學習新程式語言的平台。這是一場規模龐大的協作，有數千人貢獻程式碼、數百位維護者打造各種語言的學習路徑，還有數千位導師支持其他開發者。數百萬人用它來提升自己的程式設計能力，而這也是我真心感到自豪的一件事。

但 Exercism 是為已經會寫程式的開發者設計的，**我們卻一直吸引到完全零基礎的初學者**。事實上，根據上次統計，**每天有超過 500 人**註冊 Exercism，而他們從來沒寫過一行程式碼。Exercism 對他們來說真的行不通，因為它本來就不是為他們打造的，所以我們只能請他們離開。

這實在很糟。

我經營 Exercism 的動力，始終是為了**社會流動**：幫助那些最需要幫助的人。我相信程式設計是一項幾乎每個人都該學會的核心技能。對某些人來說，它可以是一份職業；但對每個人而言，它教會你批判性思考和解決問題，並給你一套幾乎在任何數位工作中都用得上的本領。總之，我相信程式設計真的能改變人生，打開那些原本可能一直緊閉的門。所以看著這些初學者滿懷熱情地到來，卻得跟他們說「抱歉，這還不適合你」，讓我覺得自己很失敗。

我開始探索「學寫程式」這個領域，想了解市面上為他們準備了什麼。我和許多註冊的初學者聊過，也開始研究現有的各種資源。而當我試用那些資源時，我發現少了一樣東西。它們大多沒有觸及我心目中程式設計真正的核心：**有趣的問題解決**。

它們反而是給你一些影片看、一些測驗做，也許還有個小小的程式練習，最後發一張證書。它們教你語法和理論，卻沒有真正讓你**動手做出**東西。我認為這就是為什麼這麼多人放棄。不是寫程式太難，而是他們被教的方式，根本不像在寫程式。

所以我決定做些改變。

## Jiki 的成形之路

### 以我的經驗為基礎打造 Jiki

回想我是怎麼學會寫程式的，那不是靠課程或教學。我八歲就開始了，遠早於我接觸網際網路的年代。我是靠**做遊戲**學會的。我會把當時那個小孩腦子裡著迷的東西（有很多《星際爭霸戰》和巫師）變成某個隨手亂做的遊戲。後來長大一點，我為自己做網站和小工具，只要是我覺得有趣的都做。我沒有課程大綱。我就是一直做東西、卡住、想辦法解決，然後再做更多東西。

那段經歷塑造了我對學習的一切看法。我相信人是靠**寫程式**學會寫程式的，不是靠看別人寫、不是靠答選擇題、不是靠寫一行程式碼來「完成」一道練習，而是靠真正寫出完整的程式、解決問題。

這就是為什麼 Jiki **從第一天就以專案為核心**。你不會連續好幾個月都在做短短五行的練習。你是在打造東西，遊戲、動畫、工具，並在頭幾個月就寫出**數十行、接著數百行**程式碼。這很有挑戰性，但正是那種會讓你覺得自己真的在成為程式設計師的挑戰。

### 訓練營

2025 年一月，我為 1,000 位學生辦了一場訓練營。他們學的是一門我專門為這場訓練營寫的程式語言（叫做 JikiScript）。每週他們有大約 3 小時的直播教學，然後有一些練習要解，接著是一場 3 小時的「Labs」時段，我們會一起看練習、他們提問等等。

那是一段非常有趣的經歷，我從中學到很多。它同時也非常緊湊，因為我在寫一門程式語言、練習和單元，再加上每週 6 小時的直播和幾十小時的支援。非常感謝那些出手幫我的志工！！

最關鍵的是，我學到了一件事：我設計的步調實在太快了。我做出了一個自以為溫和又簡單的東西，結果對大家來說還是快得不得了、難得不得了。所以我把這個教訓帶進 Jiki，把步調放得更慢，加入更多步調更緩慢的練習。如果你覺得輕鬆，你會很快做完那些額外的練習；但如果你卡住了，它們（希望）會是救星！

### 移除那些自傷陷阱

我堅信，學習寫程式之所以會變得困難許多，是因為你同時還得學一門程式語言。這句話聽起來可能很怪，但請聽我說下去。

程式語言是為專業人士設計的。它們包含了許多「進階」功能，讓我們開發者能更快、更有效率地工作。它們往往也背著一堆歷史包袱（JavaScript 尤其是重災區），有些功能老早就該從語言裡拔掉了，卻為了相容舊有程式碼而必須留著。

這表示你在學習的過程中，會碰到一些要不是非常進階、要不就單純很詭異的東西。我們把這些叫做「自傷陷阱」（會讓你不小心打到自己腳的東西）。辦訓練營時，我決定寫一門沒有這些自傷陷阱的新語言（叫做 JikiScript）。不過我收到的一個回饋是：學了一門之後在真實世界用不到的語言，很讓人挫折。

所以對 Jiki 來說，我決定改用 JavaScript 或 Python 來教（課程大綱相同，語言由你選）。

但我把那些自傷陷阱拿掉了。

我為這兩種語言都寫了自訂的直譯器，把那些雜訊通通濾掉。在 JavaScript 裡，你不能再使用`var`。在你對一般函式真正上手之前，你不能使用箭頭函式。你不能寫出`[] + {}`還期待得到錯誤以外的結果。如果在這個學習階段，某件事是學習者很可能不小心做出來的，那它就會被關閉。而隨著你的進展，我們會開放更多功能和更多能力。這是一件**海量**的工作，但我認為它會帶來巨大的差別。

### 多語系（i18n）

另一項我知道必須加入的關鍵功能，是讓 Jiki 支援多種語言。

大多數人不會說英語。大多數程式設計資源都是英文的。對那些往往最沒錢花在資源上的人來說，這是一道巨大的障礙。這正是我很想解決的問題。

所以在打造 Jiki 時，我們讓所有東西都能以多種語言呈現：內容、練習、AI 助手和影片。我的計畫是 beta 版先以英文推出，然後每個月發布幾種新語言，直到今年底涵蓋全世界 95% 的人口。

### 免費增值（Freemium）

我最後必須做的決定是定價。

我百分之百確定我要讓 Jiki 免費。這整件事的重點就是幫助需要幫助的人。但我也從 Exercism 學到，當資金不足以支撐時，要經營一件事真的非常難（**感謝**每一位捐款給 Exercism 的人，是你們讓 Jiki 得以實現！！）。

所以我決定採用免費增值（Freemium）的模式。Jiki 的核心是免費的：影片和練習所有人都能使用。但還有一些不錯的額外功能（AI 支援、一些額外專案、直播、幕後內容等等），只要付一筆小額的單次費用（$29.99，並依地區用[購買力平價](https://en.wikipedia.org/wiki/Purchasing_power_parity)調整）就能使用。這是世界上大多數人都負擔得起的金額，所以如果你想支持我們在做的事，或是想使用那些功能，這都是很好的開始。

## 接著，代理式程式設計登場

就在我準備要推出時，Claude Code 和它的一群夥伴出現了，從此永遠改變了寫程式這件事。我花了很長時間猶豫到底還要不要推出 Jiki，懷疑寫程式是否還有存在的意義。但 6 個月後，我比以往任何時候都更確信：程式碼不會消失，而軟體開發者比以往任何時候都更有價值。

幾十年來，程式碼一直是我們用來創造的工具，但它同時也是一道守門人。在你精通 Python 之前，你沒辦法做資料科學；在你學會 JavaScript 之前，你做不出網站；在你學過 SQL 之前，你沒辦法處理資料庫。現在這一切都變了。Claude、ChatGPT 以及許多其他工具都能幫你寫那些程式碼。

但，這是個巨大的「但」，人類依然和以往一樣不可或缺：去設計軟體、做出明智的技術決策、把模糊的想法琢磨成精確到足以實作的東西。這一直就是軟體開發的本質：把想法變成現實的藝術。我們只是不再需要自己動手做「寫程式碼」這個步驟了。

所以 Jiki 兩者都教。它教你寫程式的基礎，因為你仍然需要理解你的 AI 在做什麼。但它也教你怎麼打造東西：網站底層是怎麼運作的、如何設計資料庫、如何架構軟體。這些都是你真正做出東西所需要的。如果你想在科技業找到工作，這些就是該精通的本事。而如果你只是想做出東西，這也會用你懂的方式教你怎麼做，而且最後不會變成一團義大利麵般的混亂。

## Jiki 是什麼，以及我希望它走向何方

Jiki 是一個學寫程式的平台，設計得高度互動又有趣。它是為初學者打造的：那些寫程式不到一年、想要打下真正扎實基礎的人。你會在一個專門設計來幫助你理解發生什麼事的自訂環境裡，透過打造專案來學習。

內容以關卡來編排。每一關，你會看一支短影片學習一個新概念，然後有一系列專案讓你實際運用它。學習的核心是**Jiki**，一個會執行你程式碼的角色。我教的一切，都是透過 Jiki 的視角：他怎麼看你的程式碼、他怎麼執行它。當你執行自己的程式碼時，你能清楚看到 Jiki 所看到的一切，以及他為什麼這麼做。

但比起功能，我真正在意的是它背後的哲學。不是每個人都需要成為軟體開發者；但懂得如何拆解問題、打造解決方案，是一種能運用到所有事情上的技能。而這正是這門課程的關鍵：放慢腳步，真正深入思考如何解決問題。這在剛開始時真的很難（我們活在一個被多巴胺驅動的時代！），但當它開竅時，會是一項了不起的技能。

我沒有什麼宏大的企圖，要讓 Jiki 取代市面上其他平台。我完全不想和任何人競爭，而且我相信在基礎之外，還有很多很棒的內容。我希望世界上能有這樣一個平台，讓盡可能多的人都能打下**真正扎實的基礎**，並且在學習的過程中玩得非常開心。因為當你有了那些基礎，學習其他一切就會**輕鬆**得多。這就是 Jiki 的目標，而我真的很興奮能把它帶到世界上。
