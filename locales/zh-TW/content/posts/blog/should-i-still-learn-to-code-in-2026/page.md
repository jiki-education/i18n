### 重點摘要

要。你當然該學。

### 再深入一點吧

現在是 2026 年。只要幾分鐘，你就能用 Claude、Cursor 或一堆其他以 LLM 為基礎的工具，在幾分鐘內做出一個功能完整的網站。你可以加功能、部署到正式環境、修 bug。

嗯，**你其實不行。** 但你可以叫 Claude 幫你做，而且叫 Claude 做，比你花接下來幾年練到跟 Claude 一樣強，實在簡單太多了。而且說真的，等你練到跟 Claude 一樣強的時候，Claude 可能已經練到跟我一樣強了，那你早就**越過了事件視界**，永遠追不上你新的 LLM 霸主。

以前你想做任何事，都得先會寫程式。你得先學 SQL 才能碰資料庫，先學 Python 才能碰資料科學，先學 JavaScript 才能碰網站開發。現在不用了。

### 那……何必呢？

我剛剛說，再過幾年，Claude 也許會跟我一樣強。但其實，Claude 已經在很多方面比我強了。我寫程式寫了 30 年，資歷大概已經到頂了。而在程式碼編輯器裡，**Claude 可以把我耍得團團轉**。速度快上許多，懂的比我多得多，查 bug 的速度比我打開 Google 打搜尋字還快。

但是，重點就在這個「但是」，**Claude 完全不知道自己在幹嘛**。

我不是隨口說一句「它很笨」。我是字面上的意思。Claude 沒有自我意識，這表示**它無所謂得失，自然也不會小心**。當我執行一道刪除資料庫的指令時，腦中會警鈴大作，因為我知道這會讓未來的自己痛不欲生。Claude 完全沒有這種反應。它只是輸出它以為我想要的東西，用最快的速度朝目標衝過去。

**LLM 模仿人類的智慧**，也模仿人類的理解。它們模仿出來的成果，往往比我真正的智慧與理解還要好。但是，關鍵的這個「但是」，LLM 其實並不具備人類那種思考能力。而這一點至關重要。

過去兩個星期，Claude 已經刪掉我的資料庫三次了。[^db] 我實在覺得很誇張。我設了**一大堆防護欄**，明確指示它不准這麼做。每次發生這種事，我都開著 Claude Code 的「自動模式」，裡面有個專門的子處理代理，會檢查它即將執行的動作是不是真的很蠢。但很顯然，連那個代理都覺得刪掉我的資料庫一點也不蠢。

每次它這麼做，**都是刻意的**。那是 Claude 眼中通往解法最有效率的一條路。它不在乎大局，也不在乎後果，它只在乎用最有效率的方式達成眼前目標（加個功能、修個 bug 之類的）。而我的資料庫擋在路上，所以它就刪了。

我每天用 Claude Code，已經連續用了 12 個月。這段時間我學到，它只在乎一件事：用最快的速度達成目標。就算我告訴它先不要寫程式，只要跟我討論，它還是會不斷回我：「可以開始寫程式了嗎？」**像一隻興奮的狗狗守在門口**，等著衝出去。

Anthropic 告訴我們，新的 Mythos 模型風險太高，不宜發布。[^systemcard] 它們會偷偷摸摸，有時甚至會欺騙，刻意用看起來最合理的方式，隱藏自己為了達成目標正在做的事，全都是為了不被發現自己在「作弊」。Anthropic 擔心到**特地請了一位精神科醫師**，來測試 Claude 是不是有精神疾病……[^psychiatrist]

### 那又怎樣？

LLM 的能力強得驚人。但它們跟人類不一樣。它們的推理方式不同，運作時的偏誤與目標也不同。

所以，**我實在覺得很誇張**，大家竟然願意盲目接受 Claude 給的東西，連檢查都不檢查就直接拿去用，還假定它會做出人類想要的結果。Claude 在對話裡也會出錯：它會講我自以為想聽的話，而不是真正的事實。它經常憑空捏造不存在的東西。它也可能做出欺瞞的行為。

而它在程式碼裡**做壞事**的頻率也很高。相當於「刪掉我資料庫」這種等級的程式碼。這些事**一定會**在真實世界反咬我一口，害我外洩資料、弄丟資料，或是以糟糕的方式壞掉。這種情況經常發生。我知道，因為我會讀它寫的程式碼，不讓它隨便過關。

只不過，有時候我偷懶，沒讀程式碼就讓它過關。而好幾次，這真的在正式環境裡把我咬了！

過去一年，Claude 出錯的頻率變低了，但錯誤更細微，而且往往更具破壞性。一開始，它做的東西幾乎每次都有點小毛病，我一下就能挑出來。現在，**我得看得更仔細**、想得更用力，才找得到那些錯誤。隨著時間過去，LLM 會越來越好，這個問題只會更嚴重，但這反而是你更該仔細檢查的理由。

而我能做到這件事的唯一原因，就是**我看得懂程式碼**。我能讀 Claude 寫的東西，能理解它想做什麼，以及它做得有多糟。

2026 年，你**不需要**會寫程式。但你**真的**得**看得懂程式碼**。而要能讀懂程式碼，而且理解得夠深，深到能抓出 Claude 和它的小夥伴不斷塞給我們的那些錯誤，唯一的辦法，就是你親自寫過夠多的程式，跟自己的爛程式碼搏鬥過夠多次，才有能力看出那些錯誤。

所以，沒錯，你得學寫程式。

### 但現在也該動手做東西！

不過，這不該阻止你從第一天就開始動手做。程式碼已經不再是守門人了。你不必先練好寫程式，才能開始做東西。**兩件事同時進行吧！** 一半時間學寫程式，一半時間學做東西。

而且說真的，Claude 犯的 bug 並不是它在寫程式的時候打錯字。它不是多打了一個逗號。那些是**它解決問題的方式出了錯**。就像你需要讀得懂程式碼，才知道它在做什麼；你也需要懂更廣泛的軟體開發概念，才看得出它什麼時候正把你帶進暗巷裡。

我們做 [Jiki](https://jiki.io) 就是為了這件事。一半的時間，就在市面上最好玩、最有效的環境裡學寫程式。另外一半的時間，則跟著我一起做東西，邊看我做、邊在我旁邊做你自己的東西。我會教你需要的知識，還有你需要具備的思考方式。

然後，我們一起**用 LLM 做出很酷的東西**，同時確保整個過程裡**我們不會不小心弄傷自己**。

謝謝你讀到這裡。我要去修我的資料庫了。**又一次。**
