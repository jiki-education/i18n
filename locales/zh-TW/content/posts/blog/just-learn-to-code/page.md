大多數初學者要面對的第一個決定，就是「我該選哪個語言？」。而多數人最後都選了 JavaScript 或 Python。

就在那一刻，有件很重要的事發生了。他們從「我要學寫程式」變成「我要學 Python」。一個星期前，他們可能連 Python 都沒聽過，也完全不了解 JS、Python、R、Java 或其他幾十種主流語言之間到底有什麼差別。但突然之間，他們就願意為了「我是 Python 派的人」這句話死守到底。

這也怪不得他們！初學者最常聽到、也最容易被搞混的說法之一，就是「學寫程式就等於學一個程式語言」。而我們這些開發者，每個人都有自己偏好的語言，一看到徬徨無助的新手，馬上就把對方當成可以拉進自己陣營的潛在信徒。談到自己的語言，很少有哪個族群比程式設計師更壁壘分明。

![兩群憤怒的程式設計師揮舞著各自支持語言的旗幟，中間一位困惑的初學者摀著耳朵](/images/blog/just-learn-to-code-tribalism.webp)

但對初學者來說，這根本沒道理。初學者不需要學 Python、JavaScript 或其他任何語言。他們需要的是寫程式的基礎，並打造一個穩固的平台，涵蓋他們日後會用到的幾十種語言。

尤其在 AI 代理寫程式的時代，你第一個星期就可能要把 TypeScript、Python、SQL、bash、JSON、Ruby 和其他更多語言推上正式環境。我們該做的，是幫助初學者盡可能從宏觀的角度理解這一切，而不是把自己窄化在某個特定語言裡。

我們設計 Jiki 的目標，就是教這些基礎。目前它用的是稍微修改過的 JavaScript。今年稍晚我們會加入 Python，屆時你可以自己選（或者讓我們丟硬幣幫你決定！），但老實說，選哪個都無所謂。

用**[Jiki](https://jiki.io)**學會寫程式。這需要花點時間。等你真正懂寫程式之後，再用**[Exercism](https://exercism.org)**去學各種語言。只要基礎打得穩，學起來會快非常多，也輕鬆很多喔。

下次有初學者問你該學哪個語言時，就告訴他們：選哪個都無所謂。幫他們解開這副枷鎖，引導他們去 Jiki 打好紮實的基礎。
