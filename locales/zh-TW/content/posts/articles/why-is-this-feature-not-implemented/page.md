試著執行你的程式碼，卻看到訊息說這個語言版本裡沒有某項東西嗎？繼續往下讀，你就會知道是怎麼回事！

如果你看到的訊息是「這個功能還沒對你開放」，那是另一種情況，請改讀**[這個功能什麼時候才會解鎖？](/articles/when-will-this-feature-unlock)**。

## 簡介

你用到了我們這個語言版本不支援的關鍵字或概念。別擔心，這不是 bug！

你在 Jiki 裡使用的 JavaScript 和 Python 版本，是**我們專門為了幫你學習而設計**的。我們刻意移除了一些功能，免得你在還沒準備好之前，就意外碰上語言裡複雜又容易搞混的部分。

## 為什麼要排除某些功能？

程式語言是為**專業人士**設計的。它們包含一些能讓有經驗的開發者工作得更快的進階功能，也帶著一些歷史包袱，也就是那些老早就該移除、卻為了讓舊系統繼續運作而保留下來的功能。

學習的時候，這些功能只會帶來混淆。把它們移除之後，Jiki 讓你能專注在真正重要的事上：**學會像程式設計師一樣思考**。

### 腳槍

我們把某些功能稱為「腳槍」，因為它們就像一把對著自己腳的槍，一不小心就會打中自己。這些功能是：

- **本身就有問題**，連專業人士也最好避開
- **令人困惑的邊緣案例**，會讓你分心、無法專注在核心概念上
- **歷史包袱**，純粹為了向後相容而存在

這些功能會永久排除在 Jiki 之外，因為它們造成的混淆實在不值得。

### 進階功能

其他功能被排除，是因為它們對你目前的學習階段來說**太進階了**。這些功能本身並不糟，只是在學基礎的時候幫不上忙。

隨著你在 Jiki 裡一步步前進，有些功能會陸續解鎖。不過現在，先專心把基礎練好。

## 具體細節

除非你真的想知道背後是怎麼運作的、以及我們做過哪些決定，否則這一段可以跳過。

### JavaScript

| 功能                                                    | 為什麼排除                                                                                                |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `var`                                                      | 請改用 `let` 或 `const`。`var` 的作用域規則容易讓人搞混，連有經驗的開發者都會因此寫出 bug。 |
| `with`                                                     | 已經被棄用，而且很容易搞混。它會產生語意模糊、難以理解的程式碼。                                    |
| `debugger`                                                 | 開發工具，學習時用不到。                                                                       |
| `void`                                                     | 很少用得上，對初學者來說也很容易搞混。                                                                       |
| `yield`                                                    | 進階的產生器功能。之後在學習的路上，你會學到產生器。                                 |
| `delete`                                                   | 用在陣列和物件上時，行為容易讓人搞混。                                                           |
| `import` / `export`                                        | 模組系統的功能。為了保持簡單，Jiki 用不同的方式處理模組。                                  |
| 位元運算子（`&`、`\|`、`^`、`~`、`<<`、`>>`、`>>>`） | 學習階段幾乎用不到，而且很容易搞混。這些是用來做低階位元操作的。                 |

### Python

| 功能    | 為什麼排除                                                                                                     |
| ---------- | --------------------------------------------------------------------------------------------------------------------- |
| `global`   | 從函式內部修改全域變數，會讓程式碼變得難以理解。請改學著把值當作參數傳遞。 |
| `nonlocal` | 給巢狀函式用的進階作用域功能。學基礎的時候用不到。                                 |
| `assert`   | 除錯用的工具，在正式環境中可以被停用。請改學著妥善處理錯誤。                               |

## 如果我需要某個功能怎麼辦？

Jiki 裡的每一道練習，都設計成能用你到目前為止學過的功能解開。如果你碰上限制，通常都有更好的做法，可以用現有的功能來解決你的問題。這也是學習的一部分：想辦法在限制中把事情做出來。

如果你真的認為某個功能應該在你這個階段就能用，歡迎告訴我們喔！我們一直根據大家的回饋，調整哪些功能該被納入。
