## 關於課程

### 費用是多少？

Learn to Code 的練習是程式設計課程大綱的核心，完全免費。不用信用卡、不用試用期，也沒有任何附帶條件。

Jiki Premium 是依國家定價的一次性付款，開通後可解鎖 Jiki Challenges，並享有無限的 Ask Jiki AI 支援、可參加的定期 Q&A 直播、課程證書、無廣告的學習體驗，以及新功能的搶先體驗。

### 這門課程每週需要花多少時間？

你想花多少時間都可以，長短完全由你決定。大多數人會在 8 到 12 週內完成這門課程，平均每週約 5 到 10 小時。

### 這門課程有多難？我需要有多聰明？

這門課程的設計適合所有人，不論你的背景如何。我們不認為學程式設計需要「很聰明」。但你需要付出努力，並且願意接受挑戰。

只要你肯付出努力、卡住時願意求助、並且願意擁抱挑戰，你會驚訝自己在短時間內能走得多遠。

### Jiki 現在可以用了嗎？

可以，你今天就能註冊，開始免費的 Learn to Code 課程大綱。

### 我已經報名過 Bootcamp 了，這有什麼不同嗎？

謝謝你參與 Bootcamp！Jiki 是我們 Bootcamp 演進的下一階段。你解過的大部分練習都會出現在 Jiki 裡，而且還會多出很多很多。我們也把 3 小時的影片拆成 5 到 10 分鐘的小段落，讓你更容易看完！

身為 Bootcamp 的成員，你會自動獲得終身的 Jiki Premium。這項權益適用於最初的 Learn to Code 課程，以及未來的所有課程。

## Jiki Premium

### 我可以免費試用 Jiki 嗎？

可以喔！你可以免費註冊，並使用 Basic 方案，想用多久就用多久。需要完整權限時再升級 Premium，完全沒有壓力。

### Premium 是訂閱制嗎？

不是。Premium 是單次付款。付一次就能終身擁有 Premium，不需要續訂，也沒有任何東西要取消。

### 終身使用權是什麼意思？

你的 Premium 使用權限永遠不會過期，也不會再向你收費。所有 Premium 功能你都能繼續使用，包括我們之後新增的功能。

### 我已經訂閱 Premium 了，我的訂閱會怎麼樣？

什麼都不會改變。你的訂閱會照原本的方式繼續，你隨時都能從帳號設定中管理或取消。

### 你們有提供學生或負擔不起 Premium 的人折扣嗎？

我們希望每個人都能使用 Jiki。如果費用對你來說是個障礙，請[與我們聯絡](/articles/support)，我們會盡力協助。

### 我之後可以升級嗎？

當然可以。你隨時都能從帳號升級到 Premium。
