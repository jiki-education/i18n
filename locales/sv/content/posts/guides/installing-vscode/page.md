## Introduktion

Visual Studio Code (VS Code) är en kostnadsfri kodredigerare utvecklad av Microsoft som fungerar på Windows, macOS och Linux. Det är redigeraren vi rekommenderar när du lär dig programmera. Om du inte är säker på vad en kodredigerare är eller varför du behöver en, börja med vår guide om [att använda en kodredigerare](/guides/using-a-code-editor).

Den här guiden går igenom hur du installerar VS Code på varje operativsystem. Hitta ditt system nedan och följ stegen. Du behöver bara göra detta en gång.

## Windows

1. Öppna [code.visualstudio.com](https://code.visualstudio.com) i din webbläsare.
2. Klicka på knappen **Ladda ned för Windows** (_Download for Windows_). Detta laddar ned den officiella installationsfilen (en `.exe`-fil).
3. När nedladdningen är klar öppnar du filen för att starta installationsprogrammet.
4. Godkänn licensavtalet och klicka sedan på **Nästa** (_Next_) för att acceptera standardalternativen. Vi rekommenderar att du låter rutan som lägger till VS Code i din högerklicksmeny vara ikryssad, eftersom det är praktiskt senare.
5. Klicka på **Installera** (_Install_) och sedan **Slutför** (_Finish_). VS Code öppnas när det är klart.

## macOS

1. Öppna [code.visualstudio.com](https://code.visualstudio.com) i din webbläsare.
2. Klicka på knappen **Ladda ned för macOS** (_Download for macOS_). Detta laddar ned en `.zip`-fil som innehåller appen.
3. Öppna mappen **Hämtningar** (_Downloads_) och dubbelklicka på den nedladdade filen för att packa upp den. Du får en app som heter **Visual Studio Code**.
4. Dra **Visual Studio Code** till mappen **Program** (_Applications_).
5. Öppna mappen **Program** och dubbelklicka på **Visual Studio Code** för att starta den. Om macOS frågar om du är säker på att du vill öppna den klickar du på **Öppna** (_Open_).

## Linux

1. Öppna [code.visualstudio.com](https://code.visualstudio.com) i din webbläsare.
2. Klicka på **Ladda ned för Linux** (_Download for Linux_) och välj paketet som passar din distribution:
   - Välj **.deb**-paketet på Debian- och Ubuntu-baserade system.
   - Välj **.rpm**-paketet på Fedora-, Red Hat- och openSUSE-baserade system.
3. Öppna det nedladdade paketet med din dators programinstallerare och klicka på **Installera** (_Install_), eller installera det från terminalen:
   - På Debian eller Ubuntu kör du `sudo apt install ./<file>.deb` i den mapp där du laddade ned det.
   - På Fedora eller Red Hat kör du `sudo dnf install ./<file>.rpm` i den mapp där du laddade ned det.
4. När det är installerat öppnar du VS Code från din programmeny, eller genom att köra `code` i terminalen.

## Öppna VS Code

Oavsett hur du installerade det kan du nu öppna VS Code när du vill skriva kod. På Windows och macOS visas det tillsammans med dina andra program, och på Linux finns det i din programmeny.

Det var allt. Nu har du en riktig kodredigerare installerad och är redo att börja skriva kod.
