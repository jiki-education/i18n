Neste exercício, a tua tarefa é desenhar um ícone meteorológico de um dia de chuva, com o sol a espreitar por trás das nuvens. No final, deve ficar assim:

<img src="/static/images/exercise-assets/cloud-rain-sun/finished.webp" alt="Cenário terminado com nuvem, chuva e sol" style="width: 100%; max-width: 300px; border: 1px solid rgba(0, 0, 0, 0.3); border-radius: 5px; box-shadow: 0 0 3px rgba(0, 0, 0, 0.1); margin-bottom: 8px;" />

Desenhámos um modelo para ti. As tuas formas devem ficar mesmo por dentro das linhas. Também já adicionámos a base da nuvem ao código, para te facilitar um pouco a vida. **Não podes alterar essa linha** (vais ver que está esbatida e tem um símbolo de cadeado ao lado).

Vais precisar das funções `circle` (círculo) e `ellipse` (elipse). Só deves usar elipses para as gotas de chuva. Se as usares no sol ou nas nuvens, as coisas não vão funcionar.

Quase todos os números de que precisas são divisíveis por 5 (por exemplo, 5, 10, 15, etc.). A única exceção é o raio horizontal das gotas de chuva, que é `3`.

Diverte-te!
