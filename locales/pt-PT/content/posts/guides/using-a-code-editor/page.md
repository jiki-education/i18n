## Introdução

Quando começas a escrever código no teu próprio computador, precisas de um sítio onde o escrever. Esse "sítio" é um editor de código. É uma das primeiras ferramentas a que vais recorrer. É também onde vais passar muito tempo ao longo da tua carreira. É provável que vás trocando e experimentando novos editores com o tempo, por isso vale a pena perceber o que é e como escolher um bom editor para começar.

## Um editor de código não é um processador de texto

É fácil assumir que qualquer programa que te deixe escrever serve. O erro mais comum é recorreres a um processador de texto como o Microsoft Word ou o Google Docs. Esses programas foram criados para escrever documentos destinados a pessoas, por isso alteram silenciosamente o que escreves. Transformam aspas retas em aspas curvas “inteligentes”, corrigem automaticamente as tuas palavras e guardam formatação oculta. Tudo isto estraga o código.

Um editor de código é um tipo de editor de texto. Trabalha com texto simples e nunca acrescenta formatação oculta, por isso o que escreves é exatamente aquilo que o computador vê. A diferença é que um editor de código é um editor de texto criado especificamente para código. Além de trabalhar com texto simples, compreende a estrutura do que estás a escrever e ajuda-te de formas que um processador de texto nunca conseguiria:

- **Realce de sintaxe** colore as diferentes partes do código para ser mais fácil de ler e de detetar erros.
- **Indentação automática** mantém o código alinhado, o que é muito importante em muitas linguagens.
- **Indicações de erro** assinalam problemas, muitas vezes antes de sequer executares o programa.
- **Preenchimento automático** sugere o resto do que estás a escrever, para escreveres mais depressa e cometeres menos erros de digitação.
- **Extensões** permitem adicionar suporte para novas linguagens e ferramentas à medida que evoluis.

## A nossa recomendação

Há muitos bons editores de código e não podes fazer uma má escolha por aqui. Ainda assim, recomendamos o **Visual Studio Code**, normalmente abreviado para VS Code. É gratuito, funciona em Windows, macOS e Linux, é amigável para principiantes e é um dos editores mais usados em todo o mundo, por isso quase todos os tutoriais que encontrares vão partir do princípio de que o estás a usar.

Quando quiseres instalá-lo, segue o nosso guia sobre [instalar o VS Code](/guides/installing-vscode).

## Outros editores de que podes ouvir falar

Não precisas de nenhum destes para acompanhar o Jiki, mas é provável que te cruzes com eles. Fica aqui uma visita rápida pelos mais comuns:

- O <a href="https://code.visualstudio.com" target="_blank" rel="noopener noreferrer">Visual Studio Code (VS Code)</a> é o editor gratuito e multiplataforma que recomendamos.
- O <a href="https://www.sublimetext.com" target="_blank" rel="noopener noreferrer">Sublime Text</a> é um editor rápido e leve que tem sido popular durante muitos anos.
- O <a href="https://zed.dev" target="_blank" rel="noopener noreferrer">Zed</a> é um editor mais recente e muito rápido, focado na velocidade e na colaboração.
- Os <a href="https://www.jetbrains.com/ides/" target="_blank" rel="noopener noreferrer">IDEs da JetBrains</a> (como o <a href="https://www.jetbrains.com/pycharm/" target="_blank" rel="noopener noreferrer">PyCharm</a> e o <a href="https://www.jetbrains.com/idea/" target="_blank" rel="noopener noreferrer">IntelliJ IDEA</a>) são ferramentas poderosas e mais pesadas, destinadas a programadores profissionais que trabalham em grandes projetos.
- O <a href="https://www.vim.org" target="_blank" rel="noopener noreferrer">Vim</a> e o <a href="https://neovim.io" target="_blank" rel="noopener noreferrer">Neovim</a> são editores controlados pelo teclado que vivem no terminal. São muito apreciados por programadores experientes, mas têm uma curva de aprendizagem íngreme.

O nosso conselho enquanto estás a aprender é simples: começa pelo VS Code, habitua-te a escrever código e explora os outros mais tarde, quando descobrires do que gostas.
