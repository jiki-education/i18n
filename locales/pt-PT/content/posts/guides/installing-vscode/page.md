## Introdução

O Visual Studio Code (VS Code) é um editor de código gratuito criado pela Microsoft que funciona no Windows, no macOS e no Linux. É o editor que recomendamos enquanto estás a aprender a programar. Se não sabes bem o que é um editor de código ou porque precisas de um, começa pelo nosso guia sobre [como usar um editor de código](/guides/using-a-code-editor).

Este guia acompanha-te durante a instalação do VS Code em cada sistema operativo. Encontra o teu sistema abaixo e segue os passos. Só precisas de fazer isto uma vez.

## Windows

1. Abre [code.visualstudio.com](https://code.visualstudio.com) no teu navegador.
2. Clica no botão **Descarregar para Windows**. Isto descarrega o instalador oficial (um ficheiro `.exe`).
3. Quando a transferência terminar, abre o ficheiro para executar o instalador.
4. Aceita o contrato de licença e continua a clicar em **Seguinte** para aceitares as opções predefinidas. Recomendamos que deixes assinalada a caixa que adiciona o VS Code ao menu de contexto, porque dá jeito mais tarde.
5. Clica em **Instalar** e, em seguida, em **Concluir**. O VS Code abre quando estiver pronto.

## macOS

1. Abre [code.visualstudio.com](https://code.visualstudio.com) no teu navegador.
2. Clica no botão **Descarregar para macOS**. Isto descarrega um ficheiro `.zip` com a aplicação.
3. Abre a pasta **Transferências** e faz duplo clique no ficheiro descarregado para o descomprimir. Vais obter uma aplicação chamada **Visual Studio Code**.
4. Arrasta o **Visual Studio Code** para a pasta **Aplicações**.
5. Abre a pasta **Aplicações** e faz duplo clique em **Visual Studio Code** para o iniciares. Se o macOS perguntar se queres mesmo abri-lo, clica em **Abrir**.

## Linux

A forma mais fiável de instalar o VS Code no Linux é descarregar o pacote oficial para a tua distribuição a partir da Microsoft.

1. Abre [code.visualstudio.com](https://code.visualstudio.com) no teu navegador.
2. Clica em **Descarregar para Linux** e escolhe o pacote que corresponde à tua distribuição:
   - Escolhe o pacote **.deb** nos sistemas baseados em Debian e Ubuntu.
   - Escolhe o pacote **.rpm** nos sistemas baseados em Fedora, Red Hat e openSUSE.
3. Abre o pacote descarregado com o instalador de software do teu sistema e clica em **Instalar**, ou instala-o a partir do terminal:
   - No Debian ou Ubuntu, executa `sudo apt install ./<file>.deb` na pasta onde o descarregaste.
   - No Fedora ou Red Hat, executa `sudo dnf install ./<file>.rpm` na pasta onde o descarregaste.
4. Quando estiver instalado, abre o VS Code a partir do menu de aplicações ou executando `code` no terminal.

## Abrir o VS Code

Independentemente da forma como o instalaste, agora podes abrir o VS Code sempre que quiseres escrever código. No Windows e no macOS, aparece ao lado das tuas outras aplicações. No Linux, fica no menu de aplicações.

É tudo. Agora tens um editor de código a sério instalado e estás pronto para começar a escrever código.
