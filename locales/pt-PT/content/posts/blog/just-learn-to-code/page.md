Uma das primeiras decisões que a maioria dos principiantes enfrenta é: «Que linguagem devo escolher?». A maioria acaba por escolher JavaScript ou Python.

Nesse momento, acontece algo importante. Deixam de pensar «vou aprender a programar» e passam a pensar «vou aprender Python». Há uma semana, talvez nunca tivessem ouvido falar de Python e, de certeza, não têm uma verdadeira noção das diferenças entre JS, Python, R, Java ou as dezenas de outras linguagens importantes. Mas, de repente, estão dispostos a defender com unhas e dentes que «sou uma pessoa de Python».

E eu não os censuro! Uma das mensagens mais confusas e misturadas que os principiantes ouvem é a de que aprender a programar é o mesmo que aprender uma linguagem de programação. E nós, os programadores, que temos todos uma linguagem favorita, vemos um novato vulnerável e identificamo-lo logo como um potencial convertido à nossa linguagem. Há poucos grupos mais tribais do que os programadores no que toca à linguagem.

![Programadores em duas multidões zangadas a agitar cartazes de linguagens de programação diferentes enquanto um principiante confuso tapa os ouvidos no meio](/images/blog/just-learn-to-code-tribalism.webp)

Mas, para um principiante, isto é um disparate. Um principiante não precisa de aprender Python, JavaScript ou qualquer outra linguagem. Precisa de aprender os fundamentos da programação e de construir uma base sólida que abranja as dezenas de linguagens que acabará por usar ao longo do tempo.

Sobretudo na era da programação com agentes, em que podes estar a colocar TypeScript, Python, SQL, bash, JSON, Ruby e muitas outras linguagens em produção logo na primeira semana. Precisamos de ajudar os principiantes a perceber o que está a acontecer ao nível mais abrangente possível, em vez de os fecharmos numa linguagem específica.

Concebemos o Jiki para ensinar os fundamentos. Neste momento, usa uma versão ligeiramente modificada de JavaScript. Mais tarde, ainda este ano, vamos acrescentar Python e poderás escolher (ou podemos atirar uma moeda ao ar para escolher por ti!), mas, sinceramente, isso não importa.

Aprende a programar com o **[Jiki](https://jiki.io)**. Vai demorar algum tempo. Depois, quando perceberes a programação, usa o **[Exercism](https://exercism.org)** para aprenderes linguagens. Vai ser MUITO mais rápido e fácil se tiveres os fundamentos bem assentes.

E, da próxima vez que um principiante te perguntar que linguagem deve aprender, diz-lhe que isso não importa. Liberta-o das correntes e aponta-lhe, em vez disso, o Jiki para ganhar fundamentos sólidos.
