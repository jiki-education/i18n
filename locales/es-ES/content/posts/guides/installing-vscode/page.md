## Introducción

Visual Studio Code (VS Code) es un editor de código gratuito creado por Microsoft que funciona en Windows, macOS y Linux. Es el editor que recomendamos mientras aprendes a programar. Si no tienes claro qué es un editor de código o por qué lo necesitas, empieza con nuestra guía sobre [usar un editor de código](/guides/using-a-code-editor).

Esta guía te explica cómo instalar VS Code en cada sistema operativo. Busca tu sistema a continuación y sigue los pasos. Solo necesitas hacerlo una vez.

## Windows

1. Abre [code.visualstudio.com](https://code.visualstudio.com) en tu navegador web.
2. Haz clic en el botón **Download for Windows**. Esto descarga el instalador oficial (un archivo `.exe`).
3. Cuando termine la descarga, abre el archivo para ejecutar el instalador.
4. Acepta el acuerdo de licencia y luego haz clic en **Next** para aceptar las opciones predeterminadas. Te recomendamos dejar activada la casilla que añade VS Code al menú del clic derecho, ya que es útil más adelante.
5. Haz clic en **Install** y luego en **Finish**. VS Code se abrirá cuando esté listo.

## macOS

1. Abre [code.visualstudio.com](https://code.visualstudio.com) en tu navegador web.
2. Haz clic en el botón **Download for macOS**. Esto descarga un archivo `.zip` que contiene la aplicación.
3. Abre tu carpeta **Descargas** y haz doble clic en el archivo descargado para descomprimirlo. Obtendrás una app llamada **Visual Studio Code**.
4. Arrastra **Visual Studio Code** a la carpeta **Aplicaciones**.
5. Abre la carpeta **Aplicaciones** y haz doble clic en **Visual Studio Code** para iniciarlo. Si macOS te pregunta si estás seguro de abrirlo, haz clic en **Open**.

## Linux

La forma más fiable de instalar VS Code en Linux es descargar el paquete oficial para tu distribución desde Microsoft.

1. Abre [code.visualstudio.com](https://code.visualstudio.com) en tu navegador web.
2. Haz clic en **Download for Linux** y elige el paquete que corresponda a tu distribución:
   - Elige el paquete **.deb** en sistemas basados en Debian y Ubuntu.
   - Elige el paquete **.rpm** en sistemas basados en Fedora, Red Hat y openSUSE.
3. Abre el paquete descargado con el instalador de software de tu sistema y haz clic en **Install**, o instálalo desde la terminal:
   - En Debian o Ubuntu, ejecuta `sudo apt install ./<file>.deb` en la carpeta donde lo descargaste.
   - En Fedora o Red Hat, ejecuta `sudo dnf install ./<file>.rpm` en la carpeta donde lo descargaste.
4. Una vez instalado, abre VS Code desde el menú de aplicaciones o ejecutando `code` en la terminal.

## Abrir VS Code

Sin importar cómo lo instalaste, ya puedes abrir VS Code cuando quieras escribir código. En Windows y macOS aparecerá junto a tus demás aplicaciones, y en Linux estará en el menú de aplicaciones.

Eso es todo. Ahora tienes un editor de código profesional instalado y estás listo para empezar a escribir código.
