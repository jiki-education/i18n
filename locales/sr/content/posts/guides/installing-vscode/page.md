## Uvod

Visual Studio Code (VS Code) je besplatan editor koda koji je napravio Microsoft i koji radi na Windows, macOS i Linux. To je editor koji preporučujemo dok učiš da programiraš. Ako nisi siguran šta je editor koda ili zašto ti je potreban, počni sa našim vodičem o [korišćenju editora koda](/guides/using-a-code-editor).

Ovaj vodič te vodi kroz instaliranje VS Code-a na svakom operativnom sistemu. Pronađi svoj sistem ispod i prati korake. Ovo treba da uradiš samo jednom.

## Windows

1. Otvori [code.visualstudio.com](https://code.visualstudio.com) u svom internet pregledaču.
2. Klikni na dugme **Download for Windows**. Time se preuzima zvanični instalater (`.exe` fajl).
3. Kada se preuzimanje završi, otvori fajl da pokreneš instalater.
4. Prihvati ugovor o licenci, a zatim nastavi da klikćeš **Next** da prihvatiš podrazumevane opcije. Preporučujemo da ostaviš obeleženo polje koje dodaje VS Code u tvoj meni desnog klika, jer je to kasnije korisno.
5. Klikni **Install**, a zatim **Finish**. VS Code će se otvoriti kada bude spreman.

## macOS

1. Otvori [code.visualstudio.com](https://code.visualstudio.com) u svom internet pregledaču.
2. Klikni na dugme **Download for macOS**. Time preuzimaš `.zip` fajl koji sadrži aplikaciju.
3. Otvori svoj **Downloads** folder i dvaput klikni na preuzeti fajl da ga otpakuješ. Dobićeš aplikaciju pod nazivom **Visual Studio Code**.
4. Prevuci **Visual Studio Code** u svoj **Applications** folder.
5. Otvori svoj **Applications** folder i dvaput klikni na **Visual Studio Code** da ga pokreneš. Ako macOS pita da li si siguran da želiš da ga otvoriš, klikni **Open**.

## Linux

Najpouzdaniji način da instaliraš VS Code na Linux je da preuzmeš zvanični paket za svoju distribuciju od Microsoft-a.

1. Otvori [code.visualstudio.com](https://code.visualstudio.com) u svom internet pregledaču.
2. Klikni na **Download for Linux** i izaberi paket koji odgovara tvojoj distribuciji:
   - Izaberi **.deb** paket na sistemima baziranim na Debian i Ubuntu.
   - Izaberi **.rpm** paket na sistemima baziranim na Fedora, Red Hat i openSUSE.
3. Otvori preuzeti paket pomoću sistemskog instalatera softvera i klikni **Install**, ili ga instaliraj iz terminala:
   - Na Debian ili Ubuntu, pokreni `sudo apt install ./<file>.deb` u folderu gde se nalazi preuzeti fajl.
   - Na Fedora ili Red Hat, pokreni `sudo dnf install ./<file>.rpm` u folderu gde se nalazi preuzeti fajl.
4. Kada se instalira, otvori VS Code iz menija aplikacija ili pokretanjem `code` u terminalu.

## Otvaranje VS Code-a

Bez obzira na to kako je instaliran, sada možeš da otvoriš VS Code kad god želiš da pišeš kod. Na Windows i macOS će se pojaviti pored ostalih tvojih aplikacija, a na Linux će biti u meniju aplikacija.

To je to. Sada imaš instaliran pravi editor koda i možeš da počneš da pišeš kod.
