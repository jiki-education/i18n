## Introduzione

Visual Studio Code (VS Code) è un editor di codice gratuito creato da Microsoft che funziona su Windows, macOS e Linux. È l'editor che consigliamo mentre impari a programmare. Se non sei sicuro di cosa sia un editor di codice o del perché ne hai bisogno, inizia con la nostra guida su [usare un editor di codice](/guides/using-a-code-editor).

Questa guida ti accompagna nell'installazione di VS Code su ciascun sistema operativo. Trova il tuo sistema qui sotto e segui i passaggi. Lo farai solo una volta.

## Windows

1. Apri [code.visualstudio.com](https://code.visualstudio.com) nel tuo browser.
2. Clicca il pulsante **Download for Windows**. In questo modo scaricherai il programma di installazione ufficiale (un file `.exe`).
3. Al termine del download, apri il file per eseguire l'installer.
4. Accetta il contratto di licenza, poi continua a cliccare **Next** per accettare le opzioni predefinite. Ti consigliamo di lasciare selezionata la casella che aggiunge VS Code al menu contestuale, perché ti tornerà utile in seguito.
5. Clicca **Install**, poi **Finish**. VS Code si aprirà quando è pronto.

## macOS

1. Apri [code.visualstudio.com](https://code.visualstudio.com) nel tuo browser.
2. Clicca il pulsante **Download for macOS**. Verrà scaricato un file `.zip` contenente l'app.
3. Apri la cartella **Download** e fai doppio clic sul file scaricato per decomprimerlo. Otterrai un'app chiamata **Visual Studio Code**.
4. Trascina **Visual Studio Code** nella cartella **Applicazioni**.
5. Apri la cartella **Applicazioni** e fai doppio clic su **Visual Studio Code** per avviarlo. Se macOS ti chiede se sei sicuro di volerlo aprire, clicca **Apri**.

## Linux

Il modo più affidabile per installare VS Code su Linux è scaricare il pacchetto ufficiale per la tua distribuzione da Microsoft.

1. Apri [code.visualstudio.com](https://code.visualstudio.com) nel tuo browser.
2. Clicca **Download for Linux** e scegli il pacchetto che corrisponde alla tua distribuzione:
   - Scegli il pacchetto **.deb** su sistemi basati su Debian e Ubuntu.
   - Scegli il pacchetto **.rpm** su sistemi basati su Fedora, Red Hat e openSUSE.
3. Apri il pacchetto scaricato con il gestore di installazione del tuo sistema e clicca **Installa**, oppure installalo dal terminale:
   - Su Debian o Ubuntu, esegui `sudo apt install ./<file>.deb` nella cartella in cui l'hai scaricato.
   - Su Fedora o Red Hat, esegui `sudo dnf install ./<file>.rpm` nella cartella in cui l'hai scaricato.
4. Una volta installato, apri VS Code dal menu delle applicazioni, oppure eseguendo `code` nel terminale.

## Aprire VS Code

In qualunque modo tu l'abbia installato, ora puoi aprire VS Code ogni volta che vuoi scrivere codice. Su Windows e macOS comparirà insieme alle altre applicazioni, e su Linux lo troverai nel menu delle applicazioni.

Fatto. Ora hai un editor di codice a tutti gli effetti installato e sei pronto a iniziare a scrivere codice.
